## 윤곽선 (Contour)

윤곽선은 **같은 값(흰색) 영역의 경계를 따라 이은 점들의 목록**입니다. 이진화(R10)로 물체를 흰색, 배경을 검은색으로 만든 뒤 `findContours`로 경계를 추적합니다. 색 인식(A01), 라인 트레이싱(A03), 색 추적(A04)이 모두 “마스크 → 가장 큰 윤곽선 → 중심·크기” 흐름을 씁니다.

```python
contours, hierarchy = cv2.findContours(binary, mode, method)       # OpenCV 4.x
_, contours, hierarchy = cv2.findContours(binary, mode, method)    # OpenCV 3.x (원본 교재 예제)
contours = cv2.findContours(binary, mode, method)[-2]              # 두 버전 모두 동작 (MentorPi 소스 방식)
```

원본 교재의 예제는 OpenCV 3 형식(반환값 3개)이라 OpenCV 4에서는 `ValueError: not enough values to unpack`이 납니다. MentorPi 소스처럼 `[-2]`로 받으면 두 버전 모두에서 동작합니다.

| 인자 | 값 | 의미 |
|---|---|---|
| mode | `RETR_EXTERNAL` | 가장 바깥 윤곽만 (물체 찾기에 가장 많이 씀) |
| | `RETR_LIST` | 모든 윤곽, 계층 없음 |
| | `RETR_CCOMP` | 2단계 계층(바깥 / 구멍) |
| | `RETR_TREE` | 전체 포함 관계 트리 |
| method | `CHAIN_APPROX_NONE` | 경계의 모든 점 저장 |
| | `CHAIN_APPROX_SIMPLE` | 직선 구간은 끝점만 (사각형은 점 4개) |
| | `CHAIN_APPROX_TC89_L1` | Teh-Chin 근사 (MentorPi 라인·색 노드가 사용) |

`hierarchy[0][i]`는 `[다음, 이전, 첫 자식, 부모]` 인덱스이고 없으면 −1입니다. 부모가 있는 윤곽은 **구멍**의 경계입니다. 결과 표시는 `cv2.drawContours(img, contours, -1, color, thickness)`로 합니다(`-1`은 전부, `thickness=-1`은 채우기).

### 모멘트: 면적과 중심

영상 모멘트 $m_{pq} = \sum x^p y^q I(x, y)$는 모양의 요약 통계입니다.

| 값 | 의미 | 쓰임 |
|---|---|---|
| $m_{00}$ | 면적(0차) | 너무 작은 윤곽 걸러내기 |
| $(c_x, c_y) = (m_{10}/m_{00},\ m_{01}/m_{00})$ | 무게중심 | 로봇이 향할 목표점 |
| $\mu_{20}, \mu_{11}, \mu_{02}$ | 중심 모멘트(2차) | 방향·길쭉함, 이동 불변 |
| $\nu_{pq}$, Hu 모멘트 | 정규화 중심 모멘트 | 크기(·회전) 불변 모양 비교 `matchShapes` |

`cv2.contourArea(cnt)`는 $m_{00}$과 같은 면적을, `cv2.arcLength(cnt, True)`는 닫힌 둘레를 돌려줍니다. $m_{00} = 0$(점이나 선처럼 납작한 윤곽)이면 중심 계산이 0으로 나누기가 되므로 **반드시 먼저 검사**합니다.

### 모양 근사와 분류

`cv2.approxPolyDP(cnt, epsilon, True)`는 Douglas-Peucker 알고리즘으로 윤곽을 **꼭짓점이 적은 다각형**으로 줄입니다. `epsilon`은 원래 곡선과 근사선 사이 허용 거리이며, 보통 둘레의 1~4 %로 잡습니다. 꼭짓점 수로 삼각형(3)·사각형(4)·원(많음)을 구분할 수 있습니다.

```python run
import cv2
import numpy as np

img = cv2.imread("shapes.png")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
_, binary = cv2.threshold(gray, 240, 255, cv2.THRESH_BINARY_INV)   # 흰 배경 → 검정, 도형 → 흰색
contours = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)[-2]
contours = sorted(contours, key=lambda c: cv2.boundingRect(c)[0])  # 왼쪽부터

for c in contours:
    area = cv2.contourArea(c)
    peri = cv2.arcLength(c, True)
    m = cv2.moments(c)
    cx, cy = m["m10"] / m["m00"], m["m01"] / m["m00"]
    approx = cv2.approxPolyDP(c, 0.02 * peri, True)
    n = len(approx)
    circularity = 4 * np.pi * area / peri ** 2                 # 원이면 1
    kind = {3: "triangle", 4: "rectangle"}.get(n, "circle" if circularity > 0.85 else "ellipse/poly")
    print("중심 (%3.0f,%3.0f) 면적 %6.0f 둘레 %5.0f 꼭짓점 %2d 원형도 %.2f → %s"
          % (cx, cy, area, peri, n, circularity, kind))
    cv2.drawContours(img, [approx], -1, (0, 0, 0), 2)
    cv2.putText(img, kind, (int(cx) - 30, int(cy)), cv2.FONT_HERSHEY_SIMPLEX, 0.5, (0, 0, 0), 1)
cv2.imshow("shapes", img)
```

```text
중심 (140,150) 면적  15176 둘레   462 꼭짓점  8 원형도 0.90 → circle
중심 (190,377) 면적   9100 둘레   458 꼭짓점  3 원형도 0.55 → triangle
중심 (390,150) 면적  25200 둘레   640 꼭짓점  4 원형도 0.77 → rectangle
중심 (470,360) 면적  20720 둘레   575 꼭짓점  8 원형도 0.79 → ellipse/poly
```

- 원형도(circularity) $4πA/P^2$는 이론상 원에서 1, 정사각형에서 0.785, 정삼각형에서 0.605입니다. 픽셀 윤곽은 계단 모양이라 둘레가 조금 길게 재져 원도 0.90 정도로 나옵니다. 꼭짓점 수만으로 원과 타원을 가르기 어려울 때 보조 기준이 됩니다.
- 사각형 면적이 `181 × 141`이 아니라 `180 × 140`인 것은 윤곽선이 **경계 픽셀의 중심**을 잇기 때문입니다.

### 외접 도형과 볼록 껍질

@fig[r11-contour] 한 윤곽을 설명하는 네 가지 도형: 외접 사각형, 최소 회전 사각형, 최소 외접원, 볼록 껍질

| 함수 | 반환 | 쓰임 |
|---|---|---|
| `cv2.boundingRect(c)` | `(x, y, w, h)` 축 정렬 사각형 | ROI 자르기, 간단한 박스 |
| `cv2.minAreaRect(c)` | `((cx, cy), (w, h), angle)` | 기울어진 선·블록의 **각도** (라인 트레이싱의 선 중심) |
| `cv2.boxPoints(rect)` | 회전 사각형의 꼭짓점 4개 | `drawContours`로 그리기 (`np.intp`로 변환) |
| `cv2.minEnclosingCircle(c)` | `((cx, cy), r)` | 공·원형 표식의 크기 (색 인식 결과) |
| `cv2.convexHull(c)` | 볼록 다각형 점들 | 오목한 부분 찾기(손가락 사이), solidity = 면적 / 껍질 면적 |
| `cv2.fitEllipse(c)` | 회전 타원 | 기울기·장단축 (점 5개 이상 필요) |

```python run
import cv2
import numpy as np

mask = np.zeros((200, 300), np.uint8)
box = cv2.boxPoints(((100, 100), (120, 40), 30)).astype(np.int32)   # 30° 기울어진 막대
cv2.fillPoly(mask, [box], 255)
cv2.fillPoly(mask, [np.array([[200, 40], [280, 40], [280, 160], [250, 160], [250, 70], [200, 70]], np.int32)], 255)  # ㄱ자

view = cv2.cvtColor(mask, cv2.COLOR_GRAY2BGR)
for c in cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)[-2]:
    x, y, w, h = cv2.boundingRect(c)
    (rx, ry), (rw, rh), ang = cv2.minAreaRect(c)
    (ex, ey), r = cv2.minEnclosingCircle(c)
    hull = cv2.convexHull(c)
    solidity = cv2.contourArea(c) / cv2.contourArea(hull)
    print("boundingRect %s | minAreaRect %.0fx%.0f @ %.0f° | 외접원 r=%.1f | solidity %.2f"
          % ((x, y, w, h), max(rw, rh), min(rw, rh), ang, r, solidity))
    cv2.rectangle(view, (x, y), (x + w, y + h), (0, 255, 0), 1)
    cv2.drawContours(view, [np.intp(cv2.boxPoints(cv2.minAreaRect(c)))], -1, (0, 0, 255), 2)
    cv2.circle(view, (int(ex), int(ey)), int(r), (255, 0, 0), 1)
    cv2.polylines(view, [hull], True, (0, 255, 255), 1)
cv2.imshow("fits", view)
```

```text
boundingRect (38, 52, 124, 96) | minAreaRect 120x41 @ -60° | 외접원 r=63.1 | solidity 0.98
boundingRect (200, 40, 81, 121) | minAreaRect 120x80 @ -90° | 외접원 r=72.1 | solidity 0.69
```

기울어진 막대는 축 정렬 사각형(초록)이 실제보다 훨씬 크지만, 최소 회전 사각형(빨강)은 120×40 크기를 거의 그대로 돌려줍니다. 각도가 30°가 아니라 −60°로 나온 것은 `minAreaRect`가 **어느 변을 기준으로 각도를 재는지**가 너비·높이 순서와 OpenCV 버전에 따라 달라지기 때문입니다(−60°의 짧은 변 방향 = 30°의 긴 변 방향). 각도를 제어에 쓸 때는 `boxPoints`로 긴 변을 찾아 직접 계산하는 편이 안전합니다. ㄱ자는 오목하므로 solidity가 1보다 한참 작습니다.

## 특징 매칭 (Feature Matching)

윤곽선은 **색이나 밝기로 분리되는 물체**에 강하지만, 무늬가 있는 물체(포스터, 책 표지)를 다른 거리·각도에서 찾으려면 **특징점(keypoint)**이 필요합니다.

1. **검출(detect)**: 코너처럼 어느 방향으로 움직여도 모양이 변하는, 다시 찾기 쉬운 점을 고릅니다.
2. **기술(describe)**: 점 주변 패치를 숫자 벡터(기술자, descriptor)로 요약합니다. 회전·크기·밝기 변화에 덜 민감하게 만듭니다.
3. **매칭(match)**: 두 영상의 기술자끼리 거리가 가장 가까운 짝을 찾습니다.

| 알고리즘 | 검출 / 기술 | 기술자 | 거리 | 특징 |
|---|---|---|---|---|
| ORB | FAST 코너 + 방향 보정 BRIEF | 256비트 이진 | 해밍(Hamming, XOR 비트 수) | 빠름, 특허 없음, 라즈베리파이에 적합 |
| SIFT | DoG 극값 + 기울기 히스토그램 | 128차원 실수 | 유클리드 L2 | 크기·회전에 강함, 느림 (OpenCV 4.4+ 기본 포함) |
| AKAZE | 비선형 스케일 공간 | 이진 | 해밍 | ORB보다 정확, SIFT보다 빠름 |

### 매처와 걸러내기

- **BFMatcher**(brute-force): 모든 짝을 비교합니다. `cv2.BFMatcher(cv2.NORM_HAMMING, crossCheck=True)`는 “A의 최선이 B이고 B의 최선도 A”인 짝만 남깁니다.
- **FlannBasedMatcher**: 근사 최근접 이웃 탐색(FLANN)으로 큰 데이터에서 빠릅니다. ORB 같은 이진 기술자에는 LSH 인덱스(`algorithm=6`)를 씁니다.
- **비율 검사(Lowe's ratio test)**: `knnMatch(k=2)`로 가장 가까운 두 후보를 받아 `d1 < 0.75 · d2`인 경우만 남깁니다. 1등과 2등이 비슷하면 모호한 짝이므로 버리는 것입니다.
- **RANSAC 호모그래피**: 남은 짝으로 `cv2.findHomography(src, dst, cv2.RANSAC, 5.0)`를 구하면, 잘못된 짝(outlier)을 무시하고 두 영상 사이의 원근 변환(R09)을 얻습니다. `mask`의 1 개수가 인라이어 수입니다.

```python run
import cv2
import numpy as np

rng = np.random.default_rng(3)                               # 무늬가 많은 "포스터" 합성
img1 = np.full((360, 480), 128, np.uint8)
for i in range(60):
    x, y = [int(v) for v in rng.integers(0, [480, 360])]
    c, s = int(rng.integers(0, 256)), int(rng.integers(8, 40))
    if i % 3 == 0:
        cv2.circle(img1, (x, y), s // 2, c, -1)
    else:
        cv2.rectangle(img1, (x, y), (x + s, y + int(rng.integers(8, 40))), c, -1)
h, w = img1.shape
R = cv2.getRotationMatrix2D((w / 2, h / 2), 20, 0.8)          # 20° 회전 + 0.8배로 "다른 시점" 흉내
img2 = cv2.warpAffine(img1, R, (w, h), borderValue=128)

orb = cv2.ORB_create(nfeatures=500)
kp1, des1 = orb.detectAndCompute(img1, None)
kp2, des2 = orb.detectAndCompute(img2, None)
print("특징점: img1 %d개, img2 %d개, 기술자 %s %s" % (len(kp1), len(kp2), des1.shape, des1.dtype))

bf = cv2.BFMatcher(cv2.NORM_HAMMING)
good = [m for m, n in bf.knnMatch(des1, des2, k=2) if m.distance < 0.75 * n.distance]
print("비율 검사 통과 짝:", len(good))

src = np.float32([kp1[m.queryIdx].pt for m in good]).reshape(-1, 1, 2)
dst = np.float32([kp2[m.trainIdx].pt for m in good]).reshape(-1, 1, 2)
H, inl = cv2.findHomography(src, dst, cv2.RANSAC, 5.0)
angle = np.degrees(np.arctan2(-H[1, 0], H[0, 0]))
scale = np.hypot(H[0, 0], H[1, 0])
print("RANSAC 인라이어 %d / %d, 추정 회전 %.1f°, 배율 %.2f" % (int(inl.sum()), len(good), angle, scale))
vis = cv2.drawMatches(img1, kp1, img2, kp2, good[:30], None, flags=2)
cv2.imshow("ORB matches", vis)
```

```text
특징점: img1 499개, img2 500개, 기술자 (499, 32) uint8
비율 검사 통과 짝: 215
RANSAC 인라이어 190 / 215, 추정 회전 20.0°, 배율 0.80
```

직접 만든 20°·0.8배 변환을 호모그래피가 거의 그대로 되찾습니다. 같은 코드를 무늬가 적은 `scene.png`에 돌리면 특징점이 수십 개뿐이고 추정 각도도 크게 틀립니다. 특징 매칭은 **질감(texture)이 풍부한 물체**에 쓰는 도구이고, 단색 물체는 색·윤곽선으로 찾는 편이 낫습니다. ORB 결과는 OpenCV 버전에 따라 개수가 조금 다를 수 있습니다. 실제 로봇에서는 기준 사진(img1)을 미리 찍어 두고, 카메라 프레임(img2)에서 같은 물체의 위치와 기울기를 이렇게 추정합니다.

:::info 원본 교재의 FLANN 예제
원본 `flann_demo.py`는 ORB 기술자에 LSH 인덱스(`table_number=6, key_size=12, multi_probe_level=1`)와 `checks=50`을 씁니다. `knnMatch(k=2)` 결과를 모두 그리므로 잘못된 짝도 함께 보입니다. 위처럼 비율 검사를 더하면 훨씬 깔끔해집니다.
:::

## 코너 검출 (Corner Detection)

작은 창을 영상 위에서 조금씩 움직여 본다고 생각해 봅시다.

- **평탄한 곳**: 어느 방향으로 움직여도 창 안 밝기가 거의 안 바뀝니다.
- **엣지**: 엣지를 **가로지르는** 방향으로만 크게 바뀝니다.
- **코너**: **모든 방향**으로 크게 바뀝니다.

이 변화량을 2차 형식으로 근사하면 2×2 **구조 텐서** $M = \sum w(x,y) [I_x^2,\ I_xI_y;\ I_xI_y,\ I_y^2]$가 나오고, 두 고윳값 $λ_1, λ_2$가 두 주방향의 변화량입니다.

@fig[r11-harris] 구조 텐서 고윳값 평면에서 평탄·엣지·코너 영역 (Harris와 Shi-Tomasi 경계)

| 방법 | 코너 점수 | 판정 |
|---|---|---|
| Harris (1988) | $R = \det M - k(\operatorname{tr} M)^2 = λ_1λ_2 - k(λ_1+λ_2)^2$, $k$ = 0.04~0.06 | $R$ 큼 → 코너, $R < 0$ → 엣지, $|R|$ 작음 → 평탄 |
| Shi-Tomasi (1994) | $R = \min(λ_1, λ_2)$ | 두 방향 모두 변화가 커야 코너, 추적용으로 더 안정 |

`cv2.cornerHarris(gray, blockSize, ksize, k)`는 픽셀마다 $R$ 값을 담은 `float32` 영상을 돌려줍니다. 원본 예제(`corners_demo.py`)는 이를 0~255로 정규화해 120보다 큰 픽셀에 원을 그립니다. 실전에서는 **개수와 최소 간격을 지정**할 수 있는 `cv2.goodFeaturesToTrack`(Shi-Tomasi)을 더 많이 씁니다. 광류(optical flow) 추적의 출발점이기도 합니다.

```python run
import cv2
import numpy as np

img = cv2.imread("shapes.png")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

harris = cv2.cornerHarris(np.float32(gray), 2, 3, 0.04)
print("Harris R: 최대 %.3g, 최소 %.3g (음수 = 엣지)" % (harris.max(), harris.min()))
strong = harris > 0.05 * harris.max()
print("R > 5%% of max 인 픽셀: %d" % np.count_nonzero(strong))

corners = cv2.goodFeaturesToTrack(gray, maxCorners=20, qualityLevel=0.2, minDistance=15)
pts = sorted(np.intp(corners).reshape(-1, 2).tolist())
print("Shi-Tomasi 코너 %d개:" % len(pts), pts)
for x, y in pts:
    cv2.circle(img, (x, y), 5, (0, 0, 0), 2)
img[strong] = (0, 0, 255)
cv2.imshow("corners", img)
```

```text
Harris R: 최대 2.56e+08, 최소 -1.04e+08 (음수 = 엣지)
R > 5% of max 인 픽셀: 28
Shi-Tomasi 코너 7개: [[120, 420], [190, 290], [260, 420], [300, 80], [300, 220], [480, 80], [480, 220]]
```

사각형의 네 꼭짓점과 삼각형의 세 꼭짓점이 코너로 잡히고, 원과 타원의 매끈한 경계는 잡히지 않습니다. 찾은 좌표는 `shapes.png`를 그릴 때 쓴 꼭짓점(사각형 (300, 80)–(480, 220), 삼각형 (120, 420)·(260, 420)·(190, 290))과 일치합니다. 흐리거나 실제 카메라 영상에서는 한두 픽셀 어긋나므로, 더 정확히 하려면 `cv2.cornerSubPix`로 서브픽셀 보정을 합니다.

```python robot
import cv2
import numpy as np
import rclpy
from rclpy.node import Node
from cv_bridge import CvBridge
from sensor_msgs.msg import Image


class ShapeClassifier(Node):
    def __init__(self):
        super().__init__('shape_classifier')
        self.bridge = CvBridge()
        self.create_subscription(Image, '/ascamera/camera_publisher/rgb0/image', self.on_image, 1)

    def on_image(self, msg):
        frame = cv2.resize(self.bridge.imgmsg_to_cv2(msg, 'bgr8'), (320, 240))
        gray = cv2.GaussianBlur(cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY), (5, 5), 0)
        _, binary = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY_INV + cv2.THRESH_OTSU)
        binary = cv2.morphologyEx(binary, cv2.MORPH_OPEN, np.ones((3, 3), np.uint8))
        for c in cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)[-2]:
            area = cv2.contourArea(c)
            if area < 500:
                continue
            peri = cv2.arcLength(c, True)
            n = len(cv2.approxPolyDP(c, 0.03 * peri, True))
            kind = {3: 'tri', 4: 'rect'}.get(n, 'circle' if 4 * np.pi * area / peri ** 2 > 0.8 else '?')
            x, y, w, h = cv2.boundingRect(c)
            cv2.rectangle(frame, (x, y), (x + w, y + h), (0, 255, 0), 2)
            cv2.putText(frame, kind, (x, y - 5), cv2.FONT_HERSHEY_SIMPLEX, 0.5, (0, 255, 0), 1)
        cv2.imshow('shapes', frame)
        if cv2.waitKey(1) & 0xFF == ord('q'):
            raise KeyboardInterrupt


def main():
    rclpy.init()
    node = ShapeClassifier()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        cv2.destroyAllWindows()
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

## 자주 나는 오류와 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| `ValueError: not enough values to unpack (expected 3, got 2)` | OpenCV 3 형식 코드를 OpenCV 4에서 실행 | `contours = cv2.findContours(...)[-2]` |
| 화면 테두리 전체가 윤곽 하나로 잡힘 | 물체가 검정·배경이 흰색 | `THRESH_BINARY_INV`로 뒤집기 |
| `ZeroDivisionError` (중심 계산) | `m00 == 0`인 납작한 윤곽 | 면적 하한으로 거르거나 `if m["m00"]:` 검사 |
| `drawContours` Assertion 오류 | 윤곽 하나를 리스트로 감싸지 않음, `float` 좌표 | `[cnt]`, `np.intp(box)` |
| ORB 매칭이 엉뚱한 곳끼리 이어짐 | 거리 기준 없이 모든 짝 사용 | 비율 검사 + RANSAC, 무늬가 적은 물체는 특징 매칭 부적합 |
| `knnMatch` 결과 언팩 오류 | 어떤 점은 후보가 1개뿐 | `for pair in matches: if len(pair) == 2:` |
| `des`가 `None` | 특징점이 하나도 없음(무늬 없는 영상) | `nfeatures`·`fastThreshold` 조정, 입력 확인 |
| `goodFeaturesToTrack`이 `None` | 조건을 만족하는 코너 없음 | `qualityLevel`을 낮추고 `None` 검사 |
