## 파이썬 소개

파이썬(Python)은 1991년에 처음 발표된 **인터프리터(interpreter) 방식**의 범용 언어입니다. 소스를 기계어로 미리 컴파일하지 않고, 실행할 때 한 줄씩 해석하므로 **수정 → 즉시 실행**이 빠릅니다.

| 특징 | 로봇 개발에서 |
|---|---|
| 문법이 간결하고 읽기 쉬움 | ROS 2 노드(`rclpy`)를 짧은 코드로 작성 |
| 동적 타이핑 | 변수 선언 없이 바로 사용(대신 오타·자료형 실수를 실행 중에 발견) |
| 방대한 라이브러리 | OpenCV, NumPy, MediaPipe, PyTorch를 그대로 사용 |
| C/C++ 확장 | 무거운 계산은 C로 된 라이브러리가 대신 수행 |

**객체 지향(object-oriented)**과 **절차 지향(procedure-oriented)**을 모두 지원합니다. 절차 지향은 "문제를 푸는 단계"를 함수로 차례대로 구현하고, 객체 지향은 문제를 이루는 "사물(객체)"과 그 행동을 정의합니다. ROS 2 노드는 `Node` 클래스를 상속하는 객체 지향 방식이라 B06에서 클래스를 배웁니다.

:::info Python 2는 쓰지 않습니다
Python 2.x는 2020년에 공식 지원이 끝났습니다. MentorPi 컨테이너와 라즈베리파이 OS 모두 `python3`를 씁니다. 원본 예제에도 `sys.version_info.major == 2`이면 종료하는 검사가 들어 있습니다.
:::

## 첫 프로그램: Hello World

원본 절차대로 터미널에서 파일을 만들고 실행합니다.

```bash
sudo apt install vim          # vim 편집기 설치(이미 있으면 생략)
mkdir test && cd test
touch hello.py
vim hello.py                  # i 로 편집 모드 → print("Hello World") 입력 → Esc → :wq
python3 hello.py
```

`print()`의 전체 형식은 `print(*objects, sep=' ', end='\n', file=sys.stdout, flush=False)`입니다.

- `objects`: 출력할 값들, 쉼표로 여러 개
- `sep`: 값 사이에 넣을 문자열(기본 공백)
- `end`: 마지막에 붙일 문자열(기본 줄바꿈)
- `flush`: 버퍼를 즉시 비울지. 원본 버튼 예제(`key.py`)가 `print('\r…', end='', flush=True)`로 **같은 줄을 계속 덮어쓰는** 것이 이 인자 덕분입니다.

```python run
print("Hello World")
print(100 + 100)                    # 수식은 따옴표 없이 → 계산 결과
print("x", "y", "theta", sep=", ")  # 구분자 바꾸기
print("battery", end=": ")          # 줄바꿈 대신 ': '
print(7.65, "V")

# 자료형 확인
for value in [42, 0.2, "cmd_vel", True, None]:
    print(repr(value), "->", type(value).__name__)

# f-string: 로봇 로그에 가장 많이 쓰는 형식
x, y, yaw = 1.23456, -0.5, 1.5708
print(f"pose x={x:.2f} y={y:+.2f} yaw={yaw:.3f} rad")
```

```text

42 -> int
0.2 -> float
'cmd_vel' -> str

None -> NoneType

```

## 기본 문법

### 주석과 들여쓰기

- `#` 뒤는 한 줄 주석, `'''…'''`/`"""…"""`는 여러 줄 문자열(함수 설명 docstring에 사용)
- 파이썬은 중괄호 대신 **들여쓰기로 코드 블록**을 구분합니다. 같은 블록은 같은 칸만큼, 관례상 **공백 4칸**. 탭과 공백을 섞으면 `IndentationError`/`TabError`가 납니다.
- 한 줄은 79자 안팎(PEP 8 권장), 긴 식은 괄호 안에서 줄을 나눕니다.

### 식별자(이름) 규칙

- 영문자·숫자·밑줄(`_`)로 구성, **숫자로 시작 불가**, 대소문자 구분(`Speed`≠`speed`)
- 예약어(`if`, `for`, `class`, `import`, `lambda` …)는 이름으로 못 씀
- 관례: 변수·함수 `snake_case`(`max_linear`), 클래스 `CamelCase`(`MecanumChassis`), 상수 `UPPER_CASE`(`WHEEL_DIAMETER`)

### 자료형 한눈에

| 자료형 | 예 | 변경 가능? | 로봇 예 |
|---|---|---|---|
| `int`, `float` | `3`, `0.065` | 불변 | 서보 펄스 1500, 바퀴 지름 |
| `bool` | `True` | 불변 | 버튼 눌림 여부 |
| `str` | `'MentorPi_Mecanum'` | 불변 | 토픽 이름, 환경 변수 |
| `list` | `[0.8, 1.2, 0.4]` | **가변** | 라이다 거리 배열 |
| `tuple` | `(255, 0, 0)` | 불변 | RGB 색, (x, y) 좌표 |
| `dict` | `{'id': 1, 'rps': 0.5}` | **가변** | 파라미터, 설정 |
| `set` | `{1, 2}` | **가변** | 이미 처리한 ID 모음 |

### 연산자

| 종류 | 연산자 | 주의 |
|---|---|---|
| 산술 | `+ - * / // % **` | `/`는 항상 실수, `//`는 몫(내림), `**`는 거듭제곱 |
| 비교 | `== != < <= > >=` | 실수는 `==` 대신 오차 범위로 비교 |
| 논리 | `and or not` | 단락 평가: `a and b`에서 `a`가 거짓이면 `b`는 계산 안 함 |
| 소속 | `in`, `not in` | `'scan' in topic` |
| 비트 | `& \| ^ ~ << >>` | 패킷 바이트 조립(B08)에 사용 |

```python run
# 산술: 나눗셈 종류
print(7 / 2, 7 // 2, 7 % 2, 2 ** 10)
print(-7 // 2)            # 몫은 '내림' → -4

# 실수 비교는 오차 범위로
print(0.1 + 0.2 == 0.3, abs((0.1 + 0.2) - 0.3) < 1e-9)

# 비트 연산: 16비트 값을 하위/상위 바이트로 쪼개기 (B08 패킷에서 사용)
duration_ms = 1000
low, high = duration_ms & 0xFF, (duration_ms >> 8) & 0xFF
print(hex(low), hex(high), low + (high << 8))

# 문자열
topic = "/ros_robot_controller/set_rgb"
print(topic.split("/"))
print(topic.startswith("/ros"), "rgb" in topic, len(topic))
print(topic.upper()[-7:], topic.replace("rgb", "buzzer"))
```


## 조건문

```text
if 조건1:
    …
elif 조건2:      # 0개 이상
    …
else:            # 생략 가능
    …
```

조건은 위에서부터 검사해 **처음 참인 블록 하나만** 실행합니다. 따라서 범위를 나눌 때는 경계가 겹치지 않게 순서대로 씁니다.

원본 예제(`conditional_statement.py`)는 `input()`으로 키·몸무게를 받아 BMI를 판정합니다. 여기서는 같은 구조를 **배터리 전압 판정**에도 적용해 봅니다. B01에서 본 "6.4 V 아래면 충전" 규칙을 코드로 옮긴 것입니다.

```python run
def bmi_grade(height_m, weight_kg):
    bmi = weight_kg / (height_m ** 2)
    if bmi < 18.5:
        grade = "저체중"
    elif bmi < 24.9:          # 18.5 <= bmi 는 위에서 이미 걸러짐
        grade = "정상"
    elif bmi < 29.9:
        grade = "과체중"
    else:
        grade = "비만"
    return bmi, grade

for h, w in [(1.75, 55), (1.75, 70), (1.60, 70)]:
    bmi, g = bmi_grade(h, w)
    print(f"키 {h} m, 몸무게 {w} kg -> BMI {bmi:.1f} {g}")

# 같은 구조로 배터리 상태 판정 (mV 정수로 보고됨)
for mv in [8200, 7400, 6600, 6300]:
    v = mv / 1000
    if v >= 7.4:
        state = "충분"
    elif v >= 6.8:
        state = "보통"
    elif v >= 6.4:
        state = "곧 충전"
    else:
        state = "즉시 충전 (주행 금지)"
    print(f"{mv} mV = {v:.2f} V : {state}")

# 조건 표현식(삼항)과 범위 비교
speed = 0.35
limited = 0.2 if speed > 0.2 else speed
print("limited:", limited, "| 0 < speed <= 0.5 ?", 0 < speed <= 0.5)
```

```text
키 1.75 m, 몸무게 55 kg -> BMI 18.0 저체중
키 1.75 m, 몸무게 70 kg -> BMI 22.9 정상
키 1.6 m, 몸무게 70 kg -> BMI 27.3 과체중
8200 mV = 8.20 V : 충분
7400 mV = 7.40 V : 충분
6600 mV = 6.60 V : 곧 충전
6300 mV = 6.30 V : 즉시 충전 (주행 금지)
limited: 0.2 | 0 < speed <= 0.5 ? True
```

:::tip `input()`은 Playground에서 쓰지 않습니다
원본 예제는 `height = float(input("height(m)："))`처럼 키보드 입력을 받습니다. 터미널에서 `python3 conditional_statement.py`로 실행하면 그대로 동작합니다. 로봇 노드는 사람 입력 대신 **센서 토픽**에서 값을 받으므로, 여기서는 함수 인자로 값을 넘기는 형태로 바꿨습니다.
:::

## 반복문

| 문 | 쓰임 | 로봇 예 |
|---|---|---|
| `while 조건:` | 조건이 참인 동안 반복(횟수 미정) | "장애물이 사라질 때까지 회전" |
| `for x in 반복가능객체:` | 요소를 하나씩 꺼내 반복 | 라이다 거리 360개 검사 |
| `range(start, stop, step)` | 정수 수열(stop은 **미포함**) | 모터 ID 1~4: `range(1, 5)` |
| `break` | 반복 즉시 탈출 | 목표 발견 시 중단 |
| `continue` | 이번 회차만 건너뜀 | 잘못된 측정값(inf, 0) 무시 |
| `for … else` | `break` 없이 끝났을 때만 `else` 실행 | "끝까지 못 찾음" 처리 |

원본 `loop_statement.py`의 계승(factorial)과 문자열 한 글자씩 출력을 먼저 재현하고, 라이다 데이터 처리로 확장합니다.

```python run
# 원본 예제: while로 n! 계산
n = 5
fact, i = 1, 1
while i <= n:
    fact = fact * i
    i = i + 1
print("n!={}".format(fact))

# 원본 예제: for로 문자열 한 글자씩
for c in "ROS2":
    print(c, end=" ")
print()

# 라이다 거리(m) 일부: inf = 반사 없음, 0.0 = 측정 실패
ranges = [1.20, 0.95, float("inf"), 0.0, 0.42, 0.38, 0.55, 2.10]
valid = []
for r in ranges:
    if r == 0.0 or r == float("inf"):
        continue                 # 쓸 수 없는 값은 건너뛰기
    valid.append(r)
print("valid:", valid)
print("min:", min(valid), "at index", ranges.index(min(valid)))

# 0.4 m 보다 가까운 점을 처음 찾으면 멈추기
for idx, r in enumerate(ranges):
    if 0.0 < r < 0.4:
        print("장애물! index", idx, "distance", r)
        break
else:
    print("가까운 장애물 없음")

# range: 모터 ID 1~4
print([mid for mid in range(1, 5)], list(range(10, 0, -3)))
```

```text
n!=120
R O S 2 
valid: [1.2, 0.95, 0.42, 0.38, 0.55, 2.1]
min: 0.38 at index 5
장애물! index 5 distance 0.38
[1, 2, 3, 4] [10, 7, 4, 1]
```

:::warning 무한 루프와 로봇
`while True:`로 센서를 계속 읽는 프로그램은 반드시 **빠져나갈 조건**(Ctrl+C 처리, `break`)과 **종료 시 정지 명령**을 넣습니다. 원본 확장보드 예제들이 `signal.signal(signal.SIGINT, Stop)`으로 Ctrl+C를 잡아 모터를 0으로 만든 뒤 `break`하는 것이 바로 이 패턴입니다(B08·B09).
:::

## 함수

```text
def 함수이름(매개변수들):
    """설명(docstring)"""
    …
    return 값        # 없으면 None 반환
```

- **매개변수(parameter)**: 정의할 때의 이름, **인자(argument)**: 호출할 때 넘기는 실제 값
- `return a, b`처럼 여러 값을 돌려주면 튜플로 묶여 반환되고, 받을 때 풀 수 있습니다.

### 인자 종류

| 종류 | 정의 | 호출 | 예 |
|---|---|---|---|
| 위치 인자 | `def f(a, b)` | `f(1, 2)` | 순서대로 대입 |
| 기본값 인자 | `def f(a, b=0.2)` | `f(1)` | 생략 시 기본값 |
| 가변 위치 인자 | `def f(*args)` | `f(1, 2, 3)` | 튜플로 모임 |
| 키워드 인자 | — | `f(b=2, a=1)` | 이름으로 대입(순서 무관) |
| 가변 키워드 인자 | `def f(**kwargs)` | `f(x=1, y=2)` | 딕셔너리로 모임 |
| 키워드 전용 인자 | `def f(a, *, unit)` | `f(1, unit='m')` | `*` 뒤는 이름으로만 |

아래 `val_map`은 원본 `sdk.common`의 같은 이름 함수와 같은 일을 합니다. 조이패드 스틱 값(−1~1)을 속도 범위로 선형 변환하는, 로봇 코드에서 가장 흔한 함수입니다.

```python run
def val_map(x, in_min, in_max, out_min, out_max):
    """x 를 [in_min, in_max] 에서 [out_min, out_max] 로 선형 변환"""
    return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

def clamp(v, limit=0.2):                 # 기본값 인자
    return max(-limit, min(limit, v))

def rps_of(speed, *, diameter=0.065):    # * 뒤는 키워드 전용
    import math
    return speed / (math.pi * diameter)

def set_motors(*speeds, **options):      # 가변 인자
    ids = list(range(1, len(speeds) + 1))
    return list(zip(ids, speeds)), options

for stick in [-1.0, -0.5, 0.0, 0.6, 1.0]:
    v = val_map(stick, -1, 1, -0.5, 0.5)
    print(f"stick {stick:+.1f} -> v {v:+.2f} -> clamped {clamp(v):+.2f}")

print(round(rps_of(0.2), 4), round(rps_of(0.2, diameter=0.067), 4))
pairs, opts = set_motors(0.5, -0.5, 0.5, -0.5, unit="rps", verbose=True)
print(pairs)
print(opts)
```

```text
stick -1.0 -> v -0.50 -> clamped -0.20
stick -0.5 -> v -0.25 -> clamped -0.20
stick +0.0 -> v +0.00 -> clamped +0.00
stick +0.6 -> v +0.30 -> clamped +0.20
stick +1.0 -> v +0.50 -> clamped +0.20
0.9794 0.9502
[(1, 0.5), (2, -0.5), (3, 0.5), (4, -0.5)]
{'unit': 'rps', 'verbose': True}
```

### 가변 객체와 불변 객체 전달

파이썬은 인자로 **객체의 참조(이름표)**를 넘깁니다. 그래서

- 불변 객체(`int`, `float`, `str`, `tuple`)를 함수 안에서 "바꾸면" 새 객체가 만들어질 뿐 **호출한 쪽 값은 그대로**입니다.
- 가변 객체(`list`, `dict`)를 함수 안에서 수정(`append`, 항목 대입)하면 **호출한 쪽 객체도 바뀝니다.**

```python run
def add_offset(value, offset):
    value = value + offset          # 새 int 객체를 지역 이름에 붙임
    return value

def add_offset_all(values, offset):
    for i in range(len(values)):
        values[i] += offset         # 같은 list 객체를 직접 수정

pulse = 1500
print(add_offset(pulse, 45), pulse)         # pulse 는 그대로

pulses = [1500, 1500, 1500]
add_offset_all(pulses, 45)
print(pulses)                               # 원본 리스트가 바뀜

# 흔한 함정: 가변 기본값은 한 번만 만들어진다
def log_bad(msg, history=[]):
    history.append(msg)
    return history

def log_good(msg, history=None):
    if history is None:
        history = []
    history.append(msg)
    return history

print(log_bad("a"), log_bad("b"))           # 같은 리스트가 계속 쌓임
print(log_good("a"), log_good("b"))
```

```text
[1545, 1545, 1545]
['a', 'b'] ['a', 'b']
['a'] ['b']
```

## 컨테이너 자료형 다루기

| 자료형 | 만들기 | 꺼내기 | 바꾸기 |
|---|---|---|---|
| 리스트 | `[1, 2]`, `list(range(3))` | `a[0]`, `a[-1]`, `a[1:3]` | `append`, `insert`, `pop`, `remove`, `a[i] = v`, `sort` |
| 튜플 | `(1, 2)`, `1, 2` | 리스트와 같음 | 불가(새로 만들어야 함) |
| 딕셔너리 | `{'k': v}`, `dict(k=v)` | `d['k']`, `d.get('k', 기본값)` | `d['k'] = v`, `update`, `pop` |
| 집합 | `{1, 2}`, `set()` | `in` 검사(순서 없음) | `add`, `discard`, `\|` 합, `&` 교, `-` 차 |

```python run
colors = [(255, 0, 0), (0, 255, 0), (0, 0, 255)]
```

## 모듈

**모듈(module)**은 함수·클래스·변수를 모은 `.py` 파일이고, 여러 모듈을 폴더로 묶은 것이 **패키지(package)**입니다.

```python
import math                              # 모듈 전체
from math import pi, sqrt                # 필요한 이름만
import ros_robot_controller_sdk as rrc   # 별칭 — 원본 확장보드 예제의 방식
```

`import`하면 파이썬은 현재 폴더 → 설치된 라이브러리 경로(`sys.path`) 순으로 파일을 찾습니다. 원본 확장보드 예제를 `~/board_demo` 폴더 **안에서** 실행해야 하는 이유는 `ros_robot_controller_sdk.py`가 같은 폴더에 있기 때문입니다.

자기 모듈을 만들 때는 테스트 코드를 `if __name__ == '__main__':` 아래에 둡니다. 직접 실행하면 `__name__`이 `'__main__'`이라 실행되고, 다른 파일에서 `import`하면 실행되지 않습니다. 원본 SDK 파일 맨 아래의 시험 코드도 이 구조입니다.

```python run
import math
from math import degrees, radians, atan

WHEEL_D = 0.065
print("둘레:", round(math.pi * WHEEL_D, 4), "m")

# 애커만 조향: 회전 반경 R 에 필요한 조향각
L = 0.145
for R in [0.5, 0.3, 0.26]:
    delta = atan(L / R)
    pulse = 1500 + 2000 * degrees(-delta) / 180
    print(f"R={R} m -> delta={degrees(delta):.1f} deg -> servo pulse {pulse:.0f}")

print("29도 =", round(radians(29), 4), "rad, hypot(3,4) =", math.hypot(3, 4))
print(__name__)
```

```text

R=0.5 m -> delta=16.2 deg -> servo pulse 1320
R=0.3 m -> delta=25.8 deg -> servo pulse 1213
R=0.26 m -> delta=29.1 deg -> servo pulse 1176
29도 = 0.5061 rad, hypot(3,4) = 5.0
__main__
```

## 자주 나는 오류와 해결

| 증상(오류 메시지) | 원인 | 해결 |
|---|---|---|
| `IndentationError: expected an indented block` | `if`/`for`/`def` 뒤 블록을 들여쓰지 않음 | 콜론 다음 줄을 4칸 들여쓰기 |
| `TabError: inconsistent use of tabs and spaces` | 탭과 공백 혼용(원본 `loop_statement.py`는 탭 사용) | 편집기에서 탭을 공백 4칸으로 통일 |
| `SyntaxError: invalid syntax` (`if x = 1`) | 비교에 `=` 사용, 콜론 누락, 괄호 짝 불일치 | 비교는 `==`, 줄 끝 `:` 확인 |
| `NameError: name 'x' is not defined` | 오타, 정의 전 사용, 다른 함수의 지역 변수 | 철자·정의 순서 확인 |
| `TypeError: can only concatenate str (not "float") to str` | `"BMI：" + bmi`처럼 문자열과 숫자 결합 | `str(bmi)` 또는 f-string |
| `ValueError: could not convert string to float` | `float(input())`에 숫자가 아닌 입력 | 입력 확인, `try/except`(B06) |
| `IndexError: list index out of range` | 없는 인덱스 접근 | `len()` 확인, 음수 인덱스 활용 |
| `KeyError: 5` | 딕셔너리에 없는 키 | `d.get(5, 기본값)` 또는 `in`으로 먼저 검사 |
| `ModuleNotFoundError: No module named 'ros_robot_controller_sdk'` | 모듈 파일이 없는 폴더에서 실행 | 예제 폴더로 `cd` 후 실행 |
| `0.1 + 0.2 == 0.3`이 `False` | 이진 부동소수점 오차 | `abs(a - b) < 1e-9`로 비교 |
