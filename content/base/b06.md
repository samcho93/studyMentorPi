## 클래스와 객체

### 왜 클래스인가

B05의 함수만으로도 프로그램을 짤 수 있지만, 로봇 코드에는 **데이터와 그 데이터를 다루는 동작이 짝**을 이루는 것이 많습니다. 예를 들어 섀시는 `wheelbase`, `track_width`, `wheel_diameter`라는 데이터와 "속도 명령을 바퀴 회전수로 바꾸는" 동작을 가집니다. 이 둘을 묶은 설계도가 **클래스(class)**, 설계도로 찍어 낸 실체가 **객체(object, 인스턴스)**입니다.

원본 `controller/mecanum.py`의 `MecanumChassis`, ROS 2의 모든 노드(`class MyNode(Node)`)가 이 구조입니다.

| 용어 | 뜻 | 예 |
|---|---|---|
| 클래스 | 설계도 | `class MecanumChassis:` |
| 인스턴스 | 설계도로 만든 객체 | `m = MecanumChassis()` |
| `__init__` | 생성자, 인스턴스 속성 초기화 | `self.wheel_diameter = 0.065` |
| `self` | 메서드가 호출된 인스턴스 자신 | `self.speed_covert(v)` |
| 인스턴스 속성 | 객체마다 다른 값 | 각 로봇의 바퀴 지름 |
| 클래스 속성 | 모든 인스턴스가 공유 | `gravity = 9.80665`(원본 `RosRobotController`) |
| 상속 | 부모 클래스의 속성·메서드를 물려받음 | `class MyNode(Node)` |
| 다형성 | 같은 메서드 이름, 클래스마다 다른 동작 | 메카넘·애커만의 `set_velocity()` |

아래 코드는 원본 `mecanum.py`의 계산식을 그대로 옮긴 클래스입니다. 바퀴 순서와 부호(`[-m1, -m2, m3, m4]`)까지 원본과 같습니다.

```python run
import math

class Chassis:
    wheel_count = 4                          # 클래스 속성

    def __init__(self, name, wheel_diameter):
        self.name = name                     # 인스턴스 속성
        self.wheel_diameter = wheel_diameter

    def speed_covert(self, speed):           # m/s -> rps (원본 함수 이름 그대로)
        return speed / (math.pi * self.wheel_diameter)

    def describe(self):
        return f"{self.name}: d={self.wheel_diameter} m, wheels={self.wheel_count}"

class MecanumChassis(Chassis):
    def __init__(self, wheelbase=0.1368, track_width=0.1446, wheel_diameter=0.065):
        super().__init__("mecanum", wheel_diameter)
        self.wheelbase, self.track_width = wheelbase, track_width

    def set_velocity(self, vx, vy, wz):
        k = (self.wheelbase + self.track_width) / 2
        m1 = vx - vy - wz * k
        m2 = vx + vy - wz * k
        m3 = vx + vy + wz * k
        m4 = vx - vy + wz * k
        return [round(self.speed_covert(v), 3) for v in [-m1, -m2, m3, m4]]

class AckermannChassis(Chassis):
    def __init__(self, wheelbase=0.145, wheel_diameter=0.067):
        super().__init__("ackermann", wheel_diameter)
        self.wheelbase = wheelbase

    def set_velocity(self, vx, vy, wz):      # vy 는 무시(옆으로 못 감)
        if vx == 0 or wz == 0:
            steer = 0.0
        else:
            steer = math.degrees(math.atan(self.wheelbase * wz / vx))
        rps = round(self.speed_covert(vx), 3)
        return {"rear_rps": rps, "steer_deg": round(steer, 1)}

for ch in [MecanumChassis(), AckermannChassis()]:
    print(ch.describe())
    for cmd in [(0.2, 0, 0), (0, 0.2, 0), (0.2, 0, 0.5)]:
        print("  cmd", cmd, "->", ch.set_velocity(*cmd))    # 다형성
print(isinstance(MecanumChassis(), Chassis), Chassis.wheel_count)
```

```text
mecanum: d=0.065 m, wheels=4
  cmd (0.2, 0, 0) -> [-0.979, -0.979, 0.979, 0.979]
  cmd (0, 0.2, 0) -> [0.979, -0.979, 0.979, -0.979]
  cmd (0.2, 0, 0.5) -> [-0.635, -0.635, 1.324, 1.324]
ackermann: d=0.067 m, wheels=4
  cmd (0.2, 0, 0) -> {'rear_rps': 0.95, 'steer_deg': 0.0}
  cmd (0, 0.2, 0) -> {'rear_rps': 0.0, 'steer_deg': 0.0}
  cmd (0.2, 0, 0.5) -> {'rear_rps': 0.95, 'steer_deg': 19.9}
True 4
```

결과를 읽어 봅시다. 메카넘 전진(0.2, 0, 0)에서 M1·M2가 음수인 것은 **왼쪽 모터가 반대 방향으로 장착**되어 있어 부호를 뒤집었기 때문입니다. 좌측 평행이동(0, 0.2, 0)은 대각선 바퀴끼리 같은 방향으로 도는 전형적인 메카넘 패턴입니다(M01에서 유도).

## 예외 처리

**오류(error)** 중 실행 도중 발생해 처리할 수 있는 것을 **예외(exception)**라고 합니다. 처리하지 않으면 프로그램이 멈추고 트레이스백(traceback)을 출력합니다. 로봇에서는 센서 값이 비거나, 시리얼 포트가 없거나, 파일이 없을 때가 대표적입니다.

| 예외 | 언제 |
|---|---|
| `ZeroDivisionError` | 0으로 나눔(속도 0일 때 회전 반경 계산 등) |
| `ValueError` | 형식은 맞는데 값이 부적절: `float("abc")` |
| `TypeError` | 자료형이 맞지 않음: `"a" + 1` |
| `KeyError`, `IndexError` | 딕셔너리 키, 리스트 인덱스 없음 |
| `FileNotFoundError` | 파일·장치 없음(`/dev/ttyAMA0` 미존재) |
| `AttributeError` | 객체에 없는 속성·메서드 |
| `KeyboardInterrupt` | Ctrl+C |
| `ImportError`/`ModuleNotFoundError` | 모듈 없음 |

```text
try:
    위험한 코드
except 예외종류 as e:     # 여러 개 가능, 구체적인 것부터
    처리
else:
    예외가 없을 때만
finally:
    항상 실행(정리: 모터 정지, 포트 닫기)
```

```python run
import math

def turning_radius(v, w):
    return v / w                       # w == 0 이면 ZeroDivisionError

def parse_reading(text):
    value = float(text)                # 숫자가 아니면 ValueError
    if value < 0:
        raise ValueError(f"negative range: {value}")
    return value

for v, w in [(0.2, 0.5), (0.2, 0.0)]:
    try:
        r = turning_radius(v, w)
    except ZeroDivisionError:
        r = math.inf                   # 직진 = 회전 반경 무한대
        print("w=0 -> 직진, R = inf")
    else:
        print(f"R = {r:.2f} m")

for s in ["1.25", "abc", "-0.3", "0.8"]:
    try:
        print("ok:", parse_reading(s))
    except ValueError as e:
        print("skip:", type(e).__name__, "-", e)

class MotorFault(Exception):
    """사용자 정의 예외"""

def drive(battery_v):
    try:
        if battery_v < 6.4:
            raise MotorFault(f"battery low ({battery_v} V)")
        print("driving...")
    finally:
        print("finally: motors -> 0")  # 성공·실패와 무관하게 정지

for bv in [7.6, 6.2]:
    try:
        drive(bv)
    except MotorFault as e:
        print("MotorFault:", e)
```

```text
R = 0.40 m
w=0 -> 직진, R = inf
ok: 1.25
skip: ValueError - could not convert string to float: 'abc'
skip: ValueError - negative range: -0.3
ok: 0.8
driving...
finally: motors -> 0
finally: motors -> 0
MotorFault: battery low (6.2 V)
```

:::warning except는 좁게
`except:` 또는 `except Exception:`으로 모든 예외를 삼키면 오타(`NameError`)까지 숨어 디버깅이 어려워집니다. 로봇 루프에서 Ctrl+C(`KeyboardInterrupt`)까지 잡아 버리면 프로그램이 멈추지 않을 수도 있습니다. **예상한 예외만** 잡고, 정리 작업은 `finally`에 둡니다. 원본 `bus_servos_read.py`도 `except KeyboardInterrupt:`만 따로 잡습니다.
:::

## 멀티스레딩

### 프로세스와 스레드

- **프로세스(process)**: 실행 중인 프로그램. 메모리 등 자원을 독립적으로 가짐. `python3 a.py`를 실행하면 프로세스 하나
- **스레드(thread)**: 프로세스 안의 실행 흐름. 같은 프로세스의 스레드들은 **메모리를 공유**합니다. 공장(프로세스)의 조립 라인(스레드)에 비유할 수 있습니다.

로봇 프로그램은 "시리얼로 들어오는 바이트를 계속 읽는 일"과 "메인 로직"을 동시에 해야 합니다. 원본 확장보드 SDK의 `Board.__init__`는 바로 이 목적의 스레드를 띄웁니다.

```python
# ros_robot_controller_sdk.py (요약)
self.imu_queue = queue.Queue(maxsize=1)          # 최신 값 1개만 보관
threading.Thread(target=self.recv_task, daemon=True).start()   # 수신 전용 스레드

def packet_report_imu(self, data):               # 수신 스레드가 호출
    try:
        self.imu_queue.put_nowait(data)
    except queue.Full:
        pass                                     # 아직 안 읽은 값이 있으면 새 값은 버림

def get_imu(self):                               # 메인 스레드가 호출
    return struct.unpack('<6f', self.imu_queue.get(block=False))
```

- `daemon=True`: 메인 프로그램이 끝나면 이 스레드도 함께 종료
- `Queue`: 스레드 간 데이터 전달용으로 **내부에 잠금이 있어 안전**합니다. `maxsize=1`로 두면 "가장 최근 값 하나"만 주고받는 우편함이 됩니다.
- 여러 스레드가 같은 장치에 명령-응답을 할 때는 `threading.Lock`으로 한 번에 하나만 들어가게 합니다(SDK의 `servo_read_lock`).

### Thread 객체와 동기화

| 항목 | 설명 |
|---|---|
| `Thread(target=f, args=(…), kwargs={…}, name=…, daemon=…)` | 함수로 스레드 만들기 |
| `class T(Thread): def run(self): …` | 상속으로 만들기(`run` 재정의) |
| `start()` / `join(timeout)` | 시작 / 끝날 때까지 기다리기 |
| `is_alive()`, `name` | 상태, 이름 |
| `Lock` | `acquire()`/`release()` 또는 `with lock:` — 한 번에 한 스레드만 |
| `RLock` | 같은 스레드가 여러 번 획득 가능(재진입), 획득 횟수만큼 해제 |

여러 스레드가 같은 변수를 `counter += 1`처럼 고치면 "읽기 → 더하기 → 쓰기" 사이에 다른 스레드가 끼어들어 값이 사라질 수 있습니다(**경쟁 조건, race condition**). `Lock`으로 이 구간을 보호합니다.

```python run
import threading
import queue

counter = 0
lock = threading.Lock()

def worker(n):
    global counter
    for _ in range(n):
        with lock:                     # 임계 구역 보호
            counter += 1

threads = [threading.Thread(target=worker, args=(10000,), name=f"T{i}") for i in range(4)]
for t in threads:
    t.start()
for t in threads:
    t.join()                           # 모두 끝날 때까지 대기
print("counter =", counter, "| alive:", any(t.is_alive() for t in threads))

# 상속으로 만든 스레드
class Summer(threading.Thread):
    def __init__(self, values):
        super().__init__()
        self.values, self.result = values, None
    def run(self):
        self.result = sum(self.values)

s = Summer(range(1, 101)); s.start(); s.join()
print("sum 1..100 =", s.result)

# SDK 방식의 maxsize=1 큐: 최신 값 하나만 보관
q = queue.Queue(maxsize=1)
for sample in ["imu#1", "imu#2", "imu#3"]:
    try:
        q.put_nowait(sample)
    except queue.Full:
        print("full -> drop", sample)
print("get:", q.get(block=False))
try:
    q.get(block=False)
except queue.Empty:
    print("empty -> None 반환 (SDK get_imu 와 같은 처리)")
```

```text
counter = 40000 | alive: False
sum 1..100 = 5050
full -> drop imu#2
full -> drop imu#3
get: imu#1
empty -> None 반환 (SDK get_imu 와 같은 처리)
```

:::info 파이썬 스레드와 GIL
CPython에는 GIL(Global Interpreter Lock)이 있어 **순수 파이썬 계산**은 스레드를 늘려도 동시에 실행되지 않습니다. 대신 시리얼·네트워크·`sleep`처럼 **기다리는 작업**에서는 스레드가 효과적입니다. SDK의 수신 스레드가 딱 이 경우입니다. 무거운 계산을 병렬로 하려면 `multiprocessing`이나 NumPy(내부가 C)를 씁니다. (브라우저 Playground에서는 스레드가 순차 실행으로 흉내 내어지지만 결과는 같습니다.)
:::

## NumPy 기초

NumPy는 **같은 자료형의 다차원 배열(`ndarray`)**과 그 위의 빠른 연산을 제공합니다. OpenCV 이미지는 NumPy 배열이고, 라이다 거리도 배열로 바꾸면 반복문 없이 한 번에 계산할 수 있습니다(**벡터화, vectorization**).

| 작업 | 함수 |
|---|---|
| 만들기(고정값) | `np.array`, `np.zeros`, `np.ones`, `np.full`, `np.eye` |
| 만들기(규칙) | `np.arange(start, stop, step)`, `np.linspace(start, stop, num)` |
| 부분 선택 | 인덱스 `a[i, j]`, 슬라이스 `a[1:3, :]`, 팬시 인덱스 `a[[0, 2]]`, 불리언 마스크 `a[a > 0.5]` |
| 모양 바꾸기 | `reshape`, `ravel`, `T`(전치) |
| 합치기·나누기 | `np.concatenate`, `np.vstack`, `np.hstack`, `np.split` |
| 복사 | 슬라이스는 **뷰(view, 원본 공유)**, `.copy()`는 독립 복사본 |

@fig[b06-numpy] `reshape(4, 90)`으로 360개 라이다 거리를 90°씩 4개 섹터로 나누고, `axis=1` 방향으로 최솟값을 구하면 섹터별 가장 가까운 거리가 나옵니다.

```python run
import numpy as np

a = np.arange(12)                     # 0..11
print(a, a.ndim, a.shape)
b = a.reshape(3, 4)
print(b)
print("b[1, 2] =", b[1, 2], "| row 0:", b[0], "| col 1:", b[:, 1])
print(np.zeros(3), np.ones((2, 2)).tolist(), np.full(2, 1500))
print(np.linspace(0, 1, 5), np.round(np.linspace(-np.pi, np.pi, 5), 3))

# 불리언 마스크와 팬시 인덱스
r = np.array([1.2, 0.35, np.inf, 0.8, 0.28, 0.0])
valid = r[np.isfinite(r) & (r > 0)]
print("valid:", valid, "| near idx:", np.where((r > 0) & (r < 0.4))[0])
print(r[[0, 3]])

# 뷰와 복사
v = a[:3]; v[0] = 99
c = a[3:6].copy(); c[0] = -1
print(a[:6])

# 합치기와 나누기
x = np.array([1, 2]); y = np.array([3, 4])
print(np.concatenate([x, y]), np.vstack([x, y]).tolist(), np.hstack([x, y]))
print([p.tolist() for p in np.split(np.arange(6), 3)])
```

### 로봇 데이터에 적용하기

아래는 두 가지 전형적인 계산입니다. (1) 360개 라이다 거리를 섹터로 나눠 최솟값 구하기(M06의 회피 알고리즘 바탕), (2) 메카넘 기구학을 **행렬 곱** 한 번으로 계산하기(M01).

```python run
import numpy as np

# (1) 가상의 360° 스캔: 1도 간격, 0번 = 전방, 반시계 +
angles = np.arange(360)
ranges = np.full(360, 2.0)
ranges[350:360] = 0.45; ranges[0:10] = 0.45      # 정면에 물체
ranges[80:100] = 0.9                               # 왼쪽 벽
ranges[200] = np.inf                               # 반사 없음

clean = np.where(np.isfinite(ranges), ranges, 12.0)   # inf -> 최대 거리
front = np.concatenate([clean[315:], clean[:45]])      # -45..+45도
sectors = clean.reshape(4, 90).min(axis=1)             # 0-89,90-179,...
print("front min:", front.min(), "| sector mins:", sectors)
print("closest angle:", int(angles[np.argmin(clean)]), "deg")

# 극좌표 -> 직교 좌표 (라이다 점을 로봇 좌표로)
th = np.radians([0, 90, 180])
d = clean[[0, 90, 180]]
print(np.round(np.c_[d * np.cos(th), d * np.sin(th)], 3))

# (2) 메카넘 역기구학: rps = M @ [vx, vy, wz]
a, b, D = 0.1368, 0.1446, 0.065
k = (a + b) / 2
M = np.array([[1, -1, -k],
              [1,  1, -k],
              [1,  1,  k],
              [1, -1,  k]]) / (np.pi * D)
sign = np.array([-1, -1, 1, 1])                        # 원본의 [-m1,-m2,m3,m4]
for cmd in ([0.2, 0, 0], [0, 0.2, 0], [0, 0, 0.5]):
    print(cmd, "->", np.round(sign * (M @ cmd), 3))
```

```text
[0, 0.2, 0] -> [ 0.979 -0.979  0.979 -0.979]
[0, 0, 0.5] -> [0.345 0.345 0.345 0.345]
```

## 자주 나는 오류와 해결

| 증상(오류 메시지) | 원인 | 해결 |
|---|---|---|
| `TypeError: __init__() missing 1 required positional argument` | 생성자 인자 누락 | 기본값을 주거나 인자 전달 |
| `TypeError: set_velocity() takes 3 positional arguments but 4 were given` | 메서드 정의에 `self` 빠짐 | 첫 매개변수로 `self` |
| `AttributeError: 'MecanumChassis' object has no attribute 'wheel_diameter'` | 자식 `__init__`에서 `super().__init__()` 호출 누락 | 부모 생성자 호출 |
| `FileNotFoundError` | 상대 경로 기준(현재 폴더)이 예상과 다름, `~` 미확장 | `os.getcwd()` 확인, `os.path.expanduser` |
| 파일 내용이 사라짐 | `'w'` 모드로 열면 기존 내용 삭제 | 추가는 `'a'` |
| `UnicodeDecodeError` | 인코딩 불일치 | `encoding='utf-8'` 명시 |
| 스레드 결과 합계가 가끔 틀림 | 경쟁 조건 | `Lock`으로 임계 구역 보호 |
| 프로그램이 끝나지 않음 | non-daemon 스레드가 무한 루프 | 종료 플래그 + `join()`, 또는 `daemon=True` |
| `error: externally-managed-environment` | 시스템 파이썬 보호(bookworm) | apt 패키지 또는 venv 사용 |
| `ValueError: cannot reshape array of size 360 into shape (4,100)` | 원소 수 불일치 | 곱이 원소 수와 같게(4×90) |
| 배열을 고쳤더니 원본도 바뀜 | 슬라이스는 뷰 | `.copy()` |
