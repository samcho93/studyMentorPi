## QR 코드의 구조

QR(Quick Response) 코드는 1994년 일본 덴소 웨이브가 만든 2차원 바코드입니다. 흑백 정사각형 칸(모듈, module)에 데이터를 담으며, 어느 방향에서 찍어도 읽히도록 설계되었습니다.

@fig[a02-qr] QR 코드의 구성 요소: 파인더 패턴 3개, 타이밍 패턴, 데이터 영역, 여백(quiet zone)

| 구성 요소 | 역할 |
|---|---|
| 파인더 패턴 (finder pattern) | 세 모서리의 7×7 “回” 모양. 1:1:3:1:1 흑백 비율이 어느 각도로 잘라도 나타나서, 검출기가 위치·회전을 찾는 기준이 됩니다. |
| 타이밍 패턴 | 파인더 사이를 잇는 흑백 교대 줄. 모듈 간격(격자)을 알려 줍니다. |
| 정렬 패턴 (버전 2 이상) | 오른쪽 아래의 작은 5×5 패턴. 원근 왜곡 보정에 씁니다. |
| 형식·버전 정보 | 오류 정정 수준과 마스크 패턴 번호 |
| 데이터 + 오류 정정 코드 | 리드-솔로몬(Reed-Solomon) 부호로 일부가 가려져도 복원 |
| 여백 (quiet zone) | 코드 둘레의 흰 띠. 표준은 **4모듈**. 없으면 주변 무늬와 섞여 인식률이 떨어집니다. |

### 버전과 크기

버전 $V$(1~40)의 한 변 모듈 수는 $17 + 4V$입니다. 버전 1은 21×21, 버전 2는 25×25, 버전 40은 177×177입니다. 담을 수 있는 글자 수는 버전과 **오류 정정 수준**에 따라 정해집니다.

| 오류 정정 수준 | 복원 가능한 손상 | 버전 1 (바이트) | 버전 2 (바이트) |
|---|---|---|---|
| L | 약 7 % | 17 | 32 |
| M (기본) | 약 15 % | 14 | 26 |
| Q | 약 25 % | 11 | 20 |
| H | 약 30 % | 7 | 14 |

로봇이 바닥이나 벽의 QR을 읽는 환경에서는 흠집·반사에 강한 H 수준이 유리합니다. 대신 같은 버전에 담을 수 있는 글자가 줄어 **버전(크기)이 커집니다**.

## QR 코드 만들기

원본 예제 `qrcode_creater.py`는 파이썬 `qrcode` 라이브러리를 씁니다.

```python robot
import cv2
import numpy as np
import qrcode

qr = qrcode.QRCode(version=1,                                   # 1~40, fit=True면 필요한 만큼 자동 증가
                   error_correction=qrcode.constants.ERROR_CORRECT_H,
                   box_size=5,                                  # 모듈 한 칸 = 5×5 픽셀
                   border=4)                                    # 여백 4모듈 (표준 최솟값)
qr.add_data('hiwonder')
qr.make(fit=True)
img = qr.make_image(fill_color=(0, 0, 0), back_color=(255, 255, 255))
bgr = cv2.cvtColor(np.asarray(img), cv2.COLOR_RGB2BGR)
cv2.imwrite('myQRcode.jpg', bgr)
print(bgr.shape)
```

직접 계산해 봅시다. `hiwonder`는 8바이트인데 H 수준의 버전 1은 7바이트까지라 `fit=True`가 **버전 2**(25모듈)로 올립니다. 여백을 더하면 $25 + 2×4 = 33$모듈, 칸당 5픽셀이므로 **165×165 픽셀**입니다. (원본 코드 주석은 버전 1을 “12×12 행렬”이라고 설명하지만, 표준의 버전 1은 21×21입니다.)

Playground에는 `qrcode` 라이브러리가 없으므로 OpenCV에 들어 있는 `cv2.QRCodeEncoder`를 씁니다. 이 인코더는 결과에 **2모듈 여백**을 붙여 돌려줍니다.

```python run
import cv2
import numpy as np

params = cv2.QRCodeEncoder_Params()
for level, name in [(cv2.QRCodeEncoder_CORRECT_LEVEL_L, "L"), (cv2.QRCodeEncoder_CORRECT_LEVEL_H, "H")]:
    params.correction_level = level
    enc = cv2.QRCodeEncoder.create(params)
    for text in ["forward", "MentorPi", "hiwonder-robot"]:
        m = enc.encode(text)                        # 모듈 1칸 = 1픽셀, 여백 2모듈 포함
        n = m.shape[0] - 4                          # 여백 제외 모듈 수
        print("수준 %s  %-15s → %2d×%-2d 모듈 (버전 %d)" % (name, repr(text), n, n, (n - 17) // 4))

m = cv2.QRCodeEncoder.create(params).encode("MentorPi")
big = cv2.resize(m, None, fx=8, fy=8, interpolation=cv2.INTER_NEAREST)   # 보간하면 경계가 흐려짐
big = cv2.copyMakeBorder(big, 16, 16, 16, 16, cv2.BORDER_CONSTANT, value=255)  # 여백을 4모듈로
print("저장용 이미지:", big.shape, "값:", np.unique(big).tolist())
cv2.imshow("QR MentorPi (H)", big)
```

```text
수준 L  'forward'       → 21×21 모듈 (버전 1)
수준 L  'MentorPi'      → 21×21 모듈 (버전 1)
수준 L  'hiwonder-robot' → 21×21 모듈 (버전 1)
수준 H  'forward'       → 21×21 모듈 (버전 1)
수준 H  'MentorPi'      → 25×25 모듈 (버전 2)
수준 H  'hiwonder-robot' → 25×25 모듈 (버전 2)
저장용 이미지: (264, 264) 값: [0, 255]
```

모듈을 확대할 때는 반드시 `INTER_NEAREST`를 씁니다. 선형 보간을 쓰면 칸 경계에 회색이 생겨 인식률이 떨어집니다.

## QR 코드 인식

### pyzbar (원본 예제)

원본 `qrcode_detecter.py`는 카메라 토픽 `/ascamera/camera_publisher/rgb0/image`를 구독하고, 별도 스레드에서 `pyzbar.decode(image)`로 QR을 읽습니다. 결과 객체마다 `obj.polygon`(꼭짓점), `obj.rect`(외접 사각형), `obj.data`(바이트 문자열)를 주며, 꼭짓점이 4개보다 많으면 `convexHull`로 정리한 뒤 `cv2.line`으로 초록 테두리를 그리고 `putText`로 내용을 씁니다.

### cv2.QRCodeDetector

OpenCV만으로도 인식할 수 있습니다.

```python
det = cv2.QRCodeDetector()
data, points, straight = det.detectAndDecode(img)   # data: 문자열('' = 실패), points: (1, 4, 2) 꼭짓점
ok, datas, points, _ = det.detectAndDecodeMulti(img) # 한 화면에 여러 개
```

검출은 두 단계입니다. 먼저 **파인더 패턴 세 개**를 찾아 코드의 네 꼭짓점을 추정하고(`detect`), 그 사각형을 원근 변환(R09)으로 반듯하게 편 뒤 격자를 읽어 리드-솔로몬 복호를 합니다(`decode`). `straight`가 그 반듯하게 편 코드 이미지입니다.

```python run
import cv2
import numpy as np

img = cv2.imread("qr.png")                      # 330×330, 내용 "MentorPi"
det = cv2.QRCodeDetector()
data, pts, _ = det.detectAndDecode(img)
print("원본: %r, 꼭짓점 %s" % (data, pts.reshape(-1, 2).astype(int).tolist()))

h, w = img.shape[:2]
tests = {}
tests["30° 회전"] = cv2.warpAffine(img, cv2.getRotationMatrix2D((w / 2, h / 2), 30, 0.8), (w, h), borderValue=(255, 255, 255))
src = np.float32([[0, 0], [w, 0], [w, h], [0, h]])
dst = np.float32([[40, 20], [w - 10, 60], [w - 30, h - 50], [20, h - 10]])
tests["원근 기울임"] = cv2.warpPerspective(img, cv2.getPerspectiveTransform(src, dst), (w, h), borderValue=(255, 255, 255))
tests["흐림 9x9"] = cv2.GaussianBlur(img, (9, 9), 0)
tests["1/3 크기"] = cv2.resize(img, None, fx=1 / 3, fy=1 / 3, interpolation=cv2.INTER_AREA)
dark = img.copy()
cv2.rectangle(dark, (200, 200), (250, 250), (0, 0, 0), -1)      # 오른쪽 아래 일부 가림
tests["일부 가림"] = dark
tests["여백 없음"] = img[60:270, 60:270]
for name, t in tests.items():
    d, p, _ = det.detectAndDecode(t)
    print("%-8s → %s" % (name, repr(d) if d else "실패"))
cv2.imshow("원근 기울임", tests["원근 기울임"])
```

```text
원본: 'MentorPi', 꼭짓점 [[60, 60], [269, 60], [269, 269], [60, 269]]
30° 회전   → 'MentorPi'
원근 기울임   → 'MentorPi'
흐림 9x9   → 'MentorPi'
1/3 크기   → 'MentorPi'
일부 가림    → 실패
여백 없음    → 실패
```

`qr.png`는 L 수준으로 만들어져 가려진 영역을 복원할 여유가 적습니다. 실제 코드를 인쇄할 때는 H 수준으로 만들고, 여백을 넉넉히 두며, 카메라에서 한 모듈이 **최소 3~4픽셀** 이상으로 보이게 크기를 정합니다.

## QR 명령으로 로봇 움직이기

QR 코드를 “표지판”으로 쓰면 로봇에게 간단한 명령을 줄 수 있습니다. 설계할 때 다음을 챙깁니다.

- **명령표를 고정**하고 모르는 문자열은 무시합니다(임의 문자열을 속도로 해석하지 않기).
- 같은 코드를 연속 프레임에서 여러 번 읽으므로, **새 명령일 때만** 동작을 바꿉니다.
- 코드를 놓치면(일정 시간 인식 없음) **정지**합니다. 카메라가 가려지거나 노드가 멈췄을 때 계속 달리지 않게 하는 워치독(watchdog)입니다.
- 속도는 실물 한계(선속도 ≤ 0.2 m/s, 각속도 ≤ 0.5 rad/s) 안에서 정합니다.

Playground에는 카메라가 없으므로, 아래 노드는 타이머에서 명령 QR을 “카메라 프레임”처럼 만들어 인식합니다. 인식·명령 변환·워치독 구조는 실물 노드와 같습니다.

```python run
import cv2
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import Twist
from nav_msgs.msg import Odometry
import mentorpi_sim as sim                                  # 시뮬 전용
sim.setup(world="empty", duration=9.0, noise=False)         # 시뮬 전용
COMMANDS = {"forward": (0.15, 0.0), "left": (0.0, 0.5), "right": (0.0, -0.5), "stop": (0.0, 0.0)}
SCRIPT = ["forward", "forward", "left", "left", "hello", "forward", None, None]  # None = 코드 안 보임

def camera_frame(text):                                     # 시뮬 전용: 명령 QR을 프레임으로
    if text is None:
        return cv2.cvtColor(cv2.imread("scene.png"), cv2.COLOR_BGR2GRAY)
    q = cv2.QRCodeEncoder.create().encode(text)
    return cv2.copyMakeBorder(cv2.resize(q, None, fx=8, fy=8, interpolation=cv2.INTER_NEAREST),
                              20, 20, 20, 20, cv2.BORDER_CONSTANT, value=255)

class QrCommand(Node):
    def __init__(self):
        super().__init__('qr_command')
        self.det = cv2.QRCodeDetector()
        self.pub = self.create_publisher(Twist, 'cmd_vel', 1)
        self.create_subscription(Odometry, 'odom', self.on_odom, 10)
        self.current, self.last_seen, self.k, self.pose = "stop", 0.0, 0, (0.0, 0.0)
        self.create_timer(1.0, self.on_frame)               # 실물: 이미지 콜백
        self.create_timer(0.1, self.on_control)

    def on_odom(self, msg):
        self.pose = (msg.pose.pose.position.x, msg.pose.pose.position.y)

    def on_frame(self):
        text = SCRIPT[self.k] if self.k < len(SCRIPT) else None
        self.k += 1
        data, _, _ = self.det.detectAndDecode(camera_frame(text))
        now = self.get_clock().now().nanoseconds * 1e-9
        if data in COMMANDS:
            self.last_seen = now
            if data != self.current:
                self.current = data
                self.get_logger().info('새 명령 %s  (x=%.2f, y=%.2f)' % (data, *self.pose))
        elif data:
            self.get_logger().warn('모르는 코드 %r 무시' % data)

    def on_control(self):
        now = self.get_clock().now().nanoseconds * 1e-9
        if now - self.last_seen > 1.5 and self.current != "stop":
            self.current = "stop"
            self.get_logger().warn('코드 안 보임 → 정지 (x=%.2f, y=%.2f)' % self.pose)
        cmd = Twist()
        cmd.linear.x, cmd.angular.z = COMMANDS[self.current]
        self.pub.publish(cmd)

rclpy.init()
node = QrCommand()
try:
    rclpy.spin(node)
except KeyboardInterrupt:
    pass
finally:
    node.pub.publish(Twist())
    node.destroy_node()
    rclpy.shutdown()
```

```text
[INFO] [1.000] [qr_command]: 새 명령 forward  (x=0.00, y=0.00)
[INFO] [3.000] [qr_command]: 새 명령 left  (x=0.27, y=0.00)
[WARN] [5.000] [qr_command]: 모르는 코드 'hello' 무시
[WARN] [5.600] [qr_command]: 코드 안 보임 → 정지 (x=0.28, y=0.00)
[INFO] [6.000] [qr_command]: 새 명령 forward  (x=0.28, y=0.00)
[WARN] [7.500] [qr_command]: 코드 안 보임 → 정지 (x=0.34, y=0.19)
[sim] 시뮬레이션 시간 9.0 s 종료 (sim.setup(duration=...)으로 변경)
```

`forward`를 두 프레임 연속 읽어도 로그는 한 번만 나옵니다(새 명령일 때만). `hello`는 명령표에 없어 무시되고 “유효한 명령을 본 시각”도 갱신하지 않으므로, 마지막 `left`(4 s)에서 1.5 s가 지난 5.6 s에 워치독이 로봇을 세웁니다. 다시 `forward`가 보이면 출발하고, 코드가 사라지자 7.5 s에 또 정지합니다. 결과적으로 로봇은 약 0.28 m 전진 → 약 75° 좌회전 → 조금 더 전진한 자리에서 멈춥니다(`noise=False`라 매번 같은 결과).

## 실습 (실물)

:::safety 실물 실습 전 확인
- 생성·인식 예제는 바퀴를 움직이지 않습니다. QR 명령 노드를 실물로 돌릴 때는 **로봇 주변 1 m 이상을 비우고**, 바퀴를 띄운 상태에서 먼저 시험합니다.
- 명령 노드의 속도는 선속도 0.15 m/s, 각속도 0.5 rad/s 이하로 둡니다. `Ctrl+C`로 끝내면 정지 명령이 발행되는지 확인합니다.
- `~/.stop_ros.sh`로 앱 서비스를 끄고 실습하며, 끝나면 컨테이너 밖에서 `sudo systemctl restart start_node.service`를 실행합니다.
:::

### 3) QR 명령 노드 (선택)

위 Playground 노드에서 `# 시뮬 전용` 줄과 `camera_frame()`을 지우고, 이미지 토픽 콜백으로 바꾸면 실물 노드가 됩니다. MentorPi 앱 노드들은 섀시 명령을 `/controller/cmd_vel`로 보내므로, 실물에서는 발행 토픽을 이 이름으로 바꿉니다(이 경우 속도 제한은 코드에서 직접 지켜야 합니다).

```python robot
from cv_bridge import CvBridge
from sensor_msgs.msg import Image
# __init__ 안에서
self.bridge = CvBridge()
self.pub = self.create_publisher(Twist, '/controller/cmd_vel', 1)
```

## 자주 나는 오류와 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| `ModuleNotFoundError: qrcode` / `pyzbar` | PC 환경에 라이브러리 없음 | `pip install qrcode pyzbar` (pyzbar는 `sudo apt install libzbar0` 필요) 또는 `cv2.QRCodeEncoder/Detector` 사용 |
| 화면의 QR은 읽히는데 인쇄본은 안 읽힘 | 여백 부족, 광택 종이 반사 | 여백 4모듈 이상, 무광 용지, 조명 각도 조정 |
| 멀리서 인식 실패 | 모듈이 너무 작게 찍힘 | 코드를 크게 인쇄하거나 가까이, 버전을 낮게(짧은 문자열) |
| `detectAndDecode`가 꼭짓점은 주는데 내용이 `''` | 검출은 됐지만 복호 실패(흐림·가림) | 초점·조명 개선, H 수준으로 재생성 |
| 같은 명령이 매 프레임 반복 실행 | 새 명령 여부를 확인하지 않음 | 직전 명령과 비교해 바뀔 때만 동작 |
| 코드가 사라져도 로봇이 계속 달림 | 워치독 없음 | 마지막 인식 시각을 기록해 시간 초과 시 정지 |
| 한글 내용이 깨짐 | 바이트 → 문자열 인코딩 | `obj.data.decode('utf-8')` |

## 과제

:::task 기본 과제
1. `detectAndDecodeMulti`로 한 화면의 QR 세 개(`forward`, `left`, `stop`)를 동시에 인식하고, 화면 왼쪽에 있는 코드부터 순서대로 출력합니다.
2. 인식한 QR의 네 꼭짓점 좌표로 코드의 **화면상 크기**(변 길이 평균)를 구하고, 코드 실제 크기와 카메라 초점거리로 거리를 추정하는 식을 세웁니다.
:::

:::task 심화 과제
3. QR 코드 네 꼭짓점과 `cv2.solvePnP`로 카메라에 대한 코드의 자세(거리·각도)를 구하고, 로봇이 코드 정면 30 cm 앞에 서도록 하는 제어기를 설계합니다.
4. 바닥에 QR 표지 4개(“구역 A~D”)를 붙이고, 라인 트레이싱(A03) 중에 표지를 읽으면 구역 이름을 로그로 남기는 통합 노드를 설계합니다.
:::
