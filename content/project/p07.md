## 학습 목표

- 라이다 주행 문제를 **마르코프 결정 과정**(MDP, Markov Decision Process)으로 정식화합니다: 상태(섹터 거리 + 직전 행동), 행동(전진·좌회전·우회전), 보상(진행 − 충돌 − 근접 벌점), 할인율을 스스로 정하고 근거를 댑니다.
- 넘파이만으로 **벡터화된 2D 광선 투사 환경**을 만들고, 표 기반 **Q-러닝**(ε-탐욕)과 작은 **DQN**(MLP, 재현 버퍼, 타깃 네트워크)을 몇 초 안에 학습시킵니다.
- 학습 곡선이 아니라 **평가 지표**(100 m당 충돌, 무충돌 비율, 주행 거리, 좌우 진동, 안전 개입률)로 정책을 비교하고, 여러 시드와 **규칙 기반 기준선**까지 포함해 결론을 냅니다.
- 보상 설계의 함정(제자리 회전, 진동, 손실 함수가 가리는 벌점 크기)을 실험으로 찾아내고 고칩니다.
- **도메인 무작위화**(잡음·누락·미끄럼·지연·거리 편향)로 시뮬→실물 간극을 줄이고, 가중치를 JSON/npz로 내보내 MentorPi의 ROS 2 정책 노드(`/scan_raw` → `/controller/cmd_vel`)에 **안전 덮어쓰기**와 속도 제한을 붙여 실행합니다.

## 프로젝트 개요와 요구사항

M06의 라이다 회피는 사람이 쓴 규칙입니다. "앞이 0.6 m보다 가까우면 90° 돌아라" 같은 규칙은 이해하기 쉽지만, 임계값과 회전량을 환경마다 손으로 맞춰야 합니다. 이 프로젝트에서는 규칙을 쓰는 대신 **보상만 정의하고, 로봇이 시행착오로 정책을 배우게** 합니다. 그리고 그 결과가 정말로 규칙보다 나은지, 실물로 옮겨도 버티는지를 연구처럼 **측정해서** 답합니다.

학습은 수만 번의 충돌을 겪어야 하므로 실물에서 할 수 없습니다. 그래서 흐름은 다음과 같습니다.

1. 넘파이로 만든 빠른 2D 환경(Playground 안에서 1~2초)에서 학습합니다.
2. 같은 정책을 Playground의 가상 MentorPi(rclpy, `arena` 월드)에 올려 **ROS 2 노드로** 평가합니다.
3. 도메인 무작위화로 다시 학습해 간극에 강해졌는지 확인합니다.
4. 정책 파일만 로봇으로 옮겨, 안전층을 두른 정책 노드로 실물에서 시험합니다.

## 이론

### 마르코프 결정 과정

MDP는 다섯 가지 $(\mathcal{S}, \mathcal{A}, P, R, \gamma)$로 정의합니다. 매 시각 $t$에 에이전트는 상태 $s_t$를 보고 행동 $a_t$를 고르며, 환경은 다음 상태 $s_{t+1} \sim P(\cdot \mid s_t, a_t)$와 보상 $r_{t+1}$을 돌려줍니다. 목표는 할인된 누적 보상(return)

$G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \dots$

의 기댓값을 최대로 하는 정책 $\pi(a \mid s)$를 찾는 것입니다. 행동 가치 함수 $Q^\pi(s, a) = \mathbb{E}_\pi[G_t \mid s_t = s, a_t = a]$의 최적값은 **벨만 최적 방정식**을 만족합니다.

$Q^*(s, a) = \mathbb{E}\left[ r + \gamma \max_{a'} Q^*(s', a') \right]$

$Q^*$를 알면 최적 정책은 $\pi^*(s) = \arg\max_a Q^*(s, a)$로 바로 나옵니다.

**할인율 고르기.** $\gamma$는 "얼마나 먼 미래까지 보는가"를 정합니다. 유효 지평은 대략 $1/(1-\gamma)$ 스텝입니다. 우리는 5 Hz로 결정하고 $\gamma = 0.95$를 쓰므로 약 20 스텝 = 4 s, 0.18 m/s로 0.7 m 앞까지의 결과를 봅니다. 라이다 상태의 "근접" 경계(0.7 m)와 맞춘 값입니다.

### 상태·행동·보상 설계

@fig[p07-mdp] 라이다 9개 빔을 좌·전·우 섹터로 묶고, 섹터 최소 거리를 3단계로 나눕니다. 직전 행동까지 합쳐 상태는 3·3·3·3 = 81개입니다.

| 요소 | 설계 | 이유 |
|---|---|---|
| 빔 | −90°, −60°, −30°, −15°, 0°, 15°, 30°, 60°, 90° | 360개 빔을 그대로 쓰면 표가 폭발. 전방을 촘촘히 |
| 섹터 | L = {60°, 90°}, F = {−30°…30°}, R = {−60°, −90°} | 로봇 반지름 0.13 m: 30° 방향 0.3 m 물체는 옆으로 0.15 m, 부딪힐 수 있으므로 F에 포함 |
| 단계 | $d < 0.35$ → 0(위험), $d < 0.7$ → 1(근접), 그 외 2(여유) | 0.35 m = 반지름 + 제동·회전 여유, 0.7 m ≈ 4 s 지평 |
| 직전 행동 | F/L/R | 라이다 한 장은 **부분 관측**(POMDP)입니다. 회전 중인지 알아야 좌우 진동을 줄임 |
| 행동 | F: (0.18 m/s, 0), L: (0, +0.5 rad/s), R: (0, −0.5 rad/s) | 안전 한계 안의 이산 행동 3개 |
| 보상 | $r = 10\,\Delta s - 0.02\,[a \ne F] - 0.3\,\frac{\max(0,\,0.35 - d_F)}{0.35} - 5\,[\text{충돌}]$ | 진행(전진 거리 $\Delta s$) − 회전 비용 − 근접 벌점 − 충돌 |

상태 번호는 $s = ((L \cdot 3 + F) \cdot 3 + R) \cdot 3 + a_{prev}$입니다. 전진 한 스텝($0.18 \times 0.2 = 0.036$ m)의 진행 보상은 0.36이므로, 20 s(100 스텝) 동안 쉬지 않고 전진하면 최대 36점입니다. 충돌 −5는 약 14스텝의 전진과 맞먹습니다.

**종료와 잘림은 다릅니다.** 충돌은 진짜 종료(terminal)라서 다음 상태의 가치를 더하지 않습니다($\gamma \max Q(s') \cdot 0$). 반면 20 s 에피소드가 끝나는 것은 시간 **잘림**(truncation)이라서 부트스트랩을 해야 합니다. 둘을 섞으면 "20 s가 끝날 무렵엔 아무렇게나 해도 된다"는 이상한 가치가 학습됩니다.

### 표 기반 Q-러닝

상태가 81개뿐이므로 $Q$를 81×3 표에 담을 수 있습니다. 전이 $(s, a, r, s')$를 겪을 때마다 TD(시간차) 목표 쪽으로 조금씩 옮깁니다.

$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \right]$

행동은 **ε-탐욕**으로 고릅니다. 확률 ε로 무작위, 아니면 $\arg\max_a Q(s, a)$. ε를 1에서 0.05로 줄여 가며 처음엔 탐험, 나중엔 활용합니다. Q-러닝은 **비정책(off-policy)** 방법이라 무작위로 움직이며 모은 경험으로도 탐욕 정책의 가치를 배웁니다.

```text
Q ← 0 (81×3),  ε ← 1
for 에피소드 = 1..40:
    E개 환경을 무작위 자세로 초기화, s ← 상태(스캔)
    for k = 1..100:                         # 20 s
        a ← ε-탐욕(Q, s)                    # E개 동시에
        s', r, 충돌 ← 환경.step(a)
        y ← r + γ·max Q(s')·(1 − 충돌)      # 충돌 = 종료, 부트스트랩 없음
        Q(s, a) ← Q(s, a) + α (y − Q(s, a))
        충돌한 환경은 새 자세에서 다시 시작
        s ← s'
    ε ← max(0.05, 1 − 에피소드/25)
```

한 번에 E = 32개 환경을 **넘파이 배열로 동시에** 진행합니다. 로봇 32대의 광선 투사가 `(32, 9, 16)` 배열 연산 한 번이라 파이썬 반복문보다 수십 배 빠릅니다. Playground에서 1~2초 안에 12만 번의 전이를 모으는 비결입니다.

### DQN: 함수 근사로 넘어가기

상태를 81칸으로 나누면 0.34 m와 0.36 m가 전혀 다른 상태가 되고, 빔 9개의 연속값 정보가 버려집니다. **DQN**(Deep Q-Network, Mnih et al. 2015)은 표 대신 신경망 $Q_\theta(s, \cdot)$로 모든 행동의 가치를 한 번에 냅니다. 입력은 빔 9개(1 m에서 포화) + 직전 행동 one-hot 3개 = 12차원, 은닉층 32개(ReLU), 출력 3개로 가중치는 515개입니다.

@fig[p07-dqn] DQN 학습 구조. 경험은 재현 버퍼에 쌓고, 무작위 미니배치로 학습하며, 목표값은 느리게 복사되는 타깃 네트워크로 계산합니다.

신경망에 TD 학습을 그대로 붙이면 쉽게 발산합니다. DQN의 두 장치가 이를 막습니다.

| 장치 | 문제 | 해결 |
|---|---|---|
| 재현 버퍼(experience replay) | 연속 샘플은 서로 비슷해(상관) 경사가 한쪽으로 쏠림 | 2만 개 전이를 저장하고 무작위로 64개씩 뽑음 |
| 타깃 네트워크 $\theta^-$ | 목표 $y$가 방금 고친 $\theta$로 계산돼 움직이는 과녁을 쫓음 | 100 스텝마다만 $\theta^- \leftarrow \theta$ 복사 |

손실은 $L(\theta) = \mathbb{E}_{(s,a,r,s') \sim \mathcal{D}}\left[ \ell\left(Q_\theta(s, a) - y\right) \right]$, $y = r + \gamma (1 - d) \max_{a'} Q_{\theta^-}(s', a')$이고, $\ell$은 Huber 손실(오차가 $\delta$보다 크면 기울기를 $\pm\delta$로 자름)입니다. 역전파는 두 층뿐이라 넘파이로 직접 씁니다: $\partial L/\partial W_2 = h^\top g$, $\partial L/\partial h = g W_2^\top \odot [h > 0]$, $\partial L/\partial W_1 = x^\top (\partial L/\partial h)$. 최적화는 Adam입니다.

### 보상 설계의 함정

보상은 "무엇을 원하는지"를 알려 주는 유일한 통로라서, 조금만 어긋나도 에이전트는 **보상은 높지만 원하지 않는 행동**을 찾아냅니다(reward hacking).

| 증상 | 원인이 된 보상 | 고치는 법 |
|---|---|---|
| 제자리에서 계속 돈다 | 진행 보상 없이 "생존 +1"만 줌 → 안 부딪히는 게 최선 | 전진 거리에 비례하는 진행 보상 |
| 좌·우 회전을 번갈아(진동) | 회전 비용 0, 상태에 직전 행동 없음 | 회전 비용 −0.02, 상태에 $a_{prev}$ 추가 |
| 벽에 바짝 붙어 달린다 | 근접 벌점 없음 → 충돌 직전까지 최대 속도가 이득 | 전방 0.35 m 안에서 선형 근접 벌점 |
| 후진으로 달린다 | $|v|$에 보상, 후진 행동 허용 | $\Delta s$를 전진 방향으로만, 후진 행동 제거(뒤는 라이다 사각) |
| 충돌 벌점을 −5에서 −10으로 키워도 DQN 결과가 똑같다 | Huber δ = 1이 오차를 ±1로 잘라 벌점 크기 정보가 사라짐 | δ를 키우거나(실습 2는 3) 보상 전체를 같은 비율로 줄임 |
| 학습 곡선은 오르는데 평가는 나쁘다 | 곡선은 ε 탐험이 섞인 값, 에피소드 20 s 잘림 | ε = 0 탐욕 정책을 **별도 평가**로 측정 |

마지막 두 줄은 실제로 이 장의 코드를 만들며 겪은 일입니다. 특히 Huber 손실 문제는 충돌 벌점만 바꾼 두 실험의 학습된 가중치가 **비트 단위까지 같게** 나와서 발견했습니다. 이상한 결과가 나오면 "운이 나빴다"로 넘기지 말고 원인을 추적하세요.

### 시뮬→실물 간극과 도메인 무작위화

넘파이 환경은 완벽한 라이다와 완벽한 바퀴를 가정합니다. 실물은 다릅니다.

| 간극 | 실물에서의 모습 | 환경 모델 |
|---|---|---|
| 라이다 잡음 | 거리 ±1~3 cm 흔들림 | 가우스 잡음 σ ~ U(0, 5 cm) |
| 빔 누락 | 검은 천·유리·빛 반사에서 0 또는 inf | 확률 U(0, 5 %)로 빔을 inf로 |
| 거리 편향 | 장착 오프셋, 물체 재질, 로봇에 실은 짐으로 실제 반지름 증가 | 모든 빔에 +U(0, 0.2 m) |
| 미끄럼 | 메카넘 롤러 미끄럼으로 명령보다 덜 움직임 | 속도 × U(0.7, 1.0) |
| 지연 | 스캔 수신 → 결정 → 모터까지 수십~수백 ms | 확률 U(0, 1)로 한 주기(0.2 s) 전 명령 실행 |

**도메인 무작위화**(domain randomization, Tobin et al. 2017)는 이 파라미터 $\xi$를 에피소드마다 분포 $p(\xi)$에서 뽑아, 정책이 **분포 전체에서** 잘하도록 학습합니다.

$\max_\pi \; \mathbb{E}_{\xi \sim p(\xi)} \left[ \mathbb{E}_{\pi, \xi} [G_0] \right]$

실물이 $p(\xi)$의 "한 표본"처럼 보이면 정책이 그대로 통한다는 생각입니다. 대가도 있습니다. 표 기반처럼 표현력이 작은 정책은 모든 도메인에서 동시에 최적일 수 없어 **이상적 환경의 성능이 떨어질 수** 있고, 학습이 더 오래 걸립니다. 범위를 너무 넓히면 겁쟁이 정책(계속 회전)이 됩니다. 실습 3에서 직접 확인합니다.

### 정책 파일

학습 코드와 로봇 코드가 **같은 전처리**를 쓰도록, 빔 각도·섹터·단계 경계·행동표를 정책과 함께 `policy.json`에 저장합니다(형식은 실습 (실물)의 내보내기 코드). 한쪽에서만 경계를 바꾸는 실수를 막고, 노드는 파일만 바꿔 다른 정책을 실행합니다. DQN은 가중치 `W1, b1, W2, b2`를 `dqn.npz`로 따로 저장합니다. 로봇에 파이토치가 없어도 넘파이 행렬곱 두 번이면 추론이 끝납니다.

### 안전층: 원본 `lidar_controller`의 규칙 재사용

원본 `app/lidar_controller.py`의 회피 모드는 전방 `scan_angle`(기본 90°, 즉 ±45°)을 왼쪽·오른쪽 절반으로 나누고, 0과 inf를 뺀 최소 거리를 `threshold`(기본 0.6 m)와 비교해 한쪽만 막히면 반대로, 양쪽이 막히면 크게 돕니다. 우리는 이 규칙을 **정책 위에 덮어씌우는 안전 필터**로 씁니다.

```text
정책 행동 (v, ω) ← π(s)
left  ← min(ranges[0° < θ ≤ +45°]),  right ← min(ranges[−45° ≤ θ < 0°])   # 0·inf 제외
if min(left, right) < stop_dist:           # 안전 덮어쓰기
    v ← 0
    ω ← −ω_max if left < right else +ω_max  # 먼 쪽으로 제자리 회전
v ← clip(v, −0.2, 0.2),  ω ← clip(ω, −0.5, 0.5)
if 마지막 스캔이 0.5 s보다 오래됨: v, ω ← 0
```

임계값은 원본의 0.6 m보다 작은 0.25 m로 둡니다. 0.6 m면 정책이 판단할 여지 없이 안전층이 거의 모든 것을 결정해 버려서, 무엇을 평가하는지 알 수 없게 됩니다. 대신 **개입률**(안전층이 행동을 바꾼 비율)을 기록합니다. 개입률이 높다는 것은 정책이 실물에서 위험한 행동을 자주 골랐다는 뜻이므로, 그 자체가 sim-to-real 간극의 측정값이 됩니다.

### 실습 1. 표 기반 Q-러닝

arena 월드와 같은 장애물을 넘파이로 옮긴 환경에서 32대를 동시에 학습합니다. 끝나면 ε = 0 탐욕 정책을 무작위 시작 32곳에서 60 s씩 평가하고, 정책을 81글자 문자열로 출력합니다.

```python run
import math, numpy as np
import mentorpi_sim as sim                                   # 시뮬 전용 (sim.plot)

rng = np.random.default_rng(0)
BOX = [(0.8, 0.8, 0.3, 0.3), (-0.9, 0.6, 0.3, 0.5), (0.7, -1.0, 0.5, 0.3)]   # arena 월드와 같은 배치
CYL = np.array([(-0.6, -0.8, 0.12), (0.0, 1.3, 0.12), (1.3, -0.1, 0.1)])
S = [(-2, -2, 2, -2), (2, -2, 2, 2), (2, 2, -2, 2), (-2, 2, -2, -2)]
for x, y, w, h in BOX:
    a, b, c, d = x - w / 2, y - h / 2, x + w / 2, y + h / 2
    S += [(a, b, c, b), (c, b, c, d), (c, d, a, d), (a, d, a, b)]
SEG = np.array(S, float)
RAY = np.radians([-90, -60, -30, -15, 0, 15, 30, 60, 90])    # 9개 빔 (0 = 전방, 반시계 +)
ACT = np.array([(0.18, 0.0), (0.0, 0.5), (0.0, -0.5)])       # 0 전진 F, 1 좌회전 L, 2 우회전 R  (v, ω)
DT, RAD = 0.2, 0.13                                          # 5 Hz 결정, 로봇 반지름
def cast(x, y, th):                                          # (E,) 자세 → (E, 9) 거리: 벡터화 광선 투사
    a = th[:, None] + RAY
    dx, dy = np.cos(a)[..., None], np.sin(a)[..., None]
    ox, oy = SEG[:, 0] - x[:, None, None], SEG[:, 1] - y[:, None, None]
    ex, ey = SEG[:, 2] - SEG[:, 0], SEG[:, 3] - SEG[:, 1]
    den = dx * ey - dy * ex + 1e-12
    t, u = (ox * ey - oy * ex) / den, (ox * dy - oy * dx) / den
    best = np.where((t > 0) & (u >= 0) & (u <= 1), t, 9).min(-1)
    cx, cy = CYL[:, 0] - x[:, None, None], CYL[:, 1] - y[:, None, None]
    b = dx * cx + dy * cy; disc = b * b - (cx * cx + cy * cy - CYL[:, 2] ** 2)
    tc = b - np.sqrt(np.maximum(disc, 0))
    return np.minimum(best, np.where((disc > 0) & (tc > 0), tc, 9).min(-1))
def clearance(x, y):                                         # 가장 가까운 장애물 표면까지 거리 (E,)
    px, py, ex, ey = SEG[:, 0], SEG[:, 1], SEG[:, 2] - SEG[:, 0], SEG[:, 3] - SEG[:, 1]
    t = np.clip(((x[:, None] - px) * ex + (y[:, None] - py) * ey) / (ex * ex + ey * ey), 0, 1)
    d = np.hypot(px + t * ex - x[:, None], py + t * ey - y[:, None]).min(1)
    return np.minimum(d, (np.hypot(CYL[:, 0] - x[:, None], CYL[:, 1] - y[:, None]) - CYL[:, 2]).min(1))
def spawn(n):                                                # 장애물에서 0.3 m 이상 떨어진 무작위 자세
    p = rng.uniform([-1.8, -1.8, -math.pi], [1.8, 1.8, math.pi], (3 * n + 40, 3))
    return p[clearance(p[:, 0], p[:, 1]) > 0.3][:n]
def state(r, last):                                          # 섹터(좌·전·우) × 3단계 × 직전 행동 → 0..80
    L, F, R = r[:, 7:].min(1), r[:, 2:7].min(1), r[:, :2].min(1)
    b = lambda d: np.digitize(d, [0.35, 0.7])
    return ((b(L) * 3 + b(F)) * 3 + b(R)) * 3 + last
def step(P, a):                                              # 운동학 + 보상
    v, w = ACT[a, 0], ACT[a, 1]
    th = P[:, 2] + w * DT
    nx, ny = P[:, 0] + v * DT * np.cos(th), P[:, 1] + v * DT * np.sin(th)
    hit = clearance(nx, ny) < RAD
    P2 = np.where(hit[:, None], P, np.stack([nx, ny, th], 1))
    r = cast(P2[:, 0], P2[:, 1], P2[:, 2])
    rew = 10 * v * DT * ~hit - 0.02 * (a > 0) - 0.3 * np.clip(0.35 - r[:, 3:6].min(1), 0, None) / 0.35 - 5.0 * hit
    return P2, r, rew, hit

E, Q, alpha, gamma = 32, np.zeros((81, 3)), 0.2, 0.95
returns = []
for ep in range(40):
    eps = max(0.05, 1.0 - ep / 25)
    P = spawn(E); last = np.zeros(E, int); s = state(cast(P[:, 0], P[:, 1], P[:, 2]), last); G = np.zeros(E)
    for k in range(100):                                     # 100 스텝 = 20 s
        a = np.where(rng.random(E) < eps, rng.integers(0, 3, E), Q[s].argmax(1))
        P, r, rew, hit = step(P, a)
        s2 = state(r, a)
        target = rew + gamma * Q[s2].max(1) * ~hit              # 충돌 = 종료 전이 (부트스트랩 없음)
        Q[s, a] += alpha * (target - Q[s, a])
        G += rew
        if hit.any():                                          # 충돌한 로봇은 새 위치에서 다시 시작
            P[hit] = spawn(hit.sum()); a = np.where(hit, 0, a)
            s2 = np.where(hit, state(cast(P[:, 0], P[:, 1], P[:, 2]), 0), s2)
        s, last = s2, a
    returns.append(G.mean())
    if ep % 10 == 9:
        print("에피소드 %2d  ε=%.2f  평균 보상 %6.2f" % (ep + 1, eps, G.mean()))
sim.plot(list(range(1, 41)), returns, "Q-learning 에피소드 평균 보상")

P = spawn(E); last = np.zeros(E, int); dist, nh = 0.0, np.zeros(E)       # 탐욕 정책 평가 60 s
for k in range(300):
    a = Q[state(cast(P[:, 0], P[:, 1], P[:, 2]), last)].argmax(1)
    P0 = P.copy(); P, r, rew, hit = step(P, a)
    dist += np.hypot(*(P[:, :2] - P0[:, :2]).T).sum(); nh += hit
    if hit.any(): P[hit] = spawn(hit.sum())
    last = a
print("평가 60 s × %d대: 주행 %.0f m, 충돌 %d회 → %.2f 회/100 m, 무충돌 비율 %.0f%%" % (E, dist, nh.sum(), 100 * nh.sum() / dist, 100 * (nh == 0).mean()))
print("방문한 상태 %d / 81" % (np.abs(Q).sum(1) > 0).sum())
print("POLICY =", repr("".join("FLR"[i] for i in Q.argmax(1))))
```

```text
에피소드 10  ε=0.64  평균 보상   9.82   (대략)
에피소드 20  ε=0.24  평균 보상  19.81
에피소드 30  ε=0.05  평균 보상  23.37
에피소드 40  ε=0.05  평균 보상  19.21
평가 60 s × 32대: 주행 220 m, 충돌 4회 → 1.82 회/100 m, 무충돌 비율 88%
방문한 상태 81 / 81
POLICY = 'LLLLLLRFRFFFFFFRFRFLLRFFFFFLLLLFFFRRLLLFLFRFLFFLRFFFFFLLLRLLRRRFFFFFRFFRFFFFFFFRF'
```

- 에피소드 40개(×32대 = 12만 전이)면 평균 보상이 36점 만점에 20점대로 오릅니다. 40번째에 조금 내려간 것은 무작위 시작 위치 때문이며, 학습 곡선 한 점으로 판단하지 않습니다.
- 평가에서 32대 중 4대가 한 번씩 부딪혔습니다(무충돌 88 %). **시드를 1~4로 바꿔** 돌려 보면 충돌 0인 시드도, 15회/100 m인 시드도 나옵니다(실험과 평가의 표).
- POLICY의 k번째 글자는 상태 k의 행동입니다. 예를 들어 상태 0(L·F·R 모두 위험, 직전 F)은 `L`입니다. 이 문자열을 실습 3·4와 정책 파일에 그대로 씁니다.

### 실습 2. 넘파이 DQN

같은 환경에서 12차원 연속 입력을 받는 2층 MLP를 재현 버퍼·타깃 네트워크·Adam으로 학습합니다. 역전파를 직접 쓰므로 식과 코드를 한 줄씩 맞춰 보세요.

```python run
import math, numpy as np
import mentorpi_sim as sim                                   # 시뮬 전용 (sim.plot)

rng = np.random.default_rng(0)
BOX = [(0.8, 0.8, 0.3, 0.3), (-0.9, 0.6, 0.3, 0.5), (0.7, -1.0, 0.5, 0.3)]   # arena 월드와 같은 배치
CYL = np.array([(-0.6, -0.8, 0.12), (0.0, 1.3, 0.12), (1.3, -0.1, 0.1)])
S = [(-2, -2, 2, -2), (2, -2, 2, 2), (2, 2, -2, 2), (-2, 2, -2, -2)]
for x, y, w, h in BOX:
    a, b, c, d = x - w / 2, y - h / 2, x + w / 2, y + h / 2
    S += [(a, b, c, b), (c, b, c, d), (c, d, a, d), (a, d, a, b)]
SEG = np.array(S, float)
RAY = np.radians([-90, -60, -30, -15, 0, 15, 30, 60, 90])    # 9개 빔 (0 = 전방, 반시계 +)
ACT = np.array([(0.18, 0.0), (0.0, 0.5), (0.0, -0.5)])       # 0 전진 F, 1 좌회전 L, 2 우회전 R  (v, ω)
DT, RAD = 0.2, 0.13                                          # 5 Hz 결정, 로봇 반지름
def cast(x, y, th):                                          # (E,) 자세 → (E, 9) 거리: 벡터화 광선 투사
    a = th[:, None] + RAY
    dx, dy = np.cos(a)[..., None], np.sin(a)[..., None]
    ox, oy = SEG[:, 0] - x[:, None, None], SEG[:, 1] - y[:, None, None]
    ex, ey = SEG[:, 2] - SEG[:, 0], SEG[:, 3] - SEG[:, 1]
    den = dx * ey - dy * ex + 1e-12
    t, u = (ox * ey - oy * ex) / den, (ox * dy - oy * dx) / den
    best = np.where((t > 0) & (u >= 0) & (u <= 1), t, 9).min(-1)
    cx, cy = CYL[:, 0] - x[:, None, None], CYL[:, 1] - y[:, None, None]
    b = dx * cx + dy * cy; disc = b * b - (cx * cx + cy * cy - CYL[:, 2] ** 2)
    tc = b - np.sqrt(np.maximum(disc, 0))
    return np.minimum(best, np.where((disc > 0) & (tc > 0), tc, 9).min(-1))
def clearance(x, y):                                         # 가장 가까운 장애물 표면까지 거리 (E,)
    px, py, ex, ey = SEG[:, 0], SEG[:, 1], SEG[:, 2] - SEG[:, 0], SEG[:, 3] - SEG[:, 1]
    t = np.clip(((x[:, None] - px) * ex + (y[:, None] - py) * ey) / (ex * ex + ey * ey), 0, 1)
    d = np.hypot(px + t * ex - x[:, None], py + t * ey - y[:, None]).min(1)
    return np.minimum(d, (np.hypot(CYL[:, 0] - x[:, None], CYL[:, 1] - y[:, None]) - CYL[:, 2]).min(1))
def spawn(n):                                                # 장애물에서 0.3 m 이상 떨어진 무작위 자세
    p = rng.uniform([-1.8, -1.8, -math.pi], [1.8, 1.8, math.pi], (3 * n + 40, 3))
    return p[clearance(p[:, 0], p[:, 1]) > 0.3][:n]
def step(P, a):                                              # 실습 1과 같은 운동학, 충돌 벌점만 −10
    v, w = ACT[a, 0], ACT[a, 1]
    th = P[:, 2] + w * DT
    nx, ny = P[:, 0] + v * DT * np.cos(th), P[:, 1] + v * DT * np.sin(th)
    hit = clearance(nx, ny) < RAD
    P = np.where(hit[:, None], P, np.stack([nx, ny, th], 1))
    r = cast(P[:, 0], P[:, 1], P[:, 2])
    rew = 10 * v * DT * ~hit - 0.02 * (a > 0) - 0.3 * np.clip(0.35 - r[:, 3:6].min(1), 0, None) / 0.35 - 10.0 * hit
    return P, r, rew, hit

obs = lambda r, last: np.hstack([np.minimum(r, 1.0), np.eye(3)[last]])   # 거리 9개(1 m 포화) + 직전 행동
W = {"W1": rng.normal(0, 0.4, (12, 32)), "b1": np.zeros(32), "W2": rng.normal(0, 0.2, (32, 3)), "b2": np.zeros(3)}
Wt = {k: v.copy() for k, v in W.items()}                     # 타깃 네트워크 θ⁻
Mo = {k: 0 * v for k, v in W.items()}; Ve = {k: 0 * v for k, v in W.items()}
def qnet(p, x):
    h = np.maximum(0, x @ p["W1"] + p["b1"]); return h @ p["W2"] + p["b2"], h
def learn(s, a, r, s2, d, it, lr=3e-3, gamma=0.95):         # 미니배치 한 번: TD 목표 → Huber(δ=3) → Adam
    y = r + gamma * qnet(Wt, s2)[0].max(1) * (1 - d)
    q, h = qnet(W, s)
    i = np.arange(len(a)); err = q[i, a] - y
    dq = np.zeros_like(q); dq[i, a] = np.clip(err, -3, 3) / len(a)
    dh = (dq @ W["W2"].T) * (h > 0)
    g = {"W2": h.T @ dq, "b2": dq.sum(0), "W1": s.T @ dh, "b1": dh.sum(0)}
    for k in W:
        Mo[k] = 0.9 * Mo[k] + 0.1 * g[k]; Ve[k] = 0.999 * Ve[k] + 0.001 * g[k] ** 2
        W[k] -= lr * Mo[k] / (1 - 0.9 ** it) / (np.sqrt(Ve[k] / (1 - 0.999 ** it)) + 1e-8)
    return float((err ** 2).mean())

E, N = 16, 20000                                             # 병렬 환경 16개, 재현 버퍼 2만 개
buf = [np.zeros((N, 12)), np.zeros(N, int), np.zeros(N), np.zeros((N, 12)), np.zeros(N)]
n, G, rets, losses = 0, np.zeros(E), [], []
P = spawn(E); o = obs(cast(P[:, 0], P[:, 1], P[:, 2]), np.zeros(E, int))
for it in range(1, 2001):
    eps = max(0.05, 1 - it / 1200)
    a = np.where(rng.random(E) < eps, rng.integers(0, 3, E), qnet(W, o)[0].argmax(1))
    P, r, rew, hit = step(P, a)
    o2 = obs(r, a); j = (n + np.arange(E)) % N; n += E
    for arr, val in zip(buf, (o, a, rew, o2, hit)): arr[j] = val
    G += rew
    if hit.any():
        P[hit] = spawn(hit.sum()); o2[hit] = obs(cast(P[hit, 0], P[hit, 1], P[hit, 2]), np.zeros(hit.sum(), int))
    o = o2
    for _ in range(2 if n >= 500 else 0):                    # 스텝마다 미니배치 64개 × 2회
        b = rng.integers(0, min(n, N), 64)
        losses.append(learn(*[arr[b] for arr in buf], len(losses) + 1))
    if it % 100 == 0:                                        # 100 스텝(20 s)마다 타깃 동기화
        Wt = {k: v.copy() for k, v in W.items()}; rets.append(G.mean()); G[:] = 0
        if it % 400 == 0:
            print("스텝 %4d  ε=%.2f  20 s 평균 보상 %6.2f  TD 손실 %.3f" % (it, eps, rets[-1], np.mean(losses[-200:])))
sim.plot(list(range(1, len(rets) + 1)), rets, "DQN 20 s 구간 평균 보상")

P = spawn(32); last = np.zeros(32, int); dist, nh = 0.0, np.zeros(32)
for t in range(300):                                         # 탐욕 정책 평가 60 s × 32대
    a = qnet(W, obs(cast(P[:, 0], P[:, 1], P[:, 2]), last))[0].argmax(1)
    P0 = P.copy(); P, r, rew, hit = step(P, a)
    dist += np.hypot(*(P[:, :2] - P0[:, :2]).T).sum(); nh += hit
    if hit.any(): P[hit] = spawn(hit.sum())
    last = a
print("평가: 주행 %.0f m, 충돌 %d회 → %.2f 회/100 m, 무충돌 비율 %.0f%%" % (dist, nh.sum(), 100 * nh.sum() / dist, 100 * (nh == 0).mean()))
print("가중치 %d개 → np.savez('dqn.npz', **W) 로 저장해 로봇에서 불러옵니다" % sum(v.size for v in W.values()))
```

### 실습 3. 도메인 무작위화

실습 1의 정책(기본)과, 에피소드마다 지연·미끄럼·거리 편향·잡음·빔 누락을 무작위로 바꾸며 새로 학습한 정책(DR)을 네 가지 시험 조건에서 비교합니다.

```python run

rng = np.random.default_rng(0)
BOX = [(0.8, 0.8, 0.3, 0.3), (-0.9, 0.6, 0.3, 0.5), (0.7, -1.0, 0.5, 0.3)]   # arena 월드와 같은 배치

    S += [(a, b, c, b), (c, b, c, d), (c, d, a, d), (a, d, a, b)]

    ex, ey = SEG[:, 2] - SEG[:, 0], SEG[:, 3] - SEG[:, 1]
    den = dx * ey - dy * ex + 1e-12
    t, u = (ox * ey - oy * ex) / den, (ox * dy - oy * dx) / den
    best = np.where((t > 0) & (u >= 0) & (u <= 1), t, 9).min(-1)
    cx, cy = CYL[:, 0] - x[:, None, None], CYL[:, 1] - y[:, None, None]
    b = dx * cx + dy * cy; disc = b * b - (cx * cx + cy * cy - CYL[:, 2] ** 2)
    tc = b - np.sqrt(np.maximum(disc, 0))
    return np.minimum(best, np.where((disc > 0) & (tc > 0), tc, 9).min(-1))
def clearance(x, y):                                         # 가장 가까운 장애물 표면까지 거리 (E,)
    px, py, ex, ey = SEG[:, 0], SEG[:, 1], SEG[:, 2] - SEG[:, 0], SEG[:, 3] - SEG[:, 1]
    t = np.clip(((x[:, None] - px) * ex + (y[:, None] - py) * ey) / (ex * ex + ey * ey), 0, 1)
    d = np.hypot(px + t * ex - x[:, None], py + t * ey - y[:, None]).min(1)
    return np.minimum(d, (np.hypot(CYL[:, 0] - x[:, None], CYL[:, 1] - y[:, None]) - CYL[:, 2]).min(1))
def spawn(n):                                                # 장애물에서 0.3 m 이상 떨어진 무작위 자세
    p = rng.uniform([-1.8, -1.8, -math.pi], [1.8, 1.8, math.pi], (3 * n + 40, 3))
    return p[clearance(p[:, 0], p[:, 1]) > 0.3][:n]
def state(r, last):                                          # 섹터(좌·전·우) × 3단계 × 직전 행동 → 0..80
    L, F, R = r[:, 7:].min(1), r[:, 2:7].min(1), r[:, :2].min(1)
    b = lambda d: np.digitize(d, [0.35, 0.7])
    return ((b(L) * 3 + b(F)) * 3 + b(R)) * 3 + last

POLICY = 'LLLLLLRFRFFFFFFRFRFLLRFFFFFLLLLFFFRRLLLFLFRFLFFLRFFFFFLLLRLLRRRFFFFFRFFRFFFFFFFRF'  # 실습 1 결과
def step(P, a, k):                                           # k: 도메인 파라미터 (환경마다 다름)
    a, k["prev"] = np.where(rng.random(len(a)) < k["lag"], k["prev"], a), a    # 지연: 한 주기 전 명령이 실행됨
    v, w = ACT[a, 0] * k["slip"], ACT[a, 1] * k["slip"]                         # 미끄럼: 명령보다 덜 움직임
    th = P[:, 2] + w * DT
    nx, ny = P[:, 0] + v * DT * np.cos(th), P[:, 1] + v * DT * np.sin(th)
    hit = clearance(nx, ny) < RAD
    P = np.where(hit[:, None], P, np.stack([nx, ny, th], 1))
    r = cast(P[:, 0], P[:, 1], P[:, 2]) + k["bias"][:, None] + rng.normal(0, 1, (len(a), 9)) * k["sd"][:, None]
    r[rng.random(r.shape) < k["drop"][:, None]] = 9.0                           # 빔 누락 → inf
    rew = 10 * v * DT * ~hit - 0.02 * (a > 0) - 0.3 * np.clip(0.35 - r[:, 3:6].min(1), 0, None) / 0.35 - 5.0 * hit
    return P, r, rew, hit
def domain(E, rand=False, **fixed):                         # 환경 E개의 도메인 파라미터
    if rand:   # 무작위화 범위: 지연 0~1주기, 미끄럼 0.7~1.0, 거리 편향 0~0.2 m, 잡음 0~5 cm, 누락 0~5 %
        u = lambda lo, hi: rng.uniform(lo, hi, E)
        k = {"lag": u(0, 1), "slip": u(0.7, 1), "bias": u(0, 0.2), "sd": u(0, 0.05), "drop": u(0, 0.05)}
    else:
        base = {**dict(lag=0.0, slip=1.0, bias=0.0, sd=0.0, drop=0.0), **fixed}
        k = {n: np.full(E, float(v)) for n, v in base.items()}
    k["prev"] = np.zeros(E, int)
    return k
def train_dr(E=32, EP=50):
    Q = np.zeros((81, 3))
    for ep in range(EP):
        eps, k = max(0.05, 1.0 - ep / 30), domain(E, rand=True)                 # 에피소드마다 새 도메인
        P = spawn(E); s = state(cast(P[:, 0], P[:, 1], P[:, 2]), np.zeros(E, int))
        for t in range(100):
            a = np.where(rng.random(E) < eps, rng.integers(0, 3, E), Q[s].argmax(1))
            P, r, rew, hit = step(P, a, k)
            s2 = state(r, a)
            Q[s, a] += 0.2 * (rew + 0.95 * Q[s2].max(1) * ~hit - Q[s, a])
            if hit.any():
                P[hit] = spawn(hit.sum()); s2 = np.where(hit, state(cast(P[:, 0], P[:, 1], P[:, 2]), 0), s2)
            s = s2
    return Q
def evaluate(Q, k, E=32, T=200):
    P = spawn(E); last = np.zeros(E, int); dist, nh = 0.0, np.zeros(E)
    r = cast(P[:, 0], P[:, 1], P[:, 2])
    for t in range(T):
        a = Q[state(r, last)].argmax(1)
        P0 = P.copy(); P, r, rew, hit = step(P, a, k)
        dist += np.hypot(*(P[:, :2] - P0[:, :2]).T).sum(); nh += hit
        if hit.any(): P[hit] = spawn(hit.sum()); r[hit] = cast(P[hit, 0], P[hit, 1], P[hit, 2])
        last = a
    return 100 * nh.sum() / dist

Q0 = np.eye(3)[["FLR".index(c) for c in POLICY]]            # 실습 1 정책을 Q 표 모양으로
Qdr = train_dr()
TESTS = {"이상적": {}, "지연+미끄럼": dict(lag=0.5, slip=0.8), "거리 편향 +12 cm": dict(bias=0.12),
         "실물 같은 조합": dict(lag=0.5, slip=0.8, bias=0.12, sd=0.03, drop=0.03)}
print("충돌 회/100 m        기본 정책   DR 정책")
for name, kw in TESTS.items():
    print("%-16s %8.2f %9.2f" % (name, evaluate(Q0, domain(32, **kw)), evaluate(Qdr, domain(32, **kw))))
print("DR POLICY =", repr("".join("FLR"[i] for i in Qdr.argmax(1))))
```

- 기본 정책은 **거리 편향 +12 cm**(장애물이 실제보다 멀어 보임)에서 무너집니다(34.5회/100 m). 정책이 0.35 m 경계에 딱 맞춰 회전을 배웠기 때문에, 12 cm만 어긋나도 너무 늦게 돕니다. DR 정책은 절반 이하(14.9)입니다.
- 지연 0.5 + 미끄럼 0.8은 이 정책에게는 의외로 큰 문제가 아니었습니다. 속도가 느리고(0.18 m/s) 결정 주기가 짧기 때문입니다. **어떤 간극이 문제인지는 측정해 봐야 압니다.**
- DR이 공짜는 아닙니다. 시드를 바꾸면 DR 정책이 이상적 환경에서 더 나쁜 경우도 나옵니다(실험과 평가). 마지막 줄의 DR POLICY를 실습 4에 넣어 실제 주행 모양도 비교하세요.

### 실습 4. 정책을 ROS 2 노드로: Playground 평가

학습한 문자열 정책을 rclpy 노드에 넣어 가상 MentorPi를 arena 월드에서 30 s 주행합니다. `/scan`(360개 빔)에서 학습 때와 같은 9개 각도를 **각도로 골라**(인덱스 아님, M05) 상태를 만들고, 정책 → 안전 덮어쓰기 → 속도 제한 순서로 `/controller/cmd_vel`을 냅니다. 실물에서는 `# 시뮬 전용` 두 줄을 지우고 `scan_topic`을 `/scan_raw`로 바꿉니다.

```python run
import math
import numpy as np
import rclpy
from rclpy.node import Node
from rclpy.qos import qos_profile_sensor_data
from geometry_msgs.msg import Twist
from sensor_msgs.msg import LaserScan
from nav_msgs.msg import Odometry
import mentorpi_sim as sim                                        # 시뮬 전용
sim.setup(world="arena", duration=30.0, start=(0.0, 0.0, 0.0))  # 시뮬 전용

POLICY = 'LLLLLLRFRFFFFFFRFRFLLRFFFFFLLLLFFFRRLLLFLFRFLFFLRFFFFFLLLRLLRRRFFFFFRFFRFFFFFFFRF'  # 실습 1
RAY = np.radians([-90, -60, -30, -15, 0, 15, 30, 60, 90])       # 학습 때와 같은 9개 빔
ACT = {'F': (0.18, 0.0), 'L': (0.0, 0.5), 'R': (0.0, -0.5)}
V_MAX, W_MAX = 0.2, 0.5                                          # 실물 안전 한계
STOP_D, HALF = 0.22, math.radians(45)                            # 안전 규칙: lidar_controller처럼 전방 ±45°를 좌·우로

class RLPolicy(Node):
    def __init__(self):
        super().__init__('rl_policy')
        self.declare_parameter('scan_topic', '/scan')             # 실물: /scan_raw
        self.cmd = self.create_publisher(Twist, '/controller/cmd_vel', 1)
        self.create_subscription(LaserScan, self.get_parameter('scan_topic').value, self.on_scan, qos_profile_sensor_data)
        self.create_subscription(Odometry, '/odom', self.on_odom, 10)
        self.scan, self.last, self.prev_xy, self.dist = None, 0, None, 0.0
        self.n_step, self.n_override, self.n_flip, self.min_r = 0, 0, 0, 9.0
        self.count = {'F': 0, 'L': 0, 'R': 0}
        self.create_timer(0.2, self.tick)                         # 학습과 같은 5 Hz
    def on_scan(self, msg):
        self.scan = msg
    def on_odom(self, m):
        p = m.pose.pose.position
        if self.prev_xy: self.dist += math.hypot(p.x - self.prev_xy[0], p.y - self.prev_xy[1])
        self.prev_xy = (p.x, p.y)
    def observe(self):
        s = self.scan
        r = np.array(s.ranges, dtype=float)
        r[~np.isfinite(r) | (r < s.range_min)] = 9.0              # inf·0 → 멀리 (학습 환경의 9 m)
        a = s.angle_min + np.arange(len(r)) * s.angle_increment
        diff = np.abs(np.arctan2(np.sin(a[None, :] - RAY[:, None]), np.cos(a[None, :] - RAY[:, None])))
        beams = np.where(diff < math.radians(3), r[None, :], 9.0).min(1)   # 빔마다 ±3° 최소
        return beams, r, np.arctan2(np.sin(a), np.cos(a))
    def tick(self):
        if self.scan is None: return
        beams, r, a = self.observe()
        b = lambda d: int(np.digitize(d, [0.35, 0.7]))
        s = ((b(beams[7:].min()) * 3 + b(beams[2:7].min())) * 3 + b(beams[:2].min())) * 3 + self.last
        act = POLICY[s]
        v, w = ACT[act]
        left = r[(a > 0) & (a <= HALF)].min(); right = r[(a < 0) & (a >= -HALF)].min()
        if min(left, right) < STOP_D:                             # 안전 덮어쓰기: 전진 금지, 먼 쪽으로 회전
            v, w = 0.0, (-W_MAX if left < right else W_MAX)
            act = 'R' if w < 0 else 'L'; self.n_override += 1
        t = Twist()
        t.linear.x = max(-V_MAX, min(V_MAX, v)); t.angular.z = max(-W_MAX, min(W_MAX, w))
        self.cmd.publish(t)
        self.n_flip += {self.last, 'FLR'.index(act)} == {1, 2}            # 좌↔우 뒤집기 = 진동
        self.last = 'FLR'.index(act); self.count[act] += 1; self.n_step += 1
        self.min_r = min(self.min_r, float(r.min()))
    def report(self):
        self.get_logger().info('결정 %d회 %s, 좌우 진동 %d회, 안전 덮어쓰기 %d회' % (
            self.n_step, self.count, self.n_flip, self.n_override))
        self.get_logger().info('주행 %.2f m, 최소 라이다 거리 %.2f m' % (self.dist, self.min_r))

rclpy.init()
node = RLPolicy()
try:
    rclpy.spin(node)
except KeyboardInterrupt:
    pass
finally:
    node.cmd.publish(Twist())
    node.report()
    node.destroy_node()
    rclpy.shutdown()
```

### 3) 정책 노드

```python robot
#!/usr/bin/env python3
# rl_policy_node.py — 학습한 정책 + 안전 덮어쓰기 + 워치독
import json
import math
import os
import numpy as np
import rclpy
from rclpy.node import Node
from rclpy.qos import qos_profile_sensor_data
from geometry_msgs.msg import Twist
from sensor_msgs.msg import LaserScan
from std_msgs.msg import String
from std_srvs.srv import SetBool

class RLPolicyNode(Node):
    def __init__(self):
        super().__init__('rl_policy')
        self.declare_parameter('policy_file', '/home/ubuntu/rl/policy.json')
        self.declare_parameter('stop_dist', 0.25)       # 안전 덮어쓰기 임계 [m]
        self.declare_parameter('scan_angle', 90.0)      # lidar_controller와 같은 전방 감시각 [deg]
        self.declare_parameter('max_linear', 0.2)
        self.declare_parameter('max_angular', 0.5)
        p = lambda n: self.get_parameter(n).value
        self.stop_d, self.half = p('stop_dist'), math.radians(p('scan_angle') / 2)
        self.vmax, self.wmax = min(0.2, p('max_linear')), min(0.5, p('max_angular'))   # 상한은 코드로 고정
        with open(p('policy_file')) as f:
            self.spec = json.load(f)
        self.rays = np.radians(self.spec['rays_deg'])
        self.mlp = None
        if self.spec['type'] == 'dqn':
            w = np.load(os.path.join(os.path.dirname(p('policy_file')), self.spec['weights']))
            self.mlp = {k: w[k] for k in ('W1', 'b1', 'W2', 'b2')}
        self.cmd = self.create_publisher(Twist, '/controller/cmd_vel', 1)
        self.status = self.create_publisher(String, '~/status', 10)
        self.create_subscription(LaserScan, '/scan_raw', self.on_scan, qos_profile_sensor_data)
        self.create_service(SetBool, '~/enable', self.on_enable)
        self.enabled, self.scan, self.scan_t, self.last = False, None, -1e9, 0
        self.n, self.n_override = 0, 0
        self.create_timer(self.spec['dt'], self.tick)
        self.get_logger().info('policy %s loaded (%s)' % (p('policy_file'), self.spec['type']))
    def now(self):
        return self.get_clock().now().nanoseconds * 1e-9
    def on_scan(self, msg):
        self.scan, self.scan_t = msg, self.now()
    def on_enable(self, req, res):
        self.enabled = req.data
        if not self.enabled:
            self.cmd.publish(Twist())
        res.success, res.message = True, 'enabled' if self.enabled else 'disabled'
        return res
    def observe(self):                                   # 학습 환경과 같은 전처리
        s = self.scan
        r = np.array(s.ranges, dtype=float)
        bad = ~np.isfinite(r) | (r <= max(s.range_min, 0.01))
        r[bad] = 9.0                                     # 0·inf → 멀리 (lidar_controller도 제외)
        a = s.angle_min + np.arange(len(r)) * s.angle_increment
        a = np.arctan2(np.sin(a), np.cos(a))
        d = np.abs(np.arctan2(np.sin(a[None, :] - self.rays[:, None]), np.cos(a[None, :] - self.rays[:, None])))
        beams = np.where(d < math.radians(3), r[None, :], 9.0).min(1)
        return beams, r, a
    def decide(self, beams):
        if self.mlp:                                     # DQN: 넘파이 행렬곱 두 번
            x = np.hstack([np.minimum(beams, self.spec['clip']), np.eye(3)[self.last]])
            h = np.maximum(0, x @ self.mlp['W1'] + self.mlp['b1'])
            return int(np.argmax(h @ self.mlp['W2'] + self.mlp['b2']))
        b = lambda k: int(np.digitize(beams[slice(*self.spec['sectors'][k])].min(), self.spec['bins']))
        s = ((b('L') * 3 + b('F')) * 3 + b('R')) * 3 + self.last
        return 'FLR'.index(self.spec['policy'][s])
    def tick(self):
        t = Twist()
        if not self.enabled:
            return
        if self.scan is None or self.now() - self.scan_t > 0.5:   # 워치독
            self.cmd.publish(t)
            self.get_logger().warn('no /scan_raw for 0.5 s -> stop', throttle_duration_sec=2.0)
            return
        beams, r, a = self.observe()
        act = self.decide(beams)
        v, w = self.spec['actions']['FLR'[act]]
        left = r[(a > 0) & (a <= self.half)].min()
        right = r[(a < 0) & (a >= -self.half)].min()
        override = min(left, right) < self.stop_d
        if override:                                     # 안전 덮어쓰기 (lidar_controller 규칙)
            v, w = 0.0, (-self.wmax if left < right else self.wmax)
            self.n_override += 1
        t.linear.x = max(-self.vmax, min(self.vmax, v))
        t.angular.z = max(-self.wmax, min(self.wmax, w))
        self.cmd.publish(t)
        self.last = 0 if t.linear.x > 0 else (1 if t.angular.z > 0 else 2)
        self.n += 1
        self.status.publish(String(data='policy=%s final=%s override=%d rate=%.1f%%' % (
            'FLR'[act], 'FLR'[self.last], override, 100.0 * self.n_override / self.n)))

def main():
    rclpy.init()
    node = RLPolicyNode()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.cmd.publish(Twist())
        node.destroy_node()
        rclpy.shutdown()

if __name__ == '__main__':
    main()
```

- 상태의 "직전 행동"에는 정책이 고른 행동이 아니라 **실제로 실행된 행동**(덮어쓰기 뒤)을 넣습니다. 학습 환경에서도 상태의 $a_{prev}$는 실행된 행동이었기 때문입니다.
- 정지 상태에서 `self.last`가 R로 기록되는 것은 무해합니다(정지는 덮어쓰기 없이 나오지 않음).
- 라이다가 거꾸로 장착됐거나 각도 기준이 다르면 M05처럼 각도 오프셋을 더하세요. 인덱스로 방향을 가정하지 않고 `angle_min + i·Δθ`로 계산하는 이유입니다.

## 실험과 평가

### 지표 정의

| 지표 | 정의 | 왜 필요한가 |
|---|---|---|
| 100 m당 충돌 | 충돌 수 ÷ 실제 주행 거리 × 100 | 많이 달린 정책이 불리하지 않도록 거리로 정규화 |
| 무충돌 비율 | 60 s 시험 중 한 번도 안 부딪힌 비율 | "대부분은 괜찮은데 가끔 크게 실패"를 드러냄 |
| 주행 거리 | 같은 시간 동안 이동한 거리 | 안 움직이는 정책(충돌 0)이 1등하는 것을 막음 |
| 좌우 진동 | L↔R 뒤집기 횟수 | 실물에서 모터 부하·흔들림 |
| 안전 개입률 | 덮어쓰기 횟수 ÷ 결정 횟수 | 정책이 실물에서 위험한 행동을 고른 빈도 = 간극의 크기 |

### 결과 1: 시드 5개, 같은 넘파이 평가 (32대 × 60 s)

실습 1·2의 코드에서 `default_rng(0)`만 0~4로 바꿔 측정한 실제 값입니다. 규칙 기준선은 같은 환경에서 "전방 섹터 < 임계값이면 좌·우 중 넓은 쪽으로 회전, 아니면 전진"입니다.

| 정책 | 100 m당 충돌 (시드 0/1/2/3/4) | 평균 | 무충돌 비율 평균 | 주행 거리 평균 |
|---|---|---|---|---|
| 무작위 | 74.7 / 77.3 / 77.6 / 81.1 / 68.3 | 75.8 | 4 % | 114 m |
| 항상 전진 | 83.2 / 90.2 / 85.3 / 88.7 / 89.3 | 87.3 | 0 % | 335 m |
| 규칙 (임계 0.6 m, 원본 기본값) | 0 / 0 / 0 / 0 / 0 | 0.0 | 100 % | 81 m |
| 규칙 (임계 0.35 m) | 0 / 0 / 0 / 0 / 0 | 0.0 | 100 % | 208 m |
| Q-러닝 (40 에피소드) | 1.82 / 0 / 0 / 15.76 / 0 | 3.5 | 86 % | 237 m |
| DQN (2000 스텝) | 1.16 / 2.68 / 13.79 / 11.43 / 9.18 | 7.6 | 60 % | 265 m |

해석:

- **잘 튜닝한 규칙이 이 짧은 학습 예산의 RL보다 안전합니다.** 대신 RL 정책은 같은 시간에 14~27 % 더 멀리 갑니다. "더 빨리 탐험하되 가끔 부딪힌다"는 트레이드오프이며, 무엇이 나은지는 요구사항(N2)이 정합니다.
- 원본 기본 임계 0.6 m 규칙은 4 × 4 m 경기장에서 너무 조심스러워 81 m밖에 못 갑니다. 규칙의 약점은 **환경마다 손으로 다시 맞춰야** 한다는 점입니다.
- RL은 시드 분산이 큽니다. 시드 하나로 결론을 내면 안 됩니다. 연구 논문이 여러 시드의 평균과 신뢰구간을 보고하는 이유입니다.

### 결과 2: 도메인 무작위화 (100 m당 충돌, 시드 0~3)

| 시험 조건 | 기본 정책 (시드 0/1/2/3) | 평균 | DR 정책 (시드 0/1/2/3) | 평균 |
|---|---|---|---|---|
| 이상적 | 1.38 / 1.46 / 2.28 / 4.07 | 2.3 | 0.00 / 7.70 / 3.64 / 0.00 | 2.8 |
| 지연 0.5 + 미끄럼 0.8 | 0.00 / 0.00 / 0.89 / 3.51 | 1.1 | 0.00 / 7.96 / 7.06 / 0.00 | 3.8 |
| 거리 편향 +12 cm | 34.52 / 34.30 / 29.82 / 33.88 | 33.1 | 14.92 / 5.27 / 5.00 / 8.87 | 8.5 |
| 실물 같은 조합 | 18.04 / 22.30 / 26.09 / 12.51 | 19.7 | 11.93 / 16.71 / 28.85 / 8.35 | 16.5 |

(기본 정책은 실습 1의 같은 정책이고, 시드는 DR 학습과 평가 난수만 바꿉니다.)

- DR은 **거리 편향**에 대해 확실히 효과가 있습니다(33 → 8.5). 편향을 훈련 분포에 넣었기 때문입니다.
- 이상적 환경과 지연 조건에서는 오히려 약간 나빠졌습니다. 81칸 표 하나로 모든 도메인을 만족할 수 없어서 생기는 **보수성·표현력의 대가**입니다. 실습 4에서 본 DR 정책의 진동도 같은 뿌리입니다.
- 결론: DR은 "켜면 좋아지는 스위치"가 아니라, **실물에서 측정한 간극에 맞춰 범위를 정하는 설계 작업**입니다.

### 결과 3: 실물 (팀이 채움)

정책(`lidar_controller` 0.5 m, Q-러닝 기본, Q-러닝 DR, DQN)마다 3회씩 접촉 수, 주행 거리, 개입률, 진동 횟수를 같은 표에 기록합니다. 가장 중요한 관찰은 시뮬과 실물의 **순위가 같은지**입니다. 순위가 뒤집혔다면 어떤 간극 때문인지 T4·T5 시험으로 추적하세요.

## 확장 과제

- **Double DQN**: 목표를 $y = r + \gamma Q_{\theta^-}(s', \arg\max_{a'} Q_\theta(s', a'))$로 바꿔 과대추정을 줄이고, 시드 5개 평균으로 효과를 보입니다.
- **연속 행동**: 행동을 5개(강한·약한 좌우 회전 포함)로 늘리거나, DDPG/SAC 같은 연속 행동 알고리즘을 조사해 선속도·각속도를 직접 내게 합니다.
- **목표 도달 과제**: 상태에 목표 방향·거리를 넣고 보상에 목표 접근을 추가해 "장애물을 피하며 목표로 가는" 정책을 만듭니다. Nav2 DWB와 비교합니다.
- **안전 강화학습**: 덮어쓰기가 개입한 전이에 벌점을 주거나(shielding), 제약 MDP(CMDP)로 충돌 확률 상한을 둡니다.
- **시스템 식별 + DR**: 실물 `/odom`과 명령을 녹화(rosbag)해 미끄럼·지연을 추정하고, 그 값 주변으로 DR 범위를 좁힙니다.
- **애커만 섀시**: 제자리 회전이 불가능한 애커만(최대 조향 29°)에 맞게 행동을 (v, δ)로 바꿔 다시 학습합니다.

## 자주 나는 오류와 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 학습 곡선이 전혀 오르지 않음 | ε가 너무 빨리 0이 됨, 또는 충돌을 종료로 처리하지 않아 가치가 폭주 | ε 감소 기간 늘리기, `* ~hit`로 종료 처리 |
| 정책이 제자리 회전만 함 | 진행 보상이 회전 비용·근접 벌점보다 작음 | 보상 항의 크기를 한 스텝 기준으로 계산해 비교 |
| DQN 손실이 NaN | 학습률이 크거나 입력이 inf(라이다 inf를 그대로 넣음) | 입력을 1 m에서 포화(`np.minimum`), lr 3e-3 이하 |
| 보상을 바꿔도 DQN 결과가 같음 | Huber δ가 오차를 잘라 벌점 크기가 전달되지 않음 | δ를 보상 규모에 맞추기(실습 2는 3) |
| Playground에서는 잘 되는데 실물에서 계속 덮어쓰기 | 라이다 각도 기준·장착 오프셋이 다름, 짐 때문에 반지름 증가 | `angle_min + i·Δθ`로 각도 계산, 각도 오프셋 보정, DR에 편향 추가 |
| 실물 노드가 움직이지 않음 | `~/enable`을 안 켬, `controller.launch.py` 미실행 | `ros2 service call /rl_policy/enable ...`, `ros2 topic echo /controller/cmd_vel` |
| `/scan_raw` 콜백이 안 불림 | QoS 불일치 | `qos_profile_sensor_data` 사용 (M05) |
| 로봇이 좌우로 떨기만 함 | 경계 상태에서 L/R 번갈아 선택(DR 정책에서 흔함) | 진동 지표 확인, 회전 비용 증가, 같은 회전 방향 유지 규칙(히스테리시스) |
| 정책 파일을 바꿨는데 동작이 이상함 | 학습 때와 다른 빔 각도·단계 경계 | 전처리 파라미터를 정책 파일에 함께 저장하고 노드가 그것을 읽게 함 |

## 과제

3. DQN에 Double DQN과 학습 스텝 2배를 적용하고, 시드 5개 평균이 표 기반 Q-러닝을 이기는지 검정합니다(평균과 표준편차, 가능하면 부트스트랩 신뢰구간).
