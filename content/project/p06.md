## 학습 목표

- 점-점 ICP(Iterative Closest Point)의 목적함수에서 SVD(Kabsch) 닫힌 해를 유도하고, 최근접 이웃·이상치 제거·수렴 판정을 갖춘 ICP를 NumPy로 구현합니다.
- 점-선(point-to-line) ICP를 가우스-뉴턴으로 풀고, 정보 행렬 $H = JᵀJ$로 공분산과 **퇴화**(긴 복도)를 판정합니다.
- 연속 스캔 매칭을 합성해 **스캔 매칭 오도메트리**를 만들고, 휠 오도메트리·정답과 ATE/RPE로 비교합니다.
- 상태 $[x, y, θ, v, ω]$의 EKF를 직접 구현해 휠 속도·IMU 각속도·ICP 속도를 다중 주기로 융합하고, NEES/NIS로 공분산 튜닝의 일관성을 검사합니다.
- MentorPi의 `robot_localization` 설정(`controller/config/ekf.yaml`)과 rf2o 레이저 오도메트리를 읽고, 직접 만든 융합기와 실물에서 비교합니다.

## 프로젝트 개요와 요구사항

M03에서 보았듯 MentorPi의 `/odom`은 휠 속도와 IMU를 `robot_localization`이 융합한 값입니다. 휠은 미끄러지면 모르고, 로봇이 벽에 막혀도 명령 속도를 적분하므로 거리가 계속 늘어납니다. 라이다는 **주변이 어떻게 움직였는지**를 직접 보므로 이런 오차를 잡을 수 있습니다. 원본에도 이 아이디어가 들어 있습니다: `ekf.yaml`의 `odom1: odom_rf2o`와 `controller/launch/rf2o_laser_odometry.launch.py`. 다만 기본 `controller.launch.py`는 rf2o를 켜지 않습니다.

이 프로젝트에서는 그 부품들을 **직접 만듭니다**: 스캔 두 장의 상대 이동을 구하는 ICP, 그것을 이어 붙인 스캔 오도메트리, 여러 센서를 확률적으로 합치는 EKF. 그리고 원본의 `robot_localization` + rf2o와 같은 조건에서 비교해, 무엇이 왜 더 좋거나 나쁜지 수치로 설명합니다.

## 이론

### 스캔 매칭과 SE(2)

2D 자세 $T = (x, y, θ)$는 점 $p$를 $T(p) = R(θ)·p + t$로 옮깁니다($R(θ)$는 2 × 2 회전 행렬, $t = [x, y]ᵀ$). 두 자세의 **합성** $T_1 ⊕ T_2$는 "T₁ 좌표계에서 본 T₂"를 바깥 좌표로 옮기는 것입니다.

```text
(x1, y1, θ1) ⊕ (x2, y2, θ2) = (x1 + cosθ1·x2 − sinθ1·y2,  y1 + sinθ1·x2 + cosθ1·y2,  θ1 + θ2)
```

스캔 매칭은 이전 스캔 $Q$ 좌표계에서 본 현재 스캔 $P$의 자세 $Δ_k$를 찾는 문제이고, 스캔 오도메트리는 $T_k = T_{k−1} ⊕ Δ_k$로 이어 붙입니다. 매 스캔의 작은 오차가 합성되며 쌓이므로 **드리프트**는 피할 수 없습니다. 이를 끊으려면 지도와 맞추거나(scan-to-map, slam_toolbox) 루프를 닫아야 합니다(M09).

### 점-점 ICP와 SVD 닫힌 해

Besl & McKay(1992)의 ICP는 "대응을 모르는 정합"을 두 단계 반복으로 풉니다: ① 현재 추정으로 $P$를 옮겨 각 점의 **최근접 이웃** $q_{j(i)}$를 대응으로 삼고, ② 대응이 고정됐다고 보고 최소제곱 변환을 구합니다.

② 단계의 목적함수는 $E(R, t) = Σ_i ‖R·p_i + t − q_i‖²$입니다. $t$로 미분해 0으로 두면 $t = q̄ − R·p̄$ (두 무게중심 $p̄, q̄$)가 나오고, 중심을 뺀 $p′_i = p_i − p̄$, $q′_i = q_i − q̄$로 다시 쓰면

```text
E(R) = Σ ‖R p′_i − q′_i‖² = Σ (‖p′_i‖² + ‖q′_i‖²) − 2 · trace(R · W),   W = Σ p′_i q′_iᵀ  (2×2 교차공분산)
```

이므로 $trace(R·W)$를 최대화하면 됩니다. $W = U Σ Vᵀ$ (SVD)라 하면 $trace(R U Σ Vᵀ) = trace(Vᵀ R U · Σ)$이고, 직교행렬 $Vᵀ R U$의 대각 원소는 1 이하이므로 $Vᵀ R U = I$일 때 최대, 즉 **$R = V Uᵀ$**입니다. $det(R) = −1$(반사)이 나오면 $V$의 마지막 열 부호를 바꿉니다(Kabsch 1976, Arun 1987). 2D에서는 $θ = atan2(W_{01} − W_{10}, W_{00} + W_{11})$로도 같습니다.

```text
T ← T0
repeat (최대 N회):
    P' ← T(P)
    j(i) ← argmin_j ‖P'_i − Q_j‖                        # 최근접 이웃
    keep ← d_i < max(τ, 3·median(d))                    # 이상치 제거
    (R, t) ← Kabsch(P'[keep], Q[j[keep]])               # 증분 변환
    T ← (R, t) ∘ T
until ‖t‖ < ε_t and |∠R| < ε_θ
```

| 요소 | 선택 | 이유 |
|---|---|---|
| 최근접 이웃 | 전수 $O(NM)$ / k-d 트리 $O(N log M)$ | 라이다 360점은 전수도 수 ms. 3D 점군은 트리 필수 |
| 이상치 | 거리 게이트 τ, 중앙값 배수, Trimmed ICP(가까운 80 %만) | 새로 보인 벽·움직이는 사람·가려짐 |
| 초기값 | 직전 이동(등속), 또는 휠 오도메트리 | ICP는 **국소 최적화** — 멀리서 시작하면 틀린 극소 |
| 수렴 | 증분 < ε, 최대 반복 | 잔차 감소가 멈추면 끝 |

### 점-선 ICP와 가우스-뉴턴

라이다는 벽의 **같은 점**을 두 번 재지 않습니다. 1° 간격 빔이 로봇이 움직이면 벽의 다른 곳에 떨어지므로, 점-점 대응은 "빔끼리"의 거짓 대응이 되고 ICP는 제자리에 붙잡힙니다(**표본화 편향**, 실습 2에서 확인). 점-선 ICP(Chen & Medioni 1991, Censi 2008 PL-ICP)는 대응점 $q_i$에서의 벽 법선 $n_i$ 방향 거리만 벌합니다.

```text
r_i(ξ) = n_iᵀ (R(θ) p_i + t − q_i),    ξ = (x, y, θ)
J_i   = ∂r_i/∂ξ = [ n_x,  n_y,  n_iᵀ S (p′_i − t) ],    S = [[0, −1], [1, 0]]  (90° 회전)
(Σ J_iᵀ J_i) Δξ = −Σ J_iᵀ r_i          # 가우스-뉴턴 정규방정식,  H = Σ J_iᵀ J_i
```

법선은 스캔 순서의 이웃 두 점 차 $q_{i+1} − q_{i−1}$에 수직인 단위벡터로 구하고, 이웃이 멀면(모서리·끊김) 그 점을 버립니다. 점-선은 벽을 따라 미끄러지는 방향을 벌하지 않으므로 표본화 편향이 없고 보통 3~6회에 수렴합니다.

**공분산.** 잔차가 독립 잡음 $σ$를 가진다고 보면 추정 공분산은 $Σ_ξ ≈ σ²·H⁻¹$입니다(Censi 2007은 대응 변화까지 고려한 더 정확한 식을 줍니다). 이 값을 EKF의 측정 공분산으로 넘깁니다.

### 퇴화: 긴 복도 문제

$H$의 병진 부분 $H_{xy} = Σ n_i n_iᵀ$의 고윳값 $λ_{min} ≤ λ_{max}$를 봅시다. 좌우 벽만 보이는 복도에서는 모든 법선이 ±y 방향이라 $H_{xy} ≈ diag(0, N)$ — **x(복도 방향) 이동은 잔차를 바꾸지 않으므로 관측 불가능**합니다. ICP는 그 방향으로 아무 값이나(보통 초기값 근처) 돌려줍니다.

| 판정 | 식 | 쓰임 |
|---|---|---|
| 조건수 | $κ = λ_{max} / λ_{min}$ | κ > 100이면 퇴화로 간주 (실습 4: 정상 8, 복도 44 이상) |
| 퇴화 인자 (Zhang 2016) | $λ_{min}$ 자체가 임계값 이하 | 점 수·잡음에 맞춰 임계값 조정 |
| 약한 방향 | $λ_{min}$의 고유벡터 | 그 방향만 다른 센서(휠)에 맡김 |

대책은 ① 약한 방향 공분산을 크게 해서 EKF가 휠을 믿게 하기(`icp_odometry.py`), ② ICP 안에 휠 오도메트리 사전값 항 $+λ_p‖e_{weak}ᵀ(ξ − ξ_{odom})‖²$를 넣기(실습 4), ③ 약한 방향 성분을 갱신에서 빼기(solution remapping)입니다.

### 확장 칼만 필터 (EKF)

상태 $x = [x, y, θ, v, ω]ᵀ$(전진 속도 v, 각속도 ω)와 공분산 $P$를 유지합니다. 등속 운동 모델과 야코비안은

```text
f(x):  x' = x + v·cosθ·Δt,   y' = y + v·sinθ·Δt,   θ' = θ + ω·Δt,   v' = v,   ω' = ω
F = ∂f/∂x = [[1, 0, −v·sinθ·Δt, cosθ·Δt, 0 ],
             [0, 1,  v·cosθ·Δt, sinθ·Δt, 0 ],
             [0, 0,  1,         0,       Δt],
             [0, 0,  0,         1,       0 ],
             [0, 0,  0,         0,       1 ]]
예측:  x ← f(x),   P ← F P Fᵀ + Q·Δt
갱신:  S = H P Hᵀ + R,   K = P Hᵀ S⁻¹,   x ← x + K (z − H x),   P ← (I − K H) P (I − K H)ᵀ + K R Kᵀ
```

측정은 모두 상태의 일부를 직접 봅니다($H$는 단위행렬의 행 선택).

| 센서 | 주기 | 측정 z | H가 고르는 상태 | R |
|---|---|---|---|---|
| 휠 `/odom_raw` | 50 Hz | v | 4번째 (v) | $σ_v²$, 미끄럼 편향까지 고려해 넉넉히 (0.05 m/s)² |
| IMU `/imu` | 50 Hz | ω (자이로) | 5번째 (ω) | 정지 시 자이로 분산 측정 (0.01 rad/s)² |
| ICP `/odom_icp` | 10 Hz | (Δx/Δt, Δθ/Δt) | v, ω | $σ²H⁻¹/Δt²$ + 바닥값 |

ICP 결과를 **위치**가 아니라 **속도**로 넣는 것은 robot_localization의 `differential` 모드와 같은 생각입니다. 두 위치 추정(ICP 누적, EKF)은 서로 다른 드리프트를 가지므로 위치끼리 섞으면 필터가 두 값 사이를 오가지만, 상대 이동은 독립 측정으로 다룰 수 있습니다. 센서마다 도착 시각이 다르므로 **측정이 올 때마다 그 시각까지 예측한 뒤 갱신**합니다(비동기 다중 주기).

@fig[p06-ekf] 다중 주기 EKF의 한 구간. 예측마다 속도 불확실성이 커지고, 휠 갱신에서 조금, ICP 갱신에서 크게 줄어듭니다.

### 공분산 튜닝과 일관성 (NEES·NIS)

$Q$(모델을 얼마나 못 믿나)와 $R$(센서를 얼마나 못 믿나)은 필터의 성격을 정합니다. 숫자가 "그럴듯한지"는 **일관성 검사**로 확인합니다.

- **NEES** (normalized estimation error squared): 정답이 있을 때(시뮬레이션) $ε = eᵀ P⁻¹ e$, $e = x_{true} − x̂$. 필터가 일관적이면 $ε$은 자유도 n(위치·방향이면 3)의 χ² 분포를 따라 **평균이 n**입니다. 평균 ≫ n이면 과신(P가 너무 작음 → Q 증가), ≪ n이면 과소신(Q·R 감소).
- **NIS** (normalized innovation squared): 정답 없이 실물에서 $ν = (z − Hx)ᵀ S⁻¹ (z − Hx)$의 평균이 측정 차원 m이어야 합니다. `my_ekf.py`가 종료할 때 센서별 평균 NIS를 출력하고, ICP 갱신은 $ν > χ²_{2, 0.999} = 13.8$이면 버립니다(게이팅).

| 증상 | 원인 | 조정 |
|---|---|---|
| 추정이 느리게 따라옴(회전 후 늦게 멈춤) | 속도의 Q가 너무 작음 | $Q_v, Q_ω$ 증가 |
| 추정이 센서 잡음을 그대로 따라 떨림 | R이 너무 작음 | 해당 센서 R 증가 |
| NEES가 수십 | 편향(미끄럼)을 잡음으로 표현 못 함 | 편향 센서 R 증가, 또는 편향 상태 추가 |
| 두 센서 사이를 오감 | 서로 모순인데 둘 다 확신 | 한쪽은 위치, 다른 쪽은 속도로(differential) |

### MentorPi의 robot_localization 설정

`src/driver/controller/config/ekf.yaml`(M03)의 핵심입니다. 15칸 불리언 순서는 `x y z roll pitch yaw vx vy vz vroll vpitch vyaw ax ay az`입니다.

| 입력 | 토픽 | 쓰는 값 | 옵션 | 우리 EKF와 비교 |
|---|---|---|---|---|
| `odom0` | `odom_raw` | vx, vy, vyaw | differential false | v만 사용 (vyaw는 원본도 공분산 1e3이라 사실상 무시) |
| `odom1` | `odom_rf2o` | x, y, yaw | **relative true** | 우리는 ICP를 **속도**로 넣음 |
| `imu0` | `imu` | yaw, vyaw | relative true | ω만 사용 |
| 공통 | `frequency: 100`, `two_d_mode: true`, `publish_tf: true` | 15차원 전방향 모델, `process_noise_covariance` 대각 (x, y 0.05, yaw 0.06, vx·vy 0.025, vyaw 0.02 …) | | 5차원 외발(unicycle) 모델 — **메카넘 옆걸음 vy가 없음** |

`odom_publisher_node`는 `/odom_raw` twist 공분산을 vx·vy 1e-3, vyaw 1e3으로 보내므로, 원본 EKF에서 각속도는 IMU가, 선속도는 휠이 거의 전부를 맡습니다(M03). rf2o(Jaimez 외 2016)는 ICP가 아니라 연속 스캔의 **거리 흐름**(range flow) 방정식을 조밀하게 푸는 방법으로, 대응 탐색이 없어 매우 빠릅니다. 원본 launch는 `/scan_raw`를 받아 `/odom_rf2o`를 10 Hz로 내고 TF는 발행하지 않습니다(`publish_tf: False`).

### 실습 1. 스캔 두 장의 점-점 ICP

1 s 간격(전진 0.2 m/s + 좌회전 0.4 rad/s)의 스캔 두 장을 저장하고, SVD(Kabsch) ICP로 상대 이동을 구해 정답과 비교합니다.

```python run
import math
import numpy as np
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import Twist
from sensor_msgs.msg import LaserScan
import mentorpi_sim as sim                                    # 시뮬 전용
sim.setup(world="room", duration=3.05, start=(-1.7, -0.75, 0.0))  # 시뮬 전용

def points(scan):                                             # LaserScan → 라이다 좌표계 점 (N×2)
    r = np.array(scan.ranges); a = scan.angle_min + np.arange(len(r)) * scan.angle_increment
    ok = np.isfinite(r) & (r < 8.0)
    return np.c_[r[ok] * np.cos(a[ok]), r[ok] * np.sin(a[ok])]

def kabsch(P, Q):                                             # min Σ‖R p + t − q‖² (SVD)
    mp, mq = P.mean(0), Q.mean(0)
    U, _, Vt = np.linalg.svd((P - mp).T @ (Q - mq))
    R = Vt.T @ U.T
    if np.linalg.det(R) < 0: Vt[1] *= -1; R = Vt.T @ U.T      # 반사 방지
    return R, mq - R @ mp

def icp(P, Q, T0=(0.0, 0.0, 0.0), iters=30, reject=0.3, log=False):
    x, y, th = T0
    for k in range(iters):
        c, s = math.cos(th), math.sin(th)
        Pw = P @ np.array([[c, s], [-s, c]]) + (x, y)          # 현재 추정으로 P를 Q 좌표로
        d2 = ((Pw[:, None, :] - Q[None, :, :]) ** 2).sum(2)
        j = d2.argmin(1); d = np.sqrt(d2[np.arange(len(P)), j])  # 최근접 이웃 (전수 탐색)
        keep = d < max(reject, 3 * np.median(d)) if reject else np.ones(len(P), bool)
        R, t = kabsch(Pw[keep], Q[j[keep]])                   # 증분 변환
        x, y = R @ (x, y) + t; th += math.atan2(R[1, 0], R[0, 0])
        if log and k % 4 == 0: print('  iter %2d  rmse %.4f m  inliers %3d/%d  dT=(%.4f, %.4f, %.3f deg)' % (
            k, np.sqrt((d[keep] ** 2).mean()), keep.sum(), len(P), t[0], t[1], math.degrees(math.atan2(R[1, 0], R[0, 0]))))
        if np.hypot(*t) < 1e-4 and abs(math.atan2(R[1, 0], R[0, 0])) < 1e-4: break   # 수렴
    return (x, y, th), np.sqrt((d[keep] ** 2).mean()), k + 1

class Recorder(Node):
    def __init__(self):
        super().__init__('icp_pair')
        self.cmd = self.create_publisher(Twist, '/cmd_vel', 10)
        self.create_subscription(LaserScan, '/scan', self.on_scan, 10)
        self.rec = {}
        self.create_timer(0.1, self.drive)
    def drive(self):
        t = Twist(); t.linear.x, t.angular.z = 0.2, 0.4       # 전진하며 좌회전
        self.cmd.publish(t)
    def on_scan(self, s):
        t = round(self.get_clock().now().nanoseconds * 1e-9, 1)
        if t in (2.0, 3.0): self.rec[t] = (points(s), sim.pose())   # 시뮬 전용: 정답 자세
rclpy.init(); node = Recorder()
try:
    rclpy.spin(node)
finally:
    node.cmd.publish(Twist()); node.destroy_node(); rclpy.shutdown()

(Q, g0), (P, g1) = node.rec[2.0], node.rec[3.0]
dx, dy = g1[0] - g0[0], g1[1] - g0[1]; c, s = math.cos(g0[2]), math.sin(g0[2])
true = (c * dx + s * dy, -s * dx + c * dy, g1[2] - g0[2])    # 이전 스캔 좌표계에서 본 이동 (정답)
print('points: prev %d, curr %d' % (len(Q), len(P)))
print('true motion      dx %.3f  dy %.3f  dth %.2f deg' % (true[0], true[1], math.degrees(true[2])))
T, e, n = icp(P, Q, log=True)
print('ICP (reject)     dx %.3f  dy %.3f  dth %.2f deg  rmse %.4f  %d iters' % (T[0], T[1], math.degrees(T[2]), e, n))
T, e, n = icp(P, Q, reject=None)
print('ICP (no reject)  dx %.3f  dy %.3f  dth %.2f deg  rmse %.4f  %d iters' % (T[0], T[1], math.degrees(T[2]), e, n))
```

### 실습 2. 스캔 매칭 오도메트리 — 점-점 vs 점-선

반지름 0.8 m 원을 한 바퀴(25 s) 돌며 연속 스캔(10 Hz)을 매칭해 이어 붙입니다. 휠 오도메트리(`/odom`), 점-점 ICP, 점-선 ICP의 ATE(정답 궤적과의 위치 오차 RMS)를 비교하고 그래프 탭에 궤적을 그립니다.

```python run
import math
import numpy as np
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import Twist
from nav_msgs.msg import Odometry
from sensor_msgs.msg import LaserScan
from tf_transformations import euler_from_quaternion
import mentorpi_sim as sim                                    # 시뮬 전용
START = (-1.7, -0.75, 0.0)
sim.setup(world="room", duration=25.0, start=START, noise=True)  # 시뮬 전용: 바퀴 미끄럼 켬

def points(scan):
    r = np.array(scan.ranges); a = scan.angle_min + np.arange(len(r)) * scan.angle_increment
    ok = np.isfinite(r) & (r < 8.0)
    return np.c_[r[ok] * np.cos(a[ok]), r[ok] * np.sin(a[ok])][::2]   # 2°마다 180점 (속도)

def icp(P, Q, T0, line=True, iters=20):                      # line=True: 점-선, False: 점-점(SVD)
    t = np.roll(Q, -1, 0) - np.roll(Q, 1, 0); N = np.c_[-t[:, 1], t[:, 0]]
    ln = np.hypot(*N.T); okn = (ln > 1e-6) & (ln < 0.3); N = N / np.where(okn, ln, 1)[:, None]
    x, y, th = T0
    for _ in range(iters):
        c, s = math.cos(th), math.sin(th); Pw = P @ np.array([[c, s], [-s, c]]) + (x, y)
        d2 = ((Pw[:, None, :] - Q[None, :, :]) ** 2).sum(2); j = d2.argmin(1)
        k = (np.sqrt(d2[np.arange(len(P)), j]) < 0.2) & (okn[j] | (not line))
        if line:                                              # 가우스-뉴턴 한 걸음 (선형화)
            n, e = N[j[k]], Pw[k] - Q[j[k]]
            J = np.c_[n, n[:, 1] * (Pw[k, 0] - x) - n[:, 0] * (Pw[k, 1] - y)]
            dx, dy, da = -np.linalg.solve(J.T @ J, J.T @ (n * e).sum(1))
            x, y, th = x + dx, y + dy, th + da
        else:                                                 # 닫힌 해 (Kabsch, SVD)
            A, B = Pw[k], Q[j[k]]; U, _, Vt = np.linalg.svd((A - A.mean(0)).T @ (B - B.mean(0)))
            R = Vt.T @ U.T; tt = B.mean(0) - R @ A.mean(0)
            x, y = R @ (x, y) + tt; da = math.atan2(R[1, 0], R[0, 0]); th += da; dx, dy = tt
        if max(abs(dx), abs(dy), abs(da)) < 1e-5: break
    return x, y, th

def compose(p, d):                                            # p ⊕ d (SE(2) 합성)
    c, s = math.cos(p[2]), math.sin(p[2])
    return (p[0] + c * d[0] - s * d[1], p[1] + s * d[0] + c * d[1], p[2] + d[2])

class ScanOdom(Node):
    def __init__(self):
        super().__init__('scan_odometry')
        self.cmd = self.create_publisher(Twist, '/cmd_vel', 10)
        self.create_subscription(LaserScan, '/scan', self.on_scan, 10)
        self.create_subscription(Odometry, '/odom', self.on_odom, 10)
        self.prev, self.odom = None, START
        self.est = {'icp_p2p': [START, (0.0, 0.0, 0.0)], 'icp_p2l': [START, (0.0, 0.0, 0.0)]}  # [자세, 직전 이동]
        self.log = {'gt': [], 'odom': [], 'icp_p2p': [], 'icp_p2l': []}
        self.create_timer(0.1, self.drive)
    def drive(self):
        t = Twist(); t.linear.x, t.angular.z = 0.2, 0.25      # 반지름 0.8 m 원 한 바퀴
        self.cmd.publish(t)
    def on_odom(self, m):                                     # /odom은 odom 프레임(시작=0) → 월드로
        q = m.pose.pose.orientation
        self.odom = compose(START, (m.pose.pose.position.x, m.pose.pose.position.y, euler_from_quaternion([q.x, q.y, q.z, q.w])[2]))
    def on_scan(self, s):
        P = points(s)
        if self.prev is not None:
            for k, e in self.est.items():
                e[1] = icp(P, self.prev, e[1], line=(k == 'icp_p2l'))   # 초기값 = 직전 이동 (등속 가정)
                e[0] = compose(e[0], e[1])
        self.prev = P
        self.log['gt'].append(sim.pose()); self.log['odom'].append(self.odom)   # 시뮬 전용: gt
        for k, e in self.est.items(): self.log[k].append(e[0])

rclpy.init(); node = ScanOdom()
try:
    rclpy.spin(node)
finally:
    node.cmd.publish(Twist()); node.destroy_node(); rclpy.shutdown()

G = np.array(node.log['gt'])
for k in ('odom', 'icp_p2p', 'icp_p2l'):
    E = np.array(node.log[k]); e = np.hypot(*(E[:, :2] - G[:, :2]).T)
    dth = math.degrees(math.atan2(math.sin(E[-1, 2] - G[-1, 2]), math.cos(E[-1, 2] - G[-1, 2])))
    print('%-8s ATE %.3f m | final %.3f m, %+6.1f deg | max %.3f m' % (k, np.sqrt((e ** 2).mean()), e[-1], dth, e.max()))
    sim.plot(E[:, 0], E[:, 1], label=k)                       # 시뮬 전용 그래프
sim.plot(G[:, 0], G[:, 1], label='ground truth')
```

- **휠**: 한 바퀴 뒤 14 cm·10° 틀립니다. 방향 오차 10.4°는 각속도 미끄럼 3 % × 360°와 맞습니다.
- **점-점 ICP**: 완전히 무너집니다(ATE 1.5 m). 스캔 간 이동(2 cm)이 빔 간격(1 m 거리에서 3.5 cm)보다 작아서 최근접 이웃이 "같은 번호의 빔"이 되고, ICP가 거의 움직이지 않은 쪽 극소에 붙잡힙니다. 실습 1(1 s 간격)에서는 잘 되던 것이 연속 매칭에서 안 되는 이유입니다.
- **점-선 ICP**: ATE 3.3 cm, 방향 오차 0.2°. 벽을 따라 미끄러지는 방향을 벌하지 않으므로 표본화 편향이 없습니다.

### 실습 3. EKF 융합 — 휠, 휠+IMU, 휠+IMU+ICP

같은 주행에서 EKF 세 개를 동시에 돌립니다. `odom`은 휠 v·ω, `odom+imu`는 원본 MentorPi처럼 휠 v + IMU ω, `odom+imu+icp`는 여기에 ICP 속도를 더합니다. NEES 평균(3이면 이상적)도 함께 봅니다.

```python run
import math
import numpy as np
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import Twist
from nav_msgs.msg import Odometry
from sensor_msgs.msg import LaserScan, Imu
import mentorpi_sim as sim                                    # 시뮬 전용
START = (-1.7, -0.75, 0.0)
sim.setup(world="room", duration=25.0, start=START, noise=True)  # 시뮬 전용

def points(scan):
    r = np.array(scan.ranges); a = scan.angle_min + np.arange(len(r)) * scan.angle_increment
    ok = np.isfinite(r) & (r < 8.0)
    return np.c_[r[ok] * np.cos(a[ok]), r[ok] * np.sin(a[ok])][::2]

def icp(P, Q, T0, iters=15):                                  # 실습 2의 점-선 ICP (H도 돌려줌)
    t = np.roll(Q, -1, 0) - np.roll(Q, 1, 0); N = np.c_[-t[:, 1], t[:, 0]]
    ln = np.hypot(*N.T); okn = (ln > 1e-6) & (ln < 0.3); N = N / np.where(okn, ln, 1)[:, None]
    x, y, th = T0
    for _ in range(iters):
        c, s = math.cos(th), math.sin(th); Pw = P @ np.array([[c, s], [-s, c]]) + (x, y)
        d2 = ((Pw[:, None, :] - Q[None, :, :]) ** 2).sum(2); j = d2.argmin(1)
        k = okn[j] & (np.sqrt(d2[np.arange(len(P)), j]) < 0.2)
        n, e = N[j[k]], Pw[k] - Q[j[k]]
        J = np.c_[n, n[:, 1] * (Pw[k, 0] - x) - n[:, 0] * (Pw[k, 1] - y)]
        H = J.T @ J; dx = -np.linalg.solve(H, J.T @ (n * e).sum(1))
        x, y, th = x + dx[0], y + dx[1], th + dx[2]
        if np.abs(dx).max() < 1e-5: break
    return (x, y, th), H

Q_PROC = np.diag([1e-5, 1e-5, 1e-5, 0.02, 0.5])                # 공정 잡음 밀도 (튜닝 대상)
SIG_ODOM_V = 0.05                                             # 휠 속도 표준편차 [m/s]
class EKF:                                                    # 상태 [x, y, θ, v, ω]
    def __init__(self, x0):
        self.x = np.array([*x0, 0.0, 0.0]); self.P = np.diag([1e-6, 1e-6, 1e-6, 1e-2, 1e-2])
    def predict(self, dt):
        x, y, th, v, w = self.x; c, s = math.cos(th), math.sin(th)
        self.x = np.array([x + v * c * dt, y + v * s * dt, th + w * dt, v, w])
        F = np.eye(5); F[0, 2], F[0, 3], F[1, 2], F[1, 3], F[2, 4] = -v * s * dt, c * dt, v * c * dt, s * dt, dt
        self.P = F @ self.P @ F.T + Q_PROC * dt
    def update(self, z, idx, R):                              # z = H x + 잡음, H = 단위행렬의 행 선택
        H = np.eye(5)[idx]; S = H @ self.P @ H.T + R; K = self.P @ H.T @ np.linalg.inv(S)
        self.x = self.x + K @ (np.atleast_1d(z) - H @ self.x); self.P = (np.eye(5) - K @ H) @ self.P

CFG = {'odom': ('odom',), 'odom+imu': ('odom_v', 'imu'), 'odom+imu+icp': ('odom_v', 'imu', 'icp')}
class Fusion(Node):
    def __init__(self):
        super().__init__('ekf_fusion')
        self.cmd = self.create_publisher(Twist, '/cmd_vel', 10)
        self.create_subscription(Odometry, '/odom', self.on_odom, 10)
        self.create_subscription(Imu, '/imu', self.on_imu, 10)
        self.create_subscription(LaserScan, '/scan', self.on_scan, 10)
        self.f = {k: EKF(START) for k in CFG}; self.prev, self.delta = None, (0.0, 0.0, 0.0)
        self.err = {k: [] for k in CFG}; self.nees = {k: [] for k in CFG}
    def use(self, src): return [f for k, f in self.f.items() if src in CFG[k]]
    def on_odom(self, m):
        t = Twist(); t.linear.x, t.angular.z = 0.2, 0.25; self.cmd.publish(t)
        v, w = m.twist.twist.linear.x, m.twist.twist.angular.z
        for f in self.f.values(): f.predict(0.02)
        for f in self.use('odom'): f.update([v, w], [3, 4], np.diag([0.02 ** 2, 0.03 ** 2]))
        for f in self.use('odom_v'): f.update(v, [3], np.diag([SIG_ODOM_V ** 2]))
    def on_imu(self, m):
        for f in self.use('imu'): f.update(m.angular_velocity.z, [4], np.diag([0.01 ** 2]))
    def on_scan(self, s):
        P = points(s)
        if self.prev is not None:
            self.delta, H = icp(P, self.prev, self.delta)
            C = 0.01 ** 2 * np.linalg.inv(H)[np.ix_([0, 2], [0, 2])] / 0.1 ** 2 + np.diag([1e-4, 1e-4])
            for f in self.use('icp'): f.update(np.array([self.delta[0], self.delta[2]]) / 0.1, [3, 4], C)
        self.prev = P
        g = np.array(sim.pose())                              # 시뮬 전용: 정답과 비교
        for k, f in self.f.items():
            e = g - f.x[:3]; e[2] = math.atan2(math.sin(e[2]), math.cos(e[2]))
            self.err[k].append(e); self.nees[k].append(e @ np.linalg.solve(f.P[:3, :3], e))

rclpy.init(); node = Fusion()
try:
    rclpy.spin(node)
finally:
    node.cmd.publish(Twist()); node.destroy_node(); rclpy.shutdown()
print('config        ATE[m]  final[m]  yaw[deg]  mean NEES (ideal 3)')
for k in CFG:
    E = np.array(node.err[k]); d = np.hypot(E[:, 0], E[:, 1])
    print('%-13s %.3f   %.3f    %+5.1f    %8.1f' % (k, np.sqrt((d ** 2).mean()), d[-1], math.degrees(E[-1, 2]), np.mean(node.nees[k])))
    sim.plot(np.arange(len(d)) * 0.1, d, label=k + ' |e| [m]')  # 시뮬 전용 그래프
```

### 실습 4. 복도 퇴화와 오도메트리 사전값

빈 방에 폭 1 m 복도를 만들고 2 s 동안 0.2 m/s로 직진하며 연속 ICP를 합산합니다. 라이다 전체 거리(복도 양 끝 벽이 보임)와 1.5 m로 자른 경우(긴 복도와 같음), 그리고 1.5 m + 휠 사전값을 비교합니다.

```python run
import math
import numpy as np
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import Twist
from nav_msgs.msg import Odometry
from sensor_msgs.msg import LaserScan
import mentorpi_sim as sim                                    # 시뮬 전용
sim.setup(world="empty", duration=3.0, start=(-0.2, 0.0, 0.0))  # 시뮬 전용
sim.add_box(0.0, 0.5, 5.6, 0.04); sim.add_box(0.0, -0.5, 5.6, 0.04)   # 시뮬 전용: 폭 1 m 복도

def points(scan, rmax):
    r = np.array(scan.ranges); a = scan.angle_min + np.arange(len(r)) * scan.angle_increment
    ok = np.isfinite(r) & (r < rmax)
    return np.c_[r[ok] * np.cos(a[ok]), r[ok] * np.sin(a[ok])]

def icp(P, Q, T0=(0.0, 0.0, 0.0), iters=15, prior=None):     # 점-선 ICP (+ 선택: 오도메트리 사전값)
    t = np.roll(Q, -3, 0) - np.roll(Q, 3, 0); N = np.c_[-t[:, 1], t[:, 0]]
    ln = np.hypot(*N.T); okn = (ln > 1e-6) & (ln < 0.5); N = N / np.where(okn, ln, 1)[:, None]
    x = np.array(T0, float)
    for _ in range(iters):
        c, s = math.cos(x[2]), math.sin(x[2]); Pw = P @ np.array([[c, s], [-s, c]]) + x[:2]
        d2 = ((Pw[:, None, :] - Q[None, :, :]) ** 2).sum(2); j = d2.argmin(1)
        k = okn[j] & (np.sqrt(d2[np.arange(len(P)), j]) < 0.3)
        n, e = N[j[k]], Pw[k] - Q[j[k]]
        J = np.c_[n, n[:, 1] * (Pw[k, 0] - x[0]) - n[:, 0] * (Pw[k, 1] - x[1])]
        H, g = J.T @ J, J.T @ (n * e).sum(1)
        if prior is not None:                                 # 약한 방향만 오도메트리가 채우도록
            H, g = H + prior[1], g + prior[1] @ (x - prior[0])
        dx = -np.linalg.solve(H, g); x += dx
        if np.abs(dx).max() < 1e-5: break
    return x, J.T @ J

VARIANTS = {'full range': (12.0, False), 'range<1.5 m': (1.5, False), 'range<1.5 m + odom prior': (1.5, True)}
class Corridor(Node):
    def __init__(self):
        super().__init__('degeneracy_check')
        self.cmd = self.create_publisher(Twist, '/cmd_vel', 10)
        self.create_subscription(LaserScan, '/scan', self.on_scan, 10)
        self.create_subscription(Odometry, '/odom', lambda m: setattr(self, 'ox', m.pose.pose.position.x), 10)
        self.prev, self.acc, self.eig, self.ox, self.px = None, {k: 0.0 for k in VARIANTS}, {}, 0.0, 0.0
        self.g0 = self.o0 = None
        self.create_timer(0.1, self.drive)
    def drive(self):
        t = Twist(); t.linear.x = 0.2 if 0.5 < self.get_clock().now().nanoseconds * 1e-9 < 2.5 else 0.0
        self.cmd.publish(t)
    def on_scan(self, s):
        if self.g0 is None: self.g0, self.o0 = sim.pose()[0], self.ox        # 시뮬 전용: 정답 x
        if self.prev is not None:
            for k, (rmax, use_prior) in VARIANTS.items():
                Q, P = points(self.prev, rmax), points(s, rmax)
                pr = (np.array([self.ox - self.px, 0, 0]), np.diag([400.0, 0, 0])) if use_prior else None
                x, H = icp(P, Q, prior=pr)
                self.acc[k] += x[0]
                w = np.linalg.eigvalsh(H[:2, :2]); self.eig[k] = (w[0], w[1], len(P))
        self.prev, self.px = s, self.ox

rclpy.init(); node = Corridor()
try:
    rclpy.spin(node)
finally:
    node.cmd.publish(Twist()); node.destroy_node(); rclpy.shutdown()

print('true forward motion %.3f m, wheel odom %.3f m' % (sim.pose()[0] - node.g0, node.ox - node.o0))   # 시뮬 전용
for k in VARIANTS:
    w0, w1, n = node.eig[k]
    print('%-25s pts %3d | eig(H_xy) %7.1f %7.1f  cond %8.0f | ICP forward %.3f m' % (k, n, w0, w1, w1 / max(w0, 1e-9), node.acc[k]))
```

:::safety
- 텔레옵 속도는 원본 제한(0.2 m/s, 0.5 rad/s) 안에서, 급출발·급정지 없이 운전합니다. 급가속은 바퀴 미끄럼을 키워 실험을 망치고 로봇을 넘어뜨릴 수 있습니다.

:::

### 3) 팀 노드: ICP 오도메트리

```python robot
#!/usr/bin/env python3
# icp_odometry.py — /scan_raw → 점-선 ICP 스캔 매칭 오도메트리 → /odom_icp (TF 발행 안 함)
import math
import numpy as np
import rclpy
from rclpy.node import Node
from rclpy.qos import qos_profile_sensor_data
from sensor_msgs.msg import LaserScan
from nav_msgs.msg import Odometry
from tf_transformations import quaternion_from_euler

def points(scan, rmax):
    r = np.array(scan.ranges, dtype=float); a = scan.angle_min + np.arange(len(r)) * scan.angle_increment
    ok = np.isfinite(r) & (r > max(scan.range_min, 0.15)) & (r < rmax)   # 0.15 m 안(차체) 제외
    return np.c_[r[ok] * np.cos(a[ok]), r[ok] * np.sin(a[ok])]

def icp(P, Q, T0, iters=15, gate=0.2):
    t = np.roll(Q, -1, 0) - np.roll(Q, 1, 0); N = np.c_[-t[:, 1], t[:, 0]]
    ln = np.hypot(*N.T); okn = (ln > 1e-6) & (ln < 0.3); N = N / np.where(okn, ln, 1)[:, None]
    x = np.array(T0, float); H = np.eye(3); k = np.zeros(len(P), bool)
    for _ in range(iters):
        c, s = math.cos(x[2]), math.sin(x[2]); Pw = P @ np.array([[c, s], [-s, c]]) + x[:2]
        d2 = ((Pw[:, None, :] - Q[None, :, :]) ** 2).sum(2); j = d2.argmin(1)   # 450×450: 파이 5에서 수 ms
        k = okn[j] & (np.sqrt(d2[np.arange(len(P)), j]) < gate)
        if k.sum() < 30: return None, None, 0
        n, e = N[j[k]], Pw[k] - Q[j[k]]
        J = np.c_[n, n[:, 1] * (Pw[k, 0] - x[0]) - n[:, 0] * (Pw[k, 1] - x[1])]
        H = J.T @ J; dx = -np.linalg.solve(H, J.T @ (n * e).sum(1)); x += dx
        if np.abs(dx).max() < 1e-5: break
    return x, H, int(k.sum())

class IcpOdometry(Node):
    def __init__(self):
        super().__init__('icp_odometry')
        self.rmax = self.declare_parameter('max_range', 8.0).value
        self.sigma = self.declare_parameter('sigma', 0.01).value      # 점-선 잔차 표준편차 [m]
        self.create_subscription(LaserScan, '/scan_raw', self.on_scan, qos_profile_sensor_data)
        self.pub = self.create_publisher(Odometry, '/odom_icp', 10)
        self.prev, self.t_prev, self.delta = None, None, np.zeros(3)
        self.pose = np.zeros(3)
    def on_scan(self, s):
        P = points(s, self.rmax)[::2]
        t = s.header.stamp.sec + s.header.stamp.nanosec * 1e-9
        if self.prev is not None and len(P) > 50:
            d, H, n = icp(P, self.prev, self.delta)
            dt = t - self.t_prev
            if d is None or not 0.01 < dt < 0.5:
                self.get_logger().warn('ICP failed (inliers < 30) — keep previous estimate', throttle_duration_sec=2.0)
            else:
                w = np.linalg.eigvalsh(H[:2, :2]); cov = self.sigma ** 2 * np.linalg.inv(H)
                if w[1] / max(w[0], 1e-9) > 100:                    # 퇴화(긴 복도): 약한 방향 불신
                    cov[:2, :2] += np.eye(2) * 1.0
                    self.get_logger().warn('degenerate scan (cond %.0f)' % (w[1] / w[0]), throttle_duration_sec=2.0)
                self.delta = d
                c, sn = math.cos(self.pose[2]), math.sin(self.pose[2])
                self.pose += (c * d[0] - sn * d[1], sn * d[0] + c * d[1], d[2])
                self.publish(s.header.stamp, d / dt, cov / dt ** 2, n)
        self.prev, self.t_prev = P, t
    def publish(self, stamp, vel, cov, n):
        o = Odometry(); o.header.stamp = stamp; o.header.frame_id = 'odom'; o.child_frame_id = 'base_footprint'
        o.pose.pose.position.x, o.pose.pose.position.y = float(self.pose[0]), float(self.pose[1])
        q = quaternion_from_euler(0.0, 0.0, float(self.pose[2]))
        o.pose.pose.orientation.x, o.pose.pose.orientation.y, o.pose.pose.orientation.z, o.pose.pose.orientation.w = q
        o.twist.twist.linear.x, o.twist.twist.linear.y, o.twist.twist.angular.z = (float(v) for v in vel)
        tc = [0.0] * 36                                              # 6×6 (x y z r p y) 중 x, y, yaw
        for a, i in enumerate((0, 1, 5)):
            for b, j in enumerate((0, 1, 5)):
                tc[i * 6 + j] = float(cov[a, b])
        o.twist.covariance = tc
        self.pub.publish(o)

def main():
    rclpy.init(); node = IcpOdometry()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node(); rclpy.shutdown()

if __name__ == '__main__':
    main()
```

```python robot
#!/usr/bin/env python3
# my_ekf.py — /odom_raw(v) + /imu(ω) + /odom_icp(v, ω) → EKF [x, y, θ, v, ω] → /odom_fused
import math
import numpy as np
import rclpy
from rclpy.node import Node
from nav_msgs.msg import Odometry
from sensor_msgs.msg import Imu
from tf_transformations import quaternion_from_euler

class MyEkf(Node):
    def __init__(self):
        super().__init__('my_ekf')
        q = self.declare_parameter('process_noise', [1e-5, 1e-5, 1e-5, 0.02, 0.5]).value
        self.Q = np.diag(q)
        self.sig_v = self.declare_parameter('sigma_wheel_v', 0.05).value
        self.sig_w = self.declare_parameter('sigma_imu_w', 0.01).value
        self.use_icp = self.declare_parameter('use_icp', True).value
        self.x = np.zeros(5); self.P = np.diag([1e-6, 1e-6, 1e-6, 1e-2, 1e-2]); self.t = None
        self.create_subscription(Odometry, '/odom_raw', self.on_odom, 10)
        self.create_subscription(Imu, '/imu', self.on_imu, 10)
        self.create_subscription(Odometry, '/odom_icp', self.on_icp, 10)
        self.pub = self.create_publisher(Odometry, '/odom_fused', 10)
        self.nis = {}                                                   # 센서별 NIS 기록
    def predict(self):
        now = self.get_clock().now().nanoseconds * 1e-9
        dt = 0.0 if self.t is None else min(now - self.t, 0.1); self.t = now
        x, y, th, v, w = self.x; c, s = math.cos(th), math.sin(th)
        self.x = np.array([x + v * c * dt, y + v * s * dt, th + w * dt, v, w])
        F = np.eye(5); F[0, 2], F[0, 3], F[1, 2], F[1, 3], F[2, 4] = -v * s * dt, c * dt, v * c * dt, s * dt, dt
        self.P = F @ self.P @ F.T + self.Q * dt
    def update(self, z, idx, R, gate=None):
        H = np.eye(5)[idx]; r = np.atleast_1d(z) - H @ self.x; S = H @ self.P @ H.T + R
        d2 = float(r @ np.linalg.solve(S, r))                           # NIS (마할라노비스 거리²)
        if gate and d2 > gate:
            self.get_logger().warn('reject %s (NIS %.1f)' % (idx, d2), throttle_duration_sec=1.0); return
        K = self.P @ H.T @ np.linalg.inv(S); self.x = self.x + K @ r
        I_KH = np.eye(5) - K @ H; self.P = I_KH @ self.P @ I_KH.T + K @ R @ K.T   # 조셉 형태 (대칭 유지)
        self.nis.setdefault(str(idx), []).append(d2)
    def on_odom(self, m):                                               # 50 Hz: 예측 + 휠 v 갱신
        self.predict()
        self.update(m.twist.twist.linear.x, [3], np.array([[self.sig_v ** 2]]))
        self.publish(m.header.stamp)
    def on_imu(self, m):
        self.predict(); self.update(m.angular_velocity.z, [4], np.array([[self.sig_w ** 2]]))
    def on_icp(self, m):                                                # 10 Hz: ICP v, ω (공분산 포함)
        if not self.use_icp: return
        c = np.array(m.twist.covariance).reshape(6, 6)[np.ix_([0, 5], [0, 5])] + np.diag([1e-4, 1e-4])
        self.predict(); self.update([m.twist.twist.linear.x, m.twist.twist.angular.z], [3, 4], c, gate=13.8)  # χ²(2) 99.9 %
    def publish(self, stamp):
        o = Odometry(); o.header.stamp = stamp; o.header.frame_id = 'odom'; o.child_frame_id = 'base_footprint'
        o.pose.pose.position.x, o.pose.pose.position.y = float(self.x[0]), float(self.x[1])
        q = quaternion_from_euler(0.0, 0.0, float(self.x[2]))
        o.pose.pose.orientation.x, o.pose.pose.orientation.y, o.pose.pose.orientation.z, o.pose.pose.orientation.w = q
        o.twist.twist.linear.x, o.twist.twist.angular.z = float(self.x[3]), float(self.x[4])
        pc = [0.0] * 36
        for a, i in enumerate((0, 1, 5)):
            for b, j in enumerate((0, 1, 5)):
                pc[i * 6 + j] = float(self.P[a, b])
        o.pose.covariance = pc
        self.pub.publish(o)

def main():
    rclpy.init(); node = MyEkf()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        for key, v in node.nis.items():                                 # 기대값 = 측정 차원 수 (1 또는 2)
            node.get_logger().info('mean NIS %s %.2f over %d updates' % (key, np.mean(v), len(v)))
        node.destroy_node(); rclpy.shutdown()

if __name__ == '__main__':
    main()
```

```python robot
#!/usr/bin/env python3
# odom_eval.py — 여러 오도메트리를 slam_toolbox 자세(map→base_footprint)와 비교: CSV 기록 + 종료 시 ATE/RPE
import csv, math, os
import numpy as np
import rclpy
from rclpy.node import Node
from rclpy.time import Time
from nav_msgs.msg import Odometry
from tf2_ros import Buffer, TransformListener, TransformException
from tf_transformations import euler_from_quaternion

SOURCES = ['/odom', '/odom_raw', '/odom_rf2o', '/odom_icp', '/odom_fused']
yaw = lambda q: euler_from_quaternion([q.x, q.y, q.z, q.w])[2]

def align(E, G):                                           # 2D 강체 정렬 (Umeyama, 척도 없음)
    me, mg = E.mean(0), G.mean(0)
    U, _, Vt = np.linalg.svd((E - me).T @ (G - mg)); R = Vt.T @ U.T
    if np.linalg.det(R) < 0: Vt[1] *= -1; R = Vt.T @ U.T
    return (E - me) @ R.T + mg

def rpe(E, G, step=1.0):                                  # 주행 거리 step [m]마다 상대 이동 오차
    s = np.r_[0, np.cumsum(np.hypot(*np.diff(G, axis=0).T))]; out, i = [], 0
    for j in range(len(G)):
        if s[j] - s[i] >= step:
            out.append(np.hypot(*((E[j] - E[i]) - (G[j] - G[i])))); i = j
    return np.mean(out) if out else float('nan')

class OdomEval(Node):
    def __init__(self):
        super().__init__('odom_eval')
        self.last = {}
        for t in SOURCES:
            self.create_subscription(Odometry, t, lambda m, t=t: self.last.__setitem__(
                t, (m.pose.pose.position.x, m.pose.pose.position.y, yaw(m.pose.pose.orientation))), 10)
        self.tf_buffer = Buffer(); self.tf_listener = TransformListener(self.tf_buffer, self)
        self.rows = []; self.create_timer(0.1, self.sample)
        self.f = open(os.path.expanduser('~/p06_run.csv'), 'w', newline=''); self.w = csv.writer(self.f)
        self.w.writerow(['t', 'ref_x', 'ref_y', 'ref_yaw'] + ['%s_%s' % (s, a) for s in SOURCES for a in 'xyθ'])
    def sample(self):
        try:
            tf = self.tf_buffer.lookup_transform('map', 'base_footprint', Time())
        except TransformException:
            return
        ref = (tf.transform.translation.x, tf.transform.translation.y, yaw(tf.transform.rotation))
        row = [self.get_clock().now().nanoseconds * 1e-9, *ref] + [v for s in SOURCES for v in self.last.get(s, (math.nan,) * 3)]
        self.rows.append(row); self.w.writerow(row)
    def report(self):
        if len(self.rows) < 20: print('no reference pose (map->base_footprint) recorded'); return
        A = np.array(self.rows); G = A[:, 1:3]
        for k, s in enumerate(SOURCES):
            E = A[:, 4 + 3 * k:6 + 3 * k]; ok = np.isfinite(E).all(1)
            if ok.sum() < 20: continue
            e = np.hypot(*(align(E[ok], G[ok]) - G[ok]).T)
            print('%-12s ATE %.3f m  max %.3f m  RPE(1 m) %.3f m' % (s, np.sqrt((e ** 2).mean()), e.max(), rpe(align(E[ok], G[ok]), G[ok])))

def main():
    rclpy.init(); node = OdomEval()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.f.close(); node.report(); node.destroy_node(); rclpy.shutdown()

if __name__ == '__main__':
    main()
```

## 실험과 평가

**지표.** ATE(Absolute Trajectory Error)는 추정 궤적을 기준 궤적에 강체 정렬한 뒤 위치 오차의 RMS, RPE(Relative Pose Error)는 주행 거리 1 m마다 상대 이동 오차의 평균입니다(Sturm 외 2012). ATE는 전체 일관성, RPE는 국소 드리프트율을 봅니다. 끝점 오차는 같은 표시로 돌아왔을 때의 위치 차이입니다.

**E1. 시뮬레이션 기준값 (실습 2·3, 반지름 0.8 m 원 한 바퀴, 약 5 m).**

| 방법 | ATE [m] | 끝점 [m] | 끝 방향 [°] | NEES |
|---|---|---|---|---|
| 휠 오도메트리 `/odom` | 0.080 | 0.138 | +10.4 | 39.8 (EKF) |
| 점-점 ICP 스캔 오도메트리 | 1.519 | 2.656 | +117.4 | — |
| 점-선 ICP 스캔 오도메트리 | 0.033 | 0.067 | −0.2 | — |
| EKF 휠 + IMU (원본 구성과 같은 입력) | 0.060 | 0.019 | +0.4 | 7.7 |
| EKF 휠 + IMU + 점-선 ICP | **0.024** | 0.021 | +0.4 | 2.0 |

**E2. 실물 비교 (방 한 바퀴 × 3회, 같은 주행에서 동시 기록).**

| 출력 | 구성 | ATE [m] | RPE (1 m) [m] | 끝점 [m] | 평균 NIS |
|---|---|---|---|---|---|
| `/odom_raw` | 휠만 (자세 적분) | | | | — |
| `/odom` | robot_localization, rf2o 끔 | | | | — |
| `/odom` | robot_localization, rf2o 켬 | | | | — |
| `/odom_rf2o` | rf2o 단독 | | | | — |
| `/odom_icp` | 팀 ICP 단독 | | | | — |
| `/odom_fused` | 팀 EKF (휠 + IMU + ICP) | | | | v: , ICP: |

**E3. 퇴화 시험.** 폭 1 m 이하, 길이 3 m 이상의 통로(책상·상자로 구성)를 2회 왕복하며 `/odom_icp`의 통로 방향 이동 거리와 줄자 값을 비교합니다. 퇴화 경고 비율(경고 스캔 / 전체 스캔)과 `/odom_fused` 오차도 기록합니다.

**E4. 처리 시간.** `icp_odometry.py`에 `time.perf_counter()`를 넣어 스캔당 처리 시간 분포(평균, 95 백분위)를 기록하고, 표본화(1/1, 1/2, 1/4)에 따른 ATE와 시간의 교환 관계를 그립니다.

## 확장 과제

- **메카넘 상태 확장**: 상태에 옆 속도 $v_y$를 넣은 $[x, y, θ, v_x, v_y, ω]$ EKF로 바꾸고 옆걸음 주행에서 비교합니다(ICP는 Δy를 이미 줍니다).
- **scan-to-map 오도메트리**: 연속 스캔 대신 최근 N장을 합친 국소 지도(키프레임)와 매칭해 드리프트를 줄입니다. 키프레임 교체 기준(이동 0.3 m 또는 회전 15°)을 실험합니다.
- **k-d 트리**: `scipy.spatial.cKDTree`(설치된 경우) 또는 격자 해시로 최근접 이웃을 바꾸고 처리 시간을 비교합니다.
- **자이로 편향 상태**: 상태에 IMU 편향 $b_ω$를 추가하고, 정지 구간에서 편향이 수렴하는지 봅니다.
- **UKF**: 같은 모델로 무향 칼만 필터를 구현해 큰 회전 속도에서 EKF와 비교합니다(robot_localization의 `ukf_node`와도 비교).
- **robot_localization에 팀 ICP 연결**: `ekf.yaml`의 `odom1`을 `odom_icp`로 바꾸고 `odom1_config`를 속도(vx, vy, vyaw)로, `odom1_differential`을 검토해 원본 필터로 팀 ICP를 쓰는 구성을 만듭니다(원본 파일은 백업).

## 자주 나는 오류와 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| ICP가 거의 0만 내놓음 (움직였는데) | 점-점 ICP의 표본화 편향, 또는 퇴화 | 점-선 ICP 사용, 조건수 확인, 초기값을 휠 오도메트리로 |
| ICP가 가끔 크게 튐 | 대응 게이트가 너무 큼, 사람·문 움직임 | τ 0.2 m, 인라이어 < 30이면 실패 처리, EKF 게이팅 |
| 회전할 때 스캔 오도메트리 방향이 늦음 | 스캔 한 장 동안의 회전(모션 왜곡) | 느린 회전(≤ 0.5 rad/s), 확장: 빔별 시각으로 왜곡 보정 |
| `np.linalg.LinAlgError: Singular matrix` | 인라이어 부족 또는 모든 법선이 같은 방향 | 인라이어 수 검사 후 건너뜀, H에 작은 대각값 더하기 |
| `/odom_icp`가 안 나옴 | `/scan_raw` QoS 불일치 | `qos_profile_sensor_data`로 구독 |
| 로봇 몸체가 점으로 잡혀 ICP가 제자리에 고정 | 라이다가 차체·케이블을 봄 | 0.15 m 안 점 제거(코드처럼), 원본 `lidar_filters_config_ld19.yaml` 확인 |
| EKF 추정이 발산하거나 NaN | Δt가 음수·아주 큼(시계 문제), P 비대칭 | Δt 상한(0.1 s), 조셉 형태 갱신 |
| 두 로봇·노드의 TF가 튐 | 팀 노드가 TF 발행 | TF 발행 제거, `ros2 run tf2_tools view_frames`로 확인 |
| 평균 NIS가 수십 | R이 너무 작음(과신) 또는 편향 | 해당 센서 R 증가, 정지 데이터로 분산 재측정 |
| rf2o를 켰더니 `/odom`이 튄다 | `odom1_relative`, 공분산 설정과 rf2o 품질 | rf2o 단독 궤적부터 확인, 원본 구성과 끈 구성 비교 |
| `ros2 launch controller rf2o_laser_odometry.launch.py`가 패키지 없음 오류 | 이미지에 rf2o 미설치 | 이 비교는 생략하고 팀 ICP로 대신 |
| `/odom_icp`의 v가 전진인데 음수, 또는 회전 방향이 반대 | 라이다 프레임이 `base_footprint`와 회전되어 장착 | `ros2 run tf2_ros tf2_echo base_footprint lidar_frame`으로 확인, ICP 결과 Δ를 그 회전만큼 base 좌표로 돌림 |
| `odom_eval`이 "no reference pose" | slam 미실행, map 프레임 없음 | `slam.launch.py`를 켜고 로봇을 조금 움직여 지도 생성 |

## 과제

:::task 기본 과제
1. 실습 1에서 스캔 간격(0.5, 1, 2, 3 s)을 바꾸며 ICP 수렴 여부와 오차를 표로 만들고, 수렴 반경을 회전 각도로 설명합니다.
2. 실습 3의 튜닝 표에 한 줄을 추가합니다: IMU 잡음 `0.01 ** 2`을 `0.05 ** 2`로 바꿨을 때 ATE·NEES가 어떻게 되는지 예측하고 실행해 확인합니다.
:::

:::task 심화 과제
3. 점-점 ICP에서 목표 스캔 $Q$를 선형 보간으로 5배 조밀하게 만들면 실습 2의 표본화 편향이 줄어드는지 실험하고, 점-선 ICP와 비교합니다.
4. 실물 E2 표를 채우고, 팀 EKF가 원본 `robot_localization`(rf2o 켬)보다 좋거나 나쁜 이유를 모델(15차원 vs 5차원), 입력 방식(위치 vs 속도), 공분산 설정으로 나눠 분석합니다.
:::
