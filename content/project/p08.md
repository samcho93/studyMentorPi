## 학습 목표

- YOLOv5 검출 상자와 깊이 영상으로 물체의 3D 위치를 구하고(핀홀 역투영), TF로 `map` 좌표에 올리는 전 과정을 식과 코드로 구현합니다.
- 여러 번의 관측을 **게이팅·누적 평균·관측 횟수**로 융합해 헛검출과 놓침에 강한 **시맨틱 지도**(이름표 붙은 랜드마크 + 방 다각형)를 JSON으로 만듭니다.
- "주방에 있는 빨간 공 앞으로 가 줘" 같은 한국어 명령을 동사·대상·색·장소·관계 **슬롯**으로 해석하는 규칙 기반 파서를 만들고, 선택 사항으로 LLM을 **엄격한 JSON 스키마**와 오프라인 대체 경로 아래에서만 씁니다.
- 슬롯을 지도 위 랜드마크에 **그라운딩**해 접근 거리를 둔 목표 자세로 바꾸고, Nav2로 주행한 뒤 **다시 보고 확인**합니다. 물체가 없거나 옮겨졌으면 탐색 패턴으로 찾아 지도를 갱신합니다.
- 지도 정확도, 파싱 정확도, 도착 오차, 과제 성공률을 측정해 어느 단계가 전체 실패를 만드는지 분석합니다.

## 프로젝트 개요와 요구사항

지금까지의 내비게이션(M11~M13, P02)은 좌표로 목표를 받았습니다. 사람은 좌표로 말하지 않습니다. "의자 옆으로 와", "주방에 있는 빨간 공 앞으로 가 줘"처럼 **물체와 장소의 이름**으로 말합니다. 이 프로젝트는 그 간극을 메웁니다.

1. 로봇이 집 안을 돌며 **무엇이 어디에 있는지** 기록합니다(시맨틱 매핑).
2. 사람의 문장을 **구조화된 명령**으로 바꿉니다(언어 이해).
3. 명령 속 이름을 지도 위의 **특정 물체와 자세**로 연결합니다(그라운딩).
4. 가서 **정말 있는지 확인**하고, 없으면 찾습니다(검증과 복구).

로봇 공학에서 **VLN**(Vision-and-Language Navigation), **객체 목표 내비게이션**(ObjectNav)으로 연구되는 문제의 작은 판입니다. 대형 모델 없이 라즈베리파이 5에서 돌아가는 구조를 만들고, 각 단계의 오류가 최종 성공률에 어떻게 쌓이는지 측정합니다.

## 이론

### 시맨틱 지도의 구조

점유 격자 지도(M09)는 "어디가 막혔나"만 압니다. 시맨틱 지도는 그 위에 **의미 층**을 얹습니다. 이 프로젝트의 지도는 세 가지로 이루어집니다.

| 층 | 내용 | 예 |
|---|---|---|
| 기하 | 점유 격자 `map_01` (Nav2가 사용) | M09에서 만든 지도 |
| 랜드마크 | 이름표, map 좌표, 관측 횟수, 마지막 관측 시각 | `{"label": "red_ball", "x": 2.2, "y": -0.2, "n": 19, "t": 815.2, "room": "주방"}` |
| 장소 | 방 이름과 다각형(map 좌표 꼭짓점) | `"주방": [[0.6, -2], [3, -2], [3, 2], [0.6, 2]]` |

방 다각형은 RViz **Publish Point**(`/clicked_point`)로 꼭짓점을 찍어 만들고, 랜드마크의 방은 점-다각형 포함 판정(ray casting 교차 수 홀짝)으로 정합니다. 이 구조는 JSON 하나로 저장되고 사람이 읽고 고칠 수 있습니다. 논문에서 쓰는 3D 장면 그래프(scene graph)의 가장 단순한 형태입니다.

### 검출 상자에서 map 좌표까지

@fig[p08-frames] 픽셀과 깊이로 광학 좌표를 구하고(역투영), TF로 map까지 옮긴 뒤, 같은 이름표끼리 융합합니다.

**① 픽셀과 깊이.** YOLOv5는 상자 $(x_1, y_1, x_2, y_2)$를 줍니다. 중심 $(u, v)$를 쓰고, 깊이는 한 픽셀이 아니라 **상자 가운데 절반 영역의 유효 깊이(0 제외) 중앙값**을 씁니다. 상자 가장자리에는 배경 깊이가 섞이고, 한 픽셀은 구멍(0)이거나 잡음일 수 있기 때문입니다. 깊이 카메라는 물체의 **앞 표면**까지를 재므로, 중심을 원하면 클래스별 대략 반지름(공 0.06 m 등)을 더합니다.

**② 역투영.** M07의 핀홀 모델을 거꾸로 풉니다. 내부 파라미터는 `camera_info`의 $K$에서 읽습니다.

$X = (u - c_x) Z / f_x$,  $Y = (v - c_y) Z / f_y$,  $Z = \text{depth}(u, v)$

이 점은 **광학 프레임**(x 오른쪽, y 아래, z 앞)의 좌표입니다. 로봇 프레임(x 앞, y 왼쪽)과 축이 다르다는 점이 가장 흔한 실수입니다. Playground 실습에서는 2D라서 $x_{base} = Z + 0.061$, $y_{base} = -X$로 직접 바꿨고, 실물에서는 TF가 이 회전을 대신합니다.

**③ TF.** MentorPi의 TF 사슬은 `map → odom → base_footprint → base_link → depth_cam → ascamera_color_0`입니다(M07, M08). `lookup_transform('map', 'ascamera_color_0', t)`가 주는 변환 $T$(회전 $R$, 이동 $\mathbf{t}$)로

$\mathbf{p}_{map} = R\,\mathbf{P}_{opt} + \mathbf{t}$

를 계산하고 높이 $z$는 버립니다. `map → odom`은 AMCL(M11)이 발행하므로, **위치 추정이 틀리면 지도도 틀립니다.** 실습 1에서 오도메트리만 쓰면 멀리 간 주방 쪽 물체의 오차가 커지는 것을 확인합니다.

**시각 동기화.** 원본 `yolo_detect.py`는 `ObjectsInfo`에 헤더(시각)를 넣지 않고, `yolo_result`의 시각도 영상 시각이 아니라 처리 끝난 시각입니다. 라즈베리파이 CPU 추론은 한 프레임에 수백 ms가 걸리므로, 로봇이 도는 중이면 "검출된 순간의 자세"와 "지금 자세"가 달라 방위 오차가 생깁니다. 실용적인 해결은 **멈춰서 보고(stop-and-look), 천천히 도는 것**이고, 근본적인 해결은 검출 노드가 입력 영상의 `header.stamp`를 결과에 복사하게 고치는 것입니다(확장 과제).

### 다중 관측 융합

한 번의 검출은 틀릴 수 있습니다. 여러 관측을 모아 확률적으로 믿을 만한 것만 남깁니다.

| 단계 | 규칙 | 목적 |
|---|---|---|
| 게이팅 | 같은 이름표이고 거리 < 0.35 m인 랜드마크에만 연결 | 다른 물체와 섞이지 않게 |
| 연결 | 게이트 안 후보가 여럿이면 가장 가까운 것(최근접 이웃) | 같은 종류 여러 개(컵 2개) |
| 갱신 | 누적 평균 $\bar{x}_n = \bar{x}_{n-1} + (x_n - \bar{x}_{n-1}) / n$ | 잡음을 $1/\sqrt{n}$로 줄임 |
| 확정 | 관측 횟수 $n \ge 3$ | 한두 번 나온 헛검출 제거 |
| 소멸 | 시야 안에 있어야 하는데 안 보이면 미스 +1, 미스가 많으면 삭제 | 옮겨진 물체 정리 |

누적 평균은 잡음 분산이 같다고 가정한 칼만 필터(정지 물체, 공정 잡음 0)와 같습니다. 관측마다 거리가 다르면(깊이 잡음은 거리의 제곱에 비례해 커짐) 분산 역수로 가중 평균하는 것이 더 좋습니다. 게이트를 유클리드 거리 대신 공분산으로 정규화한 **마할라노비스 거리** $d^2 = (\mathbf{z} - \hat{\mathbf{x}})^\top S^{-1} (\mathbf{z} - \hat{\mathbf{x}})$로 바꾸는 것이 확장 과제입니다.

**색 속성.** COCO로 학습된 `yolov5s`는 `sports ball`, `chair`, `cup`을 알지만 **색은 모릅니다.** 상자 안 픽셀을 HSV로 바꾸고, 채도·명도가 충분한 픽셀의 색상(H)을 빨강(0~10, 170~179), 초록(40~80), 파랑(100~130) 구간으로 투표해 과반이면 색을 붙입니다(A01의 색 인식과 같은 원리). 조명에 따라 흔들리므로 색도 관측마다 투표해 다수결로 확정합니다.

### 자연어 명령의 구조

명령 문장을 다섯 개의 **슬롯**으로 봅니다.

| 슬롯 | 값 | 한국어 단서 |
|---|---|---|
| 동사(intent) | `go`, `find`, `fetch` | 가·이동·와 / 찾 / 가져 |
| 대상(object) | `ball`, `chair`, `cup` | 공, 의자, 컵 |
| 색(color) | `red`, `blue`, `green`, 없음 | 빨간·빨강, 파란·파랑, 초록 |
| 장소(place) | `거실`, `주방`, 없음 | 거실, 주방·부엌 (+에 있는) |
| 관계(relation) | `at`, `front`, `side`, `behind` | 앞, 옆, 뒤 (없으면 at) |

한국어는 조사가 단어에 붙습니다("공**으로**", "주방**에**", "의자**의**"). 형태소 분석기 없이도, 어절이 사전 단어로 **시작하는지**(접두 일치)만 보면 조사를 떼어낸 효과가 납니다. 이 방법의 한계도 분명합니다. "가까운"은 동사 "가"로, "공간"은 "공"으로 잘못 걸립니다. 그래서 사전은 작게 유지하고, **시험 문장 세트**(맞게 해석해야 할 문장 + 거부해야 할 문장)로 회귀 시험을 합니다.

```text
parse(문장):
    어절 ← 한글 덩어리들
    for 슬롯 in [동사, 대상, 색, 장소, 관계]:
        for 어절 in 어절들:
            if 어절이 사전[슬롯]의 단어로 시작하고 슬롯이 비어 있으면: 채움
    return 슬롯
실행 가능? 동사 ∈ {go, find} 그리고 대상 ≠ 없음. 아니면 되묻기
```

**LLM은 선택, 그리고 울타리 안에서.** 대형 언어 모델은 "저기 빨간 거 있잖아, 그쪽으로" 같은 문장도 해석할 수 있지만, (1) 네트워크·지연, (2) 형식이 틀린 출력, (3) 없는 물체를 지어내는 문제가 있습니다. 그래서 LLM에는 **슬롯 JSON만** 내게 하고(좌표 금지), 받은 JSON은 규칙 파서와 **똑같은 스키마 검사**를 통과해야만 씁니다. 로컬 LLM 서버가 없거나, 3 s 안에 답이 없거나, 검사에 실패하면 규칙 파서 결과를 씁니다. 지도에 없는 물체는 LLM이 무엇이라 하든 그라운딩 단계에서 걸러집니다.

```json
{"type": "object", "additionalProperties": false,
 "required": ["intent", "object", "color", "place", "relation"],
 "properties": {
   "intent":   {"enum": ["go", "find", "fetch"]},
   "object":   {"enum": ["ball", "chair", "cup"]},
   "color":    {"enum": [null, "red", "blue", "green"]},
   "place":    {"enum": [null, "거실", "주방"]},
   "relation": {"enum": ["at", "front", "side", "behind"]}}}
```

### 그라운딩과 접근 자세

슬롯 → 후보 랜드마크 → 하나 선택 → 목표 자세 순서입니다.

1. **후보**: 이름표가 맞고(색이 있으면 `red_ball`처럼 정확히, 없으면 `*_ball` 전체), 장소가 있으면 그 방 안에 있는 것.
2. **선택**: 후보가 여럿이면 로봇에서 가장 가까운 것(또는 되묻기: "거실 컵과 주방 컵 중 어느 것인가요?"). 후보가 없으면 탐색.
3. **목표 자세**: 접근 방향 단위 벡터 $\mathbf{u}$(로봇 또는 마지막 경유점 → 물체)에 대해

| 관계 | 목표 위치 $\mathbf{g}$ | 의미 |
|---|---|---|
| at, 앞(front) | $\mathbf{o} - D\,\mathbf{u}$ | 로봇 쪽에서 D 앞 (보는 사람 기준 "앞") |
| 옆(side) | $\mathbf{o} + D\,\mathbf{u}_\perp$, $\mathbf{u}_\perp = (-u_y, u_x)$ | 물체의 왼쪽 옆 |
| 뒤(behind) | $\mathbf{o} + D\,\mathbf{u}$ | 물체 너머 |

방향은 항상 물체를 바라보게 $\psi = \operatorname{atan2}(o_y - g_y,\, o_x - g_x)$입니다. 접근 거리 $D$는 두 조건을 모두 만족해야 합니다: $D \ge r_{robot} + r_{obj} + \text{여유}$(부딪히지 않게), 그리고 $D - 0.061 \ge$ 깊이 카메라 최소 측정 거리(도착해서 **다시 볼 수 있게**). 앞의 조건만 생각해 0.3 m로 두면, 도착 후 물체가 카메라 최소 거리 안에 들어와 검증이 항상 실패합니다. 목표가 장애물 팽창 영역 안이면 Nav2가 거부하므로, D를 키우거나 관계를 바꿔 다시 계산합니다.

"앞"을 **보는 사람 기준**(로봇 쪽)으로 정의한 것도 설계 선택입니다. 의자처럼 고유한 앞면이 있는 물체는 물체 기준 "앞"이 다를 수 있습니다(확장 과제).

### 검증과 실패 처리

@fig[p08-fsm] 명령 실행 상태 기계. 지도에 없거나 도착해서 안 보이면 탐색으로 가고, 찾으면 지도를 고친 뒤 다시 그라운딩합니다.

Nav2의 `SUCCEEDED`는 "목표 자세에 도착했다"는 뜻이지 "물체가 거기 있다"는 뜻이 아닙니다. 물체는 옮겨질 수 있고, 지도는 틀릴 수 있습니다. 그래서 도착 후 1~3 s 동안 카메라로 다시 보고, 같은 이름표가 예상 위치 0.3~0.5 m 안에서 3회 이상 관측되어야 성공으로 칩니다. 실패하면 **탐색 패턴**을 씁니다.

1. 제자리 360° 회전(시야각 60°라 한 바퀴면 주변을 모두 봄).
2. 못 찾으면 방 중심들을 가까운 순서로 방문하며 각각 360°.
3. 발견하면 지도의 랜드마크를 새 위치로 갱신하고 GROUND로 돌아갑니다. 모두 실패하면 FAIL로 보고합니다.

## 실습 (시뮬레이션)

아래 코드는 이 페이지에서 바로 실행됩니다. ▶ 실행 후 결과 패널의 **출력** 탭에 로그가 나오고, 로봇을 움직이는 실습 1·3·4는 **2D 재생**(위에서 본 월드·라이다·궤적)과 **3D 재생**(MentorPi URDF 모델) 탭에서 다시 볼 수 있습니다. 월드는 6 × 4 m `room`이고, x = 0.6 m의 벽(문 두 곳)이 서쪽 **거실**과 동쪽 **주방**을 나눕니다. `sim.add_object()`로 이름표 붙은 물체를 놓고, YOLO + 깊이 카메라 대신 `sim.objects()`와 `sim.pose()`로 **검출기를 흉내** 냅니다(시야 ±30°, 거리 0.25~3 m, 라이다로 가림 판정, 검출률 80 %, 가끔 헛검출). 이 흉내 함수만 실물의 YOLO·깊이 콜백으로 바꾸면 나머지 코드는 같습니다.

### 실습 1. 시맨틱 매핑 투어

로봇이 거실에서 출발해 문을 지나 주방까지 경유점을 따라가며, 진행 방향 ±60°로 고개를 흔들어(메카넘이라 이동과 회전이 독립) 주변을 봅니다. 5 Hz로 검출 → 역투영 → map 좌표 → 게이팅·누적 평균을 하고, 끝나면 3회 이상 관측된 랜드마크만 방 이름과 함께 JSON으로 냅니다.

```python run
import math, json, random
import numpy as np
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import Twist
from nav_msgs.msg import Odometry
from sensor_msgs.msg import LaserScan
import mentorpi_sim as sim                                        # 시뮬 전용
START = (-2.3, -1.3, 0.0)                                         # map 좌표의 출발 자세 = odom 원점
sim.setup(world="room", duration=24.0, start=START)               # 시뮬 전용
for lab, x, y, r in [("red_ball", 2.1, -0.3, 0.06), ("blue_ball", -1.6, 0.5, 0.06), ("chair", -0.3, -1.3, 0.15),
                     ("cup", -2.5, 0.9, 0.04), ("cup", 2.6, 0.5, 0.04)]:
    sim.add_object(lab, x, y, r)                                  # 시뮬 전용
FX, CX, CAM_X = 460.0, 320.0, 0.061                               # 내부 파라미터(M07), base→depth_cam 오프셋(M08)
ROOMS = {"거실": [(-3, -2), (0.6, -2), (0.6, 2), (-3, 2)], "주방": [(0.6, -2), (3, -2), (3, 2), (0.6, 2)]}
TOUR = [(-1.2, -0.45), (-0.4, -0.3), (0.3, 0.05), (1.4, -0.2)]
def fake_yolo_depth(scan):                                        # 시뮬 전용: YOLO + 깊이 영상 대용
    x, y, th = sim.pose(); out = []
    for lab, ox, oy, r in sim.objects():
        dx, dy = ox - x, oy - y
        xc, yc = math.cos(th) * dx + math.sin(th) * dy - CAM_X, -math.sin(th) * dx + math.cos(th) * dy
        b = math.atan2(yc, xc)
        i = int(round((b - scan.angle_min) / scan.angle_increment)) % len(scan.ranges)
        if abs(b) > math.radians(30) or not 0.25 < xc < 3.0 or scan.ranges[i] < math.hypot(xc, yc) - r - 0.1:
            continue                                              # 시야 밖·거리 밖·가려짐
        if random.random() < 0.8:                                 # 검출률 80 % (놓침 20 %)
            out.append((lab, CX - FX * yc / xc + random.gauss(0, 3), xc * random.gauss(1, 0.03)))
    if random.random() < 0.05:                                    # 가끔 헛검출
        out.append(("chair", random.uniform(0, 640), random.uniform(0.5, 2.5)))
    return out
def in_poly(p, poly):
    c = False
    for (x1, y1), (x2, y2) in zip(poly, poly[1:] + poly[:1]):
        if (y1 > p[1]) != (y2 > p[1]) and p[0] < x1 + (p[1] - y1) * (x2 - x1) / (y2 - y1): c = not c
    return c

class SemanticMapper(Node):
    def __init__(self):
        super().__init__('semantic_mapper')
        self.cmd = self.create_publisher(Twist, '/controller/cmd_vel', 10)
        self.create_subscription(Odometry, '/odom', self.on_odom, 10)
        self.create_subscription(LaserScan, '/scan', lambda m: setattr(self, 'scan', m), 10)
        self.pose, self.scan, self.wp, self.marks, self.n_det = None, None, 0, [], 0
        self.create_timer(0.2, self.detect); self.create_timer(0.05, self.drive)
    def on_odom(self, m):                                         # map = START ∘ odom (실물: TF map→base_footprint)
        p, q = m.pose.pose.position, m.pose.pose.orientation
        c, s = math.cos(START[2]), math.sin(START[2])
        self.pose = (START[0] + c * p.x - s * p.y, START[1] + s * p.x + c * p.y, START[2] + 2 * math.atan2(q.z, q.w))
    def detect(self):
        if self.pose is None or self.scan is None: return
        x, y, th = self.pose
        for lab, u, z in fake_yolo_depth(self.scan):
            xo = (u - CX) * z / FX                                # 역투영: 광학 x(오른쪽)
            bx, by = CAM_X + z, -xo                               # 광학 → base (x 앞, y 왼쪽)
            mx, my = x + math.cos(th) * bx - math.sin(th) * by, y + math.sin(th) * bx + math.cos(th) * by
            self.n_det += 1
            near = [m for m in self.marks if m["label"] == lab and math.hypot(m["x"] - mx, m["y"] - my) < 0.35]
            if near:                                              # 게이트 안: 누적 평균
                m = near[0]; m["n"] += 1
                m["x"] += (mx - m["x"]) / m["n"]; m["y"] += (my - m["y"]) / m["n"]
            else:
                self.marks.append({"label": lab, "x": mx, "y": my, "n": 1})
    def drive(self):
        t = Twist()
        if self.pose and self.wp < len(TOUR):
            x, y, th = self.pose; ex, ey = TOUR[self.wp][0] - x, TOUR[self.wp][1] - y; d = math.hypot(ex, ey)
            if d < 0.05: self.wp += 1
            else:                                                 # 메카넘: 진행 방향 ±60°로 고개를 흔들며 평행이동
                k = min(0.2, 1.2 * d) / d
                t.linear.x, t.linear.y = k * (math.cos(th) * ex + math.sin(th) * ey), k * (-math.sin(th) * ex + math.cos(th) * ey)
                look = math.atan2(ey, ex) + math.radians(60) * math.sin(0.8 * self.get_clock().now().nanoseconds * 1e-9)
                t.angular.z = max(-1.0, min(1.0, 2.0 * math.atan2(math.sin(look - th), math.cos(look - th))))
        self.cmd.publish(t)

random.seed(1)
rclpy.init(); node = SemanticMapper()
try:
    rclpy.spin(node)
except KeyboardInterrupt:
    pass
finally:
    node.cmd.publish(Twist())
    truth = sim.objects()                                         # 시뮬 전용: 오차 평가
    sem = []
    for m in sorted(node.marks, key=lambda m: -m["n"]):
        err = min(math.hypot(m["x"] - tx, m["y"] - ty) for l, tx, ty, r in truth if l == m["label"]) if m["label"] in [t[0] for t in truth] else 9
        if m["n"] < 3: continue
        print("%-9s (%5.2f, %5.2f) 관측 %2d회  오차 %.2f m" % (m["label"], m["x"], m["y"], m["n"], err))
        room = next((k for k, p in ROOMS.items() if in_poly((m["x"], m["y"]), p)), "?")
        sem.append({"label": m["label"], "x": round(m["x"], 2), "y": round(m["y"], 2), "n": m["n"], "room": room})
    print("검출 %d건 → 후보 %d개 중 %d개 확정 (관측 3회 이상)" % (node.n_det, len(node.marks), len(sem)))
    doc = json.dumps({"frame": "map", "rooms": ROOMS, "landmarks": sem}, ensure_ascii=False)
    print("semantic_map.json (%d바이트) 첫 랜드마크:" % len(doc.encode()), json.dumps(sem[0], ensure_ascii=False))
    node.destroy_node(); rclpy.shutdown()
```

```python run
    {"label": "red_ball", "x": 2.2, "y": -0.2, "n": 19, "room": "주방"},

LEX = {"intent": {"가져": "fetch", "찾": "find", "이동": "go", "가": "go", "와": "go"},     # 앞쪽이 우선

       "color": {"빨간": "red", "빨강": "red", "파란": "blue", "파랑": "blue", "초록": "green"},
       "place": {"주방": "주방", "부엌": "주방", "거실": "거실"},

SCHEMA = {"intent": ["go", "find", "fetch"], "object": ["ball", "chair", "cup"], "color": [None, "red", "blue", "green"],
          "place": [None, "거실", "주방"], "relation": ["at", "front", "side", "behind"]}

def parse(text):                                                     # 규칙 기반: 사전 + 조사 무시
    words = re.findall(r"[가-힣]+", text)
    slot = {"intent": None, "object": None, "color": None, "place": None, "relation": "at"}
    for key, lex in LEX.items():
        for w in words:
            hit = next((v for k, v in lex.items() if w.startswith(k)), None)
            if hit and (slot[key] in (None, "at")):
                slot[key] = hit
    return slot

def validate(slot):                                                  # 스키마 검사 (LLM 출력도 같은 검사를 통과해야 함)
    bad = [k for k in SCHEMA if slot.get(k, "없음") not in SCHEMA[k]] + [k for k in slot if k not in SCHEMA]
    return (not bad), bad

def ground(slot, robot, D=0.4):                                     # 슬롯 → (목표 자세, 랜드마크, 설명)
    want = (slot["color"] + "_" if slot["color"] else "") + slot["object"]
    cands = [m for m in SEM["landmarks"] if (m["label"] == want or not slot["color"] and m["label"].endswith("_" + want))
             and slot["place"] in (None, m["room"])]
    if not cands:
        return None, None, "지도에 '%s'%s 없음 → 탐색 필요" % (want, " (" + slot["place"] + ")" if slot["place"] else "")
    m = min(cands, key=lambda m: math.hypot(m["x"] - robot[0], m["y"] - robot[1]))   # 여러 개면 가까운 것
    ux, uy = m["x"] - robot[0], m["y"] - robot[1]; L = math.hypot(ux, uy); ux, uy = ux / L, uy / L
    off = {"at": (-ux, -uy), "front": (-ux, -uy), "side": (-uy, ux), "behind": (ux, uy)}[slot["relation"]]
    gx, gy = m["x"] + D * off[0], m["y"] + D * off[1]
    return (round(gx, 2), round(gy, 2), round(math.atan2(m["y"] - gy, m["x"] - gx), 2)), m, \
        "%s(%.2f, %.2f) 후보 %d개" % (m["label"], m["x"], m["y"], len(cands))


robot = (-2.3, -1.3)
for text in ["빨간 공 앞으로 가 줘", "의자 옆으로 이동", "주방에 있는 컵으로 가", "컵으로 가 줘", "거실 공 뒤로 가",
             "초록색 공 찾아 줘", "파란 공 가져와", "창문 열어"]:

        print("%-14s → 거부: 집기(fetch)는 이 로봇이 못 함 → '가'로 바꿔 말해 주세요" % text); continue
    goal, m, why = ground(slot, robot)
    print("%-14s → %s/%s/%s/%s/%s | %s%s" % (text, slot["intent"], slot["color"], slot["object"],
          slot["place"], slot["relation"], why, " → 목표 %s" % (goal,) if goal else ""))

print("--- LLM 출력(가정) 검증 ---")

    except ValueError:
```

### 실습 3. 명령으로 주행하기

실습 1의 지도로 두 명령을 차례로 실행합니다. 목표가 다른 방에 있으면 문 경유점(거실 → 주방)을 거치고, 접근 방향은 마지막 경유점 → 물체로 잡습니다. 실물에서는 경유점과 주행을 Nav2가 대신합니다(전역 계획 + 코스트맵).

```python run
import math, re
import numpy as np
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import Twist
from nav_msgs.msg import Odometry
from sensor_msgs.msg import LaserScan
import mentorpi_sim as sim                                        # 시뮬 전용
START = (-0.9, -0.6, 0.0)
sim.setup(world="room", duration=30.0, start=START)               # 시뮬 전용
for lab, x, y, r in [("red_ball", 2.1, -0.3, 0.06), ("chair", -0.3, -1.3, 0.15)]:
    sim.add_object(lab, x, y, r)                                  # 시뮬 전용

LANDMARKS = [{"label": "red_ball", "x": 2.2, "y": -0.2, "room": "주방"},       # 실습 1의 지도
             {"label": "chair", "x": -0.28, "y": -1.27, "room": "거실"}]
DOOR = [(0.25, 0.1), (1.0, -0.3)]                                 # 거실 → 주방 경유점 (반대 방향은 뒤집기)
room_of = lambda x: "거실" if x < 0.6 else "주방"
OBJ, COLOR, REL = {"공": "ball", "의자": "chair"}, {"빨간": "red_", "파란": "blue_"}, {"앞": "front", "옆": "side", "뒤": "behind"}
COMMANDS = ["의자 옆으로 이동", "주방에 있는 빨간 공 앞으로 가 줘"]
def plan(cmd, pose, D=0.4):                                      # 파싱 → 그라운딩 → 경유점 + 목표 자세
    ws = re.findall(r"[가-힣]+", cmd); pick = lambda lex: next((v for w in ws for k, v in lex.items() if w.startswith(k)), "")
    label, rel = pick(COLOR) + pick(OBJ), pick(REL) or "front"
    m = next(m for m in LANDMARKS if m["label"] == label)
    path = [] if room_of(pose[0]) == m["room"] else (DOOR if m["room"] == "주방" else DOOR[::-1])
    px, py = path[-1] if path else pose[:2]                       # 접근 방향 = 마지막 경유점 → 물체
    L = math.hypot(m["x"] - px, m["y"] - py); ux, uy = (m["x"] - px) / L, (m["y"] - py) / L
    ox, oy = {"front": (-ux, -uy), "side": (-uy, ux), "behind": (ux, uy)}[rel]
    gx, gy = m["x"] + D * ox, m["y"] + D * oy
    return path + [(gx, gy)], math.atan2(m["y"] - gy, m["x"] - gx), m

class CommandNavigator(Node):
    def __init__(self):
        super().__init__('nl_navigator')
        self.cmd = self.create_publisher(Twist, '/controller/cmd_vel', 10)
        self.create_subscription(Odometry, '/odom', self.on_odom, 10)
        self.create_subscription(LaserScan, '/scan', lambda m: setattr(self, 'scan', m), 10)
        self.pose, self.scan, self.queue, self.task = None, None, list(COMMANDS), None
        self.create_timer(0.05, self.loop)
    def on_odom(self, m):
        p, q = m.pose.pose.position, m.pose.pose.orientation      # map = START ∘ odom (실물: AMCL TF)
        self.pose = (START[0] + p.x, START[1] + p.y, START[2] + 2 * math.atan2(q.z, q.w))
    def blocked(self, vx, vy):                                    # 진행 방향 ±30°에 0.2 m 이내 → 정지
        r = np.array(self.scan.ranges); a = self.scan.angle_min + np.arange(len(r)) * self.scan.angle_increment
        d = np.abs(np.arctan2(np.sin(a - math.atan2(vy, vx)), np.cos(a - math.atan2(vy, vx))))
        return bool(np.any((d < math.radians(30)) & (r < 0.2)))
    def loop(self):
        if self.pose is None or self.scan is None: return
        t, (x, y, th) = Twist(), self.pose
        if self.task is None and self.queue:
            text = self.queue.pop(0); path, yaw, m = plan(text, self.pose)
            self.task = {"text": text, "path": path, "yaw": yaw, "m": m}
            self.get_logger().info('"%s" → %s, 경유점 %d개, 목표 (%.2f, %.2f, %.0f°)' % (
                text, m["label"], len(path) - 1, path[-1][0], path[-1][1], math.degrees(yaw)))
        if self.task:
            gx, gy = self.task["path"][0]; ex, ey = gx - x, gy - y; d = math.hypot(ex, ey)
            last = len(self.task["path"]) == 1
            eyaw = math.atan2(math.sin(self.task["yaw"] - th), math.cos(self.task["yaw"] - th)) if last else 0.0
            if d < (0.04 if last else 0.12) and abs(eyaw) < 0.08:
                self.task["path"].pop(0)
                if not self.task["path"]:
                    tx, ty, tth = sim.pose()                      # 시뮬 전용: 실제 자세로 검증
                    self.get_logger().info('도착: 목표까지 %.3f m, 물체까지 %.2f m (%.1f s)' % (
                        math.hypot(tx - gx, ty - gy), math.hypot(tx - self.task["m"]["x"], ty - self.task["m"]["y"]),
                        self.get_clock().now().nanoseconds * 1e-9))
                    self.task = None
            else:
                k = min(0.2, 1.0 * d) / max(d, 1e-6)
                wx, wy = k * ex, k * ey                            # map 좌표 속도 → base 좌표
                t.linear.x, t.linear.y = math.cos(th) * wx + math.sin(th) * wy, -math.sin(th) * wx + math.cos(th) * wy
                t.angular.z = max(-0.5, min(0.5, 1.5 * eyaw))
                if d > 0.05 and self.blocked(t.linear.x, t.linear.y):
                    t.linear.x = t.linear.y = 0.0
        self.cmd.publish(t)
        if self.task is None and not self.queue: raise KeyboardInterrupt

rclpy.init(); node = CommandNavigator()
try:
    rclpy.spin(node)
except KeyboardInterrupt:
    pass
finally:
    node.cmd.publish(Twist()); node.destroy_node(); rclpy.shutdown()
```

### 실습 4. 검증과 탐색: 옮겨진 물체 찾기

지도에는 파란 공이 (−1.63, 0.54)에 있다고 적혀 있지만, 누군가 (−2.2, −0.6)으로 옮겼습니다. 로봇은 지도 위치로 가서 1 s 동안 다시 보고(VERIFY), 안 보이면 제자리에서 돌며 찾고(SEARCH), 찾으면 지도를 갱신해 다시 갑니다.

```python run
import math, random
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import Twist
from nav_msgs.msg import Odometry
from sensor_msgs.msg import LaserScan
import mentorpi_sim as sim                                        # 시뮬 전용
START = (-0.8, -0.9, 0.0)
sim.setup(world="room", duration=30.0, start=START)               # 시뮬 전용
sim.add_object("blue_ball", -2.2, -0.6, 0.06)                     # 시뮬 전용: 누군가 공을 옮겨 놓았다
FX, CX, CAM_X, D = 460.0, 320.0, 0.061, 0.4
mark = {"label": "blue_ball", "x": -1.63, "y": 0.54}              # 지도에 적힌 (옛) 위치
def fake_yolo_depth(scan):                                        # 시뮬 전용: 실습 1과 같은 검출기 흉내
    x, y, th = sim.pose(); out = []
    for lab, ox, oy, r in sim.objects():
        dx, dy = ox - x, oy - y
        xc, yc = math.cos(th) * dx + math.sin(th) * dy - CAM_X, -math.sin(th) * dx + math.cos(th) * dy
        b = math.atan2(yc, xc)
        i = int(round((b - scan.angle_min) / scan.angle_increment)) % len(scan.ranges)
        if abs(b) < math.radians(30) and 0.25 < xc < 3.0 and scan.ranges[i] > math.hypot(xc, yc) - r - 0.1 \
                and random.random() < 0.8:
            out.append((lab, CX - FX * yc / xc + random.gauss(0, 3), xc * random.gauss(1, 0.03)))
    return out

class FindAndGo(Node):
    def __init__(self):
        super().__init__('find_and_go')
        self.cmd = self.create_publisher(Twist, '/controller/cmd_vel', 10)
        self.create_subscription(Odometry, '/odom', self.on_odom, 10)
        self.create_subscription(LaserScan, '/scan', lambda m: setattr(self, 'scan', m), 10)
        self.pose, self.scan, self.seen, self.turned = None, None, [], 0.0
        self.state, self.goal, self.t0 = 'IDLE', None, 0.0
        self.create_timer(0.05, self.loop); self.create_timer(0.2, self.detect)
    def now(self): return self.get_clock().now().nanoseconds * 1e-9
    def go(self, st, why):
        self.get_logger().info('%-6s → %-6s %s' % (self.state, st, why)); self.state, self.t0 = st, self.now()
    def on_odom(self, m):
        p, q = m.pose.pose.position, m.pose.pose.orientation
        self.pose = (START[0] + p.x, START[1] + p.y, START[2] + 2 * math.atan2(q.z, q.w))
    def detect(self):                                             # 검출 → 역투영 → map 좌표 (실습 1과 같은 식)
        if self.state not in ('VERIFY', 'SEARCH') or self.scan is None: return
        x, y, th = self.pose
        for lab, u, z in fake_yolo_depth(self.scan):
            if lab == mark["label"]:
                bx, by = CAM_X + z, -(u - CX) * z / FX
                self.seen.append((x + math.cos(th) * bx - math.sin(th) * by, y + math.sin(th) * bx + math.cos(th) * by))
    def set_goal(self):                                           # 로봇 쪽에서 D만큼 앞, 물체를 바라봄
        x, y, _ = self.pose; L = math.hypot(mark["x"] - x, mark["y"] - y)
        gx, gy = mark["x"] - D * (mark["x"] - x) / L, mark["y"] - D * (mark["y"] - y) / L
        self.goal = (gx, gy, math.atan2(mark["y"] - gy, mark["x"] - gx))
    def loop(self):
        if self.pose is None or self.scan is None: return
        t, (x, y, th) = Twist(), self.pose
        if self.state == 'IDLE':
            self.set_goal(); self.go('GOTO', '지도 위치 (%.2f, %.2f)로' % (mark["x"], mark["y"]))
        elif self.state == 'GOTO':
            ex, ey = self.goal[0] - x, self.goal[1] - y; d = math.hypot(ex, ey)
            eyaw = math.atan2(math.sin(self.goal[2] - th), math.cos(self.goal[2] - th))
            if d < 0.04 and abs(eyaw) < 0.08:
                self.seen = []; self.go('VERIFY', '도착, 1 s 동안 확인')
            else:
                k = min(0.2, d) / max(d, 1e-6)
                t.linear.x, t.linear.y = k * (math.cos(th) * ex + math.sin(th) * ey), k * (-math.sin(th) * ex + math.cos(th) * ey)
                t.angular.z = max(-0.5, min(0.5, 1.5 * eyaw))
        elif self.state == 'VERIFY' and self.now() - self.t0 > 1.0:
            near = [p for p in self.seen if math.hypot(p[0] - mark["x"], p[1] - mark["y"]) < 0.3]
            if len(near) >= 3:
                sx, sy = sum(p[0] for p in near) / len(near), sum(p[1] for p in near) / len(near)
                self.go('DONE', '확인 %d회, 물체까지 %.2f m (실제 %.2f m)' % (len(near), math.hypot(sx - x, sy - y),
                        math.hypot(sim.pose()[0] - (-2.2), sim.pose()[1] - (-0.6))))   # 시뮬 전용: 실제 거리
            else:
                self.go('SEARCH', '지도 위치 근처 검출 %d회 → 제자리 360° 탐색' % len(near)); self.seen, self.turned = [], 0.0
        elif self.state == 'SEARCH':
            if len(self.seen) >= 3:                               # 3회 이상 일관되게 보이면 지도 갱신
                mark["x"] = sum(p[0] for p in self.seen[-3:]) / 3; mark["y"] = sum(p[1] for p in self.seen[-3:]) / 3
                self.set_goal(); self.go('GOTO', '발견! 지도 갱신 (%.2f, %.2f), %.0f° 돌아서' % (mark["x"], mark["y"], math.degrees(self.turned)))
            elif self.turned > 2 * math.pi:
                self.go('FAIL', '한 바퀴 돌아도 없음 → 다음 탐색 지점 또는 사용자에게 보고')
            else:
                t.angular.z = 0.5; self.turned += 0.5 * 0.05
        self.cmd.publish(t)
        if self.state in ('DONE', 'FAIL'): raise KeyboardInterrupt

random.seed(3)
rclpy.init(); node = FindAndGo()
try:
    rclpy.spin(node)
except KeyboardInterrupt:
    pass
finally:
    node.cmd.publish(Twist()); node.destroy_node(); rclpy.shutdown()
```

### 2) 시맨틱 매퍼 노드

```python robot
#!/usr/bin/env python3
# semantic_mapper.py — YOLOv5 검출 + 깊이 + TF → map 랜드마크 → ~/semantic/semantic_map.json
import json, math, os
import cv2
import numpy as np
import rclpy
from rclpy.node import Node
from rclpy.time import Time
from cv_bridge import CvBridge
from sensor_msgs.msg import Image, CameraInfo
from std_msgs.msg import String
from interfaces.msg import ObjectsInfo
from tf2_ros import Buffer, TransformListener, TransformException
from tf_transformations import quaternion_matrix

CLASSES = {'sports ball': 'ball', 'chair': 'chair', 'cup': 'cup'}     # COCO 이름 → 지도 이름 (person 제외)
HUE = {'red': [(0, 10), (170, 179)], 'green': [(40, 80)], 'blue': [(100, 130)]}   # OpenCV H 0~179
RADIUS = {'ball': 0.06, 'chair': 0.2, 'cup': 0.04}                   # 앞 표면 → 중심 보정
ROOMS = {'거실': [(-3, -2), (0.6, -2), (0.6, 2), (-3, 2)],             # /clicked_point로 측정한 값으로 교체
         '주방': [(0.6, -2), (3, -2), (3, 2), (0.6, 2)]}
GATE, CONFIRM, OPT = 0.35, 3, 'ascamera_color_0'
OUT = os.path.expanduser('~/semantic/semantic_map.json')
CAM = '/ascamera/camera_publisher/'

def in_poly(x, y, poly):
    c = False
    for (x1, y1), (x2, y2) in zip(poly, poly[1:] + poly[:1]):
        if (y1 > y) != (y2 > y) and x < x1 + (y - y1) * (x2 - x1) / (y2 - y1):
            c = not c
    return c

class SemanticMapper(Node):
    def __init__(self):
        super().__init__('semantic_mapper')
        self.bridge, self.K, self.depth, self.rgb, self.marks = CvBridge(), None, None, None, []
        self.create_subscription(CameraInfo, CAM + 'rgb0/camera_info', self.on_info, 1)
        self.create_subscription(Image, CAM + 'depth0/image_raw', lambda m: setattr(self, 'depth', m), 1)
        self.create_subscription(Image, CAM + 'rgb0/image', lambda m: setattr(self, 'rgb', m), 1)
        self.create_subscription(ObjectsInfo, '/yolov5_ros2/object_detect', self.on_det, 10)
        self.pub = self.create_publisher(String, '/semantic_map', 1)
        self.tf_buffer = Buffer()
        self.tf_listener = TransformListener(self.tf_buffer, self)
        self.create_timer(2.0, self.save)
    def on_info(self, m):
        self.K = np.array(m.k).reshape(3, 3)
    def color_of(self, x1, y1, x2, y2):                       # 상자 안 HSV 색상 투표
        hsv = cv2.cvtColor(self.bridge.imgmsg_to_cv2(self.rgb, 'bgr8')[y1:y2, x1:x2], cv2.COLOR_BGR2HSV)
        h = hsv[..., 0][(hsv[..., 1] > 80) & (hsv[..., 2] > 50)]
        votes = {c: sum(int(((h >= lo) & (h <= hi)).sum()) for lo, hi in rs) for c, rs in HUE.items()}
        best = max(votes, key=votes.get)
        return best if h.size > 30 and votes[best] > 0.4 * h.size else 'unknown'
    def on_det(self, msg):
        if self.K is None or self.depth is None or self.rgb is None:
            return
        d = self.bridge.imgmsg_to_cv2(self.depth)                  # 16UC1 [mm]
        for o in msg.objects:                                      # 원본 노드는 메시지당 1개
            if o.class_name not in CLASSES or o.score < 0.5:
                continue
            x1, y1, x2, y2 = o.box
            s = d.shape[1] / float(o.width)                         # 컬러 → 깊이 해상도 비율
            u, v = (x1 + x2) / 2.0, (y1 + y2) / 2.0
            hw, hh = max(2, int((x2 - x1) * s / 4)), max(2, int((y2 - y1) * s / 4))
            patch = d[int(v * s) - hh:int(v * s) + hh, int(u * s) - hw:int(u * s) + hw].astype(float)
            patch = patch[patch > 0]
            if patch.size < 10:
                continue
            label = CLASSES[o.class_name]
            Z = np.median(patch) / 1000.0 + RADIUS[label]
            if not 0.25 < Z < 3.0:
                continue
            fx, fy, cx, cy = self.K[0, 0], self.K[1, 1], self.K[0, 2], self.K[1, 2]
            P = np.array([(u - cx) * Z / fx, (v - cy) * Z / fy, Z, 1.0])   # 광학 프레임
            try:
                tf = self.tf_buffer.lookup_transform('map', OPT, Time())
            except TransformException as e:
                self.get_logger().warn(str(e), throttle_duration_sec=5.0)
                return
            q, t = tf.transform.rotation, tf.transform.translation
            T = quaternion_matrix([q.x, q.y, q.z, q.w])
            T[:3, 3] = [t.x, t.y, t.z]
            mx, my = (T @ P)[:2]
            if label == 'ball':
                label = self.color_of(x1, y1, x2, y2) + '_ball'
            self.fuse(label, float(mx), float(my))
    def fuse(self, label, x, y):                                  # 게이팅 + 최근접 + 누적 평균
        now = self.get_clock().now().nanoseconds * 1e-9
        near = [m for m in self.marks if m['label'] == label and math.hypot(m['x'] - x, m['y'] - y) < GATE]
        if near:
            m = min(near, key=lambda m: math.hypot(m['x'] - x, m['y'] - y))
            m['n'] += 1
            m['x'] += (x - m['x']) / m['n']
            m['y'] += (y - m['y']) / m['n']
            m['t'] = now
        else:
            self.marks.append({'label': label, 'x': x, 'y': y, 'n': 1, 't': now})
    def save(self):
        lms = [dict(m, x=round(m['x'], 2), y=round(m['y'], 2), t=round(m['t'], 1),
                    room=next((k for k, p in ROOMS.items() if in_poly(m['x'], m['y'], p)), '?'))
               for m in self.marks if m['n'] >= CONFIRM]
        doc = json.dumps({'frame': 'map', 'stamp': self.get_clock().now().nanoseconds * 1e-9,
                          'rooms': ROOMS, 'landmarks': lms}, ensure_ascii=False)
        os.makedirs(os.path.dirname(OUT), exist_ok=True)
        with open(OUT, 'w') as f:
            f.write(doc)
        self.pub.publish(String(data=doc))

def main():
    rclpy.init()
    node = SemanticMapper()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.save()
        node.destroy_node()
        rclpy.shutdown()

if __name__ == '__main__':
    main()
```

- 깊이 영상은 컬러 영상과 정렬(registered)되어 있다고 가정합니다. 정렬되지 않은 카메라라면 깊이 픽셀을 컬러 프레임으로 옮기는 외부 파라미터 변환이 먼저 필요합니다. 검증 방법: 물체 가장자리에서 컬러 상자와 깊이 경계가 일치하는지 겹쳐 봅니다.
- TF를 `Time()`(최신)으로 조회하므로 로봇이 빨리 돌면 방위 오차가 생깁니다(이론의 시각 동기화). 매핑 투어는 천천히, 볼 곳에서 멈춥니다.

### 3) 명령 실행기 노드

`LEX`, `SCHEMA`, `parse()`, `validate()`, `ground()`는 Playground 실습 2의 코드를 그대로 붙여 넣습니다(`ground()`가 읽는 전역 `SEM`만 파일에서 읽음).

```python robot
#!/usr/bin/env python3
# nl_executor.py — /nl_command → 슬롯 → 그라운딩 → Nav2 → 검증 · 탐색
import json, math, os, re
import rclpy
from rclpy.time import Time
from std_msgs.msg import String
from geometry_msgs.msg import PoseStamped
from nav2_simple_commander.robot_navigator import BasicNavigator, TaskResult
from tf2_ros import Buffer, TransformListener
from tf_transformations import quaternion_from_euler

MAP = os.path.expanduser('~/semantic/semantic_map.json')
SEM = {'landmarks': [], 'rooms': {}}
# ---- 여기에 실습 2의 LEX, SCHEMA, parse(), validate(), ground() 붙여 넣기 ----

class NLExecutor(BasicNavigator):
    def __init__(self):
        super().__init__('nl_executor')
        self.create_subscription(String, '/nl_command', lambda m: self.queue.append(m.data), 10)  # 콜백은 큐에만
        self.status = self.create_publisher(String, '/nl_status', 10)
        self.tf_buffer = Buffer()
        self.tf_listener = TransformListener(self.tf_buffer, self)
        self.queue = []
    def say(self, text):
        self.get_logger().info(text)
        self.status.publish(String(data=text))
    def now(self):
        return self.get_clock().now().nanoseconds * 1e-9
    def reload(self):
        global SEM
        with open(MAP) as f:
            SEM = json.load(f)
    def robot_xy(self):
        t = self.tf_buffer.lookup_transform('map', 'base_footprint', Time()).transform.translation
        return t.x, t.y
    def wait(self):                                               # Nav2 작업이 끝날 때까지
        while not self.isTaskComplete():
            rclpy.spin_once(self, timeout_sec=0.1)
        return self.getResult() == TaskResult.SUCCEEDED
    def drive(self, x, y, yaw):
        p = PoseStamped()
        p.header.frame_id, p.header.stamp = 'map', self.get_clock().now().to_msg()
        p.pose.position.x, p.pose.position.y = float(x), float(y)
        q = quaternion_from_euler(0.0, 0.0, yaw)
        p.pose.orientation.x, p.pose.orientation.y, p.pose.orientation.z, p.pose.orientation.w = q
        self.goToPose(p)
        return self.wait()
    def verify(self, m, t0, secs=3.0):                            # 도착 뒤 새로 관측됐는가
        end = self.now() + secs
        while self.now() < end:
            rclpy.spin_once(self, timeout_sec=0.1)
        self.reload()
        return any(l['label'] == m['label'] and l['t'] > t0 and
                   math.hypot(l['x'] - m['x'], l['y'] - m['y']) < 0.5 for l in SEM['landmarks'])
    def search(self, slot, visited):                              # 제자리 360° → 다음 방 중심
        self.spin(spin_dist=2 * math.pi, time_allowance=40)
        self.wait()
        self.reload()
        if ground(slot, self.robot_xy())[0]:
            return True
        centers = [(k, sum(p[0] for p in v) / len(v), sum(p[1] for p in v) / len(v))
                   for k, v in SEM['rooms'].items() if k not in visited]
        if not centers:
            return False
        rx, ry = self.robot_xy()
        k, cx, cy = min(centers, key=lambda c: math.hypot(c[1] - rx, c[2] - ry))
        visited.add(k)
        self.say('탐색: %s 중심으로' % k)
        self.drive(cx, cy, 0.0)
        return self.search(slot, visited)
    def execute(self, text):
        slot = parse(text)
        self.say('해석: %s' % json.dumps(slot, ensure_ascii=False))
        if slot['intent'] not in ('go', 'find') or slot['object'] is None:
            self.say('되묻기: 어떤 물체로 갈까요? ("%s")' % text)
            return
        visited = set()
        for attempt in range(3):
            self.reload()
            goal, m, why = ground(slot, self.robot_xy())
            self.say('그라운딩: %s' % why)
            if goal and (self.drive(*goal) or self.drive(*goal)):  # Nav2 실패 시 1회 재시도
                if self.verify(m, self.now()):
                    self.say('성공: %s 앞 (시도 %d)' % (m['label'], attempt + 1))
                    return
                self.say('검증 실패: %s가 보이지 않음 → 탐색' % m['label'])
            if not self.search(slot, visited):
                break
        self.say('실패: "%s"를 수행하지 못했습니다' % text)

def main():
    rclpy.init()
    bot = NLExecutor()
    bot.waitUntilNav2Active()
    bot.say('ready')
    try:
        while rclpy.ok():
            rclpy.spin_once(bot, timeout_sec=0.1)
            if bot.queue:
                bot.execute(bot.queue.pop(0))
    except KeyboardInterrupt:
        pass
    finally:
        bot.cancelTask()
        bot.destroy_node()
        rclpy.shutdown()

if __name__ == '__main__':
    main()
```

- 매퍼가 2 s마다 파일을 쓰므로 검증은 3 s 동안 기다린 뒤 "도착 이후(`t > t0`)에 새로 관측됐는지"를 봅니다. 매퍼와 실행기가 파일 하나로만 연결되어 따로 시험하기 쉽습니다.
- 콜백은 문장을 큐에 넣기만 하고, `goToPose`·`spin`처럼 안에서 기다리는 함수는 주 루프에서 부릅니다(P02와 같은 이유).
- `spin()`은 Nav2 행동 서버의 제자리 회전입니다. 코스트맵 충돌 검사를 하므로 벽 옆에서는 도중에 멈출 수 있습니다.

### 단계별 지표

| 단계 | 지표 | 측정 방법 |
|---|---|---|
| 검출 | 검출률(재현율), 헛검출 수 | 거리 0.5/1/2 m × 10회 |
| 지도 | 위치 오차 평균·최대, 헛 랜드마크 수, 놓친 랜드마크 수 | 줄자로 잰 실제 위치와 비교 |
| 언어 | 슬롯 완전 일치율, 거부 정확도 | 시험 문장 30개 |
| 그라운딩 | 올바른 물체 선택률 | 같은 종류 2개 이상 있는 경우 포함 |
| 주행 | Nav2 성공률, 도착 오차(TF) | 명령마다 |
| 전체 | 과제 성공률(검증 통과), 소요 시간 | 시나리오 10개 × 2회 |

전체 성공률은 대략 각 단계 성공률의 **곱**입니다. 검출 0.9 × 지도 0.9 × 파싱 0.95 × 주행 0.9 ≈ 0.69입니다. 한 단계만 개선해서는 크게 오르지 않으므로, 실패 로그를 단계별로 분류해 **가장 약한 고리**부터 고칩니다.

### 결과 1: 시뮬레이션 매핑 (실습 1, 검출기 난수 시드 1~4)

| 시드 | 확정 | 후보(헛 포함) | 헛 랜드마크 (n ≥ 1 / n ≥ 2 / n ≥ 3) | 거실 오차 [m] | 주방 오차 [m] |
|---|---|---|---|---|---|
| 1 | 5/5 | 10 | 5 / 0 / 0 | 0.04~0.07 | 0.14, 0.14 |
| 2 | 5/5 | 11 | 6 / 0 / 0 | 0.05~0.08 | 0.15, 0.19 |
| 3 | 5/5 | 7 | 2 / 1 / 0 | 0.04~0.09 | 0.16, 0.15 |
| 4 | 5/5 | 10 | 5 / 0 / 0 | 0.06~0.08 | 0.13, 0.19 |

- 확정 기준 $n \ge 3$에서 헛 랜드마크가 모두 사라집니다. $n \ge 2$에서도 시드 3은 하나가 남습니다. 헛검출률 5 %·초당 5회 검출이면 같은 자리에 우연히 두 번 나올 수 있기 때문입니다.
- 주방 오차(0.13~0.19 m)가 N1(0.15 m)을 넘나듭니다. 원인은 검출기가 아니라 **자세 추정**입니다. 실물에서는 AMCL 자세를 쓰고, 투어 경로를 거실 → 주방 → 거실로 돌아오게 해 두 번 보도록 하면 줄어듭니다.

## 확장 과제

- **시각 동기화**: `yolo_detect.py`가 입력 영상의 `header.stamp`를 `Detection2DArray`에 복사하도록 고치고, 매퍼가 그 시각의 TF(`lookup_transform(..., stamp)`)와 깊이 프레임을 쓰게 합니다. 회전 중 매핑 오차 전후를 비교합니다.
- **마할라노비스 게이트·가중 평균**: 거리에 따라 커지는 깊이 잡음 모델을 세우고, 분산 역수 가중 평균과 공분산 게이트로 바꿉니다.
- **관계 표현 확장**: "의자와 컵 사이", "주방 문 앞", "가장 가까운 공" 같은 관계와 최상급을 문법에 추가합니다. 고유한 앞면이 있는 물체(의자)는 방향도 추정해 물체 기준 "앞"을 계산합니다.
- **오픈 어휘 검출**: 이름표를 COCO 80개로 제한하지 않는 개방형 검출기(예: CLIP 계열)를 PC에서 돌려 비교합니다. 라즈베리파이의 계산 한계와 정확도 사이의 트레이드오프를 측정합니다.
- **LLM 계획**: "컵을 확인하고 의자로 가" 같은 여러 단계 명령을 LLM이 슬롯 **목록**으로 분해하게 하고, 각 단계는 같은 스키마 검사를 거칩니다.
- **되묻기 대화**: 후보가 둘 이상이면 `/nl_status`로 질문하고 다음 `/nl_command`를 답으로 받아 선택합니다.

## 자주 나는 오류와 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 물체가 로봇 좌우 반대쪽에 찍힘 | 광학 프레임(x 오른쪽)을 로봇 프레임(y 왼쪽)처럼 씀 | TF로 `ascamera_color_0`에서 변환, 또는 $y_{base} = -X$ |
| 물체가 모두 바닥 높이 대신 먼 곳에 찍힘 | $Y$(아래)와 $Z$(앞)를 바꿔 씀 | 역투영 식의 축 순서 확인, 높이는 map 변환 후 버림 |
| 깊이가 0 또는 수십 m | 상자 가장자리 배경, 구멍(0), mm↔m 단위 | 가운데 절반 영역 중앙값, 0 제외, `/1000` |
| 같은 물체가 여러 랜드마크로 쪼개짐 | 게이트가 너무 작음, 자세 추정 튐 | 게이트 0.35~0.5 m, AMCL 수렴 후 매핑 |
| 헛 랜드마크가 남음 | 확정 기준 n이 작음 | n ≥ 3, 또는 미스 횟수로 삭제 |
| `/yolov5_ros2/object_detect`가 안 옴 | 모델에 없는 클래스, launch가 다른 모델 고정 | `ros2 run ... -p model:=yolov5s`, 물체가 없으면 메시지도 없음 |
| 공의 색이 `unknown` | 조명, 채도 임계, 반사 | HSV 임계 조정(A01 색 실험실), 관측 다수결 |
| "가까운 공으로 가"가 이상하게 해석됨 | 접두 일치로 "가까운"이 동사 "가"로 걸림 | 최상급 사전 추가, 동사는 문장 끝 어절에서 찾기 |
| 도착했는데 검증이 항상 실패 | D가 너무 작아 물체가 카메라 최소 거리 안, 또는 시야 밖 | D ≥ 0.4 m, 목표 방향이 물체를 향하는지 확인 |
| `lookup_transform` 예외 | AMCL 초기화 전, `map` 프레임 없음 | 2D Pose Estimate 후 실행, `ros2 run tf2_ros tf2_echo map ascamera_color_0` |
