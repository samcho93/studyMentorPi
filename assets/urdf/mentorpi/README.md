# MentorPi URDF assets

Generated by `tools/urdf/convert.py` from Hiwonder `mentorpi_description`
(`src/simulations/mentorpi_description`, shipped with the MentorPi source image).

- `mentorpi_mecanum.urdf`  ← `urdf/mecanum.xacro`
- `mentorpi_ackermann.urdf` ← `urdf/ack.xacro` + `urdf/imu.urdf.xacro`
- `meshes/*` : binary STL, decimated by vertex clustering for the web viewer (visual use only).

Original meshes and URDF © Hiwonder. Used here for education (course material for MentorPi owners).
