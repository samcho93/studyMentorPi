학습 목표#

  • 영상의 기울기(gradient)를 Sobel 연산자로 계산하고, Canny 엣지 검출의 4단계(잡음 제거 → 기울기 → 비최대 억제 → 이력 임계값)를 설명합니다.
  • 구조 요소(structuring element)로 침식·팽창·열림·닫힘·탑햇·블랙햇을 적용하고, 마스크의 잡음과 구멍을 정리합니다.
  • 전역·적응형·Otsu 이진화를 비교해 조명이 고르지 않은 영상에 맞는 방법을 고릅니다.
  • 이 세 가지를 조합해 라인 트레이싱·색 인식에 쓰는 깨끗한 이진 마스크를 만듭니다.

엣지 검출 (Edge Detection)#

엣지(edge)는 밝기가 급하게 변하는 곳입니다. 물체의 경계, 바닥 위 검은 선의 가장자리, 차선의 양옆이 모두 엣지입니다. 엣지만 남기면 데이터 양은 크게 줄고 모양 정보는 남습니다.

엣지를 찾는 방법은 두 갈래입니다.

  • 1차 미분 방식: 기울기의 크기가 극대인 곳을 찾습니다. Sobel, Scharr, Canny가 여기에 속합니다.
  • 2차 미분 방식: 2차 미분이 0을 지나는 곳(zero-crossing)을 찾습니다. Laplacian이 대표적입니다. 잡음에 더 민감합니다.

기울기와 Sobel 연산자#

영상 I(x, y)의 기울기는 가로·세로 방향 미분 (G_x, G_y)입니다. 디지털 영상에서는 3×3 Sobel 커널과의 합성곱으로 근사합니다.

text
      Gx 커널              Gy 커널
   [ -1  0  +1 ]        [ -1  -2  -1 ]
   [ -2  0  +2 ]        [  0   0   0 ]
   [ -1  0  +1 ]        [ +1  +2  +1 ]

크기  G = sqrt(Gx² + Gy²)        방향  θ = atan2(Gy, Gx)

G_x는 세로로 서 있는 엣지(좌우 밝기 차)에, G_y는 가로로 누운 엣지에 반응합니다. 기울기 방향 θ는 항상 엣지와 수직입니다. 가운데 행·열에 가중치 2를 주는 것은 가벼운 가우시안 평활을 함께 하기 위해서입니다.

cv2.Sobel(src, ddepth, dx, dy, ksize)에서 ddepth는 결과 자료형입니다. 밝→어두 경계는 음수 기울기를 만드는데 uint8로 받으면 음수가 0으로 잘려 엣지의 절반이 사라집니다. 그래서 cv2.CV_16S나 cv2.CV_64F로 받은 뒤 cv2.convertScaleAbs로 절댓값을 취합니다.

Canny 엣지 검출#

1986년 John Canny가 제안한 Canny 검출기는 지금도 가장 널리 쓰이는 엣지 검출기로, 4단계로 동작합니다.

  1. 잡음 제거: 5×5 가우시안으로 흐립니다. 잡음 한 점도 큰 기울기를 만들기 때문입니다.
  2. 기울기 크기·방향: Sobel로 G와 θ를 구하고, θ를 0°·45°·90°·135° 네 방향으로 반올림합니다.
  3. 비최대 억제(Non-Maximum Suppression): 각 픽셀을 기울기 방향의 앞뒤 이웃과 비교해 최대가 아니면 0으로 만듭니다. 두꺼운 기울기 띠가 1픽셀 폭의 선이 됩니다.
  4. 이력 임계값(Hysteresis Thresholding): 두 임계값 minVal < maxVal을 씁니다. G > maxVal이면 확실한 엣지, G < minVal이면 버리고, 그 사이는 확실한 엣지와 연결되어 있을 때만 남깁니다. 끊기지 않으면서도 잡음은 버리는 비결입니다.

cv2.Canny(image, threshold1, threshold2)에서 threshold1이 minVal, threshold2가 maxVal입니다. 흔히 1:2 ~ 1:3 비율로 잡습니다. 원본 교재 예제(edge_detection.py)는 Canny(img, 1, 80)처럼 낮은 임계값을 아주 낮게 두어 약한 엣지까지 많이 남깁니다.

python브라우저 실행Playground ↗
import cv2
import numpy as np

img = np.full((100, 100), 50, np.uint8)
cv2.rectangle(img, (30, 30), (69, 69), 200, -1)           # 밝은 사각형 (경계 x=30, x=69)

gx = cv2.Sobel(img, cv2.CV_64F, 1, 0, ksize=3)
gy = cv2.Sobel(img, cv2.CV_64F, 0, 1, ksize=3)
print("가로줄 y=50의 Gx:", gx[50, 27:33].astype(int).tolist(), "... ", gx[50, 67:73].astype(int).tolist())
print("같은 위치 Gy:", gy[50, 28:32].astype(int).tolist(), "(세로 엣지에는 Gy가 반응하지 않음)")
g8 = cv2.Sobel(img, cv2.CV_8U, 1, 0, ksize=3)
print("CV_8U로 받으면 오른쪽 경계:", g8[50, 67:73].tolist(), "→ 음수가 잘려 사라짐")

mag = cv2.magnitude(gx, gy)
print("기울기 최대 %.0f, 0이 아닌 픽셀 %d" % (mag.max(), np.count_nonzero(mag)))
edges = cv2.Canny(img, 50, 150)
print("Canny 엣지 픽셀 %d (사각형 둘레 %d)" % (np.count_nonzero(edges), 4 * 40 - 4))

shapes = cv2.cvtColor(cv2.imread("shapes.png"), cv2.COLOR_BGR2GRAY)
for lo, hi in [(10, 30), (50, 150), (200, 400)]:
    print("shapes.png Canny(%d, %d): %d 픽셀" % (lo, hi, np.count_nonzero(cv2.Canny(shapes, lo, hi))))
cv2.imshow("Canny 50/150", cv2.Canny(shapes, 50, 150))

CV_8U로 받으면 오른쪽 경계: [0, 0, 0, 0, 0, 0] → 음수가 잘려 사라짐

  • 왼쪽 경계(어두움 → 밝음)는 G_x가 양수, 오른쪽 경계(밝음 → 어두움)는 음수입니다. 값 600은 밝기 차 150 × 커널 가중치 합 4에서 나옵니다.
  • 비최대 억제 덕분에 Canny 결과는 경계를 따라 1픽셀 폭입니다. 기울기가 0이 아닌 픽셀 수보다 훨씬 적습니다.

Laplacian과 Scharr

cv2.Laplacian(img, cv2.CV_64F)은 2차 미분 하나로 모든 방향의 엣지를 찾지만 잡음에 약해 보통 가우시안 뒤에 씁니다(LoG). cv2.Scharr는 3×3 커널에서 Sobel보다 방향 정확도가 높은 대안입니다.

모폴로지 처리 (Morphological Processing)#

모폴로지(형태학)는 모양을 기준으로 이진 영상을 다듬는 연산입니다. 색 임계값으로 만든 마스크에는 작은 흰 점(잡음), 물체 안의 검은 구멍, 가늘게 이어진 다리가 생기는데, 모폴로지로 정리합니다.

구조 요소, 침식, 팽창#

구조 요소(structuring element, 커널)는 0과 1로 된 작은 모양입니다. cv2.getStructuringElement(shape, (k, k))로 만들고, 모양은 MORPH_RECT(사각형), MORPH_ELLIPSE(원), MORPH_CROSS(십자) 중에서 고릅니다. 원본 교재처럼 np.ones((k, k), np.uint8)로 만들어도 사각형 커널과 같습니다.

  • 침식(erosion) cv2.erode: 커널을 올렸을 때 커널의 1 위치가 모두 흰색일 때만 가운데를 흰색으로 둡니다. 물체가 깎이고, 커널보다 작은 점은 사라집니다.
  • 팽창(dilation) cv2.dilate: 커널의 1 위치 중 하나라도 흰색이면 가운데를 흰색으로 둡니다. 물체가 불어나고, 작은 구멍이 메워집니다.

두 연산 모두 iterations로 여러 번 반복할 수 있습니다. 3×3 커널로 한 번 침식하면 경계가 1픽셀씩 깎입니다.

조합 연산: morphologyEx#

연산정의효과상수
열림 (opening)침식 → 팽창작은 흰 점 제거, 가는 연결 끊기, 큰 물체 크기는 유지cv2.MORPH_OPEN
닫힘 (closing)팽창 → 침식물체 안의 작은 검은 구멍 메우기, 가까운 조각 잇기cv2.MORPH_CLOSE
모폴로지 기울기팽창 − 침식윤곽선만 남기기cv2.MORPH_GRADIENT
탑햇 (top hat)원본 − 열림어두운 배경 위 밝고 작은 부분 추출cv2.MORPH_TOPHAT
블랙햇 (black hat)닫힘 − 원본밝은 배경 위 어둡고 작은 부분 추출cv2.MORPH_BLACKHAT

MentorPi 색 인식·라인 트레이싱 노드는 모두 inRange 직후에 3×3 사각형 커널로 침식 한 번, 팽창 한 번(= 열림)을 합니다. 작은 잡음 점을 지워 가장 큰 윤곽선을 찾을 때 엉뚱한 조각이 잡히지 않게 하는 것입니다.

python브라우저 실행Playground ↗
import cv2
import numpy as np

rng = np.random.default_rng(1)
mask = np.zeros((120, 160), np.uint8)
cv2.rectangle(mask, (40, 30), (79, 69), 255, -1)             # 40x40 물체 = 1600 픽셀
cv2.rectangle(mask, (100, 40), (139, 79), 255, -1)           # 두 번째 물체
cv2.circle(mask, (120, 60), 4, 0, -1)                        # 두 번째 물체 안의 구멍
ys, xs = rng.integers(0, 120, 60), rng.integers(0, 160, 60)
mask[ys, xs] = 255                                           # 흰 점 잡음 60개

k3 = cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3))
def info(name, m):
    outer = cv2.findContours(m, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)[-2]
    allc = cv2.findContours(m, cv2.RETR_CCOMP, cv2.CHAIN_APPROX_SIMPLE)[-2]
    print("%-14s 흰 픽셀 %5d, 덩어리 %2d, 구멍 %d" % (name, cv2.countNonZero(m), len(outer), len(allc) - len(outer)))

info("원본", mask)
info("erode 3x3", cv2.erode(mask, k3))
info("dilate 3x3", cv2.dilate(mask, k3))
opened = cv2.morphologyEx(mask, cv2.MORPH_OPEN, k3)
info("open", opened)
info("open → close", cv2.morphologyEx(opened, cv2.MORPH_CLOSE, np.ones((9, 9), np.uint8)))
cv2.imshow("mask | open", np.hstack([mask, opened]))
text
원본             흰 픽셀  3201, 덩어리 51, 구멍 1
erode 3x3      흰 픽셀  2799, 덩어리  2, 구멍 1
dilate 3x3     흰 픽셀  3946, 덩어리 46, 구멍 1
open           흰 픽셀  3151, 덩어리  2, 구멍 1
open → close   흰 픽셀  3200, 덩어리  2, 구멍 0
  • 3×3 침식은 경계를 한 픽셀씩 깎습니다(40×40 사각형 → 38×38). 잡음 점은 사라지지만 물체도 작아져 흰 픽셀이 3201 → 2799로 줄었습니다. 팽창은 반대로 잡음 점까지 키웁니다.
  • 열림(침식 → 팽창)은 잡음 점만 지우고 물체 크기는 거의 되돌립니다(3151). 잡음 점 하나는 3×3 커널보다 작아 침식에서 사라진 뒤 다시 살아나지 못하기 때문입니다.
  • 구멍(반지름 4)은 3×3 닫힘으로는 메워지지 않아 9×9 커널로 닫았습니다. 커널은 없애려는 구조보다 커야 합니다.

임계값 처리 (Thresholding)#

이진화(binarization)는 각 픽셀을 두 값(보통 0과 255)으로 나누는 연산입니다. 데이터를 크게 줄이고 관심 영역의 윤곽을 뚜렷하게 만들어 윤곽선 검출(R11)의 입력이 됩니다.

전역 임계값#

ret, dst = cv2.threshold(src, thresh, maxval, type)은 영상 전체에 하나의 임계값을 적용합니다.

typethresh보다 큰 픽셀나머지 픽셀
THRESH_BINARYmaxval0
THRESH_BINARY_INV0maxval
THRESH_TRUNCthresh그대로
THRESH_TOZERO그대로0
THRESH_TOZERO_INV0그대로

검은 선을 흰색으로 만들어야 하는 라인 트레이싱에서는 THRESH_BINARY_INV를 씁니다. findContours는 검은 배경 위의 흰 물체를 찾기 때문입니다.

Otsu 자동 임계값#

Otsu 방법은 히스토그램을 두 무리(배경·물체)로 나눌 때 두 무리 사이의 분산(between-class variance)이 최대가 되는 임계값 t를 찾습니다.

text
σ_B²(t) = ω0(t) · ω1(t) · (μ0(t) − μ1(t))²
   ω0, ω1 : 임계값 아래/위 픽셀의 비율       μ0, μ1 : 각 무리의 평균 밝기

type에 cv2.THRESH_OTSU를 더하고 thresh는 0으로 둡니다. 반환값 ret가 계산된 임계값입니다. 히스토그램이 두 봉우리(bimodal)일 때 잘 동작합니다.

적응형 임계값#

조명이 한쪽에서 비치면 같은 흰 바닥도 왼쪽은 밝고 오른쪽은 어둡습니다. 적응형(adaptive) 임계값은 픽셀마다 주변 blockSize×blockSize 영역의 평균(또는 가우시안 가중 평균)에서 C를 뺀 값을 임계값으로 씁니다.

python
dst = cv2.adaptiveThreshold(gray, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                            cv2.THRESH_BINARY, blockSize=31, C=5)

blockSize는 홀수이고 찾으려는 물체보다 커야 합니다. 원본 예제의 blockSize=5, C=3은 글자 같은 가는 구조에 맞는 값이며, 굵은 선에 쓰면 선 내부가 비어 테두리만 남습니다.

python브라우저 실행Playground ↗
import cv2
import numpy as np

h, w = 120, 240
light = np.tile(np.linspace(230, 60, w), (h, 1))            # 왼쪽 밝고 오른쪽 어두운 조명
truth = np.zeros((h, w), np.uint8)
for x in range(20, 240, 50):
    cv2.rectangle(truth, (x, 40), (x + 19, 79), 255, -1)     # 어두운 표식 5개 (정답 마스크)
img = light.copy()
img[truth > 0] *= 0.45                                       # 표식은 주변보다 55 % 어두움
img = img.astype(np.uint8)

def score(name, m):
    acc = 100.0 * np.count_nonzero(m == truth) / truth.size
    print("%-22s 정확도 %5.1f %%" % (name, acc))

_, g = cv2.threshold(img, 127, 255, cv2.THRESH_BINARY_INV)
score("전역 127", g)
t, o = cv2.threshold(img, 0, 255, cv2.THRESH_BINARY_INV + cv2.THRESH_OTSU)
score("Otsu (t=%d)" % t, o)
a = cv2.adaptiveThreshold(img, 255, cv2.ADAPTIVE_THRESH_MEAN_C, cv2.THRESH_BINARY_INV, 61, 10)
score("적응형 mean 61, C=10", a)
cv2.imshow("img", img)
cv2.imshow("global | otsu | adaptive", np.vstack([g, o, a]))
text
전역 127                 정확도  65.6 %
Otsu (t=136)           정확도  61.4 %
적응형 mean 61, C=10      정확도 100.0 %

전역 임계값과 Otsu는 한 개의 숫자로 나누기 때문에, 오른쪽의 어두운 바닥까지 표식으로 잘못 분류합니다. 적응형은 주변과 비교하므로 조명 기울기에 거의 영향을 받지 않습니다.

조합하기: 라인 트레이싱 전처리#

지금까지의 도구를 이어 붙이면 라인 트레이싱(A03)의 전처리가 됩니다. 흐림 → 이진화(검은 선을 흰색으로) → 열림 → 화면 아래쪽 띠(ROI)에서 선의 중심 x를 구합니다.

python브라우저 실행Playground ↗
import cv2
import numpy as np

img = cv2.imread("track.png")
h, w = img.shape[:2]
gray = cv2.GaussianBlur(cv2.cvtColor(img, cv2.COLOR_BGR2GRAY), (5, 5), 0)
t, mask = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY_INV + cv2.THRESH_OTSU)
mask = cv2.morphologyEx(mask, cv2.MORPH_OPEN, np.ones((3, 3), np.uint8))
print("Otsu 임계값:", t)

view = img.copy()
for y0, y1 in [(430, 460), (330, 360), (230, 260)]:             # 아래 → 위 세 띠
    band = mask[y0:y1]
    m = cv2.moments(band, binaryImage=True)
    if m["m00"] > 0:
        cx = m["m10"] / m["m00"]
        print("띠 y=%d~%d: 선 중심 x = %.1f, 화면 중앙과의 차 %+.1f px" % (y0, y1, cx, cx - w / 2))
        cv2.circle(view, (int(cx), (y0 + y1) // 2), 6, (0, 0, 255), -1)
    cv2.rectangle(view, (0, y0), (w - 1, y1), (0, 200, 255), 1)
cv2.imshow("mask", mask)
cv2.imshow("rois", view)
text
Otsu 임계값: 120.0
띠 y=430~460: 선 중심 x = 320.0, 화면 중앙과의 차 +0.0 px
띠 y=330~360: 선 중심 x = 326.3, 화면 중앙과의 차 +6.3 px
띠 y=230~260: 선 중심 x = 376.4, 화면 중앙과의 차 +56.4 px

아래 띠는 선이 거의 화면 중앙에 있고, 위 띠로 갈수록 선이 오른쪽으로 휘어 있습니다. A03에서는 이 차이에 가중치를 주어 조향 각도를 계산합니다.

python실물 전용
import cv2
import numpy as np
import rclpy
from rclpy.node import Node
from cv_bridge import CvBridge
from sensor_msgs.msg import Image


class ThresholdCompare(Node):
    def __init__(self):
        super().__init__('threshold_compare')
        self.bridge = CvBridge()
        self.create_subscription(Image, '/ascamera/camera_publisher/rgb0/image', self.on_image, 1)

    def on_image(self, msg):
        frame = cv2.resize(self.bridge.imgmsg_to_cv2(msg, 'bgr8'), (320, 240))
        gray = cv2.GaussianBlur(cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY), (5, 5), 0)
        _, g = cv2.threshold(gray, 80, 255, cv2.THRESH_BINARY_INV)
        t, o = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY_INV + cv2.THRESH_OTSU)
        a = cv2.adaptiveThreshold(gray, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C, cv2.THRESH_BINARY_INV, 51, 10)
        k = np.ones((3, 3), np.uint8)
        row = np.hstack([cv2.morphologyEx(m, cv2.MORPH_OPEN, k) for m in (g, o, a)])
        cv2.putText(row, 'global80 | otsu%d | adaptive' % t, (5, 20), cv2.FONT_HERSHEY_SIMPLEX, 0.5, 128, 1)
        cv2.imshow('frame', frame)
        cv2.imshow('compare', row)
        if cv2.waitKey(1) & 0xFF == ord('q'):
            raise KeyboardInterrupt


def main():
    rclpy.init()
    node = ThresholdCompare()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        cv2.destroyAllWindows()
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()

자주 나는 오류와 해결#

증상원인해결
Sobel 결과에서 한쪽 엣지만 보임ddepth=cv2.CV_8U로 음수 기울기가 잘림cv2.CV_16S/CV_64F로 받고 cv2.convertScaleAbs
Canny 결과가 잡음투성이흐림 없이 낮은 임계값GaussianBlur 후 적용, minVal·maxVal을 올림(1:2~1:3)
Canny 선이 끊김minVal이 너무 높음minVal을 낮춰 이력 연결을 살림
열림 후 물체까지 사라짐커널이 물체(선 폭)보다 큼커널을 줄이거나 반복 횟수를 줄임
findContours가 배경 전체를 하나의 윤곽으로 잡음물체가 검정, 배경이 흰색THRESH_BINARY_INV로 뒤집어 물체를 흰색으로
adaptiveThreshold 오류입력이 컬러, blockSize가 짝수 또는 1흑백 uint8 입력, 3 이상의 홀수
Otsu 임계값이 이상함입력이 컬러, 또는 히스토그램이 한 봉우리흑백으로 변환, 물체가 화면에 충분히 보이게 ROI 조정
