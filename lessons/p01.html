SLAM으로 만든 지도 위를 다중 지점 순찰하며 라이다로 침입자(지도에 없는 물체)를 감지하고 추적·경보·보고하는 경비 로봇을 만듭니다.

학습 목표#

  • 요구사항(기능·비기능·안전 한계)을 표로 정의하고, 이를 ROS 2 노드·토픽·액션 그래프와 상태 기계로 옮깁니다.
  • SLAM으로 만든 점유격자 지도를 거리장(distance field)으로 바꿔, 라이다 끝점 가운데 "지도에 없는 것"만 골라내는 변화 감지(change detection) 알고리즘을 구현합니다.
  • Nav2 Simple Commander로 다중 지점 순찰을 돌리다가 침입을 감지하면 목표를 취소하고, 경비 모드처럼 침입자 방향으로 회전하며, RGB LED·부저로 경보한 뒤 순찰을 재개하는 상태 기계를 만듭니다.
  • 경보 이벤트를 토픽과 CSV로 기록해 순찰 보고서를 만들고, 오경보·미감지를 수치로 평가합니다.
  • 브라우저 Playground에서 알고리즘을 먼저 검증하고, 같은 구조를 MentorPi 실물의 navigation.launch.py 위에서 실행합니다.

프로젝트 개요와 요구사항#

야간에 사무실·연구실을 도는 경비 로봇을 만듭니다. 로봇은 미리 만든 지도 위에서 정해진 지점들을 차례로 돌고(순찰), 지도에 없던 물체가 움직이면(침입자) 멈춰서 그쪽을 바라보며 경보를 울리고, 사건을 기록한 뒤, 침입자가 사라지면 하던 순찰을 이어 갑니다.

이 프로젝트는 앞 장들의 부품을 조립하는 일입니다: SLAM 지도(M09) = 변화 감지의 기준, AMCL·Nav2(M11·M12) = 순찰 주행과 map 좌표 자세, BasicNavigator 다중 목표(M13) = 순찰 순환, 라이다 경비 모드(M06, lidar_controller.py mode 3) = 침입자 쪽으로 도는 제어, ros_robot_controller 토픽(B08) = RGB LED·부저 경보.

침입 감지: 지도와 대조하기#

M06의 경비 모드는 가장 가까운 점을 바라봅니다. 빈 방 가운데서는 잘 되지만, 순찰하는 로봇은 늘 벽·가구 옆을 지나므로 가장 가까운 점은 대부분 벽입니다. 그래서 "가까운 것"이 아니라 "지도에 없던 것"을 찾아야 합니다.

  1. 거리장 만들기 — 지도를 받을 때 한 번만. 점유(≥ 50)·미탐색(−1) 칸을 0, 빈 칸을 255로 만든 영상에 cv2.distanceTransform을 적용하면 각 칸에서 가장 가까운 점유 칸까지의 거리(칸 수)가 나옵니다. 여기에 해상도(0.05 m)를 곱하면 미터 단위 거리장 D(u, v)입니다.
  2. 끝점을 map 좌표로 — TF에서 스캔 시각의 라이다 자세 (x, y, θ)를 얻고, 빔 i의 거리 r_i·각도 φ_i로 p_i = (x + r_i\cos(θ+φ_i),\ y + r_i\sin(θ+φ_i)).
  3. 변화 판정 — D(p_i) > gap이면 "지도의 어떤 벽에서도 떨어진 곳에 무언가 있다". 한 점짜리 잡음을 버리기 위해 인덱스가 이웃한(간격 ≤ 2) 빔끼리 묶고, n ≥ min\_pts인 덩어리만 남깁니다.
  4. 시간 확인 — 같은 판정이 confirm_scans(3)번 연속이면 확정합니다. 라이다 10 Hz에서 0.3 s입니다.

파라미터를 고르는 계산. 오경보의 가장 큰 원인은 위치추정 오차입니다. 로봇 방향이 δθ만큼 틀리면 거리 r의 벽 끝점이 옆으로 r·δθ만큼 밀립니다. AMCL의 방향 오차를 2°(0.035 rad)로 보면 4 m에서 0.14 m, 8 m에서 0.28 m입니다. 그래서 gap은 0.15~0.2 m, max_range는 4 m로 제한합니다. 반대로 사람 다리 하나(지름 약 0.1 m)는 2 m 거리에서 라이다 각해상도 1°(0.035 m 간격)로 약 3개 빔에 맞습니다. 두 다리와 몸통을 합하면 4개 이상이 되므로 min_pts 4가 적당합니다.

거리장이 빠른 이유

끝점마다 "모든 벽과의 거리"를 계산하면 빔 360개 × 벽 수만큼 연산이 듭니다. 거리장은 지도를 받을 때 한 번 계산해 두고, 스캔마다 배열 인덱싱 한 번(O(1))으로 끝냅니다. AMCL의 likelihood field 모델도 같은 원리입니다(M11).

def intruder(scan, x, y, th):                                     # 지도에 없는 가장 큰 덩어리
    r = np.array(scan.ranges); a = scan.angle_min + np.arange(len(r)) * scan.angle_increment
    ok = np.isfinite(r) & (r < 4.0); r = np.where(ok, r, 0.0)
    wx, wy = x + r * np.cos(a + th), y + r * np.sin(a + th)
    c, rr = np.clip(((wx - OX) / RES).astype(int), 0, 119), np.clip(((wy - OY) / RES).astype(int), 0, 79)
    idx = np.flatnonzero(ok & (DIST[rr, c] > 0.15))
    groups = [k for k in np.split(idx, np.flatnonzero(np.diff(idx) > 2) + 1) if len(k) >= 4]
    if not groups: return None
    k = max(groups, key=len)
    return wx[k].mean(), wy[k].mean(), float(np.median(a[k]))    # map 좌표, 로봇 기준 방위

class Guard(Node):
    def __init__(self):
        super().__init__('patrol_guard')
        self.cmd = self.create_publisher(Twist, '/controller/cmd_vel', 10)
        self.alarm = self.create_publisher(String, '/patrol/alarm', 10)   # 실물: set_rgb / set_buzzer
        self.create_subscription(LaserScan, '/scan', self.on_scan, 10)
        self.state, self.wp, self.pose, self.seen, self.hits, self.last_seen = 'PATROL', 0, None, None, 0, -9.0
        self.events = []
        self.create_timer(0.05, self.loop)
    def now(self): return self.get_clock().now().nanoseconds * 1e-9
    def on_scan(self, s):
        self.pose = sim.pose()                     # 시뮬 전용: 실물은 TF map→base_footprint (AMCL 보정)
        self.seen = intruder(s, *self.pose)
        self.hits = self.hits + 1 if self.seen else 0
        if self.seen: self.last_seen = self.now()
    def set_state(self, st, why):
        self.get_logger().warn('%s -> %s (%s)' % (self.state, st, why)); self.state = st
        self.events.append('%.1f s %s %s' % (self.now(), st, why))          # 보고용 이벤트 기록
        self.alarm.publish(String(data='ON' if st == 'ALERT' else 'OFF'))
    def loop(self):
        if self.pose is None: return
        x, y, th = self.pose; t = Twist()
        if self.state == 'PATROL':
            if self.hits >= 3:                                        # 0.3 s 연속 감지 → 경보
                self.set_state('ALERT', 'intruder at (%.2f, %.2f)' % self.seen[:2])
            else:
                gx, gy = ROUTE[self.wp]; d = math.hypot(gx - x, gy - y)
                if d < 0.08:
                    self.get_logger().info('WP%d reached' % (self.wp + 1)); self.wp = (self.wp + 1) % len(ROUTE)
                e = math.atan2(math.sin(math.atan2(gy - y, gx - x) - th), math.cos(math.atan2(gy - y, gx - x) - th))
                t.angular.z = max(-1.0, min(1.0, 2.0 * e))
                t.linear.x = 0.0 if abs(e) > 0.5 else min(0.2, 0.6 * d)
        elif self.state == 'ALERT':
            if self.now() - self.last_seen > 2.0:                    # 2 s 동안 안 보이면 순찰 재개
                self.set_state('PATROL', 'clear, resume WP%d' % (self.wp + 1))
            elif self.seen:
                t.angular.z = max(-1.2, min(1.2, 1.6 * self.seen[2]))  # 경비 모드처럼 방향만 추적
        self.cmd.publish(t)

#!/usr/bin/env python3
# intruder_detector.py — navigation.launch.py 실행 + 초기 위치 지정 후
import numpy as np
import cv2
import rclpy
from rclpy.node import Node
from rclpy.time import Time
from rclpy.qos import QoSProfile, DurabilityPolicy, ReliabilityPolicy, qos_profile_sensor_data
from nav_msgs.msg import OccupancyGrid
from sensor_msgs.msg import LaserScan
from geometry_msgs.msg import PointStamped
from tf2_ros import Buffer, TransformListener, TransformException
from tf_transformations import euler_from_quaternion

class IntruderDetector(Node):
    def __init__(self):
        super().__init__('intruder_detector')
        self.gap = self.declare_parameter('gap', 0.20).value            # [m] 지도 벽에서 이만큼 멀면 변화
        self.min_pts = self.declare_parameter('min_pts', 4).value       # 덩어리 최소 빔 수
        self.max_range = self.declare_parameter('max_range', 4.0).value # [m] 먼 끝점은 위치 오차가 커서 무시
        self.confirm = self.declare_parameter('confirm_scans', 3).value # 연속 확인 스캔 수
        self.dist, self.hits = None, 0
        latched = QoSProfile(depth=1, durability=DurabilityPolicy.TRANSIENT_LOCAL,
                             reliability=ReliabilityPolicy.RELIABLE)
        self.create_subscription(OccupancyGrid, '/map', self.on_map, latched)
        self.create_subscription(LaserScan, '/scan_raw', self.on_scan, qos_profile_sensor_data)
        self.pub = self.create_publisher(PointStamped, '/patrol/intruder', 10)
        self.tf_buffer = Buffer()
        self.tf_listener = TransformListener(self.tf_buffer, self)
    def on_map(self, m):
        g = np.array(m.data, dtype=np.int8).reshape(m.info.height, m.info.width)
        free = np.where((g >= 50) | (g < 0), 0, 255).astype(np.uint8)   # 점유·미탐색 = 0
        self.dist = cv2.distanceTransform(free, cv2.DIST_L2, 5) * m.info.resolution
        self.res = m.info.resolution
        self.ox, self.oy = m.info.origin.position.x, m.info.origin.position.y
        self.get_logger().info('map %d x %d loaded' % (m.info.width, m.info.height))
    def on_scan(self, s):
        if self.dist is None:
            return
        try:
            tf = self.tf_buffer.lookup_transform('map', s.header.frame_id, Time())
        except TransformException:
            return                                                       # 초기 위치 지정 전
        t, q = tf.transform.translation, tf.transform.rotation
        th = euler_from_quaternion([q.x, q.y, q.z, q.w])[2]
        r = np.array(s.ranges, dtype=float)
        a = s.angle_min + np.arange(len(r)) * s.angle_increment
        ok = np.isfinite(r) & (r > s.range_min) & (r < self.max_range)
        r = np.where(ok, r, 0.0)
        wx, wy = t.x + r * np.cos(a + th), t.y + r * np.sin(a + th)
        h, w = self.dist.shape
        c = np.clip(((wx - self.ox) / self.res).astype(int), 0, w - 1)
        rr = np.clip(((wy - self.oy) / self.res).astype(int), 0, h - 1)
        idx = np.flatnonzero(ok & (self.dist[rr, c] > self.gap))
        groups = [k for k in np.split(idx, np.flatnonzero(np.diff(idx) > 2) + 1) if len(k) >= self.min_pts]
        self.hits = self.hits + 1 if groups else 0
        if self.hits >= self.confirm:
            k = max(groups, key=len)
            p = PointStamped()
            p.header.stamp, p.header.frame_id = s.header.stamp, 'map'
            p.point.x, p.point.y = float(wx[k].mean()), float(wy[k].mean())
            self.pub.publish(p)

if __name__ == '__main__':
    rclpy.init()
    node = IntruderDetector()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()

#!/usr/bin/env python3
# patrol_guard.py — intruder_detector.py와 함께 실행
import csv, math, os, time
import rclpy
from rclpy.time import Time
from geometry_msgs.msg import PoseStamped, PointStamped, Twist
from std_msgs.msg import String
from nav2_simple_commander.robot_navigator import BasicNavigator, TaskResult
from tf2_ros import Buffer, TransformListener, TransformException
from tf_transformations import quaternion_from_euler, euler_from_quaternion
from ros_robot_controller_msgs.msg import RGBState, RGBStates, BuzzerState

ROUTE = [(1.0, 0.0, 0.0), (1.0, 1.0, 1.57), (0.0, 1.0, 3.14), (0.0, 0.0, -1.57)]  # /clicked_point로 모은 map 좌표
CLEAR_T, W_MAX, KP, MAX_FAIL = 2.0, 0.5, 1.6, 3
GREEN, RED, YELLOW = (0, 255, 0), (255, 0, 0), (255, 255, 0)

class PatrolGuard(BasicNavigator):
    def __init__(self):
        super().__init__('patrol_guard')
        self.cmd = self.create_publisher(Twist, '/controller/cmd_vel', 1)
        self.rgb = self.create_publisher(RGBStates, '/ros_robot_controller/set_rgb', 1)
        self.buzzer = self.create_publisher(BuzzerState, '/ros_robot_controller/set_buzzer', 1)
        self.event = self.create_publisher(String, '/patrol/event', 10)
        self.create_subscription(PointStamped, '/patrol/intruder', self.on_intruder, 10)
        self.tf_buffer = Buffer()
        self.tf_listener = TransformListener(self.tf_buffer, self)
        self.target, self.last_seen, self.last_beep = None, -1e9, -1e9
        self.csv = open(os.path.expanduser('~/patrol_events.csv'), 'a', newline='')
    def now(self):
        return self.get_clock().now().nanoseconds * 1e-9
    def on_intruder(self, p):
        self.target, self.last_seen = (p.point.x, p.point.y), self.now()
    def pose(self):                                    # AMCL이 보정한 map 좌표 자세
        try:
            tf = self.tf_buffer.lookup_transform('map', 'base_footprint', Time())
        except TransformException:
            return None
        t, q = tf.transform.translation, tf.transform.rotation
        return t.x, t.y, euler_from_quaternion([q.x, q.y, q.z, q.w])[2]
    def goal(self, x, y, yaw):
        p = PoseStamped()
        p.header.frame_id, p.header.stamp = 'map', self.get_clock().now().to_msg()
        p.pose.position.x, p.pose.position.y = x, y
        q = quaternion_from_euler(0.0, 0.0, yaw)
        p.pose.orientation.x, p.pose.orientation.y, p.pose.orientation.z, p.pose.orientation.w = q
        self.goToPose(p)
    def alarm(self, rgb, beep=None):                   # beep = (freq, on/off 시간, 횟수)
        self.rgb.publish(RGBStates(states=[RGBState(index=i, red=rgb[0], green=rgb[1], blue=rgb[2]) for i in (1, 2)]))
        if beep:
            self.buzzer.publish(BuzzerState(freq=beep[0], on_time=beep[1], off_time=beep[1], repeat=beep[2]))
            self.last_beep = self.now()
    def report(self, state, detail=''):
        p = self.pose() or (float('nan'),) * 3
        row = [time.strftime('%Y-%m-%d %H:%M:%S'), state, '%.2f' % p[0], '%.2f' % p[1], detail]
        csv.writer(self.csv).writerow(row); self.csv.flush()
        self.event.publish(String(data=','.join(row)))
        self.get_logger().warn(' '.join(row))
    def track(self):                                   # 경비 모드처럼 방향만 맞춘다 (전진 없음)
        p, t = self.pose(), Twist()
        if p and self.target:
            e = math.atan2(self.target[1] - p[1], self.target[0] - p[0]) - p[2]
            e = math.atan2(math.sin(e), math.cos(e))
            if abs(e) > math.radians(5):
                t.angular.z = max(-W_MAX, min(W_MAX, KP * e))
        self.cmd.publish(t)
        if self.now() - self.last_beep > 10.0:
            self.alarm(RED, (1900, 0.2, 5))

def main():
    rclpy.init()
    nav = PatrolGuard()
    nav.waitUntilNav2Active()
    i, fails, state = 0, 0, 'PATROL'
    nav.alarm(GREEN); nav.goal(*ROUTE[i])
    try:
        while rclpy.ok():
            rclpy.spin_once(nav, timeout_sec=0.05)
            if state == 'PATROL' and nav.now() - nav.last_seen < 0.5:
                nav.cancelTask(); nav.cmd.publish(Twist())             # Nav2를 먼저 멈춘다
                state = 'ALERT'
                nav.alarm(RED, (1900, 0.2, 5)); nav.report(state, 'intruder (%.2f, %.2f)' % nav.target)
            elif state == 'PATROL' and nav.isTaskComplete():
                if nav.getResult() == TaskResult.SUCCEEDED:
                    i, fails = (i + 1) % len(ROUTE), 0
                else:
                    fails += 1
                    nav.report('WP_FAIL', 'WP%d try %d' % (i + 1, fails))
                    if fails >= MAX_FAIL:
                        i, fails = (i + 1) % len(ROUTE), 0
                nav.goal(*ROUTE[i])
            elif state == 'ALERT' and nav.now() - nav.last_seen > CLEAR_T:
                nav.cmd.publish(Twist()); nav.alarm(GREEN)
                nav.report('RESUME', 'back to WP%d' % (i + 1))
                state = 'PATROL'
                nav.goal(*ROUTE[i])                                     # 중단했던 점부터
            elif state == 'ALERT':
                nav.track()
    except KeyboardInterrupt:
        pass
    finally:
        nav.cancelTask(); nav.cmd.publish(Twist())
        nav.alarm(YELLOW, (1000, 0.5, 2)); nav.report('SAFE_STOP', 'shutdown')
        nav.csv.close(); nav.destroy_node(); rclpy.shutdown()

if __name__ == '__main__':
    main()
