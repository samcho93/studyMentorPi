학습 목표#

프로젝트 개요와 요구사항#

M03에서 보았듯 MentorPi의 /odom은 휠 속도와 IMU를 robot_localization이 융합한 값입니다. 휠은 미끄러지면 모르고, 로봇이 벽에 막혀도 명령 속도를 적분하므로 거리가 계속 늘어납니다. 라이다는 주변이 어떻게 움직였는지를 직접 보므로 이런 오차를 잡을 수 있습니다. 원본에도 이 아이디어가 들어 있습니다: ekf.yaml의 odom1: odom_rf2o와 controller/launch/rf2o_laser_odometry.launch.py. 다만 기본 controller.launch.py는 rf2o를 켜지 않습니다.

이 프로젝트에서는 그 부품들을 직접 만듭니다: 스캔 두 장의 상대 이동을 구하는 ICP, 그것을 이어 붙인 스캔 오도메트리, 여러 센서를 확률적으로 합치는 EKF. 그리고 원본의 robot_localization + rf2o와 같은 조건에서 비교해, 무엇이 왜 더 좋거나 나쁜지 수치로 설명합니다.

이론#

스캔 매칭과 SE(2)#

2D 자세 T = (x, y, θ)는 점 p를 T(p) = R(θ)·p + t로 옮깁니다(R(θ)는 2 × 2 회전 행렬, t = [x, y]ᵀ). 두 자세의 합성 T_1 ⊕ T_2는 "T₁ 좌표계에서 본 T₂"를 바깥 좌표로 옮기는 것입니다.

text
(x1, y1, θ1) ⊕ (x2, y2, θ2) = (x1 + cosθ1·x2 − sinθ1·y2,  y1 + sinθ1·x2 + cosθ1·y2,  θ1 + θ2)

스캔 매칭은 이전 스캔 Q 좌표계에서 본 현재 스캔 P의 자세 Δ_k를 찾는 문제이고, 스캔 오도메트리는 T_k = T_{k−1} ⊕ Δ_k로 이어 붙입니다. 매 스캔의 작은 오차가 합성되며 쌓이므로 드리프트는 피할 수 없습니다. 이를 끊으려면 지도와 맞추거나(scan-to-map, slam_toolbox) 루프를 닫아야 합니다(M09).

점-점 ICP와 SVD 닫힌 해#

Besl & McKay(1992)의 ICP는 "대응을 모르는 정합"을 두 단계 반복으로 풉니다: ① 현재 추정으로 P를 옮겨 각 점의 최근접 이웃 q_{j(i)}를 대응으로 삼고, ② 대응이 고정됐다고 보고 최소제곱 변환을 구합니다.

② 단계의 목적함수는 E(R, t) = Σ_i ‖R·p_i + t − q_i‖²입니다. t로 미분해 0으로 두면 t = q̄ − R·p̄ (두 무게중심 p̄, q̄)가 나오고, 중심을 뺀 p′_i = p_i − p̄, q′_i = q_i − q̄로 다시 쓰면

text
E(R) = Σ ‖R p′_i − q′_i‖² = Σ (‖p′_i‖² + ‖q′_i‖²) − 2 · trace(R · W),   W = Σ p′_i q′_iᵀ  (2×2 교차공분산)

이므로 trace(R·W)를 최대화하면 됩니다. W = U Σ Vᵀ (SVD)라 하면 trace(R U Σ Vᵀ) = trace(Vᵀ R U · Σ)이고, 직교행렬 Vᵀ R U의 대각 원소는 1 이하이므로 Vᵀ R U = I일 때 최대, 즉 R = V Uᵀ입니다. det(R) = −1(반사)이 나오면 V의 마지막 열 부호를 바꿉니다(Kabsch 1976, Arun 1987). 2D에서는 θ = atan2(W_{01} − W_{10}, W_{00} + W_{11})로도 같습니다.

text
T ← T0
repeat (최대 N회):
    P' ← T(P)
    j(i) ← argmin_j ‖P'_i − Q_j‖                        # 최근접 이웃
    keep ← d_i < max(τ, 3·median(d))                    # 이상치 제거
    (R, t) ← Kabsch(P'[keep], Q[j[keep]])               # 증분 변환
    T ← (R, t) ∘ T
until ‖t‖ < ε_t and |∠R| < ε_θ
요소선택이유
최근접 이웃전수 O(NM) / k-d 트리 O(N log M)라이다 360점은 전수도 수 ms. 3D 점군은 트리 필수
이상치거리 게이트 τ, 중앙값 배수, Trimmed ICP(가까운 80 %만)새로 보인 벽·움직이는 사람·가려짐
초기값직전 이동(등속), 또는 휠 오도메트리ICP는 국소 최적화 — 멀리서 시작하면 틀린 극소
수렴증분 < ε, 최대 반복잔차 감소가 멈추면 끝

점-선 ICP와 가우스-뉴턴#

라이다는 벽의 같은 점을 두 번 재지 않습니다. 1° 간격 빔이 로봇이 움직이면 벽의 다른 곳에 떨어지므로, 점-점 대응은 "빔끼리"의 거짓 대응이 되고 ICP는 제자리에 붙잡힙니다(표본화 편향, 실습 2에서 확인). 점-선 ICP(Chen & Medioni 1991, Censi 2008 PL-ICP)는 대응점 q_i에서의 벽 법선 n_i 방향 거리만 벌합니다.

text
r_i(ξ) = n_iᵀ (R(θ) p_i + t − q_i),    ξ = (x, y, θ)
J_i   = ∂r_i/∂ξ = [ n_x,  n_y,  n_iᵀ S (p′_i − t) ],    S = [[0, −1], [1, 0]]  (90° 회전)
(Σ J_iᵀ J_i) Δξ = −Σ J_iᵀ r_i          # 가우스-뉴턴 정규방정식,  H = Σ J_iᵀ J_i

법선은 스캔 순서의 이웃 두 점 차 q_{i+1} − q_{i−1}에 수직인 단위벡터로 구하고, 이웃이 멀면(모서리·끊김) 그 점을 버립니다. 점-선은 벽을 따라 미끄러지는 방향을 벌하지 않으므로 표본화 편향이 없고 보통 3~6회에 수렴합니다.

공분산. 잔차가 독립 잡음 σ를 가진다고 보면 추정 공분산은 Σ_ξ ≈ σ²·H⁻¹입니다(Censi 2007은 대응 변화까지 고려한 더 정확한 식을 줍니다). 이 값을 EKF의 측정 공분산으로 넘깁니다.

퇴화: 긴 복도 문제#

H의 병진 부분 H_{xy} = Σ n_i n_iᵀ의 고윳값 λ_{min} ≤ λ_{max}를 봅시다. 좌우 벽만 보이는 복도에서는 모든 법선이 ±y 방향이라 H_{xy} ≈ diag(0, N) — x(복도 방향) 이동은 잔차를 바꾸지 않으므로 관측 불가능합니다. ICP는 그 방향으로 아무 값이나(보통 초기값 근처) 돌려줍니다.

판정식쓰임
조건수κ = λ_{max} / λ_{min}κ > 100이면 퇴화로 간주 (실습 4: 정상 8, 복도 44 이상)
퇴화 인자 (Zhang 2016)λ_{min} 자체가 임계값 이하점 수·잡음에 맞춰 임계값 조정
약한 방향λ_{min}의 고유벡터그 방향만 다른 센서(휠)에 맡김

대책은 ① 약한 방향 공분산을 크게 해서 EKF가 휠을 믿게 하기(icp_odometry.py), ② ICP 안에 휠 오도메트리 사전값 항 +λ_p‖e_{weak}ᵀ(ξ − ξ_{odom})‖²를 넣기(실습 4), ③ 약한 방향 성분을 갱신에서 빼기(solution remapping)입니다.

확장 칼만 필터 (EKF)#

상태 x = [x, y, θ, v, ω]ᵀ(전진 속도 v, 각속도 ω)와 공분산 P를 유지합니다. 등속 운동 모델과 야코비안은

text
f(x):  x' = x + v·cosθ·Δt,   y' = y + v·sinθ·Δt,   θ' = θ + ω·Δt,   v' = v,   ω' = ω
F = ∂f/∂x = [[1, 0, −v·sinθ·Δt, cosθ·Δt, 0 ],

공분산 튜닝과 일관성 (NEES·NIS)#

Q(모델을 얼마나 못 믿나)와 R(센서를 얼마나 못 믿나)은 필터의 성격을 정합니다. 숫자가 "그럴듯한지"는 일관성 검사로 확인합니다.

  • NEES (normalized estimation error squared): 정답이 있을 때(시뮬레이션) ε = eᵀ P⁻¹ e, e = x_{true} − x̂. 필터가 일관적이면 ε은 자유도 n(위치·방향이면 3)의 χ² 분포를 따라 평균이 n입니다. 평균 ≫ n이면 과신(P가 너무 작음 → Q 증가), ≪ n이면 과소신(Q·R 감소).
  • NIS (normalized innovation squared): 정답 없이 실물에서 ν = (z − Hx)ᵀ S⁻¹ (z − Hx)의 평균이 측정 차원 m이어야 합니다. my_ekf.py가 종료할 때 센서별 평균 NIS를 출력하고, ICP 갱신은 ν > χ²_{2, 0.999} = 13.8이면 버립니다(게이팅).

def points(scan):                                             # LaserScan → 라이다 좌표계 점 (N×2)
    r = np.array(scan.ranges); a = scan.angle_min + np.arange(len(r)) * scan.angle_increment
    ok = np.isfinite(r) & (r < 8.0)

def kabsch(P, Q):                                             # min Σ‖R p + t − q‖² (SVD)
    mp, mq = P.mean(0), Q.mean(0)
    U, _, Vt = np.linalg.svd((P - mp).T @ (Q - mq))
    R = Vt.T @ U.T
    if np.linalg.det(R) < 0: Vt[1] *= -1; R = Vt.T @ U.T      # 반사 방지
    return R, mq - R @ mp

def icp(P, Q, T0=(0.0, 0.0, 0.0), iters=30, reject=0.3, log=False):
    x, y, th = T0
    for k in range(iters):
        c, s = math.cos(th), math.sin(th)
        Pw = P @ np.array([[c, s], [-s, c]]) + (x, y)          # 현재 추정으로 P를 Q 좌표로
        d2 = ((Pw[:, None, :] - Q[None, :, :]) ** 2).sum(2)
        j = d2.argmin(1); d = np.sqrt(d2[np.arange(len(P)), j])  # 최근접 이웃 (전수 탐색)
        keep = d < max(reject, 3 * np.median(d)) if reject else np.ones(len(P), bool)
        R, t = kabsch(Pw[keep], Q[j[keep]])                   # 증분 변환
        x, y = R @ (x, y) + t; th += math.atan2(R[1, 0], R[0, 0])
        if log and k % 4 == 0: print('  iter %2d  rmse %.4f m  inliers %3d/%d  dT=(%.4f, %.4f, %.3f deg)' % (
            k, np.sqrt((d[keep] ** 2).mean()), keep.sum(), len(P), t[0], t[1], math.degrees(math.atan2(R[1, 0], R[0, 0]))))
        if np.hypot(*t) < 1e-4 and abs(math.atan2(R[1, 0], R[0, 0])) < 1e-4: break   # 수렴
    return (x, y, th), np.sqrt((d[keep] ** 2).mean()), k + 1

sim.setup(world="room", duration=25.0, start=START, noise=True)  # 시뮬 전용: 바퀴 미끄럼 켬

def points(scan):
    r = np.array(scan.ranges); a = scan.angle_min + np.arange(len(r)) * scan.angle_increment
    ok = np.isfinite(r) & (r < 8.0)
    return np.c_[r[ok] * np.cos(a[ok]), r[ok] * np.sin(a[ok])][::2]   # 2°마다 180점 (속도)

def icp(P, Q, T0, line=True, iters=20):                      # line=True: 점-선, False: 점-점(SVD)
    t = np.roll(Q, -1, 0) - np.roll(Q, 1, 0); N = np.c_[-t[:, 1], t[:, 0]]
    ln = np.hypot(*N.T); okn = (ln > 1e-6) & (ln < 0.3); N = N / np.where(okn, ln, 1)[:, None]
    x, y, th = T0
    for _ in range(iters):
        c, s = math.cos(th), math.sin(th); Pw = P @ np.array([[c, s], [-s, c]]) + (x, y)
        d2 = ((Pw[:, None, :] - Q[None, :, :]) ** 2).sum(2); j = d2.argmin(1)
        k = (np.sqrt(d2[np.arange(len(P)), j]) < 0.2) & (okn[j] | (not line))
        if line:                                              # 가우스-뉴턴 한 걸음 (선형화)
            n, e = N[j[k]], Pw[k] - Q[j[k]]
            J = np.c_[n, n[:, 1] * (Pw[k, 0] - x) - n[:, 0] * (Pw[k, 1] - y)]
            dx, dy, da = -np.linalg.solve(J.T @ J, J.T @ (n * e).sum(1))
            x, y, th = x + dx, y + dy, th + da
        else:                                                 # 닫힌 해 (Kabsch, SVD)
            A, B = Pw[k], Q[j[k]]; U, _, Vt = np.linalg.svd((A - A.mean(0)).T @ (B - B.mean(0)))
            R = Vt.T @ U.T; tt = B.mean(0) - R @ A.mean(0)
            x, y = R @ (x, y) + tt; da = math.atan2(R[1, 0], R[0, 0]); th += da; dx, dy = tt
        if max(abs(dx), abs(dy), abs(da)) < 1e-5: break
    return x, y, th

def compose(p, d):                                            # p ⊕ d (SE(2) 합성)
    c, s = math.cos(p[2]), math.sin(p[2])

실습 3. EKF 융합 — 휠, 휠+IMU, 휠+IMU+ICP#

같은 주행에서 EKF 세 개를 동시에 돌립니다. odom은 휠 v·ω, odom+imu는 원본 MentorPi처럼 휠 v + IMU ω, odom+imu+icp는 여기에 ICP 속도를 더합니다. NEES 평균(3이면 이상적)도 함께 봅니다.

def points(scan):
    r = np.array(scan.ranges); a = scan.angle_min + np.arange(len(r)) * scan.angle_increment
    ok = np.isfinite(r) & (r < 8.0)
    return np.c_[r[ok] * np.cos(a[ok]), r[ok] * np.sin(a[ok])][::2]

def icp(P, Q, T0, iters=15):                                  # 실습 2의 점-선 ICP (H도 돌려줌)
    t = np.roll(Q, -1, 0) - np.roll(Q, 1, 0); N = np.c_[-t[:, 1], t[:, 0]]
    ln = np.hypot(*N.T); okn = (ln > 1e-6) & (ln < 0.3); N = N / np.where(okn, ln, 1)[:, None]
    x, y, th = T0
    for _ in range(iters):
        c, s = math.cos(th), math.sin(th); Pw = P @ np.array([[c, s], [-s, c]]) + (x, y)
        d2 = ((Pw[:, None, :] - Q[None, :, :]) ** 2).sum(2); j = d2.argmin(1)
        k = okn[j] & (np.sqrt(d2[np.arange(len(P)), j]) < 0.2)
        n, e = N[j[k]], Pw[k] - Q[j[k]]
        J = np.c_[n, n[:, 1] * (Pw[k, 0] - x) - n[:, 0] * (Pw[k, 1] - y)]
        H = J.T @ J; dx = -np.linalg.solve(H, J.T @ (n * e).sum(1))
        x, y, th = x + dx[0], y + dx[1], th + dx[2]
        if np.abs(dx).max() < 1e-5: break
    return (x, y, th), H

Q_PROC = np.diag([1e-5, 1e-5, 1e-5, 0.02, 0.5])                # 공정 잡음 밀도 (튜닝 대상)
SIG_ODOM_V = 0.05                                             # 휠 속도 표준편차 [m/s]
class EKF:                                                    # 상태 [x, y, θ, v, ω]
    def __init__(self, x0):
        self.x = np.array([*x0, 0.0, 0.0]); self.P = np.diag([1e-6, 1e-6, 1e-6, 1e-2, 1e-2])
    def predict(self, dt):
        x, y, th, v, w = self.x; c, s = math.cos(th), math.sin(th)
        self.x = np.array([x + v * c * dt, y + v * s * dt, th + w * dt, v, w])
        F = np.eye(5); F[0, 2], F[0, 3], F[1, 2], F[1, 3], F[2, 4] = -v * s * dt, c * dt, v * c * dt, s * dt, dt
        self.P = F @ self.P @ F.T + Q_PROC * dt
    def update(self, z, idx, R):                              # z = H x + 잡음, H = 단위행렬의 행 선택
        H = np.eye(5)[idx]; S = H @ self.P @ H.T + R; K = self.P @ H.T @ np.linalg.inv(S)
        self.x = self.x + K @ (np.atleast_1d(z) - H @ self.x); self.P = (np.eye(5) - K @ H) @ self.P

        self.err = {k: [] for k in CFG}; self.nees = {k: [] for k in CFG}
    def use(self, src): return [f for k, f in self.f.items() if src in CFG[k]]
    def on_odom(self, m):

def icp(P, Q, T0=(0.0, 0.0, 0.0), iters=15, prior=None):     # 점-선 ICP (+ 선택: 오도메트리 사전값)
    t = np.roll(Q, -3, 0) - np.roll(Q, 3, 0); N = np.c_[-t[:, 1], t[:, 0]]
    ln = np.hypot(*N.T); okn = (ln > 1e-6) & (ln < 0.5); N = N / np.where(okn, ln, 1)[:, None]
    x = np.array(T0, float)
    for _ in range(iters):
        c, s = math.cos(x[2]), math.sin(x[2]); Pw = P @ np.array([[c, s], [-s, c]]) + x[:2]
        d2 = ((Pw[:, None, :] - Q[None, :, :]) ** 2).sum(2); j = d2.argmin(1)
        k = okn[j] & (np.sqrt(d2[np.arange(len(P)), j]) < 0.3)
        n, e = N[j[k]], Pw[k] - Q[j[k]]
        J = np.c_[n, n[:, 1] * (Pw[k, 0] - x[0]) - n[:, 0] * (Pw[k, 1] - x[1])]
        H, g = J.T @ J, J.T @ (n * e).sum(1)
        if prior is not None:                                 # 약한 방향만 오도메트리가 채우도록
            H, g = H + prior[1], g + prior[1] @ (x - prior[0])
        dx = -np.linalg.solve(H, g); x += dx
        if np.abs(dx).max() < 1e-5: break
    return x, J.T @ J

#!/usr/bin/env python3
# icp_odometry.py — /scan_raw → 점-선 ICP 스캔 매칭 오도메트리 → /odom_icp (TF 발행 안 함)
import math
import numpy as np
import rclpy
from rclpy.node import Node
from rclpy.qos import qos_profile_sensor_data
from sensor_msgs.msg import LaserScan
from nav_msgs.msg import Odometry
from tf_transformations import quaternion_from_euler

def points(scan, rmax):
    r = np.array(scan.ranges, dtype=float); a = scan.angle_min + np.arange(len(r)) * scan.angle_increment
    ok = np.isfinite(r) & (r > max(scan.range_min, 0.15)) & (r < rmax)   # 0.15 m 안(차체) 제외
    return np.c_[r[ok] * np.cos(a[ok]), r[ok] * np.sin(a[ok])]

def icp(P, Q, T0, iters=15, gate=0.2):
    t = np.roll(Q, -1, 0) - np.roll(Q, 1, 0); N = np.c_[-t[:, 1], t[:, 0]]
    ln = np.hypot(*N.T); okn = (ln > 1e-6) & (ln < 0.3); N = N / np.where(okn, ln, 1)[:, None]
    x = np.array(T0, float); H = np.eye(3); k = np.zeros(len(P), bool)
    for _ in range(iters):
        c, s = math.cos(x[2]), math.sin(x[2]); Pw = P @ np.array([[c, s], [-s, c]]) + x[:2]
        d2 = ((Pw[:, None, :] - Q[None, :, :]) ** 2).sum(2); j = d2.argmin(1)   # 450×450: 파이 5에서 수 ms
        k = okn[j] & (np.sqrt(d2[np.arange(len(P)), j]) < gate)
        if k.sum() < 30: return None, None, 0
        n, e = N[j[k]], Pw[k] - Q[j[k]]
        J = np.c_[n, n[:, 1] * (Pw[k, 0] - x[0]) - n[:, 0] * (Pw[k, 1] - x[1])]
        H = J.T @ J; dx = -np.linalg.solve(H, J.T @ (n * e).sum(1)); x += dx
        if np.abs(dx).max() < 1e-5: break
    return x, H, int(k.sum())

class IcpOdometry(Node):
    def __init__(self):
        super().__init__('icp_odometry')
        self.rmax = self.declare_parameter('max_range', 8.0).value
        self.sigma = self.declare_parameter('sigma', 0.01).value      # 점-선 잔차 표준편차 [m]
        self.create_subscription(LaserScan, '/scan_raw', self.on_scan, qos_profile_sensor_data)
        self.pub = self.create_publisher(Odometry, '/odom_icp', 10)
        self.prev, self.t_prev, self.delta = None, None, np.zeros(3)
        self.pose = np.zeros(3)
    def on_scan(self, s):
        P = points(s, self.rmax)[::2]
        t = s.header.stamp.sec + s.header.stamp.nanosec * 1e-9
        if self.prev is not None and len(P) > 50:
            d, H, n = icp(P, self.prev, self.delta)
            dt = t - self.t_prev
            if d is None or not 0.01 < dt < 0.5:
                self.get_logger().warn('ICP failed (inliers < 30) — keep previous estimate', throttle_duration_sec=2.0)
            else:
                w = np.linalg.eigvalsh(H[:2, :2]); cov = self.sigma ** 2 * np.linalg.inv(H)
                if w[1] / max(w[0], 1e-9) > 100:                    # 퇴화(긴 복도): 약한 방향 불신
                    cov[:2, :2] += np.eye(2) * 1.0
                    self.get_logger().warn('degenerate scan (cond %.0f)' % (w[1] / w[0]), throttle_duration_sec=2.0)
                self.delta = d
                c, sn = math.cos(self.pose[2]), math.sin(self.pose[2])
                self.pose += (c * d[0] - sn * d[1], sn * d[0] + c * d[1], d[2])
                self.publish(s.header.stamp, d / dt, cov / dt ** 2, n)
        self.prev, self.t_prev = P, t
    def publish(self, stamp, vel, cov, n):
        o = Odometry(); o.header.stamp = stamp; o.header.frame_id = 'odom'; o.child_frame_id = 'base_footprint'
        o.pose.pose.position.x, o.pose.pose.position.y = float(self.pose[0]), float(self.pose[1])
        q = quaternion_from_euler(0.0, 0.0, float(self.pose[2]))
        o.pose.pose.orientation.x, o.pose.pose.orientation.y, o.pose.pose.orientation.z, o.pose.pose.orientation.w = q
        o.twist.twist.linear.x, o.twist.twist.linear.y, o.twist.twist.angular.z = (float(v) for v in vel)
        tc = [0.0] * 36                                              # 6×6 (x y z r p y) 중 x, y, yaw
        for a, i in enumerate((0, 1, 5)):
            for b, j in enumerate((0, 1, 5)):
                tc[i * 6 + j] = float(cov[a, b])
        o.twist.covariance = tc
        self.pub.publish(o)

def main():
    rclpy.init(); node = IcpOdometry()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node(); rclpy.shutdown()

if __name__ == '__main__':
    main()

#!/usr/bin/env python3
# my_ekf.py — /odom_raw(v) + /imu(ω) + /odom_icp(v, ω) → EKF [x, y, θ, v, ω] → /odom_fused
import math
import numpy as np
import rclpy
from rclpy.node import Node
from nav_msgs.msg import Odometry
from sensor_msgs.msg import Imu
from tf_transformations import quaternion_from_euler

class MyEkf(Node):
    def __init__(self):
        super().__init__('my_ekf')
        q = self.declare_parameter('process_noise', [1e-5, 1e-5, 1e-5, 0.02, 0.5]).value
        self.Q = np.diag(q)
        self.sig_v = self.declare_parameter('sigma_wheel_v', 0.05).value
        self.sig_w = self.declare_parameter('sigma_imu_w', 0.01).value
        self.use_icp = self.declare_parameter('use_icp', True).value
        self.x = np.zeros(5); self.P = np.diag([1e-6, 1e-6, 1e-6, 1e-2, 1e-2]); self.t = None
        self.create_subscription(Odometry, '/odom_raw', self.on_odom, 10)
        self.create_subscription(Imu, '/imu', self.on_imu, 10)
        self.create_subscription(Odometry, '/odom_icp', self.on_icp, 10)
        self.pub = self.create_publisher(Odometry, '/odom_fused', 10)
        self.nis = {}                                                   # 센서별 NIS 기록
    def predict(self):
        now = self.get_clock().now().nanoseconds * 1e-9
        dt = 0.0 if self.t is None else min(now - self.t, 0.1); self.t = now
        x, y, th, v, w = self.x; c, s = math.cos(th), math.sin(th)
        self.x = np.array([x + v * c * dt, y + v * s * dt, th + w * dt, v, w])
        F = np.eye(5); F[0, 2], F[0, 3], F[1, 2], F[1, 3], F[2, 4] = -v * s * dt, c * dt, v * c * dt, s * dt, dt
        self.P = F @ self.P @ F.T + self.Q * dt
    def update(self, z, idx, R, gate=None):
        H = np.eye(5)[idx]; r = np.atleast_1d(z) - H @ self.x; S = H @ self.P @ H.T + R
        d2 = float(r @ np.linalg.solve(S, r))                           # NIS (마할라노비스 거리²)
        if gate and d2 > gate:
            self.get_logger().warn('reject %s (NIS %.1f)' % (idx, d2), throttle_duration_sec=1.0); return
        K = self.P @ H.T @ np.linalg.inv(S); self.x = self.x + K @ r
        I_KH = np.eye(5) - K @ H; self.P = I_KH @ self.P @ I_KH.T + K @ R @ K.T   # 조셉 형태 (대칭 유지)
        self.nis.setdefault(str(idx), []).append(d2)
    def on_odom(self, m):                                               # 50 Hz: 예측 + 휠 v 갱신
        self.predict()
        self.update(m.twist.twist.linear.x, [3], np.array([[self.sig_v ** 2]]))
        self.publish(m.header.stamp)
    def on_imu(self, m):
        self.predict(); self.update(m.angular_velocity.z, [4], np.array([[self.sig_w ** 2]]))
    def on_icp(self, m):                                                # 10 Hz: ICP v, ω (공분산 포함)
        if not self.use_icp: return
        c = np.array(m.twist.covariance).reshape(6, 6)[np.ix_([0, 5], [0, 5])] + np.diag([1e-4, 1e-4])
        self.predict(); self.update([m.twist.twist.linear.x, m.twist.twist.angular.z], [3, 4], c, gate=13.8)  # χ²(2) 99.9 %
    def publish(self, stamp):
        o = Odometry(); o.header.stamp = stamp; o.header.frame_id = 'odom'; o.child_frame_id = 'base_footprint'
        o.pose.pose.position.x, o.pose.pose.position.y = float(self.x[0]), float(self.x[1])
        q = quaternion_from_euler(0.0, 0.0, float(self.x[2]))
        o.pose.pose.orientation.x, o.pose.pose.orientation.y, o.pose.pose.orientation.z, o.pose.pose.orientation.w = q
        o.twist.twist.linear.x, o.twist.twist.angular.z = float(self.x[3]), float(self.x[4])
        pc = [0.0] * 36
        for a, i in enumerate((0, 1, 5)):
            for b, j in enumerate((0, 1, 5)):
                pc[i * 6 + j] = float(self.P[a, b])
        o.pose.covariance = pc
        self.pub.publish(o)

def main():
    rclpy.init(); node = MyEkf()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        for key, v in node.nis.items():                                 # 기대값 = 측정 차원 수 (1 또는 2)
            node.get_logger().info('mean NIS %s %.2f over %d updates' % (key, np.mean(v), len(v)))
        node.destroy_node(); rclpy.shutdown()

if __name__ == '__main__':
    main()

#!/usr/bin/env python3
# odom_eval.py — 여러 오도메트리를 slam_toolbox 자세(map→base_footprint)와 비교: CSV 기록 + 종료 시 ATE/RPE
import csv, math, os
import numpy as np
import rclpy
from rclpy.node import Node
from rclpy.time import Time
from nav_msgs.msg import Odometry
from tf2_ros import Buffer, TransformListener, TransformException
from tf_transformations import euler_from_quaternion

SOURCES = ['/odom', '/odom_raw', '/odom_rf2o', '/odom_icp', '/odom_fused']
yaw = lambda q: euler_from_quaternion([q.x, q.y, q.z, q.w])[2]

def align(E, G):                                           # 2D 강체 정렬 (Umeyama, 척도 없음)
    me, mg = E.mean(0), G.mean(0)
    U, _, Vt = np.linalg.svd((E - me).T @ (G - mg)); R = Vt.T @ U.T
    if np.linalg.det(R) < 0: Vt[1] *= -1; R = Vt.T @ U.T
    return (E - me) @ R.T + mg

def rpe(E, G, step=1.0):                                  # 주행 거리 step [m]마다 상대 이동 오차
    s = np.r_[0, np.cumsum(np.hypot(*np.diff(G, axis=0).T))]; out, i = [], 0
    for j in range(len(G)):
        if s[j] - s[i] >= step:
            out.append(np.hypot(*((E[j] - E[i]) - (G[j] - G[i])))); i = j
    return np.mean(out) if out else float('nan')

class OdomEval(Node):
    def __init__(self):
        super().__init__('odom_eval')
        self.last = {}
        for t in SOURCES:
            self.create_subscription(Odometry, t, lambda m, t=t: self.last.__setitem__(
                t, (m.pose.pose.position.x, m.pose.pose.position.y, yaw(m.pose.pose.orientation))), 10)
        self.tf_buffer = Buffer(); self.tf_listener = TransformListener(self.tf_buffer, self)
        self.rows = []; self.create_timer(0.1, self.sample)
        self.f = open(os.path.expanduser('~/p06_run.csv'), 'w', newline=''); self.w = csv.writer(self.f)
        self.w.writerow(['t', 'ref_x', 'ref_y', 'ref_yaw'] + ['%s_%s' % (s, a) for s in SOURCES for a in 'xyθ'])
    def sample(self):
        try:
            tf = self.tf_buffer.lookup_transform('map', 'base_footprint', Time())
        except TransformException:
            return
        ref = (tf.transform.translation.x, tf.transform.translation.y, yaw(tf.transform.rotation))
        row = [self.get_clock().now().nanoseconds * 1e-9, *ref] + [v for s in SOURCES for v in self.last.get(s, (math.nan,) * 3)]
        self.rows.append(row); self.w.writerow(row)
    def report(self):
        if len(self.rows) < 20: print('no reference pose (map->base_footprint) recorded'); return
        A = np.array(self.rows); G = A[:, 1:3]
        for k, s in enumerate(SOURCES):
            E = A[:, 4 + 3 * k:6 + 3 * k]; ok = np.isfinite(E).all(1)
            if ok.sum() < 20: continue
            e = np.hypot(*(align(E[ok], G[ok]) - G[ok]).T)
            print('%-12s ATE %.3f m  max %.3f m  RPE(1 m) %.3f m' % (s, np.sqrt((e ** 2).mean()), e.max(), rpe(align(E[ok], G[ok]), G[ok])))

def main():
    rclpy.init(); node = OdomEval()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.f.close(); node.report(); node.destroy_node(); rclpy.shutdown()

if __name__ == '__main__':
    main()

확장 과제#

  • 메카넘 상태 확장: 상태에 옆 속도 v_y를 넣은 [x, y, θ, v_x, v_y, ω] EKF로 바꾸고 옆걸음 주행에서 비교합니다(ICP는 Δy를 이미 줍니다).
  • scan-to-map 오도메트리: 연속 스캔 대신 최근 N장을 합친 국소 지도(키프레임)와 매칭해 드리프트를 줄입니다. 키프레임 교체 기준(이동 0.3 m 또는 회전 15°)을 실험합니다.
  • k-d 트리: scipy.spatial.cKDTree(설치된 경우) 또는 격자 해시로 최근접 이웃을 바꾸고 처리 시간을 비교합니다.
  • 자이로 편향 상태: 상태에 IMU 편향 b_ω를 추가하고, 정지 구간에서 편향이 수렴하는지 봅니다.
  • UKF: 같은 모델로 무향 칼만 필터를 구현해 큰 회전 속도에서 EKF와 비교합니다(robot_localization의 ukf_node와도 비교).
  • robot_localization에 팀 ICP 연결: ekf.yaml의 odom1을 odom_icp로 바꾸고 odom1_config를 속도(vx, vy, vyaw)로, odom1_differential을 검토해 원본 필터로 팀 ICP를 쓰는 구성을 만듭니다(원본 파일은 백업).

과제#

기본 과제
  1. 실습 1에서 스캔 간격(0.5, 1, 2, 3 s)을 바꾸며 ICP 수렴 여부와 오차를 표로 만들고, 수렴 반경을 회전 각도로 설명합니다.
  2. 실습 3의 튜닝 표에 한 줄을 추가합니다: IMU 잡음 0.01 ** 2을 0.05 ** 2로 바꿨을 때 ATE·NEES가 어떻게 되는지 예측하고 실행해 확인합니다.
심화 과제
  1. 점-점 ICP에서 목표 스캔 Q를 선형 보간으로 5배 조밀하게 만들면 실습 2의 표본화 편향이 줄어드는지 실험하고, 점-선 ICP와 비교합니다.
  2. 실물 E2 표를 채우고, 팀 EKF가 원본 robot_localization(rf2o 켬)보다 좋거나 나쁜 이유를 모델(15차원 vs 5차원), 입력 방식(위치 vs 속도), 공분산 설정으로 나눠 분석합니다.
