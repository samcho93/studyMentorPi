이론#

마르코프 결정 과정#

MDP는 다섯 가지 (\mathcal{S}, \mathcal{A}, P, R, \gamma)로 정의합니다. 매 시각 t에 에이전트는 상태 s_t를 보고 행동 a_t를 고르며, 환경은 다음 상태 s_{t+1} \sim P(\cdot \mid s_t, a_t)와 보상 r_{t+1}을 돌려줍니다. 목표는 할인된 누적 보상(return)

G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \dots

의 기댓값을 최대로 하는 정책 \pi(a \mid s)를 찾는 것입니다. 행동 가치 함수 Q^\pi(s, a) = \mathbb{E}_\pi[G_t \mid s_t = s, a_t = a]의 최적값은 벨만 최적 방정식을 만족합니다.

Q^(s, a) = \mathbb{E}\left[ r + \gamma \max_{a'} Q^(s', a') \right]

Q^를 알면 최적 정책은 \pi^(s) = \arg\max_a Q^*(s, a)로 바로 나옵니다.

할인율 고르기. \gamma는 "얼마나 먼 미래까지 보는가"를 정합니다. 유효 지평은 대략 1/(1-\gamma) 스텝입니다. 우리는 5 Hz로 결정하고 \gamma = 0.95를 쓰므로 약 20 스텝 = 4 s, 0.18 m/s로 0.7 m 앞까지의 결과를 봅니다. 라이다 상태의 "근접" 경계(0.7 m)와 맞춘 값입니다.

상태·행동·보상 설계#

요소설계이유
빔−90°, −60°, −30°, −15°, 0°, 15°, 30°, 60°, 90°360개 빔을 그대로 쓰면 표가 폭발. 전방을 촘촘히
섹터L = {60°, 90°}, F = {−30°…30°}, R = {−60°, −90°}로봇 반지름 0.13 m: 30° 방향 0.3 m 물체는 옆으로 0.15 m, 부딪힐 수 있으므로 F에 포함
단계d < 0.35 → 0(위험), d < 0.7 → 1(근접), 그 외 2(여유)0.35 m = 반지름 + 제동·회전 여유, 0.7 m ≈ 4 s 지평
직전 행동F/L/R라이다 한 장은 부분 관측(POMDP)입니다. 회전 중인지 알아야 좌우 진동을 줄임
행동F: (0.18 m/s, 0), L: (0, +0.5 rad/s), R: (0, −0.5 rad/s)안전 한계 안의 이산 행동 3개
보상r = 10\,\Delta s - 0.02\,[a \ne F] - 0.3\,\frac{\max(0,\,0.35 - d_F)}{0.35} - 5\,[\text{충돌}]진행(전진 거리 \Delta s) − 회전 비용 − 근접 벌점 − 충돌

상태 번호는 s = ((L \cdot 3 + F) \cdot 3 + R) \cdot 3 + a_{prev}입니다. 전진 한 스텝(0.18 \times 0.2 = 0.036 m)의 진행 보상은 0.36이므로, 20 s(100 스텝) 동안 쉬지 않고 전진하면 최대 36점입니다. 충돌 −5는 약 14스텝의 전진과 맞먹습니다.

종료와 잘림은 다릅니다. 충돌은 진짜 종료(terminal)라서 다음 상태의 가치를 더하지 않습니다(\gamma \max Q(s') \cdot 0). 반면 20 s 에피소드가 끝나는 것은 시간 잘림(truncation)이라서 부트스트랩을 해야 합니다. 둘을 섞으면 "20 s가 끝날 무렵엔 아무렇게나 해도 된다"는 이상한 가치가 학습됩니다.

표 기반 Q-러닝#

상태가 81개뿐이므로 Q를 81×3 표에 담을 수 있습니다. 전이 (s, a, r, s')를 겪을 때마다 TD(시간차) 목표 쪽으로 조금씩 옮깁니다.

Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \right]

행동은 ε-탐욕으로 고릅니다. 확률 ε로 무작위, 아니면 \arg\max_a Q(s, a). ε를 1에서 0.05로 줄여 가며 처음엔 탐험, 나중엔 활용합니다. Q-러닝은 비정책(off-policy) 방법이라 무작위로 움직이며 모은 경험으로도 탐욕 정책의 가치를 배웁니다.

text
Q ← 0 (81×3),  ε ← 1
for 에피소드 = 1..40:
    E개 환경을 무작위 자세로 초기화, s ← 상태(스캔)
    for k = 1..100:                         # 20 s
        a ← ε-탐욕(Q, s)                    # E개 동시에
        s', r, 충돌 ← 환경.step(a)
        y ← r + γ·max Q(s')·(1 − 충돌)      # 충돌 = 종료, 부트스트랩 없음
        Q(s, a) ← Q(s, a) + α (y − Q(s, a))
        충돌한 환경은 새 자세에서 다시 시작
        s ← s'
    ε ← max(0.05, 1 − 에피소드/25)

한 번에 E = 32개 환경을 넘파이 배열로 동시에 진행합니다. 로봇 32대의 광선 투사가 (32, 9, 16) 배열 연산 한 번이라 파이썬 반복문보다 수십 배 빠릅니다. Playground에서 1~2초 안에 12만 번의 전이를 모으는 비결입니다.

DQN: 함수 근사로 넘어가기#

상태를 81칸으로 나누면 0.34 m와 0.36 m가 전혀 다른 상태가 되고, 빔 9개의 연속값 정보가 버려집니다. DQN(Deep Q-Network, Mnih et al. 2015)은 표 대신 신경망 Q_\theta(s, \cdot)로 모든 행동의 가치를 한 번에 냅니다. 입력은 빔 9개(1 m에서 포화) + 직전 행동 one-hot 3개 = 12차원, 은닉층 32개(ReLU), 출력 3개로 가중치는 515개입니다.

신경망에 TD 학습을 그대로 붙이면 쉽게 발산합니다. DQN의 두 장치가 이를 막습니다.

장치문제해결
재현 버퍼(experience replay)연속 샘플은 서로 비슷해(상관) 경사가 한쪽으로 쏠림2만 개 전이를 저장하고 무작위로 64개씩 뽑음
타깃 네트워크 \theta^-목표 y가 방금 고친 \theta로 계산돼 움직이는 과녁을 쫓음100 스텝마다만 \theta^- \leftarrow \theta 복사

손실은 L(\theta) = \mathbb{E}_{(s,a,r,s') \sim \mathcal{D}}\left[ \ell\left(Q_\theta(s, a) - y\right) \right], y = r + \gamma (1 - d) \max_{a'} Q_{\theta^-}(s', a')이고, \ell은 Huber 손실(오차가 \delta보다 크면 기울기를 \pm\delta로 자름)입니다. 역전파는 두 층뿐이라 넘파이로 직접 씁니다: \partial L/\partial W_2 = h^\top g, \partial L/\partial h = g W_2^\top \odot [h > 0], \partial L/\partial W_1 = x^\top (\partial L/\partial h). 최적화는 Adam입니다.

보상 설계의 함정#

보상은 "무엇을 원하는지"를 알려 주는 유일한 통로라서, 조금만 어긋나도 에이전트는 보상은 높지만 원하지 않는 행동을 찾아냅니다(reward hacking).

증상원인이 된 보상고치는 법
제자리에서 계속 돈다진행 보상 없이 "생존 +1"만 줌 → 안 부딪히는 게 최선전진 거리에 비례하는 진행 보상
좌·우 회전을 번갈아(진동)회전 비용 0, 상태에 직전 행동 없음회전 비용 −0.02, 상태에 a_{prev} 추가
벽에 바짝 붙어 달린다근접 벌점 없음 → 충돌 직전까지 최대 속도가 이득전방 0.35 m 안에서 선형 근접 벌점
후진으로 달린다$v$에 보상, 후진 행동 허용\Delta s를 전진 방향으로만, 후진 행동 제거(뒤는 라이다 사각)
충돌 벌점을 −5에서 −10으로 키워도 DQN 결과가 똑같다Huber δ = 1이 오차를 ±1로 잘라 벌점 크기 정보가 사라짐δ를 키우거나(실습 2는 3) 보상 전체를 같은 비율로 줄임
학습 곡선은 오르는데 평가는 나쁘다곡선은 ε 탐험이 섞인 값, 에피소드 20 s 잘림ε = 0 탐욕 정책을 별도 평가로 측정

마지막 두 줄은 실제로 이 장의 코드를 만들며 겪은 일입니다. 특히 Huber 손실 문제는 충돌 벌점만 바꾼 두 실험의 학습된 가중치가 비트 단위까지 같게 나와서 발견했습니다. 이상한 결과가 나오면 "운이 나빴다"로 넘기지 말고 원인을 추적하세요.

시뮬→실물 간극과 도메인 무작위화#

넘파이 환경은 완벽한 라이다와 완벽한 바퀴를 가정합니다. 실물은 다릅니다.

간극실물에서의 모습환경 모델
라이다 잡음거리 ±1~3 cm 흔들림가우스 잡음 σ ~ U(0, 5 cm)
빔 누락검은 천·유리·빛 반사에서 0 또는 inf확률 U(0, 5 %)로 빔을 inf로
거리 편향장착 오프셋, 물체 재질, 로봇에 실은 짐으로 실제 반지름 증가모든 빔에 +U(0, 0.2 m)
미끄럼메카넘 롤러 미끄럼으로 명령보다 덜 움직임속도 × U(0.7, 1.0)
지연스캔 수신 → 결정 → 모터까지 수십~수백 ms확률 U(0, 1)로 한 주기(0.2 s) 전 명령 실행

도메인 무작위화(domain randomization, Tobin et al. 2017)는 이 파라미터 \xi를 에피소드마다 분포 p(\xi)에서 뽑아, 정책이 분포 전체에서 잘하도록 학습합니다.

\max_\pi \; \mathbb{E}_{\xi \sim p(\xi)} \left[ \mathbb{E}_{\pi, \xi} [G_0] \right]

실물이 p(\xi)의 "한 표본"처럼 보이면 정책이 그대로 통한다는 생각입니다. 대가도 있습니다. 표 기반처럼 표현력이 작은 정책은 모든 도메인에서 동시에 최적일 수 없어 이상적 환경의 성능이 떨어질 수 있고, 학습이 더 오래 걸립니다. 범위를 너무 넓히면 겁쟁이 정책(계속 회전)이 됩니다. 실습 3에서 직접 확인합니다.

안전층: 원본 lidar_controller의 규칙 재사용#

원본 app/lidar_controller.py의 회피 모드는 전방 scan_angle(기본 90°, 즉 ±45°)을 왼쪽·오른쪽 절반으로 나누고, 0과 inf를 뺀 최소 거리를 threshold(기본 0.6 m)와 비교해 한쪽만 막히면 반대로, 양쪽이 막히면 크게 돕니다. 우리는 이 규칙을 정책 위에 덮어씌우는 안전 필터로 씁니다.

text
정책 행동 (v, ω) ← π(s)
left  ← min(ranges[0° < θ ≤ +45°]),  right ← min(ranges[−45° ≤ θ < 0°])   # 0·inf 제외
if min(left, right) < stop_dist:           # 안전 덮어쓰기
    v ← 0
    ω ← −ω_max if left < right else +ω_max  # 먼 쪽으로 제자리 회전
v ← clip(v, −0.2, 0.2),  ω ← clip(ω, −0.5, 0.5)
if 마지막 스캔이 0.5 s보다 오래됨: v, ω ← 0

임계값은 원본의 0.6 m보다 작은 0.25 m로 둡니다. 0.6 m면 정책이 판단할 여지 없이 안전층이 거의 모든 것을 결정해 버려서, 무엇을 평가하는지 알 수 없게 됩니다. 대신 개입률(안전층이 행동을 바꾼 비율)을 기록합니다. 개입률이 높다는 것은 정책이 실물에서 위험한 행동을 자주 골랐다는 뜻이므로, 그 자체가 sim-to-real 간극의 측정값이 됩니다.

실습 1. 표 기반 Q-러닝#

arena 월드와 같은 장애물을 넘파이로 옮긴 환경에서 32대를 동시에 학습합니다. 끝나면 ε = 0 탐욕 정책을 무작위 시작 32곳에서 60 s씩 평가하고, 정책을 81글자 문자열로 출력합니다.

python브라우저 실행Playground ↗
import math, numpy as np
import mentorpi_sim as sim                                   # 시뮬 전용 (sim.plot)

rng = np.random.default_rng(0)
BOX = [(0.8, 0.8, 0.3, 0.3), (-0.9, 0.6, 0.3, 0.5), (0.7, -1.0, 0.5, 0.3)]   # arena 월드와 같은 배치
CYL = np.array([(-0.6, -0.8, 0.12), (0.0, 1.3, 0.12), (1.3, -0.1, 0.1)])
S = [(-2, -2, 2, -2), (2, -2, 2, 2), (2, 2, -2, 2), (-2, 2, -2, -2)]
for x, y, w, h in BOX:
    a, b, c, d = x - w / 2, y - h / 2, x + w / 2, y + h / 2
    S += [(a, b, c, b), (c, b, c, d), (c, d, a, d), (a, d, a, b)]
SEG = np.array(S, float)
RAY = np.radians([-90, -60, -30, -15, 0, 15, 30, 60, 90])    # 9개 빔 (0 = 전방, 반시계 +)
ACT = np.array([(0.18, 0.0), (0.0, 0.5), (0.0, -0.5)])       # 0 전진 F, 1 좌회전 L, 2 우회전 R  (v, ω)
DT, RAD = 0.2, 0.13                                          # 5 Hz 결정, 로봇 반지름
def cast(x, y, th):                                          # (E,) 자세 → (E, 9) 거리: 벡터화 광선 투사
    a = th[:, None] + RAY
    dx, dy = np.cos(a)[..., None], np.sin(a)[..., None]
    ox, oy = SEG[:, 0] - x[:, None, None], SEG[:, 1] - y[:, None, None]
    ex, ey = SEG[:, 2] - SEG[:, 0], SEG[:, 3] - SEG[:, 1]
    den = dx * ey - dy * ex + 1e-12
    t, u = (ox * ey - oy * ex) / den, (ox * dy - oy * dx) / den
    best = np.where((t > 0) & (u >= 0) & (u <= 1), t, 9).min(-1)
    cx, cy = CYL[:, 0] - x[:, None, None], CYL[:, 1] - y[:, None, None]
    b = dx * cx + dy * cy; disc = b * b - (cx * cx + cy * cy - CYL[:, 2] ** 2)
    tc = b - np.sqrt(np.maximum(disc, 0))
    return np.minimum(best, np.where((disc > 0) & (tc > 0), tc, 9).min(-1))
def clearance(x, y):                                         # 가장 가까운 장애물 표면까지 거리 (E,)
    px, py, ex, ey = SEG[:, 0], SEG[:, 1], SEG[:, 2] - SEG[:, 0], SEG[:, 3] - SEG[:, 1]
    t = np.clip(((x[:, None] - px) * ex + (y[:, None] - py) * ey) / (ex * ex + ey * ey), 0, 1)
    d = np.hypot(px + t * ex - x[:, None], py + t * ey - y[:, None]).min(1)
    return np.minimum(d, (np.hypot(CYL[:, 0] - x[:, None], CYL[:, 1] - y[:, None]) - CYL[:, 2]).min(1))
def spawn(n):                                                # 장애물에서 0.3 m 이상 떨어진 무작위 자세
    p = rng.uniform([-1.8, -1.8, -math.pi], [1.8, 1.8, math.pi], (3 * n + 40, 3))
    return p[clearance(p[:, 0], p[:, 1]) > 0.3][:n]
def state(r, last):                                          # 섹터(좌·전·우) × 3단계 × 직전 행동 → 0..80
    L, F, R = r[:, 7:].min(1), r[:, 2:7].min(1), r[:, :2].min(1)
    b = lambda d: np.digitize(d, [0.35, 0.7])
    return ((b(L) * 3 + b(F)) * 3 + b(R)) * 3 + last
def step(P, a):                                              # 운동학 + 보상
    v, w = ACT[a, 0], ACT[a, 1]
    th = P[:, 2] + w * DT
    nx, ny = P[:, 0] + v * DT * np.cos(th), P[:, 1] + v * DT * np.sin(th)
    hit = clearance(nx, ny) < RAD
    P2 = np.where(hit[:, None], P, np.stack([nx, ny, th], 1))
    r = cast(P2[:, 0], P2[:, 1], P2[:, 2])
    rew = 10 * v * DT * ~hit - 0.02 * (a > 0) - 0.3 * np.clip(0.35 - r[:, 3:6].min(1), 0, None) / 0.35 - 5.0 * hit
    return P2, r, rew, hit

E, Q, alpha, gamma = 32, np.zeros((81, 3)), 0.2, 0.95
returns = []
for ep in range(40):
    eps = max(0.05, 1.0 - ep / 25)
    P = spawn(E); last = np.zeros(E, int); s = state(cast(P[:, 0], P[:, 1], P[:, 2]), last); G = np.zeros(E)
    for k in range(100):                                     # 100 스텝 = 20 s
        a = np.where(rng.random(E) < eps, rng.integers(0, 3, E), Q[s].argmax(1))
        P, r, rew, hit = step(P, a)
        s2 = state(r, a)
        target = rew + gamma * Q[s2].max(1) * ~hit              # 충돌 = 종료 전이 (부트스트랩 없음)
        Q[s, a] += alpha * (target - Q[s, a])
        G += rew
        if hit.any():                                          # 충돌한 로봇은 새 위치에서 다시 시작
            P[hit] = spawn(hit.sum()); a = np.where(hit, 0, a)
            s2 = np.where(hit, state(cast(P[:, 0], P[:, 1], P[:, 2]), 0), s2)
        s, last = s2, a

import math
import numpy as np
import rclpy
from rclpy.node import Node
from rclpy.qos import qos_profile_sensor_data
from geometry_msgs.msg import Twist
from sensor_msgs.msg import LaserScan
from nav_msgs.msg import Odometry
import mentorpi_sim as sim                                        # 시뮬 전용
sim.setup(world="arena", duration=30.0, start=(0.0, 0.0, 0.0))  # 시뮬 전용

POLICY = 'LLLLLLRFRFFFFFFRFRFLLRFFFFFLLLLFFFRRLLLFLFRFLFFLRFFFFFLLLRLLRRRFFFFFRFFRFFFFFFFRF'  # 실습 1
RAY = np.radians([-90, -60, -30, -15, 0, 15, 30, 60, 90])       # 학습 때와 같은 9개 빔
ACT = {'F': (0.18, 0.0), 'L': (0.0, 0.5), 'R': (0.0, -0.5)}
V_MAX, W_MAX = 0.2, 0.5                                          # 실물 안전 한계
STOP_D, HALF = 0.22, math.radians(45)                            # 안전 규칙: lidar_controller처럼 전방 ±45°를 좌·우로

class RLPolicy(Node):
    def __init__(self):
        super().__init__('rl_policy')
        self.declare_parameter('scan_topic', '/scan')             # 실물: /scan_raw
        self.cmd = self.create_publisher(Twist, '/controller/cmd_vel', 1)
        self.create_subscription(LaserScan, self.get_parameter('scan_topic').value, self.on_scan, qos_profile_sensor_data)
        self.create_subscription(Odometry, '/odom', self.on_odom, 10)
        self.scan, self.last, self.prev_xy, self.dist = None, 0, None, 0.0
        self.n_step, self.n_override, self.n_flip, self.min_r = 0, 0, 0, 9.0
        self.count = {'F': 0, 'L': 0, 'R': 0}
        self.create_timer(0.2, self.tick)                         # 학습과 같은 5 Hz
    def on_scan(self, msg):
        self.scan = msg
    def on_odom(self, m):
        p = m.pose.pose.position
        if self.prev_xy: self.dist += math.hypot(p.x - self.prev_xy[0], p.y - self.prev_xy[1])
        self.prev_xy = (p.x, p.y)
    def observe(self):
        s = self.scan
        r = np.array(s.ranges, dtype=float)
        r[~np.isfinite(r) | (r < s.range_min)] = 9.0              # inf·0 → 멀리 (학습 환경의 9 m)
        a = s.angle_min + np.arange(len(r)) * s.angle_increment
        diff = np.abs(np.arctan2(np.sin(a[None, :] - RAY[:, None]), np.cos(a[None, :] - RAY[:, None])))
        beams = np.where(diff < math.radians(3), r[None, :], 9.0).min(1)   # 빔마다 ±3° 최소
        return beams, r, np.arctan2(np.sin(a), np.cos(a))
    def tick(self):
        if self.scan is None: return
        beams, r, a = self.observe()
        b = lambda d: int(np.digitize(d, [0.35, 0.7]))
        s = ((b(beams[7:].min()) * 3 + b(beams[2:7].min())) * 3 + b(beams[:2].min())) * 3 + self.last
        act = POLICY[s]
        v, w = ACT[act]
        left = r[(a > 0) & (a <= HALF)].min(); right = r[(a < 0) & (a >= -HALF)].min()
        if min(left, right) < STOP_D:                             # 안전 덮어쓰기: 전진 금지, 먼 쪽으로 회전
            v, w = 0.0, (-W_MAX if left < right else W_MAX)
            act = 'R' if w < 0 else 'L'; self.n_override += 1
        t = Twist()
        t.linear.x = max(-V_MAX, min(V_MAX, v)); t.angular.z = max(-W_MAX, min(W_MAX, w))
        self.cmd.publish(t)
        self.n_flip += {self.last, 'FLR'.index(act)} == {1, 2}            # 좌↔우 뒤집기 = 진동
        self.last = 'FLR'.index(act); self.count[act] += 1; self.n_step += 1
        self.min_r = min(self.min_r, float(r.min()))
    def report(self):
        self.get_logger().info('결정 %d회 %s, 좌우 진동 %d회, 안전 덮어쓰기 %d회' % (
            self.n_step, self.count, self.n_flip, self.n_override))
        self.get_logger().info('주행 %.2f m, 최소 라이다 거리 %.2f m' % (self.dist, self.min_r))

#!/usr/bin/env python3
# rl_policy_node.py — 학습한 정책 + 안전 덮어쓰기 + 워치독
import json
import math
import os
import numpy as np
import rclpy
from rclpy.node import Node
from rclpy.qos import qos_profile_sensor_data
from geometry_msgs.msg import Twist
from sensor_msgs.msg import LaserScan
from std_msgs.msg import String
from std_srvs.srv import SetBool

class RLPolicyNode(Node):
    def __init__(self):
        super().__init__('rl_policy')
        self.declare_parameter('policy_file', '/home/ubuntu/rl/policy.json')
        self.declare_parameter('stop_dist', 0.25)       # 안전 덮어쓰기 임계 [m]
        self.declare_parameter('scan_angle', 90.0)      # lidar_controller와 같은 전방 감시각 [deg]
        self.declare_parameter('max_linear', 0.2)
        self.declare_parameter('max_angular', 0.5)
        p = lambda n: self.get_parameter(n).value
        self.stop_d, self.half = p('stop_dist'), math.radians(p('scan_angle') / 2)
        self.vmax, self.wmax = min(0.2, p('max_linear')), min(0.5, p('max_angular'))   # 상한은 코드로 고정
        with open(p('policy_file')) as f:
            self.spec = json.load(f)
        self.rays = np.radians(self.spec['rays_deg'])
        self.mlp = None
        if self.spec['type'] == 'dqn':
            w = np.load(os.path.join(os.path.dirname(p('policy_file')), self.spec['weights']))
            self.mlp = {k: w[k] for k in ('W1', 'b1', 'W2', 'b2')}
        self.cmd = self.create_publisher(Twist, '/controller/cmd_vel', 1)
        self.status = self.create_publisher(String, '~/status', 10)
        self.create_subscription(LaserScan, '/scan_raw', self.on_scan, qos_profile_sensor_data)
        self.create_service(SetBool, '~/enable', self.on_enable)
        self.enabled, self.scan, self.scan_t, self.last = False, None, -1e9, 0
        self.n, self.n_override = 0, 0
        self.create_timer(self.spec['dt'], self.tick)
        self.get_logger().info('policy %s loaded (%s)' % (p('policy_file'), self.spec['type']))
    def now(self):
        return self.get_clock().now().nanoseconds * 1e-9
    def on_scan(self, msg):
        self.scan, self.scan_t = msg, self.now()
    def on_enable(self, req, res):
        self.enabled = req.data
        if not self.enabled:
            self.cmd.publish(Twist())
        res.success, res.message = True, 'enabled' if self.enabled else 'disabled'
        return res
    def observe(self):                                   # 학습 환경과 같은 전처리
        s = self.scan
        r = np.array(s.ranges, dtype=float)
        bad = ~np.isfinite(r) | (r <= max(s.range_min, 0.01))
        r[bad] = 9.0                                     # 0·inf → 멀리 (lidar_controller도 제외)
        a = s.angle_min + np.arange(len(r)) * s.angle_increment
        a = np.arctan2(np.sin(a), np.cos(a))
        d = np.abs(np.arctan2(np.sin(a[None, :] - self.rays[:, None]), np.cos(a[None, :] - self.rays[:, None])))
        beams = np.where(d < math.radians(3), r[None, :], 9.0).min(1)
        return beams, r, a
    def decide(self, beams):
        if self.mlp:                                     # DQN: 넘파이 행렬곱 두 번
            x = np.hstack([np.minimum(beams, self.spec['clip']), np.eye(3)[self.last]])
            h = np.maximum(0, x @ self.mlp['W1'] + self.mlp['b1'])
            return int(np.argmax(h @ self.mlp['W2'] + self.mlp['b2']))
        b = lambda k: int(np.digitize(beams[slice(*self.spec['sectors'][k])].min(), self.spec['bins']))
        s = ((b('L') * 3 + b('F')) * 3 + b('R')) * 3 + self.last
        return 'FLR'.index(self.spec['policy'][s])
    def tick(self):
        t = Twist()
        if not self.enabled:
            return
        if self.scan is None or self.now() - self.scan_t > 0.5:   # 워치독
            self.cmd.publish(t)
            self.get_logger().warn('no /scan_raw for 0.5 s -> stop', throttle_duration_sec=2.0)
            return
        beams, r, a = self.observe()
        act = self.decide(beams)
        v, w = self.spec['actions']['FLR'[act]]
        left = r[(a > 0) & (a <= self.half)].min()
        right = r[(a < 0) & (a >= -self.half)].min()
        override = min(left, right) < self.stop_d
        if override:                                     # 안전 덮어쓰기 (lidar_controller 규칙)
            v, w = 0.0, (-self.wmax if left < right else self.wmax)
            self.n_override += 1
        t.linear.x = max(-self.vmax, min(self.vmax, v))
        t.angular.z = max(-self.wmax, min(self.wmax, w))
        self.cmd.publish(t)
        self.last = 0 if t.linear.x > 0 else (1 if t.angular.z > 0 else 2)
        self.n += 1
        self.status.publish(String(data='policy=%s final=%s override=%d rate=%.1f%%' % (
            'FLR'[act], 'FLR'[self.last], override, 100.0 * self.n_override / self.n)))

def main():
    rclpy.init()
    node = RLPolicyNode()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.cmd.publish(Twist())
        node.destroy_node()
        rclpy.shutdown()

if __name__ == '__main__':

  • 상태의 "직전 행동"에는 정책이 고른 행동이 아니라 실제로 실행된 행동(덮어쓰기 뒤)을 넣습니다. 학습 환경에서도 상태의 a_{prev}는 실행된 행동이었기 때문입니다.

  • 라이다가 거꾸로 장착됐거나 각도 기준이 다르면 M05처럼 각도 오프셋을 더하세요. 인덱스로 방향을 가정하지 않고 angle_min + i·Δθ로 계산하는 이유입니다.

확장 과제#

  • Double DQN: 목표를 y = r + \gamma Q_{\theta^-}(s', \arg\max_{a'} Q_\theta(s', a'))로 바꿔 과대추정을 줄이고, 시드 5개 평균으로 효과를 보입니다.
  • 연속 행동: 행동을 5개(강한·약한 좌우 회전 포함)로 늘리거나, DDPG/SAC 같은 연속 행동 알고리즘을 조사해 선속도·각속도를 직접 내게 합니다.
  • 목표 도달 과제: 상태에 목표 방향·거리를 넣고 보상에 목표 접근을 추가해 "장애물을 피하며 목표로 가는" 정책을 만듭니다. Nav2 DWB와 비교합니다.
  • 안전 강화학습: 덮어쓰기가 개입한 전이에 벌점을 주거나(shielding), 제약 MDP(CMDP)로 충돌 확률 상한을 둡니다.
  • 시스템 식별 + DR: 실물 /odom과 명령을 녹화(rosbag)해 미끄럼·지연을 추정하고, 그 값 주변으로 DR 범위를 좁힙니다.
  • 애커만 섀시: 제자리 회전이 불가능한 애커만(최대 조향 29°)에 맞게 행동을 (v, δ)로 바꿔 다시 학습합니다.
