학습 목표#

  • sensor_msgs/LaserScan의 필드를 해석하고, 인덱스 ↔ 각도 ↔ 직교좌표 변환을 코드로 작성합니다.
  • 라이다 좌표의 점을 로봇·세계 좌표로 옮겨 장애물 위치를 추정합니다.

라이다의 구성과 분류#

라이다(LiDAR, Light Detection And Ranging)는 레이저를 쏘고 돌아오는 빛으로 거리를 잽니다. 원본 교재는 네 부분으로 나눕니다.

  1. 레이저 발광부: 짧은 적외선 펄스(LD19는 파장 약 905 nm)를 쏩니다.
  2. 스캔부: 발광·수광부를 모터로 회전시켜 한 평면을 훑습니다(2D 라이다).
  3. 수광부: 물체에서 반사된 빛을 받아 전기 신호로 바꿉니다.
  4. 신호 처리부: 시간 또는 각도 정보로 거리를 계산해 (각도, 거리) 쌍을 내보냅니다.

측정 원리로는 삼각측량(triangulation), 펄스(ToF), 코히어런트(FMCW) 방식이 있고, 원본 교재는 MentorPi의 라이다를 펄스 방식으로 분류합니다.

거리 측정 원리#

ToF — 빛이 다녀온 시간#

빛이 물체까지 갔다가 돌아오는 시간 t를 재면, 빛의 속도 c ≈ 3×10⁸ m/s로

text
d = c · t / 2          (왕복이므로 2로 나눔)

1 m 거리는 왕복 6.67 ns, 1 cm 분해능은 67 ps의 시간 분해능이 필요합니다. 그래서 ToF 라이다는 고속 타이밍 회로(TDC)와 여러 번 측정 평균을 씁니다. 오차가 거리에 거의 무관(대략 일정한 ±수 cm)하고 먼 거리까지 잴 수 있다는 것이 장점입니다.

삼각측량 — 빛이 맺히는 위치#

발광부와 수광 렌즈를 기준선 b만큼 떨어뜨려 두면, 물체가 가까울수록 반사광이 이미지 센서의 한쪽 끝에, 멀수록 다른 쪽에 맺힙니다. 닮은 삼각형으로

text
d = f · b / x          (f: 렌즈 초점거리, x: 센서 위 광점 위치)
∂d/∂x = −f·b / x² = −d² / (f·b)   → 오차가 거리의 제곱으로 커짐

값싸고 가까운 거리에서 정밀하지만 먼 거리에서는 급격히 부정확해집니다. 저가 청소 로봇 라이다가 이 방식을 많이 씁니다.

항목ToF(펄스)삼각측량
거리 계산시간 × 빛의 속도 / 2기준선·초점거리·광점 위치의 닮음비
오차 vs 거리거의 일정거리²에 비례해 증가
최대 거리길다 (LD19: 12 m)짧다 (보통 6~8 m)
햇빛 영향상대적으로 강함약함(센서 포화)

MentorPi의 LD19 라이다#

원본 교재(Lesson 1)의 사양 중 알고리즘에 영향을 주는 값만 추렸습니다.

항목값의미
측정 범위0.02 ~ 12 m (반사율 70 %)검은 물체·유리·거울은 더 짧거나 측정 안 됨
스캔 주파수5 ~ 13 Hz (기본 10 Hz, PWM 속도 제어)/scan_raw 발행 주기
측정 주파수4500 회/초한 바퀴 점 수 = 4500 / 10 = 450점 → 약 0.8° 간격
정확도±45 mm (0.3 ~ 12 m), 표준편차 10 mm0.3 m 미만은 경향만 맞음
각도 오차최대 2°먼 물체일수록 위치 오차 큼 (5 m에서 17 cm)
외란광30 klux까지직사광선 창가에서는 잡음 증가
통신UART 230400 bps, 8N1드라이버가 /dev/ldlidar 포트로 읽음
레이저 등급IEC-60825 Class 1눈에 안전, 그래도 들여다보지 않기

두 가지 한계를 기억하세요.

  • 스캔 평면이 하나입니다. 라이다 높이보다 낮은 물체(바닥의 케이블, 낮은 턱)나 높은 물체의 아래 틈(테이블 상판)은 보이지 않습니다. 교재가 "책을 라이다 높이보다 높게 세워 두라"고 하는 이유입니다.
  • 이동 중 왜곡(motion distortion): 한 바퀴에 0.1 s가 걸리므로 0.2 m/s로 가면 스캔 처음과 끝 사이에 2 cm, 0.5 rad/s로 돌면 2.9°가 어긋납니다. SLAM이 느린 회전을 선호하는 이유입니다.

sensor_msgs/LaserScan 해석#

필드단위의미
header.frame_id—측정 좌표계(실물 lidar_frame 등, 시뮬 lidar_frame)
header.stamp—스캔 첫 빔의 시각
angle_min, angle_maxrad첫 빔과 마지막 빔의 각도
angle_incrementrad빔 사이 각도 Δθ
time_increment, scan_times빔 사이 시간, 한 바퀴 시간 (왜곡 보정에 사용)
range_min, range_maxm유효 거리 범위. 밖의 값은 버림
ranges[]m거리 배열. 측정 없음은 inf(또는 드라이버에 따라 0, nan)
intensities[]—반사 세기 (드라이버마다 척도가 다름)

인덱스 ↔ 각도 ↔ 직교좌표#

text
θ_i = angle_min + i · angle_increment              (라디안, 0 = 라이다 전방, + = 왼쪽)
i(θ) = round((θ − angle_min) / angle_increment) mod N
x_i = r_i · cos θ_i ,   y_i = r_i · sin θ_i         (라이다 좌표계)

라이다 좌표의 점을 세계 좌표로 옮기려면 두 번 변환합니다(R06의 TF).

text
p_base  = T(base ← lidar) · p_lidar      정적 변환 (URDF, 라이다 장착 위치)
p_world = R(ψ) · p_base + (x_r, y_r)      로봇 자세 (/odom 또는 지도 위치)

MentorPi URDF에서 라이다는 차체 중심보다 약 1.2 cm 뒤, 16 cm 위에 있습니다(M08). 2D 계산에서는 수평 오프셋 1.2 cm가 무시할 만해 흔히 생략합니다.

유효하지 않은 값 거르기#

원본 앱 코드는 ranges에서 0이 아닌 값(nonzero())과 유한한 값(np.isfinite)만 남긴 뒤 최솟값을 구합니다. 드라이버에 따라 "측정 없음"을 0으로 보내는 경우가 있어 0을 그대로 두면 "0 m에 장애물"로 오판합니다. 같은 이유로 range_min 미만 값도 버리는 것이 안전합니다.

인덱스 규약 차이 — 각도로 계산하라#

데이터angle_min전방 인덱스원본 앱의 가정
이 사이트 시뮬레이터 /scan−π가운데 (N/2 = 180)—
원본 lidar_controller.py (LD19 등)—0ranges[:k] = 왼쪽, ranges[::-1][:k] = 오른쪽
원본 코드의 G4 라이다 분기—뒤집힌 순서별도 인덱스 계산

원본 앱은 라이다 종류마다 인덱스 계산을 따로 둡니다(환경 변수 LIDAR_TYPE). 여러분의 코드는 **인덱스가 아니라 angle_min + i·Δθ로 각도를 계산한 뒤 각도 범위로 고르면** 어떤 드라이버·장착 방향에서도 그대로 동작합니다. 아래 실습은 모두 이 방식입니다.

실습 (시뮬레이션)#

1. 스캔 한 장 받아 필드 읽기#

빈 방(6×6 m) 한가운데에서 앞쪽 1 m에 상자를 두고 스캔 한 장을 받습니다. 잡음을 꺼서 숫자를 검증하기 쉽게 합니다.

python브라우저 실행
import math
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import LaserScan
import mentorpi_sim as sim                                        # 시뮬 전용
sim.setup(chassis="mecanum", world="empty", duration=2.0,
          start=(0.0, 0.0, 0.0), noise=False)                     # 시뮬 전용
sim.add_box(1.0, 0.0, 0.2, 0.6)                                   # 시뮬 전용: 앞면이 x = 0.9

class ScanOnce(Node):
    def __init__(self):
        super().__init__("scan_once")
        self.create_subscription(LaserScan, "/scan", self.on_scan, 10)
        self.done = False

    def on_scan(self, msg):
        if self.done:
            return
        self.done = True
        n = len(msg.ranges)
        print("frame=%s  빔 %d개" % (msg.header.frame_id, n))
        print("angle_min=%.4f  angle_max=%.4f  increment=%.4f rad (%.2f°)" % (
            msg.angle_min, msg.angle_max, msg.angle_increment, math.degrees(msg.angle_increment)))
        print("range %.2f ~ %.1f m,  scan_time %.2f s" % (msg.range_min, msg.range_max, msg.scan_time))
        for name, deg in [("전방", 0), ("왼쪽", 90), ("후방", 180), ("오른쪽", -90), ("전방 20°", 20)]:
            i = int(round((math.radians(deg) - msg.angle_min) / msg.angle_increment)) % n
            print("  %-6s θ=%+4d°  i=%3d  r=%.3f m" % (name, deg, i, msg.ranges[i]))
        print("inf 개수:", sum(1 for r in msg.ranges if math.isinf(r)))

rclpy.init()
node = ScanOnce()
try:
    while rclpy.ok() and not node.done:
        rclpy.spin_once(node, timeout_sec=0.1)
except KeyboardInterrupt:
    pass
finally:
    node.destroy_node()
    rclpy.shutdown()

(대략)

text
frame=lidar_frame  빔 360개
angle_min=-3.1416  angle_max=3.1241  increment=0.0175 rad (1.00°)
range 0.05 ~ 12.0 m,  scan_time 0.10 s
  전방     θ=  +0°  i=180  r=0.900 m
  왼쪽     θ= +90°  i=270  r=3.000 m
  후방     θ=+180°  i=  0  r=3.000 m
  오른쪽    θ= -90°  i= 90  r=3.000 m
  전방 20° θ= +20°  i=200  r=3.193 m
inf 개수: 0
  • 전방 인덱스가 180, 왼쪽이 270, 오른쪽이 90입니다. angle_min = −π이므로 인덱스 0은 후방입니다.
  • 상자 앞면은 x = 0.9 m, 폭은 y = ±0.3 m입니다. 20° 방향 빔은 x = 0.9에서 y = 0.9·tan 20° = 0.33 m를 지나 상자 옆을 빗나가고, 3 m 떨어진 벽에 3 / cos 20° = 3.193 m에서 닿습니다.
  • 빈 방은 벽으로 둘러싸여 12 m 안에 항상 무언가가 있으므로 inf가 없습니다. 실물에서 넓은 공간을 향하면 inf가 많이 나옵니다.

2. 가장 가까운 장애물 찾기와 세계 좌표 변환#

로봇을 30° 돌려 놓고, 세계 좌표 (1.0, 0.5)에 반지름 0.1 m 원기둥을 둡니다. 스캔에서 가장 가까운 점을 찾고, 로봇 자세로 세계 좌표를 계산해 원기둥 중심을 추정합니다.

python브라우저 실행
import math
import numpy as np
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import LaserScan
from geometry_msgs.msg import Pose2D
import mentorpi_sim as sim                                        # 시뮬 전용
sim.setup(chassis="mecanum", world="empty", duration=2.0,
          start=(0.0, 0.0, math.radians(30)), noise=False)        # 시뮬 전용
sim.add_cylinder(1.0, 0.5, 0.1)                                   # 시뮬 전용

class Nearest(Node):
    def __init__(self):
        super().__init__("nearest_obstacle")
        self.create_subscription(LaserScan, "/scan", self.on_scan, 10)
        self.create_subscription(Pose2D, "/ground_truth", self.on_pose, 10)
        self.pose, self.done = None, False

    def on_pose(self, msg):
        self.pose = msg

    def on_scan(self, msg):
        if self.done or self.pose is None:
            return
        r = np.array(msg.ranges)
        th = msg.angle_min + np.arange(len(r)) * msg.angle_increment
        ok = np.isfinite(r) & (r > msg.range_min)
        i = np.argmin(np.where(ok, r, np.inf))
        d, a = r[i], th[i]
        print("최근접: 거리 %.3f m, 로봇 기준 각도 %+.1f°" % (d, math.degrees(a)))
        near = ok & (np.abs(r - d) < 0.15) & (np.abs(th - a) < math.radians(15))
        print("같은 물체로 보이는 빔: %d개" % near.sum())
        px, py = d * math.cos(a), d * math.sin(a)                 # 로봇 좌표
        x, y, psi = self.pose.x, self.pose.y, self.pose.theta
        wx = x + px * math.cos(psi) - py * math.sin(psi)          # 세계 좌표
        wy = y + px * math.sin(psi) + py * math.cos(psi)
        cx = wx + 0.1 * math.cos(psi + a)                          # 표면 → 중심
        cy = wy + 0.1 * math.sin(psi + a)
        print("표면점 세계좌표 (%.3f, %.3f), 추정 중심 (%.3f, %.3f)" % (wx, wy, cx, cy))
        xs = list(x + r[ok] * np.cos(psi + th[ok]))
        ys = list(y + r[ok] * np.sin(psi + th[ok]))
        sim.plot(xs, ys, "스캔 점 (세계 좌표)")                        # 시뮬 전용
        self.done = True

rclpy.init()
node = Nearest()
try:
    while rclpy.ok() and not node.done:
        rclpy.spin_once(node, timeout_sec=0.1)
except KeyboardInterrupt:
    pass
finally:
    node.destroy_node()
    rclpy.shutdown()

표면점 세계좌표 (0.907, 0.462), 추정 중심 (0.996, 0.508)

이론값과 비교해 보세요. 원기둥 중심까지 거리 √(1² + 0.5²) = 1.118 m, 표면까지 1.018 m, 세계 방향 26.6°에서 로봇 yaw 30°를 빼면 로봇 기준 −3.4° (오른쪽 조금)입니다. 빔 간격이 1°라 최근접 빔은 −3° 또는 −4°에 있고, 그만큼 표면점이 1 cm 안팎 어긋납니다. 원기둥은 중심에서 ±asin(0.1/1.118) = ±5.1° 폭으로 보이므로 약 10개 빔이 닿습니다.

3. 섹터별 최소거리 — 원본 앱 방식#

원본 lidar_controller.py는 뒤쪽 120°를 버리고(MAX_SCAN_ANGLE = 240), 전방 기준 좌·우로 scan_angle/2(기본 45°)씩의 섹터에서 최소거리를 구합니다. 같은 계산을 각도 기반으로 작성해 경기장(arena) 월드에서 돌려 봅니다. 로봇은 (0.35, 0.45)에서 +x를 보고 있고, 왼쪽 앞 (0.8, 0.8)에 한 변 0.3 m 상자가 있습니다.

python브라우저 실행
import math
import numpy as np
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import LaserScan
import mentorpi_sim as sim                                        # 시뮬 전용
sim.setup(chassis="mecanum", world="arena", duration=2.0,
          start=(0.35, 0.45, 0.0), noise=False)                   # 시뮬 전용

THRESHOLD = 0.6                      # 원본 기본값 [m]
SCAN_ANGLE = math.radians(90)        # enter 후 기본값 → 좌우 각 45°

def sector_min(r, th, lo, hi):
    m = (th >= lo) & (th <= hi) & np.isfinite(r) & (r > 0)
    return float(r[m].min()) if m.any() else float("inf")

class Sectors(Node):
    def __init__(self):
        super().__init__("sectors")
        self.create_subscription(LaserScan, "/scan", self.on_scan, 10)
        self.done = False

    def on_scan(self, msg):
        if self.done:
            return
        self.done = True
        r = np.array(msg.ranges)
        th = msg.angle_min + np.arange(len(r)) * msg.angle_increment
        for name, lo, hi in [("전방 ±15°", -15, 15), ("왼쪽 15~90°", 15, 90),
                             ("오른쪽 −90~−15°", -90, -15), ("후방 |θ|>120°", 120, 180)]:
            d = sector_min(r, np.abs(th) if lo == 120 else th, math.radians(lo), math.radians(hi))
            print("%-16s 최소 %.3f m" % (name, d))
        left = sector_min(r, th, 0.0, SCAN_ANGLE / 2)
        right = sector_min(r, th, -SCAN_ANGLE / 2, 0.0)
        print("원본 방식 left_range 최소 %.3f, right_range 최소 %.3f" % (left, right))
        if left <= THRESHOLD and right <= THRESHOLD:
            act = "양쪽 막힘 → 크게 회전"
        elif left <= THRESHOLD:
            act = "왼쪽 막힘 → 오른쪽으로 회전"
        elif right <= THRESHOLD:
            act = "오른쪽 막힘 → 왼쪽으로 회전"
        else:
            act = "통과 → 직진"
        print("판단(threshold %.1f m): %s" % (THRESHOLD, act))

rclpy.init()
node = Sectors()
try:
    while rclpy.ok() and not node.done:
        rclpy.spin_once(node, timeout_sec=0.1)
except KeyboardInterrupt:
    pass
finally:
    node.destroy_node()
    rclpy.shutdown()
