A08YOLOv5 데이터셋·학습·배포

사진 수집, labelImg 라벨링, 데이터셋 구성과 학습, 모델 변환 후 yolov5_ros2 노드로 로봇에서 추론.

선수 챕터: A07

학습 목표#

  • 사진 수집(collect_picture) → 라벨링(labelImg) → 변환(xml2yolo.py) → 학습(train.py) → 배포(yolov5_ros2) 전체 흐름을 직접 수행합니다.
  • PASCAL VOC XML 라벨과 YOLO txt 라벨의 차이를 알고, 정규화 좌표 변환을 손으로 계산합니다.
  • --img, --batch, --epochs, --weights와 hyp.scratch-low.yaml의 주요 하이퍼파라미터(학습률·워밍업·증강)가 무엇을 바꾸는지 설명합니다.
  • results.csv의 손실·mAP 곡선을 읽고 과적합·과소적합을 판단합니다.
  • 학습한 best.pt를 로봇의 YOLOv5 노드에 넣고 /yolov5_ros2/object_detect 토픽으로 결과를 확인합니다.

로봇에서 학습해도 되나요?

원본 교재도 밝히듯 Raspberry Pi의 CPU·메모리·저장장치 속도로는 학습이 매우 느립니다. 수십 장짜리 연습은 로봇에서 해 봐도 되지만, 클래스당 200장 이상인 실제 데이터셋은 GPU가 있는 PC나 클라우드에서 학습하고 best.pt만 로봇으로 복사하는 것이 정석입니다. 이때 data.yaml과 train.txt·val.txt 안의 경로를 PC 경로로 바꿔야 합니다.

① 사진 수집#

collect_picture/main.py는 카메라 토픽(/ascamera/camera_publisher/rgb0/image)을 받아 보여 주는 Qt 프로그램입니다. Save(space)를 누르거나 스페이스바를 치면 현재 프레임을 config.ini의 크기(640×480)로 맞춰 저장경로/JPEGImages/에 저장합니다. 화면 왼쪽 위의 save number는 이번 사진 번호, existing은 폴더에 있는 사진 수입니다.

좋은 데이터셋의 조건:

  • 다양성: 거리(30 cm ~ 1.5 m), 각도(정면·비스듬히), 기울기, 조명(밝음·어두움·역광), 배경을 골고루 섞습니다. 모델은 본 적 있는 조건만 잘 맞힙니다.
  • 실제 사용 조건과 같게: 자율주행 표지판이라면 로봇 카메라 높이에서, 맵 위에 놓인 상태로 찍습니다. 손에 들고 찍은 사진만으로 학습하면 맵 위에서 성능이 떨어집니다.
  • 양: 원본 교재 권장은 클래스당 200장 이상입니다. 클래스 사이 장수가 크게 차이 나면(예: go 500장, park 50장) 모델이 많은 쪽으로 치우칩니다.
  • 음성 예: 표지판이 없는 맵 사진도 일부 넣으면 "아무것도 없음"을 배워 오검출이 줄어듭니다. 단, xml2yolo.py는 XML 파일이 있는 사진만 학습 목록에 넣으므로 음성 예에도 물체 없는 라벨 파일이 있어야 합니다.

② labelImg 라벨링#

단축키기능
Ctrl+U사진 폴더(JPEGImages) 열기
Ctrl+R라벨 저장 폴더(Annotations) 지정
W상자 그리기 시작
Ctrl+S현재 사진 라벨 저장
A / D이전 / 다음 사진

상자를 그린 뒤 뜨는 창에 클래스 이름(예: right, turn_around)을 입력합니다. 이름은 대소문자·밑줄까지 classes.names와 글자 하나 다르지 않게 맞춰야 합니다. 상자는 물체 테두리에 딱 붙게 그립니다. 여백을 크게 잡으면 모델도 여백까지 물체로 배워 mAP_0.5:0.95가 낮아집니다.

labelImg는 PASCAL VOC 형식 XML을 저장합니다. 사진 한 장당 파일 하나이고, 물체마다 <object>가 하나씩 들어갑니다.

text
<annotation>
  <filename>12.jpg</filename>
  <size><width>640</width><height>480</height><depth>3</depth></size>
  <object>
    <name>right</name><pose>Unspecified</pose><truncated>0</truncated><difficult>0</difficult>
    <bndbox><xmin>250</xmin><ymin>120</ymin><xmax>330</xmax><ymax>210</ymax></bndbox>
  </object>
</annotation>

③④ YOLO 형식으로 변환#

YOLOv5는 사진과 **같은 이름의 .txt** 파일을 라벨로 읽습니다. 한 줄이 물체 하나이고, 모든 좌표는 영상 크기로 나눈 0~1 값입니다.

text
<클래스번호> <x_center> <y_center> <width> <height>
x_center = (xmin + xmax) / (2·W)      width  = (xmax − xmin) / W
y_center = (ymin + ymax) / (2·H)      height = (ymax − ymin) / H

정규화하는 이유는 학습 때 사진 크기를 바꾸거나(--img 640) 뒤집고 잘라도(증강) 라벨을 쉽게 따라 바꾸기 위해서입니다. 클래스 번호는 classes.names의 줄 순서(0부터)입니다.

xml2yolo.py가 하는 일을 그대로 옮긴 코드로 확인합니다.

Playground 열기

python브라우저 실행Playground ↗
import xml.etree.ElementTree as ET

xml_text = """<annotation>
  <folder>JPEGImages</folder><filename>12.jpg</filename>
  <size><width>640</width><height>480</height><depth>3</depth></size>
  <object><name>right</name><pose>Unspecified</pose><truncated>0</truncated>
    <difficult>0</difficult>
    <bndbox><xmin>250</xmin><ymin>120</ymin><xmax>330</xmax><ymax>210</ymax></bndbox>
  </object>
  <object><name>park</name><pose>Unspecified</pose><truncated>0</truncated>
    <difficult>0</difficult>
    <bndbox><xmin>420</xmin><ymin>100</ymin><xmax>500</xmax><ymax>196</ymax></bndbox>
  </object>
</annotation>"""
class_names = ["go", "right", "park", "red", "green", "crosswalk"]   # classes.names 순서

root = ET.fromstring(xml_text)
W = int(root.find("size")[0].text)
H = int(root.find("size")[1].text)
for member in root.findall("object"):            # xml2yolo.single_xml_to_txt 와 같은 계산
    cls = class_names.index(member[0].text)
    xmin, ymin, xmax, ymax = (int(member[4][k].text) for k in range(4))
    xc = (xmin + xmax) / (2 * W)
    yc = (ymin + ymax) / (2 * H)
    bw = (xmax - xmin) / W
    bh = (ymax - ymin) / H
    print(cls, xc, yc, bw, bh)

def split_counts(n):                              # xml2yolo.split(): 5 % / 15 % / 80 %
    o1, o2 = int(n * 0.05), int(n * 0.2)
    return {"test": o1, "val": o2 - o1, "train": n - o2}
for n in (37, 200, 1200):
    print(n, "장 →", split_counts(n))
text
1 0.453125 0.34375 0.125 0.1875
2 0.71875 0.30833333333333335 0.125 0.2
37 장 → {'test': 1, 'val': 6, 'train': 30}
200 장 → {'test': 10, 'val': 30, 'train': 160}
1200 장 → {'test': 60, 'val': 180, 'train': 960}

xml2yolo.py에서 알아 둘 동작:

  • member[4]처럼 자식 순서로 bndbox를 찾습니다. labelImg가 만든 XML은 순서가 name, pose, truncated, difficult, bndbox로 고정이라 동작하지만, 다른 도구로 만든 XML은 순서가 달라 실패할 수 있습니다. 오류는 except: pass로 조용히 무시되므로 변환 후 클래스별 개수 출력(right:120 등)을 꼭 확인합니다.
  • 사진을 무작위로 섞은 뒤 test 5 %, val 15 %, train 80 %로 나눕니다. random.seed를 고정하지 않아 실행할 때마다 분할이 달라집니다.
  • .txt 라벨은 Annotations가 아니라 **JPEGImages 폴더의 사진 옆**에 씁니다. YOLOv5는 사진 경로의 /images/를 /labels/로 바꿔 라벨을 찾는데, 경로에 images 폴더가 없으면 사진과 같은 폴더에서 찾기 때문입니다.
  • train.txt에는 --data로 준 경로를 이어 붙인 사진 경로가 들어갑니다. 상대 경로로 실행하면 상대 경로가 기록되어, 다른 폴더에서 학습을 돌릴 때 사진을 못 찾습니다. 원본 교재가 data.yaml·train.txt·val.txt를 절대 경로로 고치게 하는 이유입니다. 처음부터 절대 경로로 실행하면 수정이 필요 없습니다.
bash
python3 ~/software/collect_picture/xml2yolo.py \
  --data /home/ubuntu/software/collect_picture/my_data \
  --yaml /home/ubuntu/software/collect_picture/my_data/data.yaml

생성된 data.yaml은 다음과 같습니다(키 순서는 yaml.dump가 알파벳순으로 씀).

text

⑤ 학습#

bash
unzip software/yolov5.zip -d software/        # 처음 한 번
python3 software/yolov5/train.py --img 640 --batch 8 --epochs 300 \
  --data software/collect_picture/my_data/data.yaml --weights software/yolov5/yolov5n.pt
인자의미고르는 법
--img 640학습·검증 입력 크기(정사각형, 32의 배수)작은 표지판을 멀리서 잡아야 하면 크게. 추론 속도는 크기²에 비례
--batch 8한 번에 넣는 사진 수메모리가 허락하는 만큼. 작으면 BN 통계가 흔들림
--epochs 300전체 데이터를 몇 바퀴 학습데이터가 적을수록 많이. --patience 100이면 100 epoch 동안 개선 없을 때 조기 종료
--weights yolov5n.pt시작 가중치COCO로 미리 학습한 가중치에서 출발(전이 학습). n(nano)은 가볍고 s(small)는 정확
--datadata.yaml 경로클래스 수 nc와 경로 확인

전이 학습(transfer learning)이 핵심입니다. yolov5n.pt는 COCO 80개 클래스로 이미 "모서리·원·글자 모양" 같은 일반 특징을 배운 상태입니다. 백본의 이 지식을 그대로 두고 헤드를 새 클래스에 맞추므로 수백 장만으로도 학습이 됩니다. 처음부터(--weights '') 학습하면 수만 장이 필요합니다.

하이퍼파라미터와 학습률 일정#

--hyp를 주지 않으면 data/hyps/hyp.scratch-low.yaml을 씁니다.

항목값의미
lr0 / lrf0.01 / 0.01시작 학습률, 마지막 학습률 = lr0 × lrf
momentum, weight_decay0.937, 0.0005SGD 관성, 가중치 크기 벌점(과적합 억제)

좌우 뒤집기와 방향 표지판

fliplr: 0.5는 사진의 절반을 좌우 반전합니다. 우회전 표지판을 뒤집으면 좌회전 표지판이 됩니다. left와 right를 모두 학습하는 데이터셋이라면 두 클래스가 서로 섞여 버리므로, hyp.yaml을 복사해 fliplr: 0.0으로 바꾸고 --hyp로 지정해야 합니다. 원본 표지판 세트는 right만 있어 큰 문제가 드러나지 않을 뿐입니다.

학습률은 워밍업 뒤 선형으로 감소합니다(train.py의 lf = (1 − e/epochs)·(1 − lrf) + lrf). 또 YOLOv5는 명목 배치 64(nbs)를 기준으로 기울기 누적(gradient accumulation)을 합니다. 배치 8이면 8번 모아서 한 번 가중치를 갱신하므로 작은 배치에서도 학습이 안정됩니다.

python브라우저 실행Playground ↗
import math

epochs, lr0, lrf = 300, 0.01, 0.01            # hyp.scratch-low.yaml
warmup_epochs, warmup_bias_lr = 3.0, 0.1
n_train, batch, nbs = 160, 8, 64             # 학습 이미지 160장, --batch 8

nb = math.ceil(n_train / batch)              # epoch당 반복(iteration) 수
nw = max(round(warmup_epochs * nb), 100)     # 워밍업 반복 수 (최소 100)
accumulate = max(round(nbs / batch), 1)      # 몇 배치마다 가중치를 갱신?
print("epoch당 반복 %d, 워밍업 %d회(= %.1f epoch), %d배치마다 1회 갱신"
      % (nb, nw, nw / nb, accumulate))

lf = lambda e: (1 - e / epochs) * (1.0 - lrf) + lrf    # 선형 감소
for e in (0, 5, 50, 150, 250, 299):
    print("epoch %3d  lr = %.6f" % (e, lr0 * lf(e)))

python실물 전용
import rclpy
from rclpy.node import Node
from interfaces.msg import ObjectsInfo

class BestObject(Node):
    def __init__(self):
        super().__init__('best_object')
        self.create_subscription(ObjectsInfo, '/yolov5_ros2/object_detect', self.cb, 10)

    def cb(self, msg):
        for o in msg.objects:
            if o.score < 0.5:
                continue
            x1, y1, x2, y2 = o.box
            area = (x2 - x1) * (y2 - y1)
            self.get_logger().info('%s %.2f 중심=(%d,%d) 면적=%d px²' % (
                o.class_name, o.score, (x1 + x2) // 2, (y1 + y2) // 2, area))

def main():
    rclpy.init()
    node = BestObject()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()

if __name__ == '__main__':
    main()
