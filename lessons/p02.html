P02QR 지시형 실내 배송 로봇

출발 스테이션에서 QR 코드로 목적지를 받고, Nav2로 배송·복귀하며 도착 확인과 실패 복구(재계획·재시도)를 갖춘 배송 로봇.

선수 챕터: A02 M11 M13 R04
3D 시뮬레이터2D 시뮬레이터ROS 2 Playground

학습 목표#

  • 배송 로봇의 요구사항을 기능·비기능·안전 한계로 나누어 정의하고, 이를 서비스·액션·토픽 인터페이스와 배송 상태 기계로 설계합니다.
  • 스테이션 카메라로 QR 지시서를 읽어 DELIVER:<목적지> 형식을 검증하고, 목적지 조회표(이름 → map 자세)로 Nav2 목표를 만듭니다.
  • 도착을 두 번 확인합니다: 로봇 쪽(Nav2 결과 + TF 위치 오차)과 사람 쪽(버튼·서비스 수령 확인, 대기 시간 초과).
  • 주행 실패·막힘·시간 초과를 감지해 코스트맵 지우기 → 재시도 → 대체 경로(재계획) → 포기·복귀 순서로 복구합니다.
  • Playground에서 상태 기계와 복구 전략을 먼저 검증하고, MentorPi 실물에서 navigation.launch.py + 카메라로 같은 구조를 실행합니다.

프로젝트 개요와 요구사항#

연구실 입구의 스테이션(도크)에 서 있는 로봇에게 사람이 QR 지시서를 보여 주고 "배송 요청"을 누르면, 로봇이 지시서에 적힌 방까지 물건을 싣고 가서 받는 사람의 확인을 기다렸다가 스테이션으로 돌아옵니다. 길이 막히면 스스로 다른 길을 찾고, 끝내 못 가면 포기하고 돌아와 보고합니다.

QR 인식(A02), Nav2 목표 전송(M11·M13), 서비스·액션(R04)을 하나로 묶는 것이 핵심입니다. 특히 "실패했을 때 무엇을 하는가"를 설계하는 것이 이 프로젝트의 절반입니다.

시스템 설계#

인터페이스와 노드 그래프#

"배송 요청"을 무엇으로 만들까? R04에서 배운 세 가지 통신 방식을 요구사항에 맞춰 고릅니다.

방식장점단점이 프로젝트에서
토픽가장 단순접수 여부를 돌려받을 수 없음상태 방송(/delivery/status)에만 사용
서비스즉시 접수·거절 응답긴 작업의 진행 상황·취소가 없음/delivery/request, /delivery/confirm (std_srvs/Trigger)
액션진행 피드백, 취소, 최종 결과인터페이스 패키지를 만들어야 함확장: Deliver.action

기본 구현은 추가 패키지 없이 돌아가도록 std_srvs/Trigger를 씁니다. 목적지는 요청 메시지가 아니라 스테이션 카메라가 본 QR에서 옵니다. 앱에서 목적지를 직접 보내거나 진행률을 받으려면 다음 인터페이스를 정의합니다(M5 심화).

서비스 콜백 안에서 주행을 시작하지 않는다

BasicNavigator.goToPose()는 안에서 노드를 spin하며 목표 접수를 기다립니다. 서비스 콜백 안에서 부르면 이미 돌고 있는 실행기(executor) 안에서 다시 spin하게 되어 멈추거나 예외가 납니다. 콜백은 상태만 바꾸고 즉시 응답하고, 실제 goToPose()는 주 루프가 부릅니다.

QR 지시서 형식과 목적지 조회표#

규칙예이유
접두어 DELIVER:DELIVER:ROOM_A다른 용도의 QR(예: 샘플 MentorPi)을 명령으로 오해하지 않게
이름만, 좌표 금지~~GOTO:1.2,3.4~~인쇄물이 로봇을 임의 위치로 보낼 수 없게. 좌표는 로봇 안의 조회표가 결정
조회표에 주·대체 접근점ROOM_A: [(2.0, 1.0, 90°), (2.0, 0.6, 90°)]문 앞이 막혔을 때 재계획할 두 번째 목표
오류 복원 수준 M 이상, 여백 4모듈A02 참고구겨짐·반사에 강하게

조회표는 M13처럼 RViz Publish Point(/clicked_point)로 좌표를 모으고, 방향(yaw)은 받는 사람이 서 있는 쪽을 보게 정합니다.

배송 상태 기계#

현재조건동작다음
IDLE요청 + 유효 QR목적지 저장, 응답 "accepted"DELIVER (주 루프가 goToPose)
IDLEQR 없음·형식 오류·모르는 이름응답 "rejected"IDLE
DELIVERSUCCEEDED 그리고 위치 오차 ≤ 0.3 m파랑 LED, 알림음 2회ARRIVED
DELIVERFAILED/CANCELED, 시간 초과(90 s)시도 +1 → 2회: clearAllCostmaps() 후 같은 목표, 3회: 대체 접근점DELIVER
DELIVER3회 초과기록 "aborted"RETURN
ARRIVED버튼·/delivery/confirm기록 "delivered"RETURN
ARRIVED60 s 경과기록 "no receiver"RETURN
RETURN도크 도착초록 LEDIDLE
RETURN3회 실패노랑 LED, 경고음, 정지SAFE_STOP

왜 2회째에 코스트맵을 지우는가? Nav2가 실패하는 흔한 이유는 "지나간 사람"이 코스트맵에 장애물로 남아 있는 경우입니다(M13의 clearing은 라이다 빔이 그 칸을 다시 지나야 일어납니다). 지우고 다시 시도하면 대부분 해결됩니다. 진짜로 막혀 있으면 두 번째도 실패하고, 그때 다른 접근점으로 목표 자체를 바꿔 재계획합니다. 이것은 Nav2 행동 트리의 복구(코스트맵 지우기 → spin → backup) 위에 임무 수준의 복구를 한 층 더 얹는 것입니다.

실습 1. QR 지시서 읽기와 검증#

지시서 QR을 cv2.QRCodeEncoder로 만들고, 샘플 qr.png("MentorPi"), 기울어진 지시서, 빈 화면과 함께 인식·검증합니다.

python브라우저 실행
import cv2
import numpy as np

DEST = {                                   # 목적지 조회표: 이름 → map 좌표 (x, y, yaw)
    "ROOM_A": (-1.0, 0.7, 0.0),
    "ROOM_B": (1.2, -0.7, 0.0),
    "DOCK":   (-0.8, -1.4, 0.0),
}
det = cv2.QRCodeDetector()

def make_qr(text, scale=8):                # 배송 지시서에 붙일 QR (M 수준 15% 복원, 여백 4모듈)
    p = cv2.QRCodeEncoder_Params()
    p.correction_level = cv2.QRCodeEncoder_CORRECT_LEVEL_M
    m = cv2.QRCodeEncoder.create(p).encode(text)
    m = cv2.resize(m, None, fx=scale, fy=scale, interpolation=cv2.INTER_NEAREST)
    return cv2.copyMakeBorder(m, 2 * scale, 2 * scale, 2 * scale, 2 * scale, cv2.BORDER_CONSTANT, value=255)

def parse(text):                           # "DELIVER:<목적지>" 형식만 받는다
    if not text:
        return None, "QR 없음"
    kind, _, name = text.partition(":")
    if kind != "DELIVER":
        return None, "형식 아님 (%r)" % text
    if name not in DEST or name == "DOCK":
        return None, "모르는 목적지 (%r)" % name
    return DEST[name], "목적지 %s" % name

frames = {"qr.png (샘플)": cv2.imread("qr.png")}
for t in ["DELIVER:ROOM_A", "DELIVER:ROOM_B", "DELIVER:KITCHEN"]:
    frames[t] = make_qr(t)
tilt = make_qr("DELIVER:ROOM_B")                                        # 비스듬히 본 지시서
h, w = tilt.shape[:2]
M = cv2.getPerspectiveTransform(np.float32([[0, 0], [w, 0], [w, h], [0, h]]),
                                np.float32([[30, 10], [w - 5, 40], [w - 25, h - 30], [10, h - 5]]))
frames["ROOM_B 기울임"] = cv2.warpPerspective(tilt, M, (w, h), borderValue=255)
frames["빈 화면"] = np.full((200, 200), 255, np.uint8)

for name, img in frames.items():
    text, pts, _ = det.detectAndDecode(img)
    goal, why = parse(text)
    print("%-16s → 읽음 %-18r %s" % (name, text, "목표 %s" % (goal,) if goal else "거부: " + why))
cv2.imshow("ROOM_B 기울임", frames["ROOM_B 기울임"])

실습 2. 배송 요청 서비스와 상태 기계#

delivery_bot이 /delivery/request·/delivery/confirm 서비스를 제공하고, front_desk 노드가 1 s에 요청, 4 s에 중복 요청, 도착 2 s 뒤 수령 확인을 보냅니다. 메카넘 섀시는 방향을 유지한 채 목표 쪽으로 평행 이동합니다(M13 실습과 같은 방식). 실물에서는 front_desk 대신 ros2 service call을 씁니다.

python브라우저 실행
import math, cv2, rclpy
from rclpy.node import Node
from std_msgs.msg import String
from std_srvs.srv import Trigger
from geometry_msgs.msg import Twist
from nav_msgs.msg import Odometry
import mentorpi_sim as sim                                        # 시뮬 전용
sim.setup(world="room", duration=28.0, start=(-0.8, -1.4, 0.0))  # 시뮬 전용

DOCK = (-0.8, -1.4)                                               # 출발 스테이션 = odom 원점 (yaw 0)
DEST = {"ROOM_A": (-1.0, 0.7), "ROOM_B": (1.2, -0.7)}
V, TOL, WAIT = 0.2, 0.05, 6.0                                     # 속도 상한, 도착 허용오차, 수령 대기 [s]

def camera():                                                     # 시뮬 전용: 스테이션 카메라에 비친 지시서
    q = cv2.resize(cv2.QRCodeEncoder.create().encode("DELIVER:ROOM_A"), None, fx=8, fy=8, interpolation=cv2.INTER_NEAREST)
    return cv2.copyMakeBorder(q, 32, 32, 32, 32, cv2.BORDER_CONSTANT, value=255)

class DeliveryBot(Node):
    def __init__(self):
        super().__init__('delivery_bot')
        self.cmd = self.create_publisher(Twist, '/controller/cmd_vel', 10)
        self.status = self.create_publisher(String, '/delivery/status', 10)   # 상태 방송 (UI·기록용)
        self.create_subscription(Odometry, '/odom', self.on_odom, 10)
        self.create_service(Trigger, '/delivery/request', self.on_request)
        self.create_service(Trigger, '/delivery/confirm', self.on_confirm)
        self.state, self.goal, self.pos, self.t_state = 'IDLE', None, None, 0.0
        self.create_timer(0.05, self.loop)
    def now(self): return self.get_clock().now().nanoseconds * 1e-9
    def go(self, st, goal=None, why=''):
        self.get_logger().info('%-8s -> %-8s %s' % (self.state, st, why))
        self.state, self.goal, self.t_state = st, goal, self.now()
        self.status.publish(String(data=st))
    def on_odom(self, m):
        self.pos = (DOCK[0] + m.pose.pose.position.x, DOCK[1] + m.pose.pose.position.y)
    def on_request(self, req, res):
        text = cv2.QRCodeDetector().detectAndDecode(camera())[0]  # 실물: 카메라 콜백이 읽어 둔 최신 QR
        name = text.partition(':')[2] if text.startswith('DELIVER:') else ''
        res.success = self.state == 'IDLE' and name in DEST
        res.message = ('accepted ' + name) if res.success else 'rejected (state=%s)' % self.state
        if res.success: self.go('DELIVER', DEST[name], name)
        return res
    def on_confirm(self, req, res):
        res.success = self.state == 'ARRIVED'
        if res.success: self.go('RETURN', DOCK, 'received')
        return res
    def loop(self):
        t = Twist()
        if self.state == 'ARRIVED' and self.now() - self.t_state > WAIT:
            self.go('RETURN', DOCK, 'no receiver (timeout)')
        if self.goal and self.pos and self.state in ('DELIVER', 'RETURN'):
            ex, ey = self.goal[0] - self.pos[0], self.goal[1] - self.pos[1]
            d = math.hypot(ex, ey)
            if d < TOL:
                self.go('ARRIVED' if self.state == 'DELIVER' else 'IDLE', None, 'at %.1f s' % self.now())
            else:
                s = min(V, 1.2 * d) / d                           # 메카넘: 방향 유지, 목표 쪽으로 평행 이동
                t.linear.x, t.linear.y = ex * s, ey * s
        self.cmd.publish(t)

class Desk(Node):                                                 # 요청자·수령자 역할 (실물: ros2 service call)
    def __init__(self):
        super().__init__('front_desk')
        self.req = self.create_client(Trigger, '/delivery/request')
        self.ok = self.create_client(Trigger, '/delivery/confirm')
        self.create_subscription(String, '/delivery/status', self.on_status, 10)
        self.plan = {1.0: self.req, 4.0: self.req}                # 1 s 요청, 4 s 중복 요청(거절돼야 함)
        self.create_timer(0.5, self.tick)
    def now(self): return self.get_clock().now().nanoseconds * 1e-9
    def tick(self):
        for t in [t for t in self.plan if self.now() >= t]:
            cli = self.plan.pop(t)
            cli.call_async(Trigger.Request()).add_done_callback(
                lambda f, c=cli: self.get_logger().info('%s -> %s' % (c.srv_name, f.result().message or f.result().success)))
    def on_status(self, msg):
        if msg.data == 'ARRIVED':
            self.plan[self.now() + 2.0] = self.ok                 # 물건을 꺼내는 데 2 s 뒤 수령 확인

rclpy.init()
bot, desk = DeliveryBot(), Desk()
try:
    rclpy.spin(bot)
except KeyboardInterrupt:
    pass
finally:
    bot.cmd.publish(Twist()); bot.destroy_node(); desk.destroy_node()
    if rclpy.ok(): rclpy.shutdown()

실습 3. 막힘 감지 · 재시도 · 재계획#

같은 배송에서 통로에 카트(상자)가 놓여 있습니다. 진행 방향 ±25° 안에 0.35 m보다 가까운 것이 있으면 멈추고, 2 s 동안 계속 막히면 다음 시도로 넘어갑니다. 1·2회째는 같은 직선 경로(사람이라면 비켜 줄 수도 있으므로), 3회째는 서쪽으로 돌아가는 2순위 경로로 재계획합니다.

python브라우저 실행
import math, rclpy
import numpy as np
from rclpy.node import Node
from geometry_msgs.msg import Twist
from sensor_msgs.msg import LaserScan
from nav_msgs.msg import Odometry
import mentorpi_sim as sim                                        # 시뮬 전용
sim.setup(world="room", duration=30.0, start=(-0.8, -1.4, 0.0))  # 시뮬 전용
sim.add_box(-0.8, -0.3, 0.5, 0.2)                                 # 시뮬 전용: 복도를 막은 카트

DOCK = (-0.8, -1.4)
ROUTES = [[(-1.0, 0.7)],                                          # 1순위: 직선 경로
          [(-1.5, -0.55), (-1.5, 0.3), (-1.0, 0.7)]]              # 2순위: 서쪽으로 돌아가는 경로
V, TOL, STOP_D, BLOCK_T, MAX_TRY = 0.2, 0.05, 0.35, 2.0, 3

class RecoveringDelivery(Node):
    def __init__(self):
        super().__init__('delivery_recovery')
        self.cmd = self.create_publisher(Twist, '/controller/cmd_vel', 10)
        self.create_subscription(Odometry, '/odom', self.on_odom, 10)
        self.create_subscription(LaserScan, '/scan', self.on_scan, 10)
        self.pos, self.scan, self.attempt = None, None, 0
        self.new_attempt('start')
        self.create_timer(0.05, self.loop)
    def now(self): return self.get_clock().now().nanoseconds * 1e-9
    def on_odom(self, m): self.pos = (DOCK[0] + m.pose.pose.position.x, DOCK[1] + m.pose.pose.position.y)
    def on_scan(self, s): self.scan = s
    def new_attempt(self, why):
        self.attempt, self.blocked_since = self.attempt + 1, None
        if self.attempt > MAX_TRY:
            self.get_logger().error('ABORT after %d tries -> RETURN to dock' % MAX_TRY)
            self.route, self.i = [DOCK], 0; return
        k = 0 if self.attempt < 3 else 1                           # 2회까지 같은 경로(비켜 주길 기다림), 3회째 재계획
        self.route, self.i = ROUTES[k], 0
        self.get_logger().info('attempt %d (%s): route %d %s' % (self.attempt, why, k + 1, self.route))
    def front_clear(self, vx, vy):                                # 진행 방향 ±25° 안에 STOP_D보다 가까운 것?
        r = np.array(self.scan.ranges); a = self.scan.angle_min + np.arange(len(r)) * self.scan.angle_increment
        diff = np.abs(np.arctan2(np.sin(a - math.atan2(vy, vx)), np.cos(a - math.atan2(vy, vx))))
        return not np.any((diff < math.radians(25)) & (r < STOP_D))
    def loop(self):
        if self.pos is None or self.scan is None: return
        t = Twist()
        gx, gy = self.route[self.i]
        ex, ey = gx - self.pos[0], gy - self.pos[1]; d = math.hypot(ex, ey)
        if d < TOL:
            self.i += 1
            if self.i == len(self.route):
                self.get_logger().info('ARRIVED (%s) at %.1f s, attempts %d' % (
                    'dock' if self.route == [DOCK] else 'ROOM_A', self.now(), self.attempt))
                self.cmd.publish(t); rclpy.shutdown(); return
        else:
            s = min(V, 1.2 * d) / d
            if self.front_clear(ex, ey):
                t.linear.x, t.linear.y, self.blocked_since = ex * s, ey * s, None
            elif self.blocked_since is None:
                self.blocked_since = self.now()
                self.get_logger().warn('blocked at (%.2f, %.2f) - stop' % self.pos)
            elif self.now() - self.blocked_since > BLOCK_T:
                self.new_attempt('blocked %.0f s' % BLOCK_T)
        self.cmd.publish(t)

  • 적재물은 가볍고 낮은 것만 싣고 테이프로 고정합니다. 액체·유리·날카로운 물건 금지. 무거운 물건은 라이다·카메라를 가리지 않게 합니다.
  • 수령자는 로봇이 완전히 멈추고 파랑 LED가 켜진 뒤 물건을 꺼냅니다. 꺼내는 동안 손을 바퀴 근처에 두지 않습니다.
  • 멈추는 방법: 스크립트 Ctrl+C(cancelTask), ros2 topic pub --once /controller/cmd_vel geometry_msgs/msg/Twist "{}", 전원 스위치. 속도 상한(0.2 m/s, 0.5 rad/s)은 풀지 않습니다.
  • 고장 주입 시험에서 로봇을 들어 옮길 때는 먼저 Ctrl+C로 노드를 멈춥니다.

python실물 전용
#!/usr/bin/env python3
# delivery_bot.py — navigation.launch.py 실행 + 도크에서 초기 위치 지정 후
import math
import cv2
import rclpy
from rclpy.time import Time
from cv_bridge import CvBridge
from sensor_msgs.msg import Image
from std_msgs.msg import String
from std_srvs.srv import Trigger
from geometry_msgs.msg import PoseStamped
from nav2_simple_commander.robot_navigator import BasicNavigator, TaskResult
from tf2_ros import Buffer, TransformListener, TransformException
from tf_transformations import quaternion_from_euler
from ros_robot_controller_msgs.msg import RGBState, RGBStates, BuzzerState, ButtonState

DOCK = (0.0, 0.0, 0.0)                                         # map 좌표 (x, y, yaw) — /clicked_point로 측정
DEST = {'ROOM_A': [(2.0, 1.0, 1.57), (2.0, 0.6, 1.57)],       # 이름 → [주 접근점, 대체 접근점]
        'ROOM_B': [(3.5, -0.5, 0.0), (3.2, -0.8, 0.0)]}
NAV_TIMEOUT, WAIT_T, MAX_TRY, ARRIVE_TOL = 90.0, 60.0, 3, 0.30
GREEN, BLUE, YELLOW = (0, 255, 0), (0, 0, 255), (255, 255, 0)

class DeliveryBot(BasicNavigator):
    def __init__(self):
        super().__init__('delivery_bot')
        self.bridge, self.det = CvBridge(), cv2.QRCodeDetector()
        self.qr, self.qr_t, self.frame_t = '', -1e9, -1e9
        self.create_subscription(Image, '/ascamera/camera_publisher/rgb0/image', self.on_image, 1)
        self.create_subscription(ButtonState, '/ros_robot_controller/button', self.on_button, 10)
        self.create_service(Trigger, '/delivery/request', self.on_request)
        self.create_service(Trigger, '/delivery/confirm', self.on_confirm)
        self.status = self.create_publisher(String, '/delivery/status', 10)
        self.rgb = self.create_publisher(RGBStates, '/ros_robot_controller/set_rgb', 1)
        self.buzzer = self.create_publisher(BuzzerState, '/ros_robot_controller/set_buzzer', 1)
        self.tf_buffer = Buffer()
        self.tf_listener = TransformListener(self.tf_buffer, self)
        self.state, self.dest, self.target, self.attempt = 'IDLE', None, None, 0
        self.t_state = self.t_nav = self.now()
        self.confirmed = False
    def now(self):
        return self.get_clock().now().nanoseconds * 1e-9
    def go(self, state, why=''):                                 # 상태 전이 + 방송 + 표시
        self.get_logger().info('%s -> %s %s' % (self.state, state, why))
        self.state, self.t_state = state, self.now()
        self.status.publish(String(data=state))
        color, beep = {'IDLE': (GREEN, None), 'ARRIVED': (BLUE, (1900, 0.1, 2)),
                       'SAFE_STOP': (YELLOW, (1000, 0.5, 3))}.get(state, (GREEN, None))
        self.rgb.publish(RGBStates(states=[RGBState(index=i, red=color[0], green=color[1], blue=color[2]) for i in (1, 2)]))
        if beep:
            self.buzzer.publish(BuzzerState(freq=beep[0], on_time=beep[1], off_time=beep[1], repeat=beep[2]))
    # ---- 콜백: 상태만 바꾸고 바로 돌아온다
    def on_image(self, msg):
        if self.state != 'IDLE' or self.now() - self.frame_t < 0.5:  # 도크에서만, 2 Hz
            return
        self.frame_t = self.now()
        text = self.det.detectAndDecode(self.bridge.imgmsg_to_cv2(msg, 'bgr8'))[0]
        if text:
            self.qr, self.qr_t = text, self.now()
    def on_request(self, req, res):
        fresh = self.now() - self.qr_t < 2.0
        name = self.qr.partition(':')[2] if fresh and self.qr.startswith('DELIVER:') else ''
        res.success = self.state == 'IDLE' and name in DEST
        res.message = ('accepted ' + name) if res.success else 'rejected (state=%s, qr=%r)' % (self.state, self.qr if fresh else '')
        if res.success:
            self.dest, self.attempt, self.state = name, 0, 'START'  # goToPose는 주 루프에서
        return res
    def on_confirm(self, req, res):
        res.success = self.state == 'ARRIVED'
        self.confirmed = self.confirmed or res.success
        return res
    def on_button(self, msg):
        if self.state == 'ARRIVED' and msg.id == 1 and msg.state in (1, 5):   # 누름 또는 클릭
            self.confirmed = True
    # ---- 주 루프에서 부르는 함수들
    def drive(self, pose):
        p = PoseStamped()
        p.header.frame_id, p.header.stamp = 'map', self.get_clock().now().to_msg()
        p.pose.position.x, p.pose.position.y = pose[0], pose[1]
        q = quaternion_from_euler(0.0, 0.0, pose[2])
        p.pose.orientation.x, p.pose.orientation.y, p.pose.orientation.z, p.pose.orientation.w = q
        self.target, self.t_nav = pose, self.now()
        self.goToPose(p)
    def error_to_target(self):
        try:
            t = self.tf_buffer.lookup_transform('map', 'base_footprint', Time()).transform.translation
        except TransformException:
            return float('inf')
        return math.hypot(self.target[0] - t.x, self.target[1] - t.y)
    def recover(self, why):
        self.attempt += 1
        if self.attempt > MAX_TRY:
            if self.state == 'RETURN':
                self.go('SAFE_STOP', 'cannot reach dock')
                return
            self.attempt = 1
            self.go('RETURN', 'aborted: ' + why)
            self.drive(DOCK)
            return
        self.get_logger().warn('%s failed (%s) -> try %d' % (self.state, why, self.attempt))
        self.clearAllCostmaps()                                  # 지나간 사람의 흔적 지우기
        if self.state == 'RETURN':
            self.drive(DOCK)
        else:
            self.drive(DEST[self.dest][0 if self.attempt < 3 else 1])   # 3회째: 대체 접근점으로 재계획
    def step(self):
        if self.state == 'START':
            self.attempt = 1
            self.go('DELIVER', self.dest)
            self.drive(DEST[self.dest][0])
        elif self.state in ('DELIVER', 'RETURN'):
            if not self.isTaskComplete():
                if self.now() - self.t_nav > NAV_TIMEOUT:
                    self.cancelTask()                            # 다음 루프에서 CANCELED로 처리
                return
            err = self.error_to_target()
            if self.getResult() != TaskResult.SUCCEEDED or err > ARRIVE_TOL:
                self.recover('result=%s err=%.2f m' % (self.getResult(), err))
            elif self.state == 'DELIVER':
                self.confirmed = False
                self.go('ARRIVED', '%s err %.2f m' % (self.dest, err))
            else:
                self.go('IDLE', 'docked')
        elif self.state == 'ARRIVED' and (self.confirmed or self.now() - self.t_state > WAIT_T):
            self.attempt = 1
            self.go('RETURN', 'delivered' if self.confirmed else 'no receiver')
            self.drive(DOCK)

def main():
    rclpy.init()
    bot = DeliveryBot()
    bot.waitUntilNav2Active()
    bot.go('IDLE', 'ready')
    try:
        while rclpy.ok() and bot.state != 'SAFE_STOP':
            rclpy.spin_once(bot, timeout_sec=0.05)
            bot.step()
    except KeyboardInterrupt:
        pass
    finally:
        bot.cancelTask()
        bot.go('SAFE_STOP', 'shutdown')
        bot.destroy_node()
        rclpy.shutdown()

if __name__ == '__main__':
    main()

  • 콜백(on_image, on_request, on_confirm, on_button)은 변수만 바꿉니다. goToPose·cancelTask·clearAllCostmaps처럼 안에서 spin하는 함수는 모두 step()에서 부릅니다.
  • 도착 판정은 SUCCEEDED만 믿지 않고 TF로 실제 위치를 한 번 더 봅니다. AMCL이 튄 경우(로봇을 들어 옮김 등) 여기서 걸러져 재시도로 갑니다.
  • ButtonState의 state는 원본 ros_robot_controller_node.py 정의를 따릅니다(1 누름, 5 클릭, 0 짧게 누른 뒤 뗌).

4) 고장 주입 시험 (M4)#

시험방법기대 결과
T1 잠깐 막힘주행 중 사람이 5 s 경로에 섬컨트롤러 회피 또는 2회째 재시도로 성공
T2 문 앞 막힘주 접근점에 상자3회째 대체 접근점 도착, 로그에 try 3
T3 완전 차단목적지로 가는 통로 전체를 막음aborted 후 도크 복귀, IDLE
T4 미수령도착 후 아무도 확인 안 함60 s 뒤 no receiver로 복귀
T5 잘못된 지시서MentorPi QR, 모르는 방 이름rejected, 로봇 움직이지 않음

끝나면 모든 터미널 Ctrl+C 후 호스트에서 sudo systemctl restart start_node.service로 앱 서비스를 되돌립니다.

확장 과제#

  • 액션 서버: delivery_interfaces 패키지(ament_cmake, rosidl_generate_interfaces)에 Deliver.action을 정의하고 피드백(state, distance_remaining)과 취소를 지원합니다. 취소되면 즉시 RETURN으로 갑니다.
  • 배송 대기열: 요청을 거절하는 대신 큐에 넣고, 복귀하면 다음 건을 처리합니다. 지시서마다 DELIVER:ROOM_A#17처럼 건 번호를 붙여 중복 접수를 막습니다.
  • 수령자 인증: 도착지에서 수령자가 보여 준 두 번째 QR(RECEIVE:17)을 카메라로 읽어야만 수령 확인으로 인정합니다.
  • 경로 경유점: 좁은 복도는 goThroughPoses로 안전한 경유점을 지나게 합니다(M13).
  • 배터리 인식: /ros_robot_controller/battery가 기준 아래면 새 요청을 거절하고 도크에 머뭅니다.

자주 나는 오류와 해결#

증상원인해결
요청하면 서비스 호출이 끝나지 않음서비스 콜백 안에서 goToPose() 호출 → 실행기 중첩콜백은 상태만 바꾸고 주 루프에서 주행 시작
항상 rejected (qr='')카메라 토픽 없음, 2 s 넘은 오래된 QR, 너무 멀거나 반사ros2 topic hz /ascamera/camera_publisher/rgb0/image, 30~60 cm, 무광 인쇄
QR은 보이는데 detectAndDecode가 빈 문자열여백 부족, 모듈이 너무 작음여백 4모듈, 한 모듈이 영상에서 3~4픽셀 이상 (A02)
SUCCEEDED인데 ARRIVED가 안 됨TF 오차 > 0.3 m (AMCL 튐) 또는 base_footprint TF 없음RViz에서 스캔·지도 정렬 확인, ros2 run tf2_ros tf2_echo map base_footprint
같은 문 앞에서 계속 실패주·대체 접근점이 모두 팽창 영역 안접근점을 벽에서 0.4 m 이상, 코스트맵 확인(M12)
버튼을 눌러도 확인이 안 됨다른 버튼 id, 앱 서비스의 버튼 점유ros2 topic echo /ros_robot_controller/button으로 id·state 확인
복귀 후 다음 요청이 거절됨상태가 IDLE로 안 돌아옴(도크 도착 판정 실패)도크 좌표·방향 재측정, 로그의 err 값 확인
waitUntilNav2Active에서 멈춤초기 위치 미지정도크에서 2D Pose Estimate 후 실행

과제#

기본 과제
  1. Playground 실습 3에서 STOP_D(0.25/0.35/0.5 m)와 BLOCK_T(1/2/4 s)를 바꿔 도착 시간과 충돌 여부를 표로 정리합니다. 이어서 지나온 지점을 기록해 두었다가 ABORT 때 역순으로 되짚어 도크로 가도록 고치고, 2순위 경로까지 막힌 경우에도 복귀하는 것을 보입니다.
  2. 실물에서 T1~T5를 수행하고 결과표를 제출합니다.
심화 과제
  1. 확장 과제의 액션 서버를 구현하고, ros2 action send_goal /deliver delivery_interfaces/action/Deliver "{destination: ROOM_A}" --feedback으로 진행 피드백을 받는 것을 시연합니다.
  2. 두 목적지를 한 번에 도는 다중 배송(DELIVER:ROOM_A,ROOM_B)을 설계합니다. 한 곳이 실패해도 다른 곳은 배송하고, 결과 보고에 건별 성공·실패를 남깁니다.
