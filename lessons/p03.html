P03미니 시티 자율주행 챌린지

차선 유지·신호등·표지판·교차로 회전·주차를 하나의 상태 기계로 통합하고, 채점 규칙에 맞춰 트랙을 완주하는 자율주행 프로젝트.

선수 챕터: A03 A09 A10 A11
3D 시뮬레이터2D 시뮬레이터ROS 2 Playground

학습 목표#

  • 차선 유지·신호등·표지판·교차로 회전·주차를 하나의 유한 상태 기계(FSM)로 통합하고, 인식 계층(사건 생성)과 결정 계층(전이표)을 분리해 설계합니다.
  • 원본 self_driving.py의 알려진 약점(차선 상실 시 마지막 명령 유지, 같은 값인 정상·서행 속도, 쓰이지 않는 우회전 표지, 개루프 주차, 장애물 무시)을 찾아 고치고, 고친 효과를 데이터로 보입니다.
  • 챌린지 규칙과 채점표를 이해하고, 시간·감점을 고려해 속도·디바운싱·타임아웃 파라미터를 고릅니다.
  • 브라우저 시뮬레이션으로 FSM·차선 오차·도시 순환 주행을 먼저 검증한 뒤, 실물 MentorPi에서 팀 노드를 실행하고 기록(rosbag)으로 채점을 재현합니다.
  • 팀 안에서 인식·제어·안전·심판 역할을 나눠 인터페이스(토픽·사건 이름)를 먼저 합의하는 방식으로 협업합니다.

프로젝트 개요와 요구사항#

A09~A11에서 차선 유지, YOLOv5 표지판·신호등 인식, 회전 판단과 주차를 따로따로 익혔습니다. 이 프로젝트는 그것들을 한 대의 로봇 안에서 동시에, 충돌 없이 돌게 만드는 통합 과제입니다. 기능 하나하나보다 어려운 것은 "언제 무엇을 우선하는가"입니다. 횡단보도 앞에서 빨간불을 봤는데 차선이 흐려졌다면? 주차 표지를 봤는데 앞에 상자가 놓여 있다면? 이런 질문에 표 한 장으로 답할 수 있는 설계가 이 장의 목표입니다.

진행은 4~5차시(약 300분) 팀 프로젝트를 가정합니다.

챌린지 규칙과 채점#

규칙

  1. 로봇은 출발 게이트(①)에 차로 가운데로 놓고, 심판의 "출발" 신호와 함께 팀원이 노드를 시작합니다. 이후 로봇에 손을 대면 개입입니다.
  2. 신호등은 심판이 손으로 바꿉니다. 로봇이 정지선에 다가오는 동안 빨간불로 두고, 정지한 뒤 3~8 s 사이 임의 시점에 초록으로 바꿉니다.
  3. 교차로 표지(④)는 시행 전에 심판이 right 또는 go 중 하나로 정합니다(팀은 모름).
  4. 코스 1바퀴 뒤 주차 칸(⑤)에 정지하면 완주입니다. 제한 시간은 5분이며, 넘기면 그 시점까지의 점수만 인정합니다.
  5. 본선은 2회 시행하고 높은 점수를 씁니다. 시행 사이 파라미터 수정은 허용하되 5분 안에 끝냅니다.

M4. 신호등·표지 사건#

YOLOv5 콜백에서 사건을 만들고, FSM은 사건만 봅니다. 표지 right는 상태를 바꾸지 않고 기억만 하고, 교차로(junction) 사건이 올 때 읽고 지웁니다. 체크포인트: 바퀴를 띄운 채 신호등을 바꾸면 ~/state가 STOP↔SLOW로 바뀌고, 표지를 치우면 교차로에서 TURN_S가 로그에 찍힌다.

M5. 교차로 회전과 폐루프 주차#

회전은 원본처럼 고정 각속도(−0.45 rad/s)로 돌되 straight 사건으로 끝냅니다. 주차는 메카넘 기준 옆으로 0.38 m(원본 값)를 시간 대신 /odom 이동 거리로 잽니다. 체크포인트: 실습 3의 시뮬 채점이 75/75이고, 실물 주차 3회 반복 편차가 2 cm 이하(원본 시간 기반과 비교)다.

실습 1: 전이표 FSM과 사건 타임라인#

전이표·안전 전이·복귀·시간 제한·표지 기억 소비를 모두 담은 순수 Python FSM입니다. 사건은 인식 계층이 디바운싱을 마친 뒤라고 가정합니다.

# 미니 시티 FSM: 상태 × 사건 → 다음 상태 (+ 공통 안전 전이, 시간 제한, 이벤트 소비)
SPEED = {"LANE": 0.12, "SLOW": 0.06, "STOP": 0.0, "TURN_R": 0.08, "TURN_S": 0.10,
         "APPROACH": 0.06, "PARK": 0.0, "LOST": 0.0, "HOLD": 0.0, "DONE": 0.0}
TABLE = {("LANE", "crosswalk"): "SLOW",    ("SLOW", "red"): "STOP",
         ("STOP", "green"): "SLOW",        ("SLOW", "passed"): "LANE",
         ("LANE", "junction"): "TURN?",    # 표지 기억에 따라 TURN_R / TURN_S
         ("TURN_R", "straight"): "LANE",   ("TURN_S", "straight"): "LANE",
         ("LANE", "park_sign"): "APPROACH", ("APPROACH", "at_spot"): "PARK",
         ("PARK", "done"): "DONE"}
SAFETY = {"obstacle": "HOLD", "lane_lost": "LOST"}         # 어느 상태에서든 우선
RESUME = {"clear": "HOLD", "lane_found": "LOST"}           # 해제 사건 → 이전 상태로 복귀
TIMEOUT = {"STOP": 20.0, "LOST": 3.0, "HOLD": 10.0}        # 초과하면 ABORT

timeline = [(1.0, "sign_right"), (3.0, "crosswalk"), (3.5, "red"), (9.0, "green"),
            (11.0, "passed"), (12.0, "lane_lost"), (12.8, "lane_found"),
            (15.0, "junction"), (18.0, "straight"), (19.0, "obstacle"), (22.0, "clear"),
            (24.0, "junction"), (27.0, "straight"), (30.0, "park_sign"),
            (34.0, "at_spot"), (37.0, "done")]

state, prev, memo, t_in, dist, t_prev = "LANE", None, None, 0.0, 0.0, 0.0
for t, ev in timeline:
    if state in TIMEOUT and t - t_in > TIMEOUT[state]:
        print("%5.1fs 시간 초과 → ABORT" % t)
        break
    dist += SPEED[state] * (t - t_prev)
    t_prev = t
    if ev.startswith("sign_"):                             # 표지는 상태를 바꾸지 않고 기억만
        memo = ev[5:]
        print("%5.1fs %-10s 표지 기억: %s" % (t, ev, memo))
        continue
    if ev in SAFETY and state not in SAFETY.values():
        nxt, prev = SAFETY[ev], state
    elif ev in RESUME and state == RESUME[ev]:
        nxt = prev
    else:
        nxt = TABLE.get((state, ev))
    if nxt == "TURN?":
        nxt, memo = ("TURN_R" if memo == "right" else "TURN_S"), None   # 기억을 소비
    if nxt is None:
        print("%5.1fs %-10s 무시 (상태 %s)" % (t, ev, state))
        continue
    print("%5.1fs %-10s %-8s → %-8s v=%.2f  누적 %.2f m" % (t, ev, state, nxt, SPEED[nxt], dist))
    state, t_in = nxt, t
print("최종 상태:", state)

import numpy as np
import cv2

img = cv2.imread("lane.png")                           # BGR 640x480, 왼쪽 흰 선·오른쪽 노란 선
BANDS = ((400, 420, 0.7), (330, 350, 0.2), (270, 290, 0.1))
V_LANE, V_LOST, MISS_MAX = 0.12, 0.0, 3                # 차선 3프레임 연속 미검출 → 정지

HALF = {400: 139, 330: 93, 270: 54}                    # 띠별 차로 반폭 [px] (정상 영상에서 잰 값)

def line_x(mask):                                      # 선 하나의 x. 없거나 너무 넓으면(반사광) None
    xs = np.nonzero(mask)[1]
    return None if len(xs) < 20 or np.ptp(xs) > 60 else xs.mean()

def lane_error(bgr):
    lab = cv2.cvtColor(bgr, cv2.COLOR_BGR2LAB)
    yel = cv2.inRange(lab, (135, 100, 160), (255, 150, 255))   # A09에서 이 영상에 맞춘 값
    wht = cv2.inRange(lab, (200, 118, 118), (255, 138, 138))
    err = 0.0
    for y0, y1, w in BANDS:
        xy, xw = line_x(yel[y0:y1]), line_x(wht[y0:y1])
        if xy is None and xw is None:
            return None                                # 두 선 모두 없음 → 미검출
        if xy is None:
            cx = xw + HALF[y0]                         # 한 선만 보이면 반폭으로 중심 추정
        elif xw is None:
            cx = xy - HALF[y0]
        else:
            cx = (xy + xw) / 2
        err += w * (cx - bgr.shape[1] / 2)
    return err

def frames():
    yield "정상", img
    yield "오른쪽 30px 이동", np.roll(img, 30, axis=1)
    g = img.copy()
    g[260:430, 400:640] = 0                            # 노란 선 쪽이 가려짐(그림자·소품)
    yield "노란선 가림", g
    g = img.copy()
    g[260:430, 380:640] = 235                          # 강한 반사광: 흰 덩어리
    yield "반사광", g
    for k in range(3):
        yield "차선 없음 %d" % (k + 1), np.full_like(img, 90)   # 맵 밖/그림자
    yield "복귀", img

miss = 0
for name, f in frames():
    e = lane_error(f)
    miss = 0 if e is not None else miss + 1
    if e is None:

    else:
        v, w, st = V_LANE, float(np.clip(-0.004 * e, -0.5, 0.5)), "LANE"
    print("%-14s 오차 %7s px  miss=%d  %-5s v=%.2f ω=%+.3f"
          % (name, "없음" if e is None else "%+.1f" % e, miss, st, v, w))

import math
import time
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import Twist
from sensor_msgs.msg import LaserScan
import mentorpi_sim as sim                                    # 시뮬 전용
sim.setup(chassis="mecanum", world="empty", duration=30.0,
          start=(-1.3, -0.9, 0.0), noise=True)                # 시뮬 전용
for bx in (-0.12, -0.68):
    sim.add_box(bx, 0.85, 0.06, 0.4)                           # 시뮬 전용: 주차 칸 옆벽
sim.add_box(-0.4, 1.1, 0.62, 0.06)                             # 시뮬 전용: 주차 칸 뒷벽

ROUTE = [(-1.3, -0.9), (0.5, -0.9), (0.5, 0.4), (-0.4, 0.4)]  # 순환 도로 차로 중심선
STOP_X, CROSS, SLOT = -0.9, (-0.85, -0.65), (-0.4, 0.85)       # 정지선, 횡단보도, 주차 칸 중심
V = {"LANE": 0.2, "SLOW": 0.1, "STOP": 0.0, "TURN": 0.15, "PARK": 0.0}
light = lambda t: "red" if t < 5.0 else "green"                # 가상 신호등 (시간으로 바뀜)

class CityDriver(Node):
    def __init__(self):
        super().__init__("city_driver")
        self.pub = self.create_publisher(Twist, "/cmd_vel", 1)
        self.create_subscription(LaserScan, "/scan", self.on_scan, 1)
        self.state, self.seg, self.front, self.violation, self.slow_v = "LANE", 0, 9.9, False, 0.0
        self.t0 = self.t_enter = time.time()
        self.create_timer(0.05, self.step)

    def on_scan(self, msg):
        n = len(msg.ranges)
        self.front = min(msg.ranges[n // 2 - 15: n // 2 + 16])   # 전방 ±15° (인덱스 n/2 = 0°)

    def go(self, s):
        print("%5.1fs  %-5s → %s" % (time.time() - self.t0, self.state, s))
        self.state, self.t_enter = s, time.time()

    def step(self):
        t, st = time.time() - self.t0, self.state
        x, y, th = sim.pose()                                  # 시뮬 전용: 차선 인식 대용
        (ax, ay), (bx, by) = ROUTE[self.seg], ROUTE[self.seg + 1]
        hd = math.atan2(by - ay, bx - ax)
        e = -(x - ax) * math.sin(hd) + (y - ay) * math.cos(hd)   # 횡오차(왼쪽 +)
        psi = math.atan2(math.sin(th - hd), math.cos(th - hd))    # 방향 오차
        left = (bx - x) * math.cos(hd) + (by - y) * math.sin(hd)  # 구간 끝까지 거리
        if self.seg == 0 and x > STOP_X and light(t) == "red":
            self.violation = True                               # 빨간불에 정지선 통과
        if st == "LANE" and self.seg == 0 and light(t) == "red" and 0 < STOP_X - x < 0.06:
            self.go("STOP")
        elif st == "STOP" and light(t) == "green" or st == "LANE" and CROSS[0] < x < CROSS[1] and self.seg == 0:
            self.go("SLOW")
        elif st == "SLOW" and x >= CROSS[1]:
            self.go("LANE")
        elif st == "LANE" and self.seg < len(ROUTE) - 2 and left < 0.3:
            self.go("TURN")                                     # 반경 0.3 m 호로 회전
        elif st == "LANE" and left < 0.02:
            self.go("PARK")
        cmd, st = Twist(), self.state
        if st == "TURN":
            nx, ny = ROUTE[self.seg + 2]
            err = math.atan2(ny - by, nx - bx) - th
            err = math.atan2(math.sin(err), math.cos(err))
            cmd.linear.x, cmd.angular.z = V["TURN"], math.copysign(0.5, err)
            if abs(err) < 0.05:
                self.seg += 1
                self.go("LANE")
        elif st == "PARK":                                     # 메카넘: 오른쪽으로 평행 이동
            cmd.linear.y = -0.2
            if time.time() - self.t_enter > 0.45 / 0.2:
                self.finish(t, x, y, psi)
        elif st in ("LANE", "SLOW"):
            cmd.linear.x = V[st] if self.front > 0.25 else 0.0     # 전방 장애물이면 정지
            cmd.angular.z = max(-0.5, min(0.5, -3.0 * e - 1.5 * psi))
            if st == "SLOW":
                self.slow_v = max(self.slow_v, cmd.linear.x)
        self.pub.publish(cmd)

    def finish(self, t, x, y, psi):
        ex, ey = x - SLOT[0], y - SLOT[1]
        park = 20 if max(abs(ex), abs(ey)) <= 0.03 and abs(math.degrees(psi)) <= 10 else 15
        score = 20 + (0 if self.violation else 15) + (10 if self.slow_v <= 0.1 else 0) + 10 + park
        print("완주 %.1f s | 주차 오차 x %+.2f y %+.2f m, 자세 %+.1f°" % (t, ex, ey, math.degrees(psi)))
        print("신호 위반 %s, 서행 최고 %.2f m/s → 시뮬 채점 %d / 75" % (self.violation, self.slow_v, score))
        raise SystemExit

rclpy.init()
node = CityDriver()
try:
    rclpy.spin(node)
except (KeyboardInterrupt, SystemExit):
    pass
finally:
    node.pub.publish(Twist())
    node.destroy_node()
    rclpy.shutdown()

실물 챌린지 안전 수칙
  • 코스 둘레 1 m를 비우고, 심판 1명은 항상 로봇 옆에서 따라가며 들어 올릴 준비를 합니다. 들어 올리면 개입 감점이지만 안전이 먼저입니다.

#!/usr/bin/env python3
import math
import numpy as np
import rclpy
from rclpy.node import Node
from rclpy.qos import qos_profile_sensor_data
from cv_bridge import CvBridge
from sensor_msgs.msg import Image, LaserScan
from geometry_msgs.msg import Twist
from nav_msgs.msg import Odometry
from std_msgs.msg import String
from std_srvs.srv import SetBool
from interfaces.msg import ObjectsInfo
from example.self_driving.lane_detect import LaneDetector

SPEED = {"LANE": 0.12, "SLOW": 0.06, "STOP": 0.0, "TURN_R": 0.08, "TURN_S": 0.10,
         "APPROACH": 0.06, "PARK": 0.0, "LOST": 0.0, "HOLD": 0.0, "DONE": 0.0, "ABORT": 0.0}
TABLE = {("LANE", "crosswalk"): "SLOW", ("SLOW", "red"): "STOP", ("STOP", "green"): "SLOW",
         ("SLOW", "passed"): "LANE", ("LANE", "junction"): "TURN?",
         ("TURN_R", "straight"): "LANE", ("TURN_S", "straight"): "LANE",
         ("LANE", "park_sign"): "APPROACH", ("APPROACH", "at_spot"): "PARK", ("PARK", "done"): "DONE"}
NEED = {"crosswalk": 3, "red": 1, "green": 5, "sign_right": 5, "junction": 6,
        "park_sign": 5, "at_spot": 5, "lane_lost": 3, "obstacle": 2}
TIMEOUT = {"STOP": 20.0, "LOST": 3.0, "HOLD": 10.0}
SETPOINT, KP, KD, W_MAX, PARK_DIST = 130, 0.004, 0.002, 0.3, 0.38

class CityFsm(Node):
    def __init__(self):
        super().__init__('city_fsm')
        self.state, self.prev, self.memo, self.running = "LANE", "LANE", None, True
        self.hits, self.last_err, self.odom, self.park0 = {}, 0.0, (0.0, 0.0), None
        self.t_in = self.t_img = self.now()
        self.lane, self.bridge = LaneDetector("yellow"), CvBridge()
        self.pub = self.create_publisher(Twist, '/controller/cmd_vel', 1)
        self.state_pub = self.create_publisher(String, '~/state', 10)
        self.create_subscription(Image, '/ascamera/camera_publisher/rgb0/image', self.on_image, 1)
        self.create_subscription(ObjectsInfo, '/yolov5_ros2/object_detect', self.on_objects, 1)
        self.create_subscription(LaserScan, '/scan_raw', self.on_scan, qos_profile_sensor_data)
        self.create_subscription(Odometry, '/odom', self.on_odom, 10)
        self.create_service(SetBool, '~/set_running', self.on_set_running)
        self.create_timer(0.1, self.watchdog)

    def now(self):
        return self.get_clock().now().nanoseconds * 1e-9
    def seen(self, name, ok):                        # 디바운싱: NEED번 연속이면 사건 발생
        self.hits[name] = self.hits.get(name, 0) + 1 if ok else 0
        if self.hits[name] == NEED.get(name, 1):
            self.event(name)
    def event(self, ev):
        if ev == "sign_right":
            self.memo = "right"
            return
        if ev in ("lane_lost", "obstacle") and self.state not in ("LOST", "HOLD", "DONE", "ABORT"):
            nxt, self.prev = ("LOST" if ev == "lane_lost" else "HOLD"), self.state
        elif (ev, self.state) in (("lane_found", "LOST"), ("clear", "HOLD")):
            nxt = self.prev
        else:
            nxt = TABLE.get((self.state, ev))
        if nxt == "TURN?":
            nxt, self.memo = ("TURN_R" if self.memo == "right" else "TURN_S"), None
        if nxt:
            self.go(nxt, ev)
    def go(self, nxt, why):
        self.get_logger().info('%s --%s--> %s' % (self.state, why, nxt))
        self.state, self.t_in = nxt, self.now()
        self.state_pub.publish(String(data=nxt))
        if nxt == "PARK":
            self.park0 = self.odom
    def on_objects(self, msg):
        cw = max([(o.box[1] + o.box[3]) / 2 for o in msg.objects if o.class_name == 'crosswalk'] + [0])
        names = {o.class_name for o in msg.objects}
        self.seen("crosswalk", cw > 70)
        self.seen("red", "red" in names)
        self.seen("green", "green" in names)
        self.seen("sign_right", "right" in names)            # go 표지는 기억할 필요 없음
        self.seen("park_sign", "park" in names and cw > 135)
        self.seen("at_spot", self.state == "APPROACH" and cw > 180)

    def on_scan(self, msg):
        near = [r for i, r in enumerate(msg.ranges)
                if abs(msg.angle_min + i * msg.angle_increment) < math.radians(20) and 0.05 < r < 12.0]
        d = min(near + [9.9])
        self.seen("obstacle", d < 0.25)
        if self.state == "HOLD" and d > 0.35:
            self.event("clear")
    def on_odom(self, msg):
        self.odom = (msg.pose.pose.position.x, msg.pose.pose.position.y)
    def on_set_running(self, req, res):
        self.running = req.data
        self.pub.publish(Twist())
        res.success = True
        return res
    def on_image(self, msg):
        self.t_img = self.now()
        img = np.array(self.bridge.imgmsg_to_cv2(msg, "rgb8"), dtype=np.uint8)
        _, _, lane_x = self.lane(self.lane.get_binary(img), img.copy())
        self.seen("lane_lost", lane_x < 0)
        if lane_x >= 0 and self.state == "LOST":
            self.event("lane_found")
        self.seen("junction", self.state == "LANE" and lane_x > 150)
        if self.state in ("TURN_R", "TURN_S") and 0 <= lane_x <= 150 and self.now() - self.t_in > 2.0:
            self.event("straight")
        if self.state == "SLOW" and self.now() - self.t_in > 0.4 / SPEED["SLOW"]:
            self.event("passed")
        self.drive(lane_x)
    def drive(self, lane_x):
        t = Twist()
        if self.running and self.state == "PARK":            # 폐루프 주차: 옆으로 0.38 m
            moved = math.dist(self.odom, self.park0)
            t.linear.y = -0.15 if moved < PARK_DIST else 0.0
            if moved >= PARK_DIST:
                self.event("done")
        elif self.running and SPEED[self.state] > 0 and lane_x >= 0:
            t.linear.x = SPEED[self.state]
            if self.state == "TURN_R":
                t.angular.z = -0.45                          # 원본 회전 각속도
            else:
                err = SETPOINT - lane_x
                t.angular.z = float(np.clip(KP * err + KD * (err - self.last_err), -W_MAX, W_MAX))
                self.last_err = err
        self.pub.publish(t)                                  # 정지도 명시적으로 발행
    def watchdog(self):
        if self.now() - self.t_img > 0.5:
            self.pub.publish(Twist())                        # 영상이 끊기면 정지
        if self.state in TIMEOUT and self.now() - self.t_in > TIMEOUT[self.state]:
            self.go("ABORT", "timeout")

def main():
    rclpy.init()
    node = CityFsm()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.pub.publish(Twist())
        node.destroy_node()
        rclpy.shutdown()

if __name__ == '__main__':
    main()

코드에서 짚을 점:

  • drive()는 모든 프레임에서 Twist를 발행합니다. 속도가 0이어야 하는 상태(STOP·LOST·HOLD·ABORT)에서도 0을 명시적으로 보내므로, 원본처럼 마지막 명령이 남지 않습니다.
  • seen()은 연속 횟수가 NEED와 같아지는 순간 한 번만 사건을 냅니다. 빨간불이 계속 보여도 red 사건은 한 번이고, 사라졌다가 다시 보여야 다음 사건이 납니다.
  • 표지 기억 memo는 junction에서 읽힌 뒤 None이 됩니다. go 표지는 기억할 필요가 없어서 무시합니다(기억이 없으면 직진).
  • 주차 거리는 /odom(EKF 출력, 옆걸음 포함 — M03)으로 잽니다. 속도를 원본 0.2에서 0.15로 낮췄지만 거리 기반이라 위치는 같습니다.
