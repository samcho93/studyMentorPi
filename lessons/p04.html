1단계: 영상 x → 방위#

핀홀 모델에서 영상 가로 좌표 u에 찍힌 점의 방위(로봇 기준, 왼쪽 +)는

text
b_cam = −atan((u − cx) / fx)        u: 어깨 중점의 x [px], fx·cx: camera_info의 K[0], K[2]

영상 오른쪽(u > cx)은 로봇의 오른쪽(음의 방위)입니다. 원본 body_control은 결과 영상을 좌우 반전(cv2.flip)해서 보여 주므로, 반전하기 전 좌표로 계산해야 부호가 맞습니다. 추종점으로 코·얼굴 대신 어깨 중점을 쓰는 이유는 고개를 돌려도 흔들리지 않기 때문입니다(A06의 손바닥 중심과 같은 발상).

2단계: 게이팅#

  1. 방위 게이트: |a_i − b_{cam}| < 8°인 빔만 후보로 둡니다. 8°는 카메라 방위 오차(σ 2°)의 약 4배, 그리고 0.8 m 거리에서 사람 몸통 반폭(≈ 0.2 m → 14°)의 절반쯤입니다.
  2. 거리 게이트: 후보 중 최근접 거리 r이 필터 예측 \hat r에서 0.3 m 넘게 벗어나면 측정을 버립니다. 사람과 같은 방향에 있는 더 가까운 물체(의자 다리, 기둥 모서리)를 걸러냅니다. 사람이 0.3 m/s로 걸어도 0.1 s 동안 3 cm만 움직이므로 0.3 m면 충분히 넉넉합니다.
  3. 측정값: 표면 거리 r에 사람 반지름(≈ 0.12 m)을 더해 중심 거리로 만들고, 로봇 자세(/odom)로 odom 좌표 z = (x + (r+R)\cos(θ+a),\ y + (r+R)\sin(θ+a))로 바꿉니다. 방위는 카메라 값이 아니라 라이다 빔 각도 a를 씁니다. 라이다 각도가 더 정확하기 때문입니다.

3단계: α-β 필터#

사람 위치 p와 속도 v를 odom 좌표에서 추정합니다. 주기 Δt = 0.1 s(라이다)마다

text
예측:  p⁻ = p + v·Δt
갱신:  r = z − p⁻                (잔차, 측정이 있을 때만)
       p = p⁻ + α·r
       v = v + (β/Δt)·r

측정이 없으면(카메라 미검출·게이트 거부) 예측만 합니다. 그래서 잠깐 가려져도 추정 위치가 사람의 진행 방향으로 계속 움직입니다. α는 "측정을 얼마나 믿나", β는 "속도를 얼마나 빨리 고치나"입니다. α-β 필터는 등속 모델 칼만 필터가 정상상태에 이르렀을 때의 이득을 상수로 고정한 것과 같습니다. 이 장에서는 α = 0.5, β = 0.1을 씁니다. 칼만 정상상태 관계(Kalata) β = 2(2−α) − 4\sqrt{1−α}에 α = 0.5를 넣으면 β ≈ 0.17이므로, 0.1은 그보다 작게 잡아 속도 추정을 보수적으로(잡음에 덜 민감하게) 만든 값입니다. 속도는 피드포워드로 바로 모터 명령이 되므로 떨리지 않는 편이 낫습니다.

4단계: 제어 법칙#

필터가 준 사람 위치로 표면 거리 d와 방위 b를 다시 계산하고

text
v  = clip( v_ff + Kp·(d − 0.8),  −0.1, 0.2 )     v_ff = (사람 속도)·(시선 방향 단위벡터)
ω  = clip( Kb·b,  −0.5, 0.5 )                     Kp = 0.8, Kb = 1.5

M06에서 본 것처럼 P 제어만으로는 v_t로 멀어지는 목표에 e = v_t / K_p의 오차가 남습니다(0.15 m/s, Kp 0.8이면 0.19 m). 필터가 추정한 사람 속도의 시선 성분을 피드포워드로 더하면 제어기는 "따라잡는 몫"만 담당하므로 오차가 거의 0이 됩니다. 속도 추정이 있어야만 가능한 개선이라는 점이 필터를 쓰는 두 번째 이유입니다.

신원: 누가 주인인가#

MediaPipe의 레거시 Pose(mp.solutions.pose)는 한 사람만 추적합니다. 화면에 두 사람이 있으면 더 크게 보이는 사람으로 넘어갈 수 있습니다. 그래서 시작 제스처 순간 주인의 몸통(어깨~엉덩이) HSV 색 히스토그램을 등록하고, 이후 프레임마다 cv2.compareHist 상관계수가 0.5보다 낮으면 "다른 사람"으로 보고 측정을 버립니다. 거리 게이트(연속성)와 색(외형)을 함께 쓰는 셈입니다. 옷 색이 같은 사람이 옆에 있으면 여전히 헷갈리므로, 확장 과제에서 다중 인물 검출과 재식별(re-ID)을 다룹니다.

실습 1: 최근접 vs 게이팅 vs 필터#

로봇은 가만히 있고 사람이 비스듬히 걸어가며, 사람보다 가까운 곳에 의자 다리가 있습니다. 네 가지 방법의 사람 위치 오차를 비교합니다(ROS 없이 numpy만).

python브라우저 실행
import math
import numpy as np

rng = np.random.default_rng(0)
ANG = np.radians(np.arange(-180, 180))                    # 1° 간격 라이다 빔 (0 = 전방)
CHAIR = (0.7, 0.15, 0.03)                                 # 의자 다리: 사람보다 가까운 방해물
R_P, GATE, DT = 0.12, math.radians(8), 0.1

def scan(objs):                                           # 원형 물체들에 대한 레이캐스트 + 잡음 1 cm
    r = np.full(len(ANG), np.inf)
    for cx, cy, rad in objs:
        b = -(cx * np.cos(ANG) + cy * np.sin(ANG))
        disc = b * b - (cx * cx + cy * cy - rad * rad)
        t = -b - np.sqrt(np.where(disc >= 0, disc, 0))
        r = np.where((disc >= 0) & (t > 0), np.minimum(r, t), r)
    return r + rng.normal(0, 0.01, len(r))

def to_xy(r, a):                                          # 표면 거리 → 사람 중심 좌표
    return np.array([(r + R_P) * math.cos(a), (r + R_P) * math.sin(a)])

err = {"최근접(M06 방식)": [], "방위 게이트": [], "방위+거리 게이트": [], "+ α-β 필터": []}
p, v, last = None, np.zeros(2), None
for k in range(100):                                      # 10 s, 10 Hz
    truth = np.array([1.0 + 0.06 * k * DT, -0.4 + 0.09 * k * DT])   # 사람이 비스듬히 걸음
    r = scan([CHAIR, (truth[0], truth[1], R_P)])
    i = int(np.argmin(r))
    err["최근접(M06 방식)"].append(np.linalg.norm(to_xy(r[i], ANG[i]) - truth))
    b_cam = math.atan2(truth[1], truth[0]) + rng.normal(0, math.radians(2))
    if rng.random() < 0.1:                                # 카메라 검출 실패 10%
        b_cam = None
    if p is not None:
        p = p + v * DT                                    # α-β 예측
    if b_cam is not None:
        g = np.where(np.abs(ANG - b_cam) < GATE)[0]
        j = g[np.argmin(r[g])]
        z = to_xy(r[j], ANG[j])
        err["방위 게이트"].append(np.linalg.norm(z - truth))
        if last is None or np.linalg.norm(z - last) < 0.3:   # 이전 위치에서 0.3 m 넘게 튀면 거부
            last = z
            if p is None:
                p = z.copy()
            res = z - p
            p, v = p + 0.5 * res, v + 0.1 / DT * res       # α = 0.5, β = 0.1
    if last is not None:
        err["방위+거리 게이트"].append(np.linalg.norm(last - truth))
    if p is not None:
        err["+ α-β 필터"].append(np.linalg.norm(p - truth))

for name, e in err.items():
    e = np.array(e)
    print("%-16s RMS %.3f m  최대 %.3f m  (표본 %d)" % (name, np.sqrt(np.mean(e ** 2)), e.max(), len(e)))
print("추정 속도 (%.3f, %.3f) m/s  ← 실제 (0.060, 0.090)" % tuple(v))

실습 2: 게이팅 융합 + α-β 필터 + 피드포워드 추종#

sim.add_walker()로 사람이 ㄱ자 경로를 0.15 m/s로 걷습니다. 로봇은 10 Hz 라이다 콜백마다 카메라 방위로 게이트를 걸고, odom 좌표에서 α-β 필터를 돌려 0.8 m를 유지합니다.

python브라우저 실행
import math
import random
import time
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import Twist
from sensor_msgs.msg import LaserScan
from nav_msgs.msg import Odometry
from tf_transformations import euler_from_quaternion
import mentorpi_sim as sim                                          # 시뮬 전용
sim.setup(chassis="mecanum", world="empty", duration=30.0, start=(0.0, 0.0, 0.0))  # 시뮬 전용
sim.add_walker([(0.9, 0.0), (2.2, 0.0), (2.2, 1.5), (0.4, 1.5)], speed=0.15, loop=False)  # 시뮬 전용

FOV, GATE, R_P, D_REF = math.radians(30), math.radians(8), 0.12, 0.8
ALPHA, BETA, FF = 0.5, 0.1, 1.0                                     # α-β 이득, 피드포워드(0이면 끔)
random.seed(1)

def camera_bearing():                                               # 시뮬 전용: MediaPipe 대용
    x, y, th = sim.pose()
    px, py, _ = sim.movers()[0]
    b = math.atan2(py - y, px - x) - th
    b = math.atan2(math.sin(b), math.cos(b))
    if abs(b) > FOV or random.random() < 0.1:                       # 화각 밖 / 10% 검출 실패
        return None
    return b + random.gauss(0.0, math.radians(2.0))                # 영상 x → 방위 오차 σ 2°

class Follower(Node):
    def __init__(self):
        super().__init__("follow_me")
        self.pub = self.create_publisher(Twist, "/cmd_vel", 1)
        self.create_subscription(LaserScan, "/scan", self.on_scan, 1)
        self.create_subscription(Odometry, "/odom", self.on_odom, 10)
        self.odom, self.p, self.v, self.t_seen = (0.0, 0.0, 0.0), None, [0.0, 0.0], 0.0
        self.t0, self.k, self.err = time.time(), 0, []

    def on_odom(self, m):
        q = m.pose.pose.orientation
        self.odom = (m.pose.pose.position.x, m.pose.pose.position.y,
                     euler_from_quaternion([q.x, q.y, q.z, q.w])[2])

    def on_scan(self, msg):                                         # 10 Hz: 융합 + 제어
        dt, now = 0.1, time.time()
        x, y, th = self.odom
        if self.p:                                                  # 예측
            self.p = [self.p[0] + self.v[0] * dt, self.p[1] + self.v[1] * dt]
        b_cam = camera_bearing()
        if b_cam is not None:                                       # 카메라 방위로 라이다 게이팅
            best = None
            for i, r in enumerate(msg.ranges):
                a = msg.angle_min + i * msg.angle_increment
                if abs(a - b_cam) < GATE and math.isfinite(r) and (best is None or r < best[0]):
                    best = (r, a)
            if best:
                r, a = best
                z = (x + (r + R_P) * math.cos(th + a), y + (r + R_P) * math.sin(th + a))
                if self.p is None:
                    self.p = list(z)
                res = (z[0] - self.p[0], z[1] - self.p[1])
                self.p = [self.p[0] + ALPHA * res[0], self.p[1] + ALPHA * res[1]]
                self.v = [self.v[0] + BETA / dt * res[0], self.v[1] + BETA / dt * res[1]]
                self.t_seen = now
        cmd = Twist()
        if self.p and now - self.t_seen < 1.5:
            dx, dy = self.p[0] - x, self.p[1] - y
            d = math.hypot(dx, dy) - R_P                             # 표면까지 거리
            b = math.atan2(dy, dx) - th
            b = math.atan2(math.sin(b), math.cos(b))
            ff = (self.v[0] * dx + self.v[1] * dy) / math.hypot(dx, dy)   # 목표 속도의 시선 성분
            cmd.linear.x = max(-0.1, min(0.2, FF * ff + 0.8 * (d - D_REF)))
            cmd.angular.z = max(-0.5, min(0.5, 1.5 * b))
            gx, gy, _ = sim.movers()[0]                              # 시뮬 전용: 실제 거리
            rx, ry, _ = sim.pose()                                   # 시뮬 전용
            true_d = math.hypot(gx - rx, gy - ry) - R_P
            if now - self.t0 > 5:
                self.err.append(true_d - D_REF)
            if self.k % 30 == 0:
                print("t=%4.1f 실제 %.2f m 추정 %.2f m 방위 %+5.1f° v=%+.2f ω=%+.2f"
                      % (now - self.t0, true_d, d, math.degrees(b), cmd.linear.x, cmd.angular.z))
        self.k += 1
        self.pub.publish(cmd)

rclpy.init()
node = Follower()
try:
    rclpy.spin(node)
except KeyboardInterrupt:
    pass
finally:
    node.pub.publish(Twist())
    e = node.err
    print("5 s 이후 거리 오차: 평균 %+.3f m, RMS %.3f m" % (sum(e) / len(e), math.sqrt(sum(v * v for v in e) / len(e))))
    node.destroy_node()
    rclpy.shutdown()

sim.add_walker([(0.9, 0.0), (1.9, 0.0), (1.9, -1.4), (0.6, -1.4)], speed=0.2, loop=False)  # 시뮬 전용
sim.add_box(1.45, -0.55, 0.3, 0.3)                                  # 시뮬 전용: 기둥(사람을 가림)
sim.add_cylinder(0.7, -0.55, 0.07)                                  # 시뮬 전용: 바닥의 화분(장애물)

FOV, GATE, R_P, D_REF = math.radians(30), math.radians(8), 0.12, 0.8
GESTURES = [(1.0, "right_arm_up"), (27.0, "both_arms_up")]          # 시뮬 전용: 제스처 대본
random.seed(2)

def ang(a):
    return math.atan2(math.sin(a), math.cos(a))

def camera(scan):                                                   # 시뮬 전용: MediaPipe 대용
    x, y, th = sim.pose()
    px, py, _ = sim.movers()[0]
    b, dist = ang(math.atan2(py - y, px - x) - th), math.hypot(px - x, py - y)
    i = int(round((b - scan.angle_min) / scan.angle_increment)) % len(scan.ranges)
    if abs(b) > FOV or scan.ranges[i] < dist - R_P - 0.15 or random.random() < 0.1:
        return None                                                 # 화각 밖 / 가려짐 / 검출 실패
    return b + random.gauss(0.0, math.radians(2.0))

class FollowFSM(Node):
    def __init__(self):
        super().__init__("follow_fsm")
        self.pub = self.create_publisher(Twist, "/cmd_vel", 1)
        self.create_subscription(LaserScan, "/scan", self.on_scan, 1)
        self.state, self.t0, self.t_seen, self.b_last = "IDLE", time.time(), -9.0, 0.0
        self.d, self.n_block, self.t_block = None, 0, 0.0

    def go(self, s, why):
        print("%5.1fs %-6s → %-6s (%s)" % (time.time() - self.t0, self.state, s, why))
        self.state = s

    def on_scan(self, msg):
        t = time.time() - self.t0
        if GESTURES and t >= GESTURES[0][0]:                        # 오른팔 들기=시작, 양팔 들기=정지
            g = GESTURES.pop(0)[1]
            self.go("FOLLOW" if g == "right_arm_up" else "IDLE", "제스처 " + g)
        beams = [(msg.angle_min + i * msg.angle_increment, r) for i, r in enumerate(msg.ranges)]
        rng = lambda a0, a1: min([r for a, r in beams if a0 <= a <= a1] + [9.9])
        b = camera(msg)
        if b is not None:
            r = rng(b - GATE, b + GATE)                             # 게이트 안 최근접 = 사람
            if t - self.t_seen > 1.5 or abs(r - self.d) < 0.3:     # 추적 중엔 거리도 게이팅(가림막 거부)
                self.d = r if t - self.t_seen > 1.5 else 0.5 * self.d + 0.5 * r   # 재발견이면 새로 시작
                self.b_last, self.t_seen = b, t
        lost = t - self.t_seen
        if self.state == "FOLLOW" and lost > 1.5:
            self.go("SEARCH", "1.5 s 동안 안 보임")
        elif self.state == "SEARCH" and lost < 0.1:
            self.go("FOLLOW", "재발견")
        elif self.state == "SEARCH" and lost > 10.0:
            self.go("IDLE", "탐색 실패")
        cmd = Twist()
        if self.state == "FOLLOW" and lost < 1.5:
            obs = min([(r, a) for a, r in beams if abs(a) < math.radians(35)
                       and abs(a - self.b_last) > GATE] + [(9.9, 0.0)])  # 사람 게이트를 뺀 전방
            cmd.angular.z = max(-0.5, min(0.5, 1.5 * self.b_last))
            cmd.linear.x = max(-0.1, min(0.2, 0.8 * (self.d - D_REF)))
            if obs[0] < 0.35 and cmd.linear.x > 0:                  # 사람 아닌 장애물이 가까움
                cmd.linear.x = 0.0                                  # 전진 멈추고 옆으로 비켜 감(메카넘)
                cmd.linear.y = -math.copysign(0.1, obs[1])
                if self.n_block == 0 or t - self.t_block > 0.5:
                    print("%5.1fs 장애물 %.2f m (%+.0f°) → 옆으로 비킴" % (t, obs[0], math.degrees(obs[1])))
                self.n_block, self.t_block = self.n_block + 1, t
        elif self.state == "SEARCH" and lost > 3.0:                 # 1.5 s 더 기다린 뒤 마지막 방향으로 회전
            cmd.angular.z = math.copysign(0.3, self.b_last)
        self.pub.publish(cmd)

실물 추종 안전 수칙
  • 추종 대상 외의 사람은 로봇 주변 1 m 밖에 있습니다. 로봇 뒤쪽은 라이다 일부만 보므로 후진은 0.1 m/s로 제한합니다.

#!/usr/bin/env python3
import math
import cv2
import numpy as np
import mediapipe as mp
import rclpy
from rclpy.node import Node
from rclpy.qos import qos_profile_sensor_data
from cv_bridge import CvBridge
from sensor_msgs.msg import Image, LaserScan
from geometry_msgs.msg import Twist
from nav_msgs.msg import Odometry
from std_msgs.msg import String
from tf_transformations import euler_from_quaternion

FX, CX, LIDAR_YAW = 554.0, 320.0, 0.0          # camera_info K[0], K[2] / 라이다 각도 오프셋 [rad]
GATE, R_GATE, R_P, D_REF, D_MIN = math.radians(8), 0.3, 0.12, 0.8, 0.4
ALPHA, BETA, KP, KB = 0.5, 0.1, 0.8, 1.5
LM = mp.solutions.pose.PoseLandmark

class FollowMe(Node):
    def __init__(self):
        super().__init__('follow_me')
        self.pose = mp.solutions.pose.Pose(min_detection_confidence=0.7, min_tracking_confidence=0.7)
        self.bridge = CvBridge()
        self.state, self.b_cam, self.t_cam, self.t_seen, self.t_in = "IDLE", None, 0.0, -9.0, 0.0
        self.p, self.v, self.odom, self.owner, self.cnt = None, np.zeros(2), (0.0, 0.0, 0.0), None, [0, 0]
        self.pub = self.create_publisher(Twist, '/controller/cmd_vel', 1)
        self.state_pub = self.create_publisher(String, '~/state', 10)
        self.create_subscription(Image, '/ascamera/camera_publisher/rgb0/image', self.on_image, 1)
        self.create_subscription(LaserScan, '/scan_raw', self.on_scan, qos_profile_sensor_data)
        self.create_subscription(Odometry, '/odom', self.on_odom, 10)

    def now(self):
        return self.get_clock().now().nanoseconds * 1e-9

    def go(self, s, why):
        self.get_logger().info('%s --%s--> %s' % (self.state, why, s))
        self.state, self.t_in = s, self.now()
        self.state_pub.publish(String(data=s))

    def on_odom(self, m):
        q = m.pose.pose.orientation
        self.odom = (m.pose.pose.position.x, m.pose.pose.position.y,
                     euler_from_quaternion([q.x, q.y, q.z, q.w])[2])

    def on_image(self, msg):                                    # MediaPipe: 방위·제스처·신원
        rgb = self.bridge.imgmsg_to_cv2(msg, "rgb8")
        h, w = rgb.shape[:2]
        res = self.pose.process(rgb)
        if not res.pose_landmarks:
            return
        lm = res.pose_landmarks.landmark
        xs = [lm[i].x * w for i in (LM.LEFT_SHOULDER, LM.RIGHT_SHOULDER, LM.LEFT_HIP, LM.RIGHT_HIP)]
        ys = [lm[i].y * h for i in (LM.LEFT_SHOULDER, LM.RIGHT_SHOULDER, LM.LEFT_HIP, LM.RIGHT_HIP)]
        x0, x1 = int(max(0, min(xs))), int(min(w, max(xs)))
        y0, y1 = int(max(0, min(ys))), int(min(h, max(ys)))
        if x1 - x0 < 10 or y1 - y0 < 10:
            return
        hsv = cv2.cvtColor(rgb[y0:y1, x0:x1], cv2.COLOR_RGB2HSV)
        hist = cv2.normalize(cv2.calcHist([hsv], [0, 1], None, [16, 8], [0, 180, 0, 256]), None)
        r_up = lm[LM.RIGHT_WRIST].y < lm[LM.NOSE].y             # 손목이 코보다 위
        l_up = lm[LM.LEFT_WRIST].y < lm[LM.NOSE].y
        self.cnt = [self.cnt[0] + 1 if r_up and not l_up else 0, self.cnt[1] + 1 if r_up and l_up else 0]
        if self.state == "IDLE" and self.cnt[0] >= 15:          # 약 1 s (15 fps 가정)
            self.owner, self.cnt = hist, [0, 0]
            self.go("FOLLOW", "오른팔 들기 → 주인 등록")
        elif self.state != "IDLE" and self.cnt[1] >= 10:
            self.go("IDLE", "양팔 들기")
        if self.owner is None or cv2.compareHist(self.owner, hist, cv2.HISTCMP_CORREL) < 0.5:
            return                                              # 주인이 아니면 측정 없음
        u = (lm[LM.LEFT_SHOULDER].x + lm[LM.RIGHT_SHOULDER].x) / 2 * w
        self.b_cam, self.t_cam = -math.atan((u - CX) / FX), self.now()

    def on_scan(self, msg):                                     # 10 Hz: 융합 + 상태 기계 + 제어
        dt, now = 0.1, self.now()
        x, y, th = self.odom
        a = msg.angle_min + LIDAR_YAW + np.arange(len(msg.ranges)) * msg.angle_increment
        a = np.arctan2(np.sin(a), np.cos(a))
        r = np.array(msg.ranges)
        r[~np.isfinite(r) | (r < 0.05)] = 99.0
        if self.p is not None:
            self.p = self.p + self.v * dt                       # α-β 예측
        if self.b_cam is not None and now - self.t_cam < 0.2:
            idx = np.where(np.abs(a - self.b_cam) < GATE)[0]
            if len(idx):
                j = idx[np.argmin(r[idx])]
                z = np.array([x + (r[j] + R_P) * math.cos(th + a[j]), y + (r[j] + R_P) * math.sin(th + a[j])])
                fresh = now - self.t_seen > 1.5
                r_hat = None if self.p is None else math.hypot(*(self.p - (x, y))) - R_P
                if fresh or r_hat is None:                      # 상실 후 첫 측정: 트랙 새로 시작
                    self.p, self.v, self.t_seen = z, np.zeros(2), now
                elif abs(r[j] - r_hat) < R_GATE:                # 거리 게이트 통과: α-β 갱신
                    res = z - self.p
                    self.p, self.v, self.t_seen = self.p + ALPHA * res, self.v + BETA / dt * res, now
        lost = now - self.t_seen
        if self.state == "FOLLOW" and lost > 1.5:
            self.go("SEARCH", "1.5 s 미검출")
        elif self.state == "SEARCH" and lost < 0.2:
            self.go("FOLLOW", "재발견")
        elif self.state == "SEARCH" and now - self.t_in > 10.0:
            self.go("IDLE", "탐색 실패")                         # 부저 알림은 확장 과제
        t = Twist()
        if self.state == "FOLLOW" and self.p is not None:
            dx, dy = self.p - (x, y)
            d, b = math.hypot(dx, dy) - R_P, math.atan2(dy, dx) - th
            b = math.atan2(math.sin(b), math.cos(b))
            v_ff = float(self.v @ (dx, dy)) / max(math.hypot(dx, dy), 1e-3)
            t.linear.x = float(np.clip(v_ff + KP * (d - D_REF), -0.1, 0.2))
            t.angular.z = float(np.clip(KB * b, -0.5, 0.5))
            side = (np.abs(a) < math.radians(35)) & (np.abs(a - b) > GATE)
            if side.any() and r[side].min() < 0.35 and t.linear.x > 0:   # AVOID: 전진 멈춤 + 옆걸음
                t.linear.x = 0.0
                t.linear.y = -math.copysign(0.1, a[side][np.argmin(r[side])])
            if d < D_MIN:
                t.linear.x = min(t.linear.x, 0.0)               # 너무 가까우면 전진 금지
        elif self.state == "SEARCH" and lost > 3.0 and self.b_cam is not None:
            t.angular.z = math.copysign(0.3, self.b_cam)
        self.pub.publish(t)

def main():
    rclpy.init()
    node = FollowMe()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.pub.publish(Twist())
        node.destroy_node()
        rclpy.shutdown()

if __name__ == '__main__':
    main()

코드에서 짚을 점:

  • 카메라 콜백은 방위·제스처·신원만 만들고, 제어는 라이다 콜백(10 Hz) 한 곳에서 합니다. 카메라 프레임률이 흔들려도 제어 주기는 일정하고, 0.2 s보다 오래된 방위는 쓰지 않습니다.
  • 1.5 s 넘게 못 본 뒤 들어온 측정(fresh)은 거리 게이트 없이 받아 트랙을 새로 시작합니다. 그러지 않으면 사람이 멀리 이동한 뒤에는 영원히 게이트에 걸려 다시 못 찾습니다(실습 3에서 겪는 문제).
  • AVOID는 별도 상태 변수 없이 FOLLOW 안에서 명령만 바꿉니다. 로그로 구분하고 싶으면 go("AVOID", …)를 추가하세요.
  • MediaPipe Pose는 Raspberry Pi 5 CPU에서 수~십수 fps입니다. model_complexity=0을 주면 빨라지고, 영상 크기를 줄이면 fx·cx도 같은 비율로 줄여야 합니다.

  • 칼만 필터로 교체: α-β 대신 등속 모델 칼만 필터(상태 [x, y, vx, vy], 측정 잡음은 라이다 σ와 방위 σ에서 유도)를 쓰고, 공분산으로 게이트 크기를 자동으로 정하세요(마할라노비스 거리 게이팅).
  • 다리 검출: 라이다 점을 군집화해 "두 개의 작은 원호 = 다리"를 찾으면 카메라가 못 보는 뒤쪽·화각 밖에서도 사람 후보를 유지할 수 있습니다.
  • 깊이 카메라 추가: 어깨 중점의 깊이 값(ascamera depth)을 세 번째 측정으로 넣어, 라이다 높이(약 20 cm)에 걸리지 않는 사람 상체까지 쓰세요.
  • Nav2 연동: 주인이 멀어지면 사람 위치를 목표로 NavigateToPose를 보내 장애물 사이를 경로 계획으로 따라가게 하세요(M11~M13). DWA의 사람 비용(social cost)도 조사해 보세요.
  • 애커만 대응: 제자리 회전이 안 되므로 SEARCH를 전진+조향 원 그리기로 바꾸고, 최소 회전 반경을 고려해 추종 거리를 늘리세요.
