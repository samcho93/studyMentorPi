학습 목표#

  • 라즈베리파이 5의 주요 사양(CPU·메모리·RP1·전원)을 읽고, 로봇 두뇌로서의 장단점을 설명합니다.

라즈베리파이 5 개요#

라즈베리파이(Raspberry Pi)는 영국 라즈베리파이 재단이 교육용으로 만든 신용카드 크기의 컴퓨터입니다. 키보드·마우스·모니터를 연결하면 일반 PC처럼 쓸 수 있고, 40핀 GPIO로 전자 부품을 직접 제어할 수 있어 로봇·IoT의 표준 플랫폼이 되었습니다.

라즈베리파이 5는 이전 세대(4B)보다 CPU 성능이 2~3배 높고, 처음으로 자체 설계 I/O 칩 RP1을 넣어 주변장치 성능이 크게 좋아졌습니다.

포트별 용도#

GPIO 40핀#

  • GPIO0~GPIO27의 디지털 입출력과 5 V·3.3 V·GND 전원 핀
  • 일부 핀은 I2C, SPI, UART, PWM 같은 통신·신호 기능을 겸합니다(B08).
  • 신호 전압은 3.3 V입니다. 5 V를 직접 넣으면 칩이 손상됩니다. 5 V 장치는 레벨 변환기를 거칩니다.
  • 터미널에서 pinout 명령으로 핀 배치를 볼 수 있습니다.

PCIe 2.0#

라즈베리파이 5에 새로 생긴 1레인 PCIe 커넥터입니다. 전용 HAT(어댑터)를 달아 NVMe SSD, 고속 네트워크 카드, AI 가속기 등을 연결합니다. SD 카드보다 훨씬 빠른 저장장치가 필요할 때 씁니다.

MIPI CSI/DSI#

카메라(CSI, Camera Serial Interface)나 디스플레이(DSI, Display Serial Interface)를 연결하는 고속 직렬 인터페이스입니다. 두 커넥터 모두 4레인, 레인당 1.5 Gbps(합계 최대 6 Gbps)이며, 카메라 2대 / 디스플레이 2대 / 카메라 1 + 디스플레이 1 조합이 가능합니다. MentorPi는 USB 카메라를 쓰므로 비어 있지만, CSI 카메라로 확장할 수 있습니다.

디버그 UART#

보드 가장자리의 3핀 전용 UART 커넥터로, 부팅 초기 메시지와 리눅스 콘솔에 접근할 수 있습니다. 부팅이 안 될 때 원인을 찾는 데 유용합니다. 송신(TX)은 상대의 수신(RX)에 엇갈려 연결합니다.

RTC(실시간 시계)#

라즈베리파이 5에는 시계 칩이 내장되어 있고, 전용 커넥터에 충전식 코인 배터리를 달면 전원이 꺼져도 시간을 유지합니다(대기 전류 µA 수준으로 수개월). 인터넷이 없는 AP 모드 로봇에서 로그 시간을 정확히 남기려면 유용합니다.

PoE#

이더넷 포트는 IEEE 802.3at(PoE+) 규격을 지원해, PoE HAT을 달면 랜선 하나로 데이터와 전원을 함께 받습니다. 고정 설치 카메라·게이트웨이에 쓰이며, 배터리로 움직이는 MentorPi에서는 쓰지 않습니다.

사용 수칙#

수칙이유
전원은 5.1 V / 5 A. 부족하면 부팅 시 "USB 전류 600 mA로 제한" 경고5 A 전원이 감지되어야 USB 주변장치 전류 한도가 1.6 A로 올라감 → 깊이 카메라·라이다 동시 구동
모니터는 전원 먼저, HDMI 나중순서가 바뀌면 화면이 켜지지 않을 수 있음
원격 접속 중 모니터를 꽂으면 연결이 끊길 수 있음해상도가 모니터 기준으로 바뀜 → 재부팅으로 해결
방열판·팬 장착고부하 시 온도 상승 → 성능 저하(스로틀링)
만지기 전 정전기 방전부품 손상 방지
GPIO는 3.3 V5 V 입력 금지
동작 온도 0~50 °C범위 밖에서는 수명·성능 저하

방열판은 보호 필름을 떼고 SoC 위에 붙이고, 냉각 팬은 4핀 JST 팬 커넥터에 연결합니다. 보호 케이스를 조립할 때 SD 카드는 글자 면이 바닥판 쪽을 향하게 끼웁니다.

OS 설치#

운영체제 선택#

라즈베리파이용 OS로는 공식 Raspberry Pi OS(과거 명칭 Raspbian, Debian 기반), Ubuntu(MATE 등), Kali Linux, 미디어센터용 OSMC, 멀티 부팅 관리자 NOOBS(구형) 등이 있습니다. MentorPi는 Hiwonder가 Raspberry Pi OS + Docker + ROS 2 컨테이너를 미리 넣은 이미지를 제공합니다.

방법 1: Raspberry Pi Imager(새 OS)#

  1. https://www.raspberrypi.com/software/ 에서 Imager 설치
  2. CHOOSE DEVICE → Raspberry Pi 5
  3. CHOOSE OS → Raspberry Pi OS (64-bit)
  4. SD 카드(8 GB 이상, 32 GB 권장)를 카드 리더로 연결 → CHOOSE STORAGE
  5. NEXT → EDIT SETTINGS: 사용자 이름·비밀번호, Wi-Fi, 호스트 이름, 시간대, 키보드 / SERVICES → Enable SSH
  6. Yes → 기록 완료 후 "포맷하시겠습니까?" 창이 뜨면 취소(포맷하면 방금 쓴 OS가 지워짐)

방법 2: 제공 이미지 굽기(MentorPi 복구)#

원본 부록 "Burn Image"의 절차입니다. SD 카드가 망가졌거나 공장 상태로 되돌릴 때 씁니다.

  1. 이미지 압축 파일을 영문 경로에 풀어 .img 파일 얻기(한글 경로 금지)
  2. SD Card Formatter로 카드 초기화(빈 카드면 생략)
  3. Win32DiskImager에서 이미지 선택 → 장치(드라이브 문자) 확인 → Write → "Write Successful"
  4. Windows가 "포맷해야 합니다"라고 물으면 취소
이미지를 굽기 전에

SD 카드의 모든 데이터가 지워집니다. 특히 직접 만든 지도·코드·학습 모델이 있다면 먼저 백업하세요. 드라이브 문자를 잘못 고르면 PC의 USB 메모리가 지워질 수 있습니다.

기본 운용#

부팅과 종료#

  • SD 카드는 금속 단자가 보드 쪽을 향하게 끼웁니다.
  • 전원을 넣으면 LED가 빨강 → 초록으로 바뀌고, 초록이 불규칙하게 깜빡이다가(부팅·데스크톱 로딩) 안정됩니다.
  • 전원 선을 바로 뽑지 않습니다. SD 카드에는 OS와 시스템 파일이 있어 쓰기 도중 전원이 끊기면 파일 시스템이 손상됩니다.
bash
sudo shutdown -h now      # 즉시 종료(halt)
sudo shutdown -h 30       # 30분 뒤 종료
sudo shutdown -h 12:30    # 12시 30분에 종료
sudo reboot               # 재시작 (= sudo shutdown -r now)

ACT LED 깜빡임 코드#

라즈베리파이 5는 LED가 하나(ACT)만 남았고, 부팅 문제를 깜빡임 횟수로 알려 줍니다(1초 간격 반복, 원본 표 기준).

깜빡임의미확인할 것
1회SD 카드 읽기 오류카드 삽입 상태, 카드 손상
2회SD 카드 쓰기 오류쓰기 보호, 가득 참, 파일 시스템 오류
3회부트 파일 시스템 오류부트 파티션 손상, 부트 파일 누락
4회부팅 시간 초과부팅 과정 중 멈춤
5회루트 파일 시스템을 찾지 못함루트 파티션 손상 → 이미지 재설치

깜빡임 패턴은 펌웨어 버전에 따라 다를 수 있으니 공식 문서와 함께 확인합니다.

온도와 전원 상태#

bash
vcgencmd measure_temp                       # temp=60.9'C
cat /sys/class/thermal/thermal_zone0/temp   # 60050 → 60.05 °C (1/1000 단위)
vcgencmd get_throttled                      # throttled=0x0 이면 정상

get_throttled의 비트 0은 "지금 저전압", 비트 16은 "부팅 이후 저전압이 있었음"을 뜻합니다(0x50000처럼 나오면 과거에 저전압과 스로틀링이 있었던 것). 로봇이 주행 중 가끔 재부팅된다면 배터리 전압(B01)과 이 값을 함께 보세요. 데스크톱 상태 표시줄에 CPU Temp 플러그인을 추가하면 온도를 실시간으로 볼 수 있습니다.

화면 꺼짐 해제Raspberry Pi Configuration → Display → Screen Blanking, 또는 /etc/lightdm/lightdm.conf의 xserver-command=X -s 0 -dpms

원격 접속과 파일 전송#

  1. PC와 라즈베리파이를 같은 네트워크에 연결(MentorPi는 HW-… 핫스팟 또는 같은 공유기)
  2. IP 찾기: 순정 라즈베리파이는 PC의 명령 프롬프트에서 ping raspberrypi -4(호스트 이름으로 찾기), MentorPi는 AP 모드 192.168.149.1
  3. MobaXterm: Session → SSH → Remote host에 IP, Specify username pi → 비밀번호 입력(화면에 표시되지 않음)
  4. 파일 전송: MobaXterm 왼쪽 파일 창에 PC 파일을 끌어다 놓으면 라즈베리파이로, 반대로 끌면 PC로 복사
  5. VNC가 꺼져 있다면 SSH에서 sudo raspi-config → Interface Options → VNC → Yes 후 VNC Viewer로 접속
bash
# 명령행으로 파일 전송(PC → 로봇)
scp my_node.py pi@192.168.149.1:/home/pi/
# 로봇 → PC
scp pi@192.168.149.1:/home/pi/map.pgm .

시스템 설정 도구#

소스 목록과 업데이트#

패키지를 받는 서버(미러)는 /etc/apt/sources.list와 /etc/apt/sources.list.d/raspi.list에 적혀 있습니다. 원본은 가까운 미러로 바꾸는 예를 듭니다(bookworm 기준). 한 줄 형식은 deb <미러 주소> <배포판 코드명> <구성요소>입니다.

bash
sudo nano /etc/apt/sources.list     # 기존 줄은 # 으로 주석 처리 후 미러 줄 추가
# 예) deb https://<미러>/debian/ bookworm main contrib
sudo apt update                     # 패키지 목록 갱신
sudo apt full-upgrade               # 설치된 패키지 업그레이드
MentorPi에서 업그레이드는 신중하게

원본도 "개발자가 무작위로 업데이트하는 것은 권장하지 않는다"고 강조합니다. MentorPi 이미지는 커널·드라이버·Docker·컨테이너가 서로 맞춰진 상태라, full-upgrade 후 카메라·시리얼 장치 이름이 바뀌거나 컨테이너가 장치를 못 찾을 수 있습니다. 필요한 패키지만 apt install하고, 전체 업그레이드는 SD 카드 백업 후에 합니다.

raspi-config#

sudo raspi-config로 여는 텍스트 메뉴입니다. ↑↓로 이동, Enter 선택, Esc 뒤로.

메뉴내용
System Options부팅·자동 로그인, 네트워크, 소리
Display Options해상도, 화면 여백
Interface OptionsSSH, VNC, SPI, I2C, Serial Port, 1-Wire, 원격 GPIO 켜기/끄기
Performance Options오버클럭, 팬 제어 등
Localisation Options로캘, 시간대, 키보드, WLAN Country(무선 채널 법규)
Advanced Options파일 시스템 확장, 부트 설정
Update / About도구 업데이트, 정보

config.txt#

라즈베리파이에는 PC의 BIOS가 없고, 대신 부트 파티션의 **config.txt**를 GPU 펌웨어가 커널보다 먼저 읽어 하드웨어를 설정합니다. 한 줄에 한 설정(이름=값), #은 주석, 한 줄 최대 98자.

text
camera_auto_detect=1        # 인식한 CSI 카메라의 오버레이 자동 로드 (끄려면 0)
display_auto_detect=1       # 인식한 DSI 디스플레이의 오버레이 자동 로드
dtoverlay=vc4-kms-v3d       # 장치 트리 오버레이: KMS 그래픽 드라이버
dtparam=i2c_arm=on          # I2C 켜기 (raspi-config가 쓰는 줄)

원본은 경로를 /boot/config.txt로 적었지만, **Raspberry Pi OS bookworm부터는 /boot/firmware/config.txt**가 실제 파일입니다(옛 경로에는 안내문만 있음). 편집 전에 ls /boot/firmware/config.txt로 확인하세요.

네트워크 설정#

라즈베리파이 5(bookworm)는 NetworkManager가 네트워크를 관리하며, 연결 설정은 /etc/NetworkManager/system-connections/*.nmconnection 파일에 저장됩니다. 원본은 이 파일을 vim으로 만들어 세 가지 모드를 구성합니다.

모드원본 예설명
APSSID pi5, 비밀번호 12345678, 고정 IP 192.168.149.1라즈베리파이가 핫스팟
STASSID WWW, 비밀번호 hiwonder, 고정 IP 192.168.1.111공유기에 접속
유선고정 IP 192.168.1.112랜선 직결

파일을 고친 뒤 sudo systemctl restart NetworkManager → sudo reboot로 적용합니다. 명령으로 확인·연결할 때는 nmcli가 편합니다.

bash
nmcli device status                    # 장치별 연결 상태
nmcli connection show                  # 저장된 연결 목록
nmcli device wifi list                 # 주변 Wi-Fi
MentorPi의 네트워크는 도구로 바꾸세요

MentorPi의 AP/STA 전환은 앱과 hiwonder-toolbox가 관리합니다(B02). nmconnection 파일을 직접 고치면 로봇 핫스팟이 사라져 원격 접속이 끊길 수 있고, 그러면 모니터·키보드를 직접 연결해야 복구할 수 있습니다. 위 설정 실습은 순정 라즈베리파이나 백업한 SD 카드에서 하세요.

실습 (실물)#

MentorPi 호스트(라즈베리파이 OS) 터미널에서 읽기 위주로 보드 상태를 점검합니다.

안전 확인 (실물 실습 전 필수)
  • 네트워크 설정 파일, config.txt는 열람만 합니다. 수정은 담당자 확인 후 백업한 SD 카드에서.
  • 전원을 끌 때는 sudo shutdown -h now 후 확장보드 스위치를 내립니다.
  • 보드를 만지기 전 금속에 손을 대 정전기를 방전하고, 전원이 켜진 상태에서 GPIO 핀에 점퍼선을 꽂지 않습니다.
따라 하기
  1. cat /proc/device-tree/model; echo — 보드 모델 확인
  2. lscpu | head -15, free -h, df -h / — CPU 코어·메모리·SD 카드 용량
  3. vcgencmd measure_temp와 cat /sys/class/thermal/thermal_zone0/temp 비교
  4. vcgencmd get_throttled — 0x0이 아니면 비트를 해석해 기록
  5. 라이다·앱 게임을 1분 돌린 뒤 다시 온도 측정 → 부하에 따른 온도 변화 관찰
  6. lsusb — 깊이 카메라·라이다(USB 시리얼 변환기)·조이패드 수신기가 USB로 보이는지 확인
  7. ls -l /dev/ttyAMA* /dev/video* 2>/dev/null — 시리얼·카메라 장치 파일 확인
  8. sudo raspi-config → Interface Options 메뉴까지만 들어가 현재 SSH·VNC·I2C·Serial 설정을 확인하고 Esc로 변경 없이 나오기
  9. grep -v "^#" /boot/firmware/config.txt | grep -v "^$" — 활성화된 설정 줄만 보기
  10. PC에서 scp나 MobaXterm으로 파일 하나를 로봇에 보내고 다시 받아 오기

과제#

기본
  1. vcgencmd get_throttled 결과가 0x50005일 때 켜진 비트(0, 2, 16, 18)가 각각 무엇을 뜻하는지 공식 문서에서 찾아 정리합니다.
  2. MentorPi에서 USB 3.0 포트(파랑)에 꽂아야 유리한 장치와 USB 2.0에 꽂아도 되는 장치를 대역폭 기준으로 나눕니다.
심화
  1. 라즈베리파이 5의 PCIe 커넥터에 NVMe SSD를 달면 SD 카드 대비 무엇이 좋아지는지(부팅 시간, 지도·rosbag 저장, 수명) 조사해 정리합니다.
  2. 순정 라즈베리파이(또는 백업 SD 카드)에서 nmcli로 STA 연결을 하나 만들고, 생성된 .nmconnection 파일의 [wifi], [wifi-security], [ipv4] 섹션을 해석합니다.
